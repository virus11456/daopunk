# 探索與卡牌戰鬥切換

新版本採自由走動探索、遭遇後切換五術卡牌回合對決。現有即時戰鬥仍是舊原型，尚未改寫。本文件定義設計方向，數值待測。

流程：探索觸發遭遇 → 保存遭遇位置／參戰角色與當輪資源 → 暫停探索世界時間 → 展示敵方意圖 → 玩家抽牌與出牌 → 敵方行動 → 勝負結算 → 返回探索或輪迴。

原型起始值沿用五術設計：10 張起始牌、每回合 3 氣、抽 5 張；皆為待平衡值。玩家的五術、道具、法則與場地共同決定構築。敵方以可預告行動序列對戰，不要求普通敵人也執行完整玩家牌組。

星主／道主遵循同一回合框架，加入各自機制。普通交談、外交、購屋與作息不強制轉成卡牌戰鬥。多人同行、逃跑與中途加入規則需另做原型；不得假裝已完成。

探索時可移動；卡牌戰鬥不混入即時躲避。交戰期間 NPC 作息與新聞傳播不依真實對話等待時間繼續推進。戰鬥結束按明示的遊戲時間成本推進世界；任務狀態只能結算一次。

勝利後提供獎勵選擇並回到合法位置，死亡結束當輪。退出可保存同一場戰鬥狀態，載入不可重抽獎勵或重擲世界事件。需要驗證抽棄牌、能量、狀態順序、敵意預告、結算去重與輪迴清理。
