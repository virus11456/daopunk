# 星主：固定稱號與當世持有者

狀態：使用者確認的世界規則；資料與生成方式為實作提案，尚未接入遊戲。

最新內容：[40 星球貿易政治網絡](PLANET_NETWORKS.md)。首批內容：[20 個固定星主稱號與交接設計](PLANET_LORD_CATALOG.md)、[資料索引](planet-lord-registry.json)。

## 已確認規則

- 道主不隨輪迴換人；導師即歸墟道主，其身分對玩家在揭露前保密，不表示該席位無人或每輪隨機產生。
- 每顆星球有固定的星主稱號。稱號所屬星球與上位道主不因持有人姓名改變。
- 取得該稱號者就是該星球的星主；星主是可轉移的身分，不是固定角色姓名。
- 當世持有者姓名隨機生成，稱號保持固定。輪迴後可出現不同持有者；不是單純替同一個人改名。
- 取得稱號的具體途徑尚待設計。擊敗持有者不直接等於取得稱號，除非該事件明確完成授予或轉移。

## 顯示示例（名稱均為提案，非正式名單）

同一顆示例星球的固定稱號為「鎮淵星主」：第一世顯示「鎮淵星主・沈燼」，第二世可顯示「鎮淵星主・洛衡」。鎮淵星主是稱號，沈燼與洛衡是不同持有者。任務應辨識稱號與人物，不能只比較顯示文字。

## 生成與記錄提案

固定層：planet_id、title_id、title_name、dao_ruler_id。逐星球稱號名單需依正式星球設定補齊；目前環境模板不冒充正式名稱。

當世層：run_id、holder_id、generated_name、title_id、取得事件及持有狀態。名字由對應文化的姓名池生成；同名不等於同一人物。用種子生成後寫入存檔，同一輪讀檔、切換城市或再次見面不得重抽姓名。

一個稱號同一時間只有一位有效持有者；轉移時先撤銷舊持有關係，再授予新持有者，作同一筆交易保存。未完成轉移前，挑戰者不視為星主。若設計空缺狀態，稱號仍存在，是否允許空缺需在事件中明訂。

外觀、性格、派系與招式可在後續設計加入有限變體，但不隨姓名任意改變星球文化與大道／法則。本次新增提案允許玩家當輪取得一個星主稱號，取得途徑與有限權限見稱號名錄；輪迴後卸任，不永久統治。

## 輪迴與故事

保留歷代 title_id → holder_id 的任期記錄，主角可發現同一稱號換了主人。NPC 關係綁人物；統治權限綁稱號；住宅記憶綁地址。認識前任星主不等於已與新任建立關係。

跨輪迴保留的是遇見過的人物與歷史，不自動恢復前世官位。星主是否由前世事件影響抽選權重仍為待驗證提案。

## 待實作驗證

稱號跨世固定；同輪讀檔姓名一致；換人產生新 holder_id；同名人物不串關係；稱號轉移不可有雙持有者；前任失去相應權限；道主不參與星主隨機姓名生成。
