# 仙術：獲得後與生俱來，數世輪迴始終相伴

使用者最新確認：仙術一旦獲得便融入主角，之後每次開局都擁有；取消舊版攜帶欄位、重生選配與只能帶部分仙術的提案。這是設計規則，尚未接入現行原型。

## 永久保留與使用

- 已獲得的被動仙術每世開局自動生效；已獲得的主動仙術每世開局全部可用，不需再次學習、支付功德或抽到相應卡牌。
- 本輪只能修兩種五術的限制只約束學習與卡牌使用，不封鎖過去獲得的仙術。例如本轮修山＋卜，過去學會的醫術仙術「回春」仍可使用。
- 沒有仙術攜帶上限、主被動裝備槽或重生時的能力二選一；快捷列只影響操作顯示，未放在快捷列的能力仍可從完整能力頁使用。
- 同一仙術再次獲得不複製被動、不刷新主動次數；可轉為已明示的升階進度，具體轉換收益待定，不能默默消耗第二份獎勵。
- 自然死亡、普通死亡或抹殺結束當輪後，已獲得仙術紀錄都保留；主動使用次數在下一次合法遭遇／新輪依規則重置，讀檔或重新進入同一遭遇不重置。

## 仙術與卡牌分工

仙術是跨世累積的固有能力；卡牌是今世學習、收集和構築的工具。卡片的「能力牌」只持續本場，不能因名稱像被動而變成永久仙術。五術每術 45 卡的總數不計入仙術。

主動仙術可以有每場次數、氣消耗或冷卻。獲得後永遠會，不代表無限施放；本批十個基礎仙術例子沿用各自每場一次或首次觸發限制，不新增隱藏全域次數來替代已取消的攜帶槽。

被動仙術可同時生效，靠明示觸發條件、同名不疊加、效果量和狀態上限控制成長。例如定息每場首回合護體、照命每場首次命印攻擊追加傷害。不同仙術若條件同時成立都可觸發；數值需要以「所有已獲得被動同時開啟」的存檔測試，不能只測單技能。

不以未選某術為由取消已獲得能力。少數仙術若需要命印、陣位等情境，其條件仍需滿足；界面清楚標示，不能把尚未滿足觸發条件說成未攜帶。基礎例子中主動繫命與定盤可自行提供一次對應資源。

## 無法突破的世界邊界

主角 99 歲自然壽終不能靠仙術延長；一旦道主／觀察者判定抹殺，仙術不能阻擋或復活抵銷。仙術也不能免費重抽世界種子、撤銷已記錄的重大干涉或無限兌換功德。這些邊界必須在相關能力說明中呈現，不在使用時臨時改規則。

## 存檔與待驗證

永久檔記錄唯一仙術 ID、已獲得等級與獲得事件；當輪／遭遇檔另記冷卻、次數和已觸發標記。生成新輪時載入全部已獲得能力，生成同一輪的存檔續玩時不得重新發放首回合收益。

待測：經多輪後能力仍全數存在；改選兩術不丟失仙術；同名不複製；換快捷鍵不改能力；被動同時觸發正確；致命／99 歲／抹殺優先級正確。這些是驗收規格，尚未有遊戲實作通過測試。
