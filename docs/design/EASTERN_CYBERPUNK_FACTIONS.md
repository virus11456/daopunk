# 東方修仙 × 星際賽博龐克：生活與跨星勢力

使用者確認世界同時有星球賽博龐克及修仙成分。各宇宙可以有不同文明比例，但科技與修行都要落在生活、權力和資源上，不只在古代屋頂外加霓虹。

以下融合方式為新增提案：符籙可燒錄指令；義體線路與經脈共同影響修行；丹爐兼具煉丹與生化培育功能；宗門掌握功法與技術授權；企業控制供能、義體零件及資料接入。普通人生活在技術壟斷、地方互助與修行機會之間。不得因此自行更換既有宇宙大道／法則。

城市可辨識元素：廟宇終端、飛舟泊位、靈能管線、義體工坊、符籙伺服器、丹藥診所、企業／宗門關卡與修補住宅。保持 GBA 俯視清楚輪廓、有限色階與可走道路，不以大量發光遮住玩法。前批城市圖偏生活街坊，後續圖加強科技；製作區塊時依此規範統一。

## 跨星勢力

中立指不固定效忠某一星主，不等於沒有利益、倫理或敵人。各分部立場可不同，與道主、星主及其他勢力形成具體關係。
