# 五術卡牌：路徑解鎖、隨機獎勵與升級平衡

本文件為原型方案，尚未實作或通過數值平衡測試。正式分類見[五術 v2](../art-direction/five-arts-v2/README.md)。

## 解鎖增加選擇，不直接填满牌組

| 層級 | 如何獲得 | 輪迴保留 | 對隨機卡池的影響 |
|---|---|---|---|
| 永久仙術 | 功德學習主動／被動技能 | 是，重生選配 | 不混入牌堆，不稀釋抽牌 |
| 永久路徑境界 | 學會前置＋一次分支試煉；首次試煉不要求尚未解鎖的牌 | 是 | 解鎖該分支進階與終階候選卡 |
| 本輪專注分支 | 重生選一條；本輪中段可免費改一次 | 否 | 給獎勵一個定向席位，不提高牌的數值 |
| 本輪卡牌＋ | 休息點或有限導師服務 | 否 | 只升級持有牌一次，不解鎖下一階、也不改掉落權重 |

例：已解鎖山術修命三階，仍以基礎吐納開局；中期可獲得金剛不壞，後期有機會拿真空粉碎。把吐納升成＋不等於直接獲得金剛不壞。玩家選一條路徑後也能換分支或選其他牌。

## 三選一的三個席位

每個正常戰鬥獎勵先按本輪階段取得可用階層，再逐席抽取；三席卡片 ID 不重複。使用同一存檔的獎勵種子，讀檔、關閉介面或略過不重抽。排序不透露稀有度。

1. **專注席**：從主修的專注分支，抽一張已解鎖且當前階段允許的卡。確保每次都有構築方向。
2. **探索席**：從主修另外兩分支抽一張已解鎖牌，兩分支等權，避免只會湊固定套路。
3. **機緣席**：80% 主修任一分支、20% 已選副修；未選副修則全部主修。法則／共通牌日後以獨立事件提供，不佔本版 45 牌測試池。

每席先抽階層再在相應分支內均勻抽牌，不因某分支卡片較多就搶走別派機率。牌池不足時依序：同分支其他合法階層 → 主修其他合法分支 → 其他已解鎖主修合法牌；仍不足則顯示少於三張，不塞未解鎖牌、不生成重複選項。可略過，不能強迫牌組膨脹。

| 本輪主線階段 | 入門／進階／終階權重 | 配套 |
|---|---|---|
| 前期 | 100／0／0 | 基礎牌組必須能獨立完成前期；永久解鎖不使終階提前出現 |
| 中期 | 60／40／0 | 主線首個里程碑開啟；不按戰鬥回合數或重複刷怪計算 |
| 後期 | 45／40／15 | 第二個里程碑開啟；每輪無需走遍宇宙 |

永久解鎖不足時剔除不可用階層，剩餘權重重新正規化。階層是獲取門檻而非直接的強度排名；三階卡常有移除、費用、前置資源或因果代價。支線漫遊不會自動推進卡池階段。

## 防止想玩的路線一直沒出現

中期與後期各安排一次必達的公共導師服務，不依賴購屋、首都星或罕見 NPC。每次可在三項中選一：取得一張當期合法的專注分支牌／升級一張持有牌／移除一張可移除牌。每節點一次，不可重置庫存。不會贈送尚未解鎖的終階；無合法新牌時仍能選升級或移除。

指定選牌是有限保底，其餘獎勵保持隨機。不設全局隨機「永遠抽不到核心」；也不讓每次獎勵都能點名最強卡。主修與副修共用氣、手牌與狀態上限；副修先只開入門與進階，不堆疊額外職業被動。

## 跨流派與升級的取捨

每術三條路線互補，不是三套互不相通的牌。山術御器能為修命蓄勢期間提供防備；醫術針藥與丹毒爭用有限治療與藥引；命術知命供給改命成本；相術風水與器相共用三槽；卜術排序讓推演穩定但仍花氣。共用上限、唯一能力、每回合觸發上限一併約束。

永久仙術不用功德反覆施放；主動每場次數和被動觸發限制在資料中明示。沒有仙術能抵擋道主／觀察者已判定的抹殺。不能藉時間回溯回復氣、功德、治療額度、抹殺判定或已消耗服務。

## 原型驗收門檻（待測，並非已通過）

- 以固定種子跑大量獎勵，檢查三席去重、非法階層永不出現、權重重新正規化、池不足與讀檔結果穩定。
- 比較只解鎖一分支與全解鎖存檔：專注席的合法牌機率不被其他分支稀釋。
- 每術以相同敵人／起始生命／節點數測試；統計勝率、有效氣耗、空轉回合與卡片選取率，再調数值。
- 檢查醫術拖戰上限、卜術回收循环、相術重複陣位、命術取消首領动作、山術蓄勢溢出；所有限制跨複本生效。
- 導師保底在主線上可達；升級、移除、拿牌各有實際使用，不應永遠有唯一最優選。
