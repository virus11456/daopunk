# 五術 v3：兩術平等兼修，225 卡的隨機與成長

本文件取代 v2 主副修與三分支方案。正式規則為每術 45 卡、五術共 225 卡；每輪選兩術，兩者權利相同。[卡牌總覽](../art-direction/five-arts-v3/README.md) · [永久天生仙術](INNATE_IMMORTAL_ARTS.md)。數值與權重皆為原型提案，尚未實戰平衡。

## 三種不同的成長

| 系統 | 如何成長 | 跨世狀態 |
|---|---|---|
| 仙術 | 功德修行／特殊事件獲得主動、被動能力 | 全部永久持有，每世開局可用，不必選配 |
| 五術熟練度 | 每術直線 1–5 級，完成唯一實作委託或試煉 | 保留，每級解鎖九張候選卡，沒有分支 |
| 當輪卡牌 | 獎勵、商店、導師取得；每卡一次＋升級 | 牌組與＋升級輪迴重置 |

熟練度越高，該術可遇到的卡越多，但不把 45 張全部塞進起手牌組。升級一張牌不自動提升熟練度；稀有度與學習級別分開。高熟練度的新普通卡是另一種戰術工具，不要求全面勝過舊牌。

## 兩術選擇

本輪開始選兩種不同五術，兩者皆能取得普通、進階、稀有卡，沒有 25% 副修比例限制。學習級別各依永久紀錄判定，兩術不共享熟練度。沒有被選中的第三術卡不能透過借牌、複製、商店或事件入手並使用。

兩術在本輪固定，下輪重選；卡牌效果中的兩術連攜是本輪兩術，不把永久仙術當作出過另一術的卡。初始牌組 3 共通攻擊、3 共通防禦、兩術各 2 普通入門牌。

## 三選一獎勵

每次正常獎勵提供：**術 A 一席、術 B 一席、混搭一席**。A／B 只是顯示順序，可互換而不改機率與權限。混搭席先以 50%／50% 選術，再抽卡，不按兩術池大小分配。因此其中一術全解鎖不會壓縮另一術的基本出現機會。

每席先決定合法稀有度，再在該術對應候選卡抽取。玩家可標记最多兩個效果偏好，例如護體、抽牌；匹配任一偏好的候選卡權重 2，未匹配為 1，多個標籤不乘成 4。標籤不鎖技能、不收費、不建立新分支，獎勵開啟前已儲存選擇；獎勵內切換不重新抽樣。

| 本輪階段 | 普通／進階／稀有權重 |
|---|---|
| 前期 | 80／20／0 |
| 中期（主線首個里程碑後） | 65／30／5 |
| 後期（第二個里程碑後） | 50／35／15 |

先排除未解鎖與不合當期條件的牌，再把剩餘階層權重正規化。同次三選一 ID 不重複；若抽中的稀有度無未抽候選，重新在該術其餘合法稀有度抽，不能因此換到未修術。混搭選中術完全無候選时改用另一已修術；兩術都耗盡則顯示少於三張。原有持牌不排除，可以選擇複本；能力同名唯一與觸發上限仍適用。

## 卡池變大後的保底

中期與後期各一次必達公共導師服務，從「指定選一張當期合法且已解鎖的兩術卡／升級一張／移除一張」三者擇一。每節點一次，讀檔與重訪不刷新，服務不要求買房、接近道主或找到罕見城市。指定選牌給穩定構築途徑，其餘獎勵保持隨機；每次獎勵仍可略過。

不能保證某張牌在隨機獎勵內出現；保證的是兩術各有曝光、偏好能影響抽取，以及有限的指定選牌機會。數值調整前不宣稱 225 卡已達平衡。

## 十種兩術搭配示例

| 搭配 | 可行方向 | 主要取捨 |
|---|---|---|
| 山＋醫 | 護體拖過危險回合，藥引提供有限恢復或中毒 | 進攻速度較慢，治療額度不能突破 |
| 山＋命 | 山術防備命印準備期，改命作集中爆發 | 兩種資源都要支付氣去準備 |
| 山＋相 | 護體與陣位共同蓄力，再選蓄勢或陣法收尾 | 擠占手牌，不宜塞入太多純準備牌 |
| 山＋卜 | 排序確保護體與蓄勢消耗牌在合適時機到手 | 查看與抽牌本身不造成足夠傷害 |
| 醫＋命 | 淨化維持生存，用命印集中處理威脅 | 重大改命仍有世界擾動代價 |
| 醫＋相 | 藥引維持續航，面相破綻與陣法提供進攻 | 藥引與三槽各有上限，不能無限鋪場 |
| 醫＋卜 | 預見受擊時點，減少不必要的治療耗損 | 需要保留足量攻擊，避免純防禦空轉 |
| 命＋相 | 破綻放大命印爆發，器相提供防護 | 命印與破綻語義不同，不相互兌換 |
| 命＋卜 | 排序與預備控制爆發時機，命印集中輸出 | 回收不退氣、不撤回干涉紀錄 |
| 相＋卜 | 將需要的陣位牌排到手中，再安排觸發時機 | 不保證每場都湊齊三元素 |

十種搭配共用戰鬥規則；不另外增加第六類融合職業或必學混合分支。任何兩術的基礎牌組都應可完成前期，主線不得要求單一指定組合。

## 驗證要求

設計資料檢查：225 唯一 ID、每術恰好 45 張、没有 branches／主副修欄位、每級 9 張、各卡完整效果及＋版本、只存在十組兩術選擇。

隨機演算法原型另以固定種子檢查兩術席位、三選一去重、未選術永不出現、稀有度限制、卡池不足回退、互換 A/B 的權限等價，以及小卡池不被大卡池稀釋。模擬只驗證抽牌規則，不代表戰鬥勝率。

尚需 Godot 實測：十組搭配的勝率與輪長、全仙術同時持有的疊加、同名能力去重、低費取回鏈、醫術拖戰、陣位重放與首領取消動作等邊界。數據未測前不作強度保證。

## 本次離線驗證結果

[抽取規則模擬器](tools/simulate_two_arts.py)已完成 15,000 次三選一抽樣（10 種搭配、5 種熟練度組合、3 階段）；去重、階層限制、未修術排除、A/B 順序等價與極小卡池回退通過。不等大卡池的混搭席：小池 1492 次、大池 1508 次。這只驗證演算法，不代表戰鬥強度已平衡。[結果資料](two-arts-validation.json)。
