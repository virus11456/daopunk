# 肉鴿核心循環與輪迴邊界

狀態：使用者於 2026-09-26 明確確認遊戲為肉鴿。GBA 像素風、Godot／Blender 製作方向不變。以下為新版本設計，尚未接入現行即時探索原型；戰鬥方向採五術卡牌回合對決；具體數值與流程仍待原型驗證。

## 每輪冒險

選擇五術主修與起始配置 → 生成本輪路線 → 探索城市／事件／戰鬥 → 從有限獎勵構築流派 → 決戰 → 勝利或死亡結算 → 輪迴後重新出發。

每輪須有明確終點與勝敗，不能靠無限刷同一城市完成所有成長。具體輪長、章節數與終局敵人待原型測試；不預設每輪跑完十大宇宙，也不預設所有道主都是敵人。死亡結束當輪；勝利保留結局記錄後亦進入結算。暫停／離線可續玩同一輪，不等同輪迴。

## 大世界如何進入肉鴿

統治層級已確認：道主統領宇宙，星主統領星球並位於道主之下。星主可承接星球篇章，宇宙級道主則依路線出場；交涉與挑戰均可成為進展方式。

十大宇宙是世界內容庫，每個宇宙可有多顆星球、每顆星球可有多座城市。本輪從已解鎖內容抽取有限且可抵達的路線，玩家在分岔中選擇。40 個地點模板不是總量上限，也不是每輪必訪清單。

城市保留手工設計的地標、身份與穩定地址；依種子改變連接路線、事件、商店、敵人與獎勵，避免隨機化破壞世界觀。舊宅若本輪未出現，記憶事件延期且保留，不要求玩家每輪走同一路線。必要通關資訊不得綁在隨機缺席的舊宅。

## 當輪與跨輪迴

| 當輪結算後重置 | 可跨輪迴保留 |
|---|---|
| 實際牌組、卡牌升級、戰鬥增益、裝備與消耗品、Credits | 已解鎖的職業分支、候選卡池與事件選項 |
| 本輪路線、商店庫存、普通倉庫、房產與來訪排程 | 圖鑑、已知地址、劇情進度、人物記憶錨點 |
| 本輪取得的法則戰鬥配置 | 法則領悟／解鎖記錄；新一輪仍依配置限制選擇 |

五術修行樹主要擴大構築選擇，不提供無限永久攻防。已解鎖不等於開局已持有；每輪仍需獲得卡牌、道具與資源。現行原型五術熟練度 100% 與功德 50% 繼承是既有實作，未在本次改動；轉版時需明確遷移為解鎖進度，功德用途與比例待測，不直接換算成永久戰力。靈魂磨損應有可恢復的敘事代價，避免失敗越多越無法重新挑戰。

## 房屋是當輪選擇與跨世記憶

購屋是使用本輪資源換取整備、一次性服務或 NPC 事件的可選路線投資；價格與收益必須在一輪內有意義。未買房仍能完成冒險，基本休息與必要 NPC 推進有公共節點可用。

住宅整備消耗有限服務次數或節點行動機會，不提供無限回血、升級與重抽。NPC 來訪以路線進度／事件節點觸發，不要求現實時間等候或每日登入。跨世保留的是故事與選項；封存紀念品限故事用途，不攜帶前輪強力裝備、卡牌升級或被動數值。

詳見[房產與跨輪迴舊居](HOUSING_AND_REINCARNATION.md)及[五術職業](../art-direction/cards-items/FIVE_ARTS.md)。

## 原型驗證

先以 1 個宇宙、2 種主修、6～8 個節點驗證完整勝敗循環。檢查：死亡重置牌組與房產；解鎖不自動入牌組；無購屋路線可通關；舊宅缺席不阻擋主線；同種子讀檔不重抽獎勵；中途退出可續同一輪；勝敗結算只提交一次。此為待實作驗收條件，不是已通過測試。

## 世界與 NPC 的延續

玩家當輪重置不等於世界歷史清零。貿易、外交、政治依前輪後果與有約束的隨機事件持續演進；每個 NPC 配置作息與需求。詳見[生活世界與 NPC AI](LIVING_WORLD_AND_NPCS.md)。
