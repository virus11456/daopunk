# 十大宇宙：40 星球、100 個城鎮地點

依使用者「不一定 100 顆星球，一星可有多城」展開：沿用 40 顆星球，補至 100 個可探索城市／聚落／街區地點。包含既有 40 個視覺模板與新增 60 個城鎮；數據陵墓、破爛一條街等保留既有層級，不冒稱都是獨立行政城市。每宇宙 10 地點，四星配置為 3／2／3／2。

每宇宙唯一首都星為道主所在星，另指定道主駐地城；首都星的星主仍管理星球日常事務，道主統領整個宇宙，職位不混同。星主稱號固定、持有人可隨輪迴改變；道主不換人。歸墟首都與導師身分是作者資料，遊戲內按揭露階段顯示，不在玩家地圖提前標示祕密。

各城的核心用途、地標和地方衝突分別設計；共通商店、休息點不算獨有功能。此處為設計審核，唯一字串檢查不能證明所有玩法體驗已經不同，仍需原型驗證。100 個地點不等於每輪全開，路線生成只選一部分；必要主線與卡牌保底不得被稀有城市綁死。

新增功能不自動改寫舊圖，既有 40 圖保留作概念；新增 60 城目前只有設定，未生成圖、未接入 Godot。購屋資格沿用星球名錄，並非新城出現住宅就一律能買。[購屋星球](../HOUSING_PLANETS.md) · [貿易政治網絡](../PLANET_NETWORKS.md) · [結構資料](city-registry.json)

## 不重複的設計邊界

例如商港安排泊位、轉運聚落安排升降載重、舶匠城改造船艙、保航鎮處理保險、引潮埠招募領航員；皆涉及運輸但決策、輸入與結果不同。記憶城區修復活人回憶，封存城區執行亡者封存意願，碑契城判斷契約，燈信城遞送訊息，不合併成同一種「記憶服務」。

首都皆有覲見機會，但十種核心議題分別為世界異常、戰爭立場、群體心智、法令例外、交易秩序、元素實驗、物種共存、生死資料權、不可解釋異常與新生世界誓約；對話、證據與後果需按各道主設定製作。
