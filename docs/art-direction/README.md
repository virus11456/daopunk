## 目前方向

使用者指定像素風、Blender 與 Godot，偏好 GBA 時代寶可夢式的俯視地圖閱讀感。八方旅人的旅途氣氛可作情緒參考，但不採用其精細 HD-2D 光影、景深與立體舞台表現。人物、建築與素材均採原創設計。

美術一句話：**小巧、清楚、有人情味的道術賽博廢土。**

世界觀依據現有 README 與 data/dialogue/：第一宇宙歸墟、蔓哈頓深坑星、破爛一條街、數據陵墓、方舟隱修院；導師、紅、星塵、零號；五術、功德、世界變動率、輪迴。新圖為破爛街的視覺演繹，不新增正式劇情設定。

## 製作規格提案

| 項目 | 目標 |
|---|---|
| 視角 | 正交高角度俯視、正方形格網，露出屋頂與正面立面 |
| 地磚 | 16×16 px；簡潔重複圖樣；道路保持易讀 |
| 地圖人物 | 16×24 px，約二頭身；先製作四方向、每方向三格走路 |
| 場景邏輯畫布 | 320×180 px 起測，使用整數倍放大；此為現代螢幕適配提案，不宣稱是 GBA 原生解析度 |
| UI | 另設清晰文字層，避免繁體中文被強迫塞入過小像素格 |
| 著色 | 每種材質 2～3 階；選擇性深色輪廓；避免噪點堆疊 |
| 光影 | 固定光向、簡單落影；少量動畫亮點；不用景深與強烈泛光 |
| 色彩 | 深藍灰輪廓、米色地面、灰玉綠屋頂、磚紅布棚、古銅器具 |
| 特效 | 符紙、銅錢、命線，以短而清楚的像素動畫表現 |

概念圖是內建 imagegen 生成的高解析度風格示意，**不是嚴格 16px 格網圖集或可直接切割的 spritesheet**。仍有較密的屋頂、地板細節；製作版需降低細節、統一像素密度、檢查接縫和角色比例。不能將整張縮圖當作已完成遊戲素材。

## 角色與場景辨識

- 主角：深青道袍、米白圍巾、銅錢羅盤，以輪廓和兩個主色辨識。
- 紅：磚紅上衣、工具與修補攤位；保留黑市商人身分。
- 零號：米白僧衣、單側機械構造與古銅圓環，簡化至小尺寸仍可辨識。
- 破爛街：鐵皮修補、管線、符紙、小攤、盆栽；生活氣息多於空曠廢墟。
- 數據陵墓：方正入口、玉綠訊號與安靜的石材；用形狀區分科技與民俗。

## Blender → 像素素材 → Godot

1. Blender 建簡單建築與道具，固定正交鏡頭及光向，批次渲染透明背景底稿。角色可直接像素繪製；不要求每個小角色先建模。
2. 將底稿整理成目標尺寸的像素成品，限制色階、修輪廓與地磚接縫；保留 .blend 來源與 PNG 匯出檔。
3. Godot 使用 nearest 紋理取樣、固定整數縮放策略與腳底排序基準；UI 單獨測試繁體中文字可讀性。
4. 先做一個小廣場、一座建築、主角四方向走路，通過畫面驗證後再擴充。

現有 WorldMap.gd 使用 32px 地磚、project.godot 使用 1280×720 畫布；本次不直接修改。實作時須同步處理碰撞、移動速度、鏡頭、互動距離與導航，不能只替換貼圖尺寸。
