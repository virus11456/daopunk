# 城市與聚落完整配置圖

本批已生成 40／40 張完整區域配置概念圖，對應原先 20 星球環境位置、每星 2 地點。最新世界共 40 星球；新增 P3/P4 的城市不在這次已確認的 40 模板之內。名稱依既有地名或描述模板，地圖為美術延伸，數據陵墓等仍是區域而非新增行政城市。

每圖可見區域邊界、主路與側巷、特色地標及住宅候選位置。米色旗／門牌為居住功能候選；購買資格依購屋星球與區塊規則判定，非購屋地點可作旅店／借住；可走道路仍需實際碰撞、導航驗證，不是已完成 Godot 地圖。部分地面細節較密，製作時應簡化並統一像素密度。
