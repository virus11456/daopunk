# 五術正式分類與首版卡池

正式分類：**山、醫、命、相、卜**。每術三分支、每分支三張，共 45 張不同卡牌；本次分類由使用者確認，分支名稱、效果、數值及解鎖門檻為可測試提案。五術分類不等於五個互斥角色，主修決定主要獎勵，兼修提供混搭。

這是新版設計與概念美術，尚未接入 Godot。五張九卡圖版共描繪 45 張牌，並非已拆分的 45 個透明貼圖。中文卡名、費用與效果由本頁及圖鑑介面排版，生成圖留白避免文字失真；每張圖版從上到下是入門／進階／終階，從左到右是三個分支。

## 三種成長必須分開

- 永久仙術：用功德修行，重生時選配主動／被動技能，不抽牌；本批附 10 個提案。初始 1 主動＋2 被動欄為測試值。
- 永久路徑解鎖：學會分支境界，把新牌加入候選池；不自動入手，也不要求帶著前輪卡牌。
- 本輪牌組：透過獎勵、商店與導師取得卡牌；升級成「＋」只強化該牌，本輪結束重置，不自動解鎖整條路徑。

## 統一戰鬥語義（原型數值）

每回合 3 氣、抽 5 張，未保留手牌於回合末棄置；抽牌堆不足時洗入棄牌，不洗移除區。「費用」均為氣，不花功德施放。護體先承受傷害，自己下回合開始時清零，明確保留者例外；額外傷害與中毒也先過護體。所有取整向下。

- 蓄勢、劍印、藥引：上限各 3，戰內保留，戰後清零。消耗全部可在 0 層使用，只獲得基礎效果。指定消耗 3 層則不足不能出牌。
- 命印：每敵上限 3，戰內保留，敵亡移除；移轉不能複製、超上限溢出丟失。
- 虛弱：每層代表 1 個該角色的回合，攻擊傷害降低 25%；該角色回合末減 1，最多 3 層。
- 破綻：上限 3，下次受到攻擊傷害前消耗全部，每層多受 2 傷害；多段攻擊只對第一段有效，中毒不觸發。
- 中毒：上限 12，該角色回合末受等於層數的傷害後減 1。淨化指成功移除自身至少一層負面狀態。
- 治療：全來源共享每場 12 點有效回血額度；滿血不扣額度，不能以再入戰、召喚弱敵或回溯刷新同一遭遇。退出再進讀取該遭遇狀態；功德仙術同樣受限。數值待平衡。
- 陣位：共 3 槽，每槽山／水／火之一，最多各一個。放置需空槽且該元素不存在；不能放置時略過放置及其附屬效果，但牌上其他效果仍執行。轉化後仍不得重複元素；由玩家先選合法最終配置再結算。陣位戰後清空。
- 預備：只有 1 槽，新預備替換舊的；觸發一次即消失，到期取消。傷害型觸發在攻擊結算前；出牌觸發先消耗预備再執行卡牌，避免遞迴。
- 保留：牌在手上跨過回合末，至下回合結束失效；不免費打出、不複製。能力牌成功施放後離開循環，唯一能力同名不能疊加。移除牌本戰不再洗回。
- 「預測下一張」遇到無牌可出則回合結束失效；同名每回合限一次跨複本共用。查看空牌堆先按正常規則洗棄牌，不包含正在結算牌；不足查看全部。
- 取消普通動作只影響標示可取消的一個敵方動作，不能阻止劇情、自然死亡、觀察者或道主抹殺。所有仙術與卡牌不能延長主角 99 歲壽命。逆天改命造成的重大干涉紀錄不因戰後清空或回溯消除。

起始牌組提案：4 張共通攻擊（1 氣／6 傷害）、4 張共通防禦（1 氣／5 護體）、2 張所選主分支的入門牌。共通牌是功能規格，未計入本次 45 張五術圖。卡名與舊技能相同不代表沿用舊版壽命、復活或讀檔能力。

## 五術路徑總表

| 術 | 三條路徑 | 戰鬥差異 |
|---|---|---|
| 山 | 修命／修性／御器 | 蓄勢爆發／保留護體／法器攻守 |
| 醫 | 針藥／祛邪／丹毒 | 有限回血／淨化壓制／藥引與中毒 |
| 命 | 知命／改命／遮天 | 命印準備／強力干涉／保牌護身 |
| 相 | 風水／面相／器相 | 陣法引爆／破綻打擊／陣位調整 |
| 卜 | 卜卦／趨吉避凶／推演 | 牌頂排序／預備防範／有限取回 |

每張牌只能升級一次，表內「＋」覆蓋指定欄位，其餘限制仍存在。終階不保證高傷害，而是讓分支玩法完整；相同費用的不同術牌需在同一批敵人上比較。
