## 本輪分頭工作的依賴

1. 隨機事件契約：資格、冷卻、互斥、一次性／周期／後果、固定結果與歷史去重。
2. 圖鑑證據契約：經文可讀與目擊不同，訂正不刪歷史、未見不等於滅絕。
3. 最後由主線場景讀取上述資料；正式隨機權重、玩法時間壓縮、AI對話與Godot存檔另作整合。

兩個離線參考模型可先獨立驗證，但還不是同一套存檔；之後仍需統一ID、world_time與事件交易。不能把兩邊測試通過說成主線可玩。

## 時間與內容驗證範圍

20輪的19段成長期，若每段14年，合計266年；若15年則285年。這只計死亡後至覺醒的成長，不含等待新生兒與實際在世時間。第五時代需要長期歷史變化，不能按輪數強制改年代。

所有100小時、事件池300、圖鑑150～200、家庭8～12等仍是內容目標，不是已有資產。下一次評估應用可玩的短片段量測重複性與節奏，再修訂數量。
