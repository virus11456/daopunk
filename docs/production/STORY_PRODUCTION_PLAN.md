# 故事到製作的工作清單

[機器可讀盤點](story-production.json)收錄九篇來源、場數、檢查數及15項後續工作。這是來源與依賴整理，不是Godot任務資料，也不代表玩家必須照九篇順序遊玩。

## 現況

九份原稿共65場、113項逐篇文本檢查。問題可能跨篇重複；不能把提出修訂意見當修復。原稿已收與後續修訂版分開保存，目前沒有新版對話引擎、正式動畫、場景或可玩主線驗收。

## 分工

| 工作 | 交付者／狀態 |
|---|---|
| 全稿、人物、年表、伏筆、互斥真相與修訂順序 | 給Claude的統整任務，由使用者轉交；尚未收到統整稿 |

| 引擎存取、存檔遷移、正式美術與動畫 | 後續製作；先修故事與資料需求，再接Godot |

## 可先穩定的美術需求

保持GBA時代小比例、清楚像素輪廓，加上材質、天氣、作息與微動作細節；不用改為大型精緻比例人物。下表是製作需求，不是新增美術已完成。

| 共用資產 | 使用篇章 | 必須先核定的細節 |
|---|---|---|
| 紅攤位／後屋／燈與櫃子 | R01、D01、S02、M01、Y01 | 掛燈方位、頭部高度、燈亮／壞狀態及桌子位置 |
| 拾六圍裙、古舊紙、空白紙 | S01、D01、S02、M01 | 兩張紙不同外觀、所有權與借閱；文字另層顯示，不烘成不可改圖片 |
| 第一世街區與重建西段 | D01、S02 | 共享道路與永久歷史變化；新舊場景差異能被辨認 |
| 貨梯井、供電控制台、糧箱 | X01 | 斷電與恢復動畫、可用／報廢批次、實際搬運路線 |
| 安居院與九子紙牆 | M01 | 研究資料的可見與遮蔽狀態；不同紙不全當可讀線索 |
| 繭廊與葉遲的記憶演出 | F01 | 身體來源相關圖先不定；局部片段不等於完整回憶 |
| 河燈、工坊、兩份紀錄 | Y01 | 個人信不公開全文；封存可見層級與無名／閻羅形象區別 |

Blender可用於場景比例、鏡位與光影參考，像素角色與道具仍可直接做2D；不是每件資產都必須先建3D。具體素材尺寸、鏡頭、圖集與動畫幀數仍待原型選型。

## 下一步的驗收門檻

1. Claude交統整稿後，逐條對照原始來源與已答決策，不接受未經批准的人口／能力改寫。
2. P01～P09修訂與作者選擇先穩定；各章可分別前進，不為未定大結局阻塞小道具規格。
3. P10～P12完成可製作規格與視覺審閱後，才計為資產設計完成；概念圖不是精靈圖與動畫。
4. P13～P15最後接入Godot，驗證缺席、重訪、讀檔及輪迴；歷史程式不自動符合新版契約。

本批只驗證來源存在、索引數目、工作ID與依賴無環、文件連結及資料包完整；沒有執行上述引擎驗收。
