# 現行美術基準｜GBA 東方星際賽博像素

使用者最新指定：美術以本次確立版本為主。核心方向是 GBA 時代寶可夢式地圖閱讀感、原創小比例人物、東方修仙 × 星球賽博龐克。八方旅人僅作旅行情緒參考，不採精細 HD-2D、景深、寫實材質或強烈泛光。舊 RimWorld 色塊原型不再是美術標準。

保留本次十大宇宙、角色／道主及城市概念圖；卡牌版面、技能樹、戰鬥UI及配套玩法图均退役。舊卡圖若有可用符籙／器物意象，須重新作為獨立道具審核，不能沿用卡牌能力設定。此版沒有新增一套畫風。

## 角色與場景辨識

- 主角：深青道袍、米白圍巾、銅錢羅盤，以輪廓和兩個主色辨識。
- 紅：磚紅上衣、工具與修補攤位；保留黑市商人身分。
- 零號：米白僧衣、單側機械構造與古銅圓環，簡化至小尺寸仍可辨識。
- 破爛街：鐵皮修補、管線、符紙、小攤、盆栽；生活氣息多於空曠廢墟。
- 數據陵墓：方正入口、玉綠訊號與安靜的石材；用形狀區分科技與民俗。

## Blender → 像素素材 → Godot

1. Blender 建簡單建築與道具，固定正交鏡頭及光向，批次渲染透明背景底稿。角色可直接像素繪製；不要求每個小角色先建模。
2. 將底稿整理成目標尺寸的像素成品，限制色階、修輪廓與地磚接縫；保留 .blend 來源與 PNG 匯出檔。
3. Godot 使用 nearest 紋理取樣、固定整數縮放策略與腳底排序基準；UI 單獨測試繁體中文字可讀性。
4. 先做一個小廣場、一座建築、主角四方向走路，通過畫面驗證後再擴充。

現有 WorldMap.gd 使用 32px 地磚、project.godot 使用 1280×720 畫布；本次不直接修改。實作時須同步處理碰撞、移動速度、鏡頭、互動距離與導航，不能只替換貼圖尺寸。

現有高解析生成圖不是嚴格像素格成品；需清理光暈、漸層、密集噪點與不一致尺寸。沒有將其標記成完成的動畫、透明sprite或Blender模型。

導師三形象需共享臉、白髮短鬚、念珠等辨認線索。未揭露版本避免公開『歸墟道主』名稱與真身圖。鯤鵬已由使用者確認為有翅膀、無比巨大的鯨魚，三大創世生命之一；不能用牠代替導師或歸墟道主。背景是夢境底層，以小型主角／飛舟剪影建立尺度，保留GBA像素輪廓和有限色階。此為新構圖要求，尚未生成鯤鵬新圖。

## 地圖人物與肖像分開（2026-09-26參考更新）

使用者提供的畫面有輪廓簡單、頭大身短的小型俯視人物。推薦採相近的地圖閱讀比例，保留本作原創深青道袍、米白圍巾、紅的磚紅外套、零號機械眼等辨識點；不複製參考角色或素材。參考截圖不能用來精確判定原始像素尺寸，因此16×16／16×20是本作試作建議，不是量測結論。

地圖小人宜只有少量色塊，不在每個角色身上塞滿花紋與配件；對話肖像另用較大画布呈現表情和細節。角色在畫面中多大，同時取決於地磚、鏡頭和整數縮放，不能只把既有高解析概念圖縮小就當完成。要以一段街道、門口與兩名並排居民試看可讀性。

現況核對：既有主角概念圖比參考更高、服装細節更多；尚無可直接使用的四方向行走精靈。歷史Godot原型的Player與Npc以_draw繪製圓形占位，並未套用概念圖。因此目前不是使用者截圖中那種已完成的小人模型。

本次只調整試作方向與資料，未換入Godot、未新增像素圖集或動畫，也未把16×16推薦尺寸標成使用者已確認。Blender可用於建築底稿，這類小人可以直接繪成2D像素精靈，不必先建3D人物。
