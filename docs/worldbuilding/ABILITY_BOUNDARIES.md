# 能力與輪迴邊界｜待確認提案

## 已確認（2026-09-26 本次答覆）

- 每世基礎靈魂承載年限為99年，醫術與換身可作本世暫時延壽，輪迴後不保留；延壽仙術跨世保留，冷凍效果另待定；標準紀年與起算點待設計。
- 輪迴時世界繼續前進，城市和政治保留歷史；轉生耗時、回來的年齡與地點另外設計。
- 主角每一世仍為人類；特殊原因後續揭露。非人轉生不作現行主角方案。
- 重新保留山、醫、命、相、卜與跨世仙術概念；戰鬥形式待定。既有225卡、每術45張、兩術兼修、熟練度和兌換數值不自動恢復。
- 算命能看命運分支各自的發生機率、條件與走向，並藉由改變條件進而改命；不能保證唯一未來。仍需調查。
- 同門按相遇狀態辨認：留世者可相認；轉生者通常失憶，但修行能解鎖記憶；導師始終認得。門檻、恢復量與再次轉生規則待設計。
- 先前確認仍有效：主角保留全部親歷記憶；抹殺送往輪迴，多數人失憶；只有人類能學算命。

以下均為設計推薦，**除本節已確認事項外，未自動成為定案**。完整追蹤見[開發與待確認清單](DEVELOPMENT_STATUS.md)。

## 五術要解決的不同問題

| 五術 | 建議主要作用 | 必須保留的限制 | 需要確認的邊界 |
|---|---|---|---|
| 山 | 調整自身身心、感知與環境適應 | 不是永久無敵、任意延壽或無限能量來源 | 可否改善缺氧／嚴寒適應？何時仍需防護裝備？ |
| 醫 | 辨識損傷、治療與協助生命恢復 | 治癒傷口不自動召回已輪迴的靈魂 | 能否治療機體、義體與人工生命？建議需對應知識工具 |
| 命 | 讀取命運分支的機率與走向，理解牽連，據此改變條件進而改命 | 不是直接讀取唯一未來；不能靠姓名查遍全宇宙 | 推演需要本人接觸、可靠生平或何種媒介？ |
| 相 | 觀察當下形態、地勢、結構與外顯痕跡 | 看出異常不等於知道其動機；不能憑外貌斷定人格 | 是否含看穿偽裝？建議只能找出可調查的矛盾 |
| 卜 | 對具體問題與短期選項推演徵兆 | 重複提問不新增獨立證據，不可刷到必然答案 | 未改變條件時結果是否保持一致？建議是 |

命看長期關係，相看當下痕跡，卜看具體選項，避免三術成為三個名字的全知能力。山、醫等技藝是否可由其他生命學習，需逐項定義；「只有人類能學算命」不能自行擴張成全部五術都由人類獨占。

## 跨世仙術：保留什麼，限制什麼

推薦將「已獲得的仙術屬於自身」與「能在任何情況無限施展」分開。跨世保留的是能力，不要求每世重新購買；當世可用程度可以受身體成熟、精力、環境與施術條件影響。這些限制不能暗中把仙術改成每世全部歸零。

已確認消耗功德取得且包含主動與被動；尚待確認：各術敘事來源、具體種類、施展成本、能否被暫時封住、義體替換影響、是否有總數或組合限制、幼年如何呈現、失去意識時是否觸發。此批不訂技能槽、冷卻秒數、稀有度或卡片轉換規則。

## 十大道主的能力邊界候選

這是供確認的限制表，不取代現有法則對應，不預設道主互相戰鬥的數值。

| 道主／法則 | 候選能力範圍 | 候選不可直接做到之事 | 可能代價／制約 |
|---|---|---|---|
| 導師／命運 | 讀取與引導已建立連結的命途 | 任意替所有生命做決定、隨手保住全部弟子 | 越廣的干預留下越可追查的痕跡；與其他知情者立場衝突 |
| 奎托斯／因果 | 顯明或改動已成立的局部因果關係 | 抹去已被整個世界承受的全部後果 | 轉移後果仍要有承受者，不能憑空歸零 |
| 蓋亞／輪迴 | 接觸轉生痕跡與部分記憶關聯 | 無限復活、強制所有亡者記起前世 | 需可追溯連結；不能保證資料完整或取得當事人信任 |
| 玉皇 Prime／生命 | 辨識與維持部分生命結構 | 以登記決定誰真正有自我、任意賦予人類算命稟賦 | 維生要有資源，制度會有誤判 |
| 沃倫／時間 | 調整有限區域的時間流速 | 倒轉整個世界、抹除主角已親歷的記憶 | 區域邊界與外界時序需守恆式限制；模型尚待設計 |
| 聚變／空間 | 重排局部距離、位置與通道 | 無定位直達所有秘密、跨過一切封鎖 | 需穩定錨點及結構支撐；搬移會影響原住者 |
| 涂山氏／真實 | 顯明生命與造物的實際狀態 | 宣稱某人不真實便令其人格無效 | 證據和解讀分開；自身也可能誤判 |
| 閻羅 X／遮天 | 隱匿、封存指定線索與痕跡 | 任意刪掉主角已親歷記憶 | 封存依賴媒介和持續維護；外部副本未必受控 |
| 亞茲／靈魂 | 感知與保護可接觸的靈魂連續性 | 任意捏造同一個人、將所有失去化為可逆 | 不能以保護為名奪走意願；救助範圍有限 |
| 陸吾／創世 | 在既有夢境承載下形成局部新世界結構 | 不依賴造物主即重造十大宇宙 | 創造需要承載與維護；居民不等於永遠服從設計 |

共同推薦：道主知道世界本質但不全知；權能有對象、範圍、條件與代價。分清本源法則、仙術的具體表現與五術修習方法；傳奇法則也是仙術，不是第三套無關的能力。觀察者是否能約束道主，尚未決定，不能用「系統權限」四個字略過原因。

99年靈魂承載上限已確認；先定計時基準及轉生方式，再定五術資訊邊界、仙術限制、功德含義；最後細化十位道主與觀察者的制約。主線、戰鬥與獎勵要等這些規則足以承受反例後再接入。

## 命運機率與改命（追加確認）

主角不只看模糊徵兆，而能看見所觀測命運分支各自的發生機率與走向，並以此改命。此能力不保證單一未來必然發生。「所觀測」僅標明存在觀測這個動作，不擅自替使用者決定能看見全部或部分分支。

推薦演出為「觀測當前條件 → 看見分支機率與後續走向 → 調查、協商或介入 → 條件改變 → 重新觀測機率」。單純觀看是否也影響機率、可否直接施術修改機率、一般行動與術法干涉有何差異，均未定案。

僅作說明：某次事故的互斥結果為平安60%、受傷30%、死亡10%。修好煞車後可以改變三條分支比例，但必須有造成改變的原因；不是按一下就把死亡機率改成零。示例不建立正式數值或UI格式。

### 機率還要確認什麼

| ID | 待確認 | 建議方向，尚未定案 |
|---|---|---|
| A13 | 機率是真實精確值，還是依情報估計？ | 可顯示機率與觀測可信度；勿將未定誤差當確定能力缺陷 |
| A14 | 每次觀測是否看全所有分支？多遠的未來？ | 定義人物、事件、時間範圍，再討論未知分支；不預設無限全知 |
| A15 | 一條分支能否同時受傷又死亡？ | 在同一時間點用互斥結果，或使用條件機率；避免重複相加 |
| A16 | 0%與100%能否改變？ | 機率綁定當前條件；哪些條件可改、是否存在不可改之事要明訂 |
| A17 | 改命只改自己，還是改他人／群體？ | 區分作用範圍與連帶後果，保留他人的選擇和未知資訊 |
| A18 | 多位術者同時觀測或介入怎麼辦？ | 依同一世界事件順序更新，不讓兩個矛盾預言都被當唯一真相 |

這些問題會影響命／卜的分工、道主注意、可視化及玩法，但本批只確認能力概念，不選戰鬥形式，不恢復舊卡牌或變動率數值。

## 最新追加：功德與100種仙術

使用者已確認100種仙術，消耗各自不同成本的功德取得，包含延壽、生命、氣、屬性、被動與主動招式，獲得後跨世保留。取得方式與能力類型不再全列待定；具體100項與各自價格仍待製作，詳見[百種仙術基準](IMMORTAL_ARTS_FRAMEWORK.md)。

最新法則取得規則優先見[傳奇法則](LEGENDARY_LAWS.md)。十道主限制候選不等於主角取得後就具備同樣權能範圍。

延壽補充：醫術達標延壽每世一次，下世須重修，不可重複施術疊加；例值20年尚非全體技能正式數值。與換身共用或分開次數未定。

延壽、生命點與氣的仙術可疊加已確認；限制候選不能否定疊加，僅討論重複投資、公式與總上限。
