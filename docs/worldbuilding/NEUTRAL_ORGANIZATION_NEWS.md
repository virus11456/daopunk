# 中立組織近況與間接敘事

## 已確認

各個中立組織在世界中持續活動。主角不一定每一世都與它們打交道，但可以透過新聞、商隊及人們口中的消息得知近況。玩家沒有到場，不等於事件沒有發生；聽見消息也不代表必須接任務。

世界時間跨輪迴持續前進，因此組織的歷史、成員更替、合作與爭端不隨主角新生而重置。中立只指未固定效忠某一星主，不等於公正、守法、彼此結盟或不介入政治。星際商隊、雇傭兵、拍賣場、海盜及殺手組織是類型，不是各自只有一個全宇宙組織。

以下事件、稱呼、傳播流程與表現均為設計提案，非已發生的正史；不宣稱已建立新聞模擬或NPC AI。

## 十一類組織如何出現在日常消息中

前四類沿用既有設定，殺手組織為本次新增已確認類型；其正式名稱與後六個組織名稱仍為提案。近況不必都是危機，也可以是修船、換班、新航線、退休或一場沒有英雄登場的協商。

| 類型／候選組織 | 長期關心的事 | 沒接觸也能聽到的近況示例 | 常見消息途徑 |
|---|---|---|---|
| 星際商隊 | 航路、供貨、成員與信用 | 某支商隊改走較遠航線；幾週後市場才恢復某種香料 | 貨價告示、卸貨工、旅店掌櫃 |
| 雇傭兵團 | 契約、傷亡、聲譽與退役生活 | 一支兵團拒絕續約，被雇主說成違約；隊員說欠薪已久 | 招募板、老兵閒談、雇主聲明 |
| 拍賣場 | 藏品來源、鑑定、信用與買家隱私 | 一件遺物撤拍；後續不是失竊，而是原持有人的後代提出證據 | 撤拍公告、修復師、競標者抱怨 |
| 星際海盜團 | 航線控制、補給、內部權力 | 某海盜團分裂；航商的護航費先漲，居民卻還不知道誰接管據點 | 航行警告、倖存船員、走私傳聞 |
| 殺手組織（已確認類型；「無聲會」為暫名提案） | 秘密委託、契約界線、匿名與地下信用 | 某筆委託被拒；隨後一樁死亡被冒名認領，組織罕見否認 | 報刊未證實報導、地下中介、受害者親友與黑市議論 |
| 黑匣信使局（提案） | 送達、保密、離線通訊 | 一條偏遠投遞線暫停，積信後來由民間船員接力送到 | 未達信公告、收件人、渡站工作者 |
| 義體醫師公社（提案） | 零件、醫療自主、巡診 | 某批舊接頭停產，公社公布替代修復方案並增開巡診 | 診所告示、病友談話、修理鋪 |
| 廢軌打撈聯盟（提案） | 打撈權、遺物所有權、安全 | 找到一段古老軌道殘骸，後因家屬抗議暫停拆解 | 工程公報、回收商、紀念活動 |
| 自由港聯席會（提案） | 港口自治、關稅、通行規則 | 港口間談成短期互認，邊境攤商終於不用重複繳押金 | 港務公告、商販、報刊社論 |
| 斷鏈避難網（提案） | 隱私、撤離、長期安置 | 某地突然多了臨時住客，熟食攤加開晚餐；公開消息不暴露安全屋 | 社區互助、含糊傳聞、經當事人同意的報導 |
| 記憶公證所（提案） | 記錄真偽、同意、跨世證據 | 一份廣為流傳的記憶片段被證明剪接；更正傳得比原謠言慢 | 更正啟事、法院轉述、茶館爭論 |

同類組織可以有不同立場；不能用某海盜團救人就判定全體海盜善良，也不能以「中立」保證消息可信。

## 一件事，世界事實與各方說法分開

推薦以一條可追溯的世界事件作底，再產生不同來源的報導：

1. **實際發生**：某商隊因維修需求與通行談判，暫停一條航路。
2. **港務公告**：公布停航範圍、時間與替代泊位，未掌握全部內情。
3. **商販抱怨**：貨沒到，懷疑商隊囤貨漲價；這是人物推測，不是作者判定。
4. **船員口述**：知道自己的船壞了，不知道上層談判內容。
5. **後續消息**：航路恢復，舊停航公告撤下或標示過期；已發生的缺貨與損失仍存在。

每則消息建議記錄：事件ID、涉及組織／地點、發生時間、發布時間、抵達本地時間、消息來源、來源實際知道什麼、立場、是否查證、有效期限、後續更正及相關世界結果。可信度不必向玩家顯示成百分比；可用「公報、目擊、轉述、未證實」及對話細節表達。

不同人轉述同一條傳聞不算多份獨立證據。AI若用於潤飾台詞，只能使用角色可知的事件，不得自行編造戰爭、死亡、政變或道主秘密。

## 跨世聽見它們的變化

示例年表僅示範敘事方式，不指定遊戲每世長度：

- 一次人生中，主角在茶館聽說某商隊新闢航線，沒有前往。
- 多年後或下一世，某港口已靠那條航線興旺；掌櫃談起當年第一批船。
- 更晚時主角又聽見老領航員退休、新任負責人改變航路。主角可以記得早年的說法，現任店員卻未必知道。

不用讓每個組織每一世都發生大事，也不用保證玩家聽到全部近況。事件由世界時間與組織處境推進；主角碰面只是其中一個觀察點。

## 日常呈現與信息節制

- 報紙、公共終端與港務板承載正式近況；攤販、車站、旅店、船員帶來帶立場的生活轉述。
- 玩家走過可聽見一句短對話；主動詢問才展開細節。重要更正要有後續可查來源。
- 同一地區只突出與當地生活有關的少量消息。避免NPC每次見面朗讀所有組織的進度報告。
- 大事件之外留普通消息：醫師換班、老店重開、商隊婚宴、船塢完工。不是每一則都藏支線。
- 沒參與的事件也可以自行解決、留下損失或改變方向；不能因主角不接任務而永遠停在危機前一分鐘。
- 涉及保密據點、亡者私密或導師身份的消息受角色知識限制；新聞不是作者秘密的自動廣播。

## 留給編劇的交付格式

每個組織先寫：自身目標、當地聯絡面、三段近況鏈（起因／變化／後果）、一則正式消息、兩個立場不同的口述版本、未接觸玩家時的結局、可選的玩家介入點，以及往後時代留下的痕跡。組織名、人物、日期及事件均標清楚已確認或提案。

## 殺手組織的地方特色提案

「殺手組織」加入已確認類型；「無聲會」只作候選名稱，不代表全宇宙殺手都隸屬同一組織。可有不同規矩、客源與活動地區的團體。它們與雇傭兵團的區分在於秘密委託與地下契約，不把兩者寫成同一套人物換衣服。

故事重點可放在：誰有權為他人的死亡定價、組織是否真有不可接的委託、拒絕委託要承擔什麼、如何處理冒名與錯誤歸罪。這些規矩尚未定案；不預設全員守信、全員嗜殺或享有自由港豁免。

近況示例鏈（非正史）：黑市傳出一筆委託被拒 → 地方官員死亡，報刊稱疑似該組織所為 → 親友指出死者早有病況，地下聲明否認接案 → 真相仍待調查，拒單消息不自動證明它清白，也不把任何自然死亡都寫成暗殺。可用其中幾段作背景，玩家不必每世介入或加入組織。

涉及暴力的報導也應讓人看見家屬、社區及政治後果，不只把殺手當成酷炫裝飾。具名成員、契約規則、道主關係與正式年表仍待設計。
