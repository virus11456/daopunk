# 十宇宙、四十星球、一百地點｜背景名錄

本名錄保留地理、產業、地方議題與外交提案，移除隨機生成、購屋資格、解鎖與報酬。所有新增首都、星球和城市名仍是提案。每宇宙四顆代表星球不限制其餘天體存在；地點種類不等同行政層級。

各地共通的糧食、能源與運輸依赖可重複，獨特性由地標及具體社會衝突呈現。產業不是整顆星球的全部經濟。跨宇宙航路與通訊時間尚缺明確設定。
