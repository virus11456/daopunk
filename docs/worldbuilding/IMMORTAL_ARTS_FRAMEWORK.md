# 百種跨世仙術｜現行基準

狀態：本頁「已確認」來自2026-09-26本次使用者追加指示；具體100項名單與數值尚未完成，不以本頁冒充完整技能庫。

## 已確認

1. 使用者指定100種仙術，以各自功德成本學習。後續補充十種傳奇法則有特殊道主取得條件；是否包含於100種、是否另需功德待確認，不能先把總數改成110。
2. 取得仙術後跨世保留，像與生俱來的能力；不能每世重新收取同一項已取得仙術的學習費。
3. 能力包含延長壽命、生命點、法力值「氣」、具體屬性、被動能力、主動技能招式。
4. 每世基礎靈魂承載年限99年。最新修正：醫術、換身可帶來本世暫時延壽，但不能帶到下一世；已取得的延壽仙術則跨世保留。延壽、生命點與氣的仙術可疊加已確認；具體加成、總上限、計算順序及冷凍效果待定。
5. 保留五術；戰鬥方式仍未定。100仙術不等於100張卡，不恢復舊225卡或每術45張。

第4點取代先前「醫術與換身完全不能延壽」的說法。99年是基礎而非任何情況都不能突破的終值；醫術、換身如何暫時延長靈魂承載，仙術如何永久改變承載能力，敘事原理仍待補。

## 能力類型的資料欄位提案

| 效果類型 | 需要寫清楚的內容 | 邊界問題 |
|---|---|---|
| 延壽 | 增加每世可承載年限或其他明確方式 | 已確認仙術效果跨世有效；當世已接近期限時學習是否立即延長、能延多少仍待定。 |
| 生命 | 增加生命上限、恢復生命或其他效果分開標示 | 學到上限加成是否同時補滿當前生命？不能默認兩者相同 |
| 氣 | 氣上限、回復或消耗改變分開標示 | 無限回氣與主動技能會不會形成永動循環？ |
| 屬性 | 明列受影響屬性及範圍 | 屬性清單尚未定，不先假設力量、敏捷等既有數值表 |
| 被動 | 觸發條件、持續範圍、相互作用 | 是否可疊加、何時停止、能否被暫時壓制？ |
| 主動 | 對象、施展條件、消耗、效果與後果 | 戰鬥或探索皆可能使用，表現與數值須待玩法定案 |

建議每術具有：唯一ID、名稱、主要效果類型、次要效果標籤、功德成本、取得條件、施展條件、跨世保留項、是否可升級、疊加規則、關聯五術、敘事來源及相衝能力。這是資料設計提案，尚未建立100筆有效內容。

## 法則來源追加

仙術是法則之力的表現，十大道主掌管十種本源法則；法則能力屬傳奇級仙術，須經道主特殊途徑取得，詳見[十大法則](LEGENDARY_LAWS.md)。本頁一般功德學習規則不能越過傳奇取得條件。

### 暫定計算表達，數值尚未定

每世壽命額度＝99基礎年＋已學仙術的永久加成＋本世醫術／換身等暫時加成。此式的加法模型是設計提案，不宣稱所有效果必須線性相加。輪迴時暫時項歸零，永久仙術仍在；換身是否已用過、已消耗的當世時間須保留，不能重新變成剛出生再領99年。後兩項是防漏洞提案，具體規則待確認。

## 本世延壽只能一次（最新確認）

醫術修行達到要求所獲得的延壽，每世只能生效一次，不能反覆施術刷新。使用者舉例高階醫術可加20年：本世得到這次加成後不能再重複加20年；20年目前作說明例，正式年數待定。輪迴後加成清除，下一世須重新修行到相應要求才可重新取得一次。

主角仍記得所學，不因重修要求而失憶；推薦把重新修行理解為當世身體與修為重新達到施術條件，細節待確認。這條要求不自動擴張為全部五術知識、全部仙術都要重學。

醫術與換身的暫時延壽是否共用每世一次額度，或各自一次，尚待確認。現在不得利用換身清除已使用紀錄，再回頭重領醫術延壽。也不得用另一位醫者、不同名稱的同效果或存讀檔迴避同一延壽來源的次數限制；這些是待實作時需檢查的漏洞。

建議每世資料另存「當世ID、延壽來源、是否已領、加成年限、達標依據」；仙術持有紀錄則獨立跨世保存。本批僅資料設計，未實作存檔。

## 三類仙術可疊加（最新確認）

延長壽命、生命點、法力值（氣）的仙術效果可疊加，且隨已取得仙術跨世保留。這不代表同一術能無限重買，也不改變醫術本世延壽只生效一次、傳奇法則每種只取得一次的規則。

待定：各術是否可升級、加法或百分比的順序、總上限及邊際增益。例：永久延壽術甲+10年、乙+20年，若採加法則合計+30年且每世有效；下一世仍是同一個+30年，不因輪迴次數變成+60年。數字與加法僅示例，疊加本身已定。
