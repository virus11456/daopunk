# 山海探索圖鑑｜山經、海經與失聯宇宙

## 本次使用者已確認

- 在DAOPUNK的虛構世界中，《山海經》是古代先人探索諸宇宙留下的書；山經與海經都融入背景。
- 怪物、風土與國家可做成圖鑑；玩家不一定能收集完整。
- 最早存在的宇宙不只目前的十個。

這是遊戲內歷史設定，不是對現實《山海經》成書史的主張。古籍具體篇名與異獸細節在正式改編前另做來源核對。本文件其他細節皆為提案；以下補充v1.1已確認三項。

- 探索者是造物主沉睡、夢形成後的夢中人類。
- 涂山氏採九尾狐形貌，不引入大禹。
- 師門內只有師父起初知道古籍是真的，弟子當祖先故事。

## 與最新背景的銜接

v1.2「夢形成十個泡泡」不再作宇宙總數的定論。建議改寫為：「造物主的夢曾有更多宇宙；如今被共同辨識並由十大道主據守的是十個。」後半句的『共同辨識』是修法提案，不替失聯宇宙判死刑。

尚未決定：原始總數、其他宇宙的現況、十大道主如何對應早期多個宇宙、古代探索者的確切年代，以及山海經與夢外地球古籍的關係。不要自行新增道主或認定所有失聯宇宙都已破滅。

現有40星球／100地點維持現行可設計範圍；古籍國名不直接等於某宇宙或星球，一國可能跨星、一星也可有多國。地理層級分開標記。

## 山經與海經如何進入遊戲（提案）

| 卷別 | 記錄內容 | 玩家使用方式 |
|---|---|---|
| 山經 | 星球地表路線、山川、礦物、異獸棲地、聚落與祭俗 | 對照現地地貌、季節與居民說法，發現舊路改道或棲地遷移 |
| 海經 | 航行者跨越星海與宇宙間隙的見聞、遠國、邊緣世界、失聯航路 | 比對商隊航誌與古老航標；『海』是本遊戲改編用語，非現實古籍分類斷言 |
| 旁注／異本 | 後世增補、不同見聞、翻譯與誤認 | 同頁保留不同記錄，不讓一次目擊刪掉所有旧說 |

書不是全知系統。先人可能看錯、只在某季節抵達、把同族不同形態記作兩獸，或把文明技術視為神蹟。也有記得準確、後世反而不再相信的段落；不能一律用『古人誤解科技』解釋神異。

## 圖鑑的六類條目（提案）

1. 異獸與其他生命：形態、行為、棲地、智慧與自稱；不預設皆為敵人或以擊殺解鎖。
2. 山川與天候：地貌、氣候、季相及災害；行星氣候與超常現象分開。
3. 國家與聚落：制度、居民、產業、政治沿革與外界偏見；古國不自動等於現政權。
4. 風俗與技藝：節慶、飲食、喪葬、修行、機體維護等；尊重受訪者保密要求。
5. 路線與宇宙：曾通航、疑似失聯、座標不明、已證實改道；『未知』不是『不存在』。
6. 器物與遺文：原頁、抄本、碑刻、航標與口述；載體、譯文、內容主張各有來源。

## 發現與校勘流程（提案）

發現線索 → 留下來源 → 對照／實地探索 → 增補條目。不是固定四級進度：可以先目擊、後找到古籍，也可以多年只保留一則傳聞。

每個條目允許多項主張，各自標示『古籍記載／親見／他人轉述／相互矛盾／尚無法判定』與事件日期、得知日期、地點、條件。不要用一個完成百分比掩蓋不確定性。可顯示『已知條目數／待考線索数』，不顯示預先知道的全宇宙總數。

解鎖途徑包括觀察、救助、交談、交易文獻、追訪遺址與閱讀新聞；不能要求殺死唯一生命才完成圖鑑。過時資料保留年代，未知棲地不提供假精確座標。

玩家可以錯過遷徙、亡國前習俗或只開放一季的航路。不把全收集設成四結局共同門檻；關鍵主線證據須有替代取得方式，此為待編劇檢查的設計原則。

## 輪迴與圖鑑保存（提案）

主角記得自己實際讀過、見過的內容，與既定完整記憶一致；實體書、照片、碑片仍留在世界，有持有者與損毀風險。介面可重建『記憶筆記』，不能憑空重生原件或未看過的頁面。

重生後舊棲地、國名、政治關係可能過時，新增考察更新記錄，不清空歷史。玩家記憶不代表陌生NPC相信，也不等於可提交有公信力的實物證據。
