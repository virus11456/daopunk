# 40星球／100地點氣候與生活配置 v1

本批依既有名錄逐項配置，全部新增內容為**提案**。涵蓋城市、聚落與街區，不冒稱100座同級城市。已確認的是四季與天氣方向；本表未定季長、機率、溫度或引擎數值。行星列只描述已列居住地區的背景，不代表全球同一氣候。

水源與可呼吸大氣是為生活場景補上的候選解釋，不覆蓋未定的物理設定；尤其資料河與深淵另保留未知邊界。逐地條目有不同生活反應，但文化、人口與完整建築尚未完成。

資料：[climate-catalog.json](climate-catalog.json)。原名錄：[ATLAS.md](ATLAS.md)。共同規則：[四季與天氣](SEASONS_AND_WEATHER.md)。待辦：[開發現況](DEVELOPMENT_STATUS.md)。
