## 編寫邊界

主角保留全部親歷記憶，不能靠忘掉重要線索重置懸念。多數轉生者失憶；同門不能全員無條件辨認。只有人類能學算命是既定限制，機器人能否被算命仍是待探索的問題。人形不是人類族屬證據，讀命能力也不代表人格價值更高。

各篇需要具體人物願望、可觀察證據、反面解釋、行動代價与局部結束；不要只剩哲學問句或永遠待續的預告。每篇只揭示需要的真相，不先揭露夢境泡泡或導師身分。

本批完成的是文字故事提案與一致性檢查，並非正式對話腳本、任務或新遊戲實作。
