# 同門記憶與相認狀態

## 使用者已確認

相認取決於主角遇見師兄弟姐妹時，對方所處的狀態。仍在世者可以相認；轉生者通常失去前世記憶，但修行到一定程度能解鎖記憶，進而認出主角。導師始終認得主角。主角本人的全部親歷記憶一直保留，不需要這套解鎖。

「修行可以解鎖」不代表每位同門必定在相遇前達成，也不代表對方記起後一定提供幫助。具體修行路徑、所需程度、能恢復的範圍、是否需要契機，以及一般人是否也適用，尚待設計。

## 相遇狀態提案

下列分期名稱與具體演出是提案；可恢復記憶和按當時狀態相認已確認。

| 狀態 | 對方知道什麼 | 相遇表現提案 | 不能偷渡的結論 |
|---|---|---|---|
| 留世舊識 | 自己與主角相處的往事 | 先核對新身體和共同經歷，再以舊稱呼交談 | 記得不等於永遠同歲、原地等待或無條件信任 |
| 轉生未解鎖 | 當世經歷；通常不知道前世 | 把主角當陌生人，依當世行為建立關係 | 主角知道秘密不代表對方欠他人情 |
| 記憶局部解鎖 | 恢復的片段與當世記憶 | 記得一盞燈或一段對話，仍可能不知道是誰 | 熟悉感不等於已確認身分；片段分期本身待定 |
| 足以相認 | 恢復與主角相關、足以辨認的記憶 | 從當世稱呼改叫師弟，或先私下求證 | 不要求全宇宙知識，也不自動抹去當世家庭 |
| 導師 | 始終辨認主角 | 可刻意不公開身分，但作者層知道他認得 | 辨認主角不等於知道主角所有未曾說出的經歷 |

同一同門可能先在未解鎖時與主角結識，後來修行進展，再次相遇時改變對話。世界持續前進，狀態不只在主角進門時才生成；NPC獲得記憶必須有自身經歷與原因。主角死亡不會重置同門當世修行。

## 記憶、辨認、信任與幫助分開

推薦記錄四件事：恢復哪些前世片段、是否辨認主角、當世對主角的信任、當下是否願意及有能力幫忙。這些是敘事資料提案，尚未訂AI模型或數值。

例：某師姐前次以陌生旅人招待主角，後來解鎖了前世同行的記憶。再次見面，她可以說：『那天你說的燈，我終於記起來了。』但她這一世已答應守護一座城，不能因此放下所有責任跟主角走。

這保留兩個可以並存的問題：記得曾是誰，是否就必須成為從前的人？認出熟人，是否意味著舊承諾凌駕眼前的人？角色可以有不同答案，旁白不替他們宣布唯一正解。

## 待解的能力邊界

- 修行如何接觸記憶：哪種方法、師承與生命條件？不是所有升級都自動觸發。
- 恢復量：片段、特定一世或多世；是否可選擇暫緩，不先訂百分比。
- 真偽：外部記憶檔、植入資料與本人恢復怎樣區分？共同秘密只能增加證據，不保證絕對無偽造。
- 意願：他人可協助，是否能強迫解鎖？推薦尊重當事人，尚未確定能力是否技術上可強制。
- 再次輪迴：已解鎖過的同門下一世是否重回封閉狀態？未定，不能自動與主角永久完整記憶相同。
- 影響：恢復記憶的情緒衝擊、當世關係與使命如何處理？不以人格被前世完全取代作默認結果。

## 場景驗收條件（待劇本與引擎完成）

未解鎖者不說自己不可能知道的前世細節；足以相認者不反覆演陌生人；新片段出現有來源與時點；導師可隱瞞但不真的忘記主角；不把相認等同好感滿值；主角的記憶不被本表封印；同門再次轉生的規則在定案前保持明示未知。
