# 十大法則｜傳奇級仙術

## 已確認的能力來源

仙術是法則之力的具體表現。最本源的力量為十大道主掌管的十種法則，每位道主各掌管宇宙中的一種力量。法則之力可視為**傳奇級仙術**，仍屬仙術範疇，不另造一個無關的能力系統。

傳奇法則的取得途徑為：擊倒對應道主、完成對應道主給予的任務，或由該道主親自願意傳授。三者是使用者提出的替代途徑，不擅自改成三項全部必須完成。任務必須是能授予法則的指定任務，不把每件日常委託都當授予條件；具體劇情內容待設計。

取得後，法則之力跨世保留，不因輪迴消滅；使用者亦明示只能獲得一次。已確認每種法則各只能取得一次，累世可取得多種；不因新一世再次擊倒同一道主而重複領取或疊加同一法則。是否可同時使用多種、是否仍需功德、十種傳奇是否包含於100種仙術內，均待確認。

## 與100種仙術及五術的關係

建議分成三個不同問題：來源是什麼、如何學會、如何施展。

- 來源：十種本源法則；仙術是其具體表現，傳奇仙術更直接體現某一法則。
- 學會：一般仙術以功德學習；傳奇法則必須經過對應道主的特殊取得途徑。功德不能單獨跳過此條件；通過後是否還要支付功德尚未定案。
- 施展：山、醫、命、相、卜是已有修習與運用方法，不等同十種宇宙法則。是否每術都需固定配對某一法則，尚未決定。

主角取得的具體權能範圍尚未定，不自動等於道主全部權能、不自動取代其職位，也不自動獲得關於宇宙的全部知識。

## 取得事件與世界一致性

推薦將「通過取得條件」「接受傳授／取得權能」「永久持有」分開記錄。完成任務後可以有接受或拒絕的敘事，是否允許延後再領待定；一旦持有，不能因死亡再次領同一份獎勵或重演首次傳授。

擊倒道主是否指勝過試煉、使其認輸或其他形式，待確認；建議不必殺死或取代道主。這能保留「道主不隨輪迴更換」以及跨世政治延續。若允許道主被殺，則需另訂法則掌管、宇宙穩定與不換人規則的例外，不能略過。

永久保留指能力取得不被輪迴清除；不等於隨時無限施展。法則的作用範圍、條件、代價與相互制約仍待定，尤其時間、輪迴、生命不能直接讓99年一般上限與延壽仙術失去意義。
