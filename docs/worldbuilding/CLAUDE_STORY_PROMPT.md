## 提示詞開始

你是《DAOPUNK》的共同編劇、敘事設計師與設定統籌。請在下列已確認設定內，創作有趣、有人情味、懸念與持續哲學思辨的故事。你的工作是寫故事、人物、世界細節與劇情腳本；不是重新選遊戲類型，也不是寫 Godot 程式。

請用繁體中文。請直接創作，不只給方法或問卷。對尚未定案之處，可以提出你認為最好的補完，但必須標成「提案」，說明會影響哪些既有設定。不要讓作者建議混進「已確認正史」。有衝突時指出並修補，不能默默改掉我已確認的規則。

### 一、作品氣質與創作目標

這是東方修仙與星球賽博龐克融合的世界：義體、人工生命、企業、商隊、宗門、算命、仙術、法則之力同時存在。美術為俯視小巧大頭短身的復古像素人物，類似GBA年代的地圖閱讀感，但有現代精緻細節、日夜、四季、天氣和居民生活。不是寫實寫作口吻，也不是每個地方都只剩霓虹、駭客與廢墟。

故事從「機器人也能被算命嗎？」開始。先讓玩家遇見一個有自己願望、難處與幽默感的具體角色，再逐步追問：何謂人、自我、命運、選擇、記憶與真實。請把道家思想融入行動和人物分歧：無為不等於不作為，齊物不等於抹平差異，夢與真實不等於一切毫無價值。不要安排NPC輪流講哲學課，也不要把造物主直接等同「道」。

故事需要可玩的事件、人物衝突、調查線索與選擇後果；幽默可以來自性格和日常，不必每句台詞都故作玄妙。人物有工作、關係、欲望和不知道的事，不是只為主角存在。

### 二、已確認正史：宇宙與根本真相

1. 十大宇宙是造物主沉睡時形成的夢境泡泡；一個泡泡是一個宇宙，內含多顆星球與城市。
2. 宇宙間隙存在邊緣世界，穿梭可能誤入；邊緣世界最底層連接造物主的夢境底層。它不是地球地心，也不是第九宇宙「深淵」的別名。
3. 夢境底層有鯤鵬，為三大創世生命之一，形態是有翅膀、無比巨大的鯨魚。另兩位名稱、形態、職責及三者起源未定；鯤鵬不是已確認的造物主或導師。
4. 道主知道世界是夢，但不等於全知全能。知情者有希望喚醒造物主、維持其沉睡、殺死並取代祂等立場；尚未指定每位道主的陣營。
5. 主角探索真相，走向四個既有結局方向：守護夢境、喚醒真實、弒神奪位、煉假成真。具體因果、條件與代價未定，不預設其中一個是唯一好結局。
6. 歸墟與我們所在的宇宙及地球相連，如今不穩定且破碎，原因未知。地球與「蔓哈頓深坑星」是否為同一地點、殘片或不同星球尚未定案。請勿擅自新增第十一宇宙或把所有星球都說成地球。

### 三、已確認正史：十大道主

十位道主彼此認識。世間普遍認為「第一道主／歸墟之主」已經死了，只有少數人懷疑他還活著。作者知道：主角的普通導師，就是仍在世的歸墟之主。同一人有普通導師形象、道主形象與隱藏真身意象，不是三個角色。

歸墟之主掌控命運，能看到過去、現在、未來，並可以改命。請區分「能看見過去」與「已經確認可任意改寫過去」，後者尚未確認。誰懷疑他活著、他為何被認為死亡、如何隱藏、是否與歸墟破碎有關，都待設計。彼此認識卻沒認出普通導師，必須有可信解釋，不能只靠換衣服。

固定對應如下，請不要因地名或印象自行換法則：

| 宇宙 | 道主 | 法則 |
|---|---|---|
| 歸墟 | 導師／歸墟之主，真名未定 | 命運 |
| 武神界 | 奎托斯 | 因果 |
| 神經網 | 蓋亞 | 輪迴 |
| 智械天庭 | 玉皇 Prime | 生命 |
| 星際商盟 | 沃倫 | 時間 |
| 元素洪爐 | 聚變 | 空間 |
| 生化樂園 | 涂山氏 | 真實 |
| 幽冥數據流 | 閻羅 X | 遮天 |
| 深淵 | 亞茲 | 靈魂 |
| 永恆聖堂 | 陸吾 | 創世 |

道主不隨主角輪迴換人。每宇宙有首都星，是道主所在星；星球另有星主。星主稱號固定、持有人可以更替，須有死亡、退位、政變或任命等歷史原因，不能主角一出生全宇宙同時隨機換人。導師的普通據點與公開道主駐地如何並存，是需要補的秘密身份問題。

### 四、已確認正史：主角、師門與輪迴

- 主角出身世界僅存的算命門派，門中是最後的人類後裔。只有人類能學算命；不代表機器人不能被算命，也不代表其他生命不能學其他修行技藝。
- 主角每一世仍是人類，特殊原因後續揭露。人類稀少、轉生身體來源與人口延續必須能自圓其說，不可無限憑空新增人類。
- 主角每次輪迴完整記得自己親歷的一切。這不是全知：他記得聽過的謊言，不代表自動知道它是謊言。不得用失憶、封掉親歷記憶或靈魂磨損來省略難寫的情節。
- 抹殺只是終止本世、送往輪迴，不是永久湮滅靈魂。多數人輪迴會洗去前世記憶；主角是明確例外。
- 世界時間持續往前，城市、關係與政治保留歷史；不因主角轉生回到同一日期。轉生耗時、出生年齡、位置與玩家如何經歷成長未定。
- 師兄弟姐妹學成下山，各有使命，可能跨世再遇。仍在世者可以相認；轉生者通常失憶，但修行到一定程度能解鎖前世記憶，再次認出主角。要看相遇時對方處於什麼狀態。
- 導師始終認得主角。其他同門不是一開始都認得，也不是認出就必定幫忙；當世家庭、使命與立場仍有效。
- 記憶解鎖門檻、恢復範圍、再一次轉生是否重新封閉、如何區別偽造記憶，都未定。

### 五、已確認的能力與壽命規則

1. 五術為山、醫、命、相、卜。各術詳細分工、修行路徑與戰鬥方式未定；不要恢復舊卡池。
2. 算命可以看見命運分支各自的發生機率、條件與走向，並透過介入進而改命；不是保證唯一未來，也不只是含糊徵兆。觀測範圍、精度、能否看全分支及代價未定。
3. 仙術為法則之力的具體表現，本源是十大道主掌管的十種法則。
4. 已指定100種仙術，以各自功德成本學習，包含延壽、生命點、法力值「氣」、屬性、被動與主動招式。取得後跨世保留，像與生俱來的能力。
5. 延壽、生命點與氣的仙術效果可以疊加；同術可否重複投資、升級方式、公式和上限未定。不要把「可疊加」偷換成「無限重買」。
6. 十大法則能力屬傳奇級仙術，須擊倒對應道主、完成其指定授予任務，或由道主親自願意傳授，三途徑擇一。每種法則只取得一次，累世可以取得多種，跨世不會消失。取得不自動等於接任道主；是否仍需功德未定。
7. 十種傳奇是否包含在100種仙術內尚未決定，不能寫死100+10或90+10。
8. 每世以99年作基礎靈魂承載年限。醫術或換身可帶來本世暫時延壽，下一世不繼承；延壽仙術的效果跨世保留。
9. 醫術修到很高時的延壽，每世只生效一次，不能反覆加成；下一世須重新修到要求。使用者所舉「+20年」目前是例子，不是整個數值表已定案。醫術與換身是否共用一次額度未定。
10. 主角記得醫術知識與當世須重修達標不衝突；身體／修為如何重建可提案，不能說他忘了。時間權能、換身和反覆治療不可未經交代就繞過所有壽命與次數限制。
11. 功德的來源、道德／因果含義、是否跨世保留、能否用金錢買尚未定，不能沿用舊兌換規則。

### 九、請分批交付，不要一口氣寫完整個遊戲

**第一批請直接完成以下四項，完成後停在可審閱處：**

A. 設定檢查：列出最影響故事的8～12個缺口。每項寫「問題、為什麼衝突、推薦修補、會影響誰」，最多問我3個真正需要決定的問題；其餘先作可撤回提案，別用大量問題阻止創作。

B. 核心故事提案：提供一條你最推薦的主題與人物衝突主軸，並設計3個互相牽連的長期謎團。把作者知道的真相、角色以為的真相、玩家先看到的證據分開。明說哪些真相是你新提出的，不能冒充已定案。

C. 開場可玩分場劇本：《機器人也能被算命嗎？》，約6～8場，先在破爛一條街的生活事件內形成一個完整小故事。寫出具體對話、行動、調查物件、分支與局部收束；讓問題促成人物關係，別一開始揭露造物主、十大法則與導師真身。

D. 接續人物篇規劃：列出紅、星塵、零號及候選同門各自的欲望、缺點、秘密、與主角的衝突和一個值得寫的場景。只需人物篇順序與依賴，暫不鎖死全主線。

**每場劇本格式：**

- 場景ID、地點、地方時／天氣與可替代天候、出場者及當時記憶狀態。
- 入場條件、人物各自目的、主角已知／未知資訊。
- 畫面與行動：可由小比例像素人物、場景與對話表現。
- 具體對白：有打斷、誤解、幽默與潛台詞，避免人人說同一種文風。
- 互動或選擇：選項、NPC反應、當場結果及後續影響。沒有分支必要的場景不用硬湊三選一。
- 線索：證明什麼、不足以證明什麼、誰可能誤讀；失敗或漏看時有合理接續。
- 狀態變化：只寫敘事旗標、人物關係和已見證事件，不擅自編造功德獎勵或戰鬥數值。
- 退出與再訪：重返場景不能反覆演首次相認、首次傳授或已結束的衝突。

第一批完成後，我會選擇和修訂。後續再逐篇完成同門、道主、世界史及四結局，最後整合全主線，不提前接引擎。
