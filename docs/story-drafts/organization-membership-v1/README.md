# 加入中立組織 v1｜收稿與審閱

來源為使用者最新對話貼文；以下為摘要及編輯意見，非逐字原稿。全案仍為提案，不因收稿將四項待選升格為正史。未接 Godot。

## 內容摘要

加入非主線或結局必要條件；組織有義務、利益衝突、退出與跨世查驗。十一類：商隊、傭兵、拍賣場、海盜、殺手、信使局、義體醫師公社、打撈聯盟、自由港聯席會、避難網、記憶公證所。跨世以重新申請為預設，部分接受暗號或記憶查驗，部分不繼承身分。可以兼任，但義務可能衝突；燈籍秘密構成代價。

## 需要修訂的地方

1. **暗號是查驗線索，不是身分證明本身。** 暗號可能外洩、撤銷或隨組織改組失效；代收號不應直接解鎖信件、職位、資產與安全屋。分開本人延續的認定、會員資格、職務及存取權限。
2. **「重新入會」與「不承認」不是同一維度。** 拆成前世身分是否受理、當世入會方式、可恢復哪些權利；不承認前世不等於禁止當世加入。
3. **公證有能力邊界。** 能查驗某份記錄不等於保證完整、真實或證明靈魂同一；受理前世記憶不保證認證成功。不以公證技術取代真實法則，也不要求交出全部記憶。
4. **非人類也能領航。** 人類讀命是特殊路徑，機械生命仍可依航標、航誌與技術导航，與潮簿設定一致。熟練航行、辨識古物不能直接證明是人類。
5. **退出要補全。** 拍賣、公社、港務、公證、避難網等補退會、停職、交接與開除。守密可延續，任職義務不能默認跨世；簽約不等於一切命令都必須服從。
6. **職能不是一次考試全數取得。** 巡診助手不自動有獨立行醫能力；見習公證員不立刻掌握所有檔案。記憶知識、當世修為、機構授權分開。
7. **護送不能保證無戰鬥。** 白纓可提供談判、避讓、後勤路徑，但遭遇武力與戰鬥系統仍待設計。
8. **組織衝突須有知情來源。** 加入海盜不使全宇宙即時知道；記錄行為、目擊、名冊洩露與消息傳播。護航費也可能是強迫索取，不能靠名稱自動正當化。
9. **燈籍風險是情境，不是固定排名。** 海盜未必永遠最高，公社與打撈也非天然安全；看已交資料、對方知情、世界狀態與保密措施。
10. **跨世仍用世界狀態。** 引介人會死、機構會改組；保留無會員的主線替代來源。組織不會因主角死亡重置。
11. **終章不自動知夢。** 組織不知道造物主時只能表達維持生活、航路與保護居民的訴求；要明言守護夢境須有可信消息來源，不由旁白替全體表態。
12. **兩難保留調查空間。** 救燈籍不必永遠只能犧牲另一安全屋；依資源與時間提供協調、延後、轉移等可能，真無替代時寫清原因與受害者後續。

## 四項待選與建議（尚未定案）

- 殺手：先保留外部聯絡人；非暴力見證人另作可選支線，不自動開放會員。稿稱設定包禁止刺殺任務，需對照具體來源再標已定。
- 跨世：保留差異，但改用身分查驗、資格、權限三層，不以一句暗號恢復所有權利。
- 海盜：建議可加入，保留拒絕劫掠、退出與派系後果；不保證所有派系接受非暴力角色。
- 兼任：敘事上暫不設硬上限，以契約、時間與利益衝突限制；具體玩法上限待系統確立。

以上建議等待使用者確認；本次僅收錄，不代選。
