# 給 Claude｜道主總綱 v1.1 修訂，接續蓋亞與涂山氏
請先讀使用者的《道主篇總綱 v1》與本包 REVIEW.md，交付「總綱 v1.1 修訂對照」，再寫蓋亞、涂山氏兩篇的場景綱要及選項／證據依賴；本批先不要展開八篇長台詞。

既定底線：
- 世界持續前進、可以惡化；最終結局必須由玩家觸發。刪除自動未介入結局、終局倒數及靠延後時限延長存檔的說法。
- 法則取得既有三途徑保留：擊倒、完成任務、自願親授。每種實際領取一次、跨世保留；有限能力，不是奪取整個道主權能或接任。新戰鬥方式與數值不在本批決定。
- 道主逐出夢外不同於普通生命輪迴；蓋亞沒接到師父靈魂不能單獨證明存活。補寫她懷疑的可調查依據，但新證據仍標提案，列替代解釋。
- 主角完整記得親歷；NPC 只能使用自己取得的知識。所有證據標親見、紀錄、轉述、傳聞、觀命或作者提案。
- 既有角色壽命、地點歷史與前置選擇有效；不綁第二世／第三世，不復活過世的事件當事人。

總綱優先修正：
1. 定義挑戰勝利、逐出與授法先後。不能把無抵抗直接算擊倒，也不能讓已逐出者無解釋地現身授法。
2. 陸吾地方任務可早於揭穿；後期對質／結盟作替代。共治暫列現有取代路線變體，不增加第五結局。
3. 聚變居民受害不可仍算保護任務成功。若他另提親授，分類、責任與拒領後果分開。
4. 涂山氏不因暴露他人隱私或單純戰勝而宣判更懂真相。亞茲安置任務給有限可行的需求邊界。
5. 五守護、二動搖、二密謀保留提案；不替使用者回答立場定案。八位角色性格、法則名稱與駐地延用提案標記。

每篇輸出：
- 進場條件、主角與道主各自已知／未知、最晚仍可抵達的條件。
- 4～6 個場景，每場列目的、選項、拒絕、離開、缺席、後續。
- 三種授法途徑各自前置與完成點；已取得後不重复獎勵；本世重試與跨時代替代。
- 蓋亞：拒絕分享記憶不封鎖必要主線知識；可選記憶的範圍、同意與撤回時點清楚；任務替代是保護他人自主。
- 涂山氏：真實法則的主線依賴保障；傳承苑关闭、葉遲不在或未採用時仍有合理可達路徑；不得把葉遲人工生命等提案偷升正史。
- 逐項回覆 DR01～DR16，最後只列不能靠一致性修補解決的作者選擇。
不宣稱 Godot、戰鬥或 NPC 行走已實作；不要擅自增加命運回溯與自動終局。
