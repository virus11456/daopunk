# 八位道主總綱｜一致性審閱
優先服從使用者已確認：世界可惡化，結局由玩家觸發；每種法則擊倒／任務／自願傳授取得，跨世一次。以下修補方案仍標提案，不冒充新增正史。

| ID | 問題 | 修訂要求 |
|---|---|---|
| DR01 | 玉皇「未介入結局前」、陸吾「時限計畫中止」沿用已撤回倒數 | 改成世界行動／計畫進度，不能自動結束存檔。打斷行動影響世界狀態，最終抉擇仍由玩家觸發。 |
| DR02 | 道主被逐出夢外，不走普通輪迴；蓋亞沒收到師父靈魂是預期結果 | 未收到只是不足以證實死亡，不能單獨證明存活。新提案可使用晚於事發的命運干預痕跡，另設來源、日期、替代解釋；未定前不寫成證據。 |
| DR03 | 擊倒、逐出、傳承混成同一瞬間 | 分別定義挑戰勝利／權能受損／逐出。戰鬥勝利不必然逐出；若劇情必定逐出，須在離場前或由已設傳承物完成取得。後者仍待設計，不能凭空掉落。 |
| DR04 | 「拿走因果」「少一個守的人」像是剝奪道主所有權能 | 取得的是有限法則能力，不自動接任或削空道主。守護真空只有實際離場時才產生；亞茲不抵抗不等於已完成擊倒挑戰。 |
| DR05 | 陸吾任務要求真相前，節奏表卻階段八後才開 | 建議陸吾地方任務可在真相前完成；對質與結盟是後期替代路徑。不要讓已知真相者永久失去所有取得機會。 |
| DR06 | 真實是主線必需，但傳承苑人物可能已死、苑可能關閉 | 至少保留一条跨時代可達的涂山氏取得路徑；以機構後續／新當事人的真實問題承接，不能復活舊 NPC 或重置已解事件。 |
| DR07 | 蓋亞分享記憶與主線揭露容易綁成強迫交易 | 拒絕分享不應封死世界是夢等必要線索。保留替代會面／證據來源；是否傳法與是否提供主線線索分別判定。 |
| DR08 | 玩家口述師父在世便讓蓋亞「知道」 | 先記為主角轉述與她的信任判斷；親見／驗證後才能提升證據層級。她的態度不代表全體道主知道。 |
| DR09 | 聚變任務要求保住居民，居民受害卻仍判成功授法 | 分開任務成功與道主另行邀請親授。後者可刻畫他的缺陷，但必須標示損害、救援與責任；拒領不消除世界後果。 |
| DR10 | 傷人真相獎勵、戰勝就更懂真相，可能鼓勵洩露私隱 | 涂山氏評價改看證據、知情意願與後續責任。戰勝只代表試煉結果，不證明主角說的都對。 |
| DR11 | 法則邊界可能被任務文本擴張 | 時間不倒轉正式歷史；空間依位置／命錨條件；輪迴不複製靈魂；生命不自動召回已轉生者；靈魂不抹去主角記憶；創世不無限產功德或造獨立宇宙。 |
| DR12 | 親授只准親眼看到，長期玩家可能永遠錯過 | 區分直接目擊、可核驗紀錄與傳聞；道主可要求查證，不自動讀全世界。奎托斯閘門事件只是示例，不能成唯一門檻。 |
| DR13 | 任務失敗一律等下一世／時代 | 已有新證據或新安排可本世重試；失敗不必死亡。重試須尊重當事人已死亡、拒絕與問題已解等狀態。 |
| DR14 | 亞茲安置「不拋下任何人」缺少容量與拒絕條件 | 定義當批需求、資源、轉介與自願離開，不把無限人口全收作唯一解；不得為授法強迫靈魂留下。 |
| DR15 | 弒神共治可能新增第五結局；陸吾否認師父生存與結果不確定並置 | 共治暫列現有取代路線的關係變體，非新增結局；陸吾可對外宣稱死亡，內心未驗證，作者知識與公開說法分開。 |
| DR16 | 提案立場、取得節奏被當已定；拒收可能吃掉一次機會 | 五守護二動搖符合多數方向，但具體兩位仍提案。一次領取在主角實際接受時成立；已得後仍可做地方任務但不重複授法。 |

## 建議撰寫順序
蓋亞 → 涂山氏 → 玉皇 Prime → 奎托斯 → 沃倫 → 聚變 → 亞茲 → 陸吾。
先處理主線必要知識與真實法則，再擴展支線，最後寫牽涉終章的陸吾。順序是製作建議，不是玩家必走順序。

## 必測劇情案例（規格審查，未做遊戲測試）
拒交記憶仍能得到主線必要知識；传承苑已關閉仍能取得真實；早取得陸吾法則再揭穿他不重授；拒領後可再接受；擊倒但未逐出仍可交談；逐出分支不要求與已離場道主立即交談；幾百年後也不自動結局；人物已死用檔案承接且保持轉述層級。
