# 共同年表 v1.1 收稿檢查與適用修正

本稿新增 B1～B4 選擇已收錄。來源為使用者提供的作者稿；B5 仍待確認，不自動定案。先前已直接確認的十五歲下山及玩家觸發結局優先。SOURCE.md 保留來稿內容，下面提供使用時的修正，不覆蓋五篇舊稿。

| 項目 | 現行處理 |
|---|---|
| 主角下山年齡 | T+0 為十五歲，十八歲提案已被取代。 |
| 四師姐下山 | 若保留 T−10y，主角當時五歲；若保留主角八歲，則需改 T−7y。兩者不能並存，暫不代選四師姐日期。 |
| 閘門日期與死因 | T+15y 僅事件時點提案；主角若在場是三十歲，且可能生還。不可寫固定三十三歲死亡。 |
| 年表整體 | 「相對年表仍有效」改為「世界事件日期暫作候選；主角遭遇、死亡及轉生後路線僅為示例」。 |
| 轉生與覺醒 | 以死亡日 D、候選出生等待 W、覺醒年齡 A 推導 D+W+A，不固定第二世 T+31。W 未定，A 為14～15，不能宣稱每死至少15年。 |
| 示例算術 | 若 D=T+15、W=1，出生T+16，十四歲T+30、十五歲T+31；T+29十四歲只對應較早出生的另一示例，不可混用。 |
| B1／沈家 | 身體來源改為燈籍新生兒；「另設」與 B1 仍待選的舊句退役。沈家是否具名燈籍家庭、照護與血緣細節仍是提案，不能自動確定。 |
| B2／B3 | 記憶湧現者庇護苑、同門可轉生任何生命依本稿新決定記錄；葉遲為人工生命仍是提案。主角每世為人類的例外不變；非人類恢復舊記憶不等於能重新施展人類讀命術，能力邊界仍待設計。 |
| 紅與大師兄年齡 | 下山年數與當時年齡分開，按到訪世界日期算；固定75或70只作示例。 |
| 遺物交接 | 紅收存需實際死亡、遺物尋獲、紅在世並有保管權。T+17轉交不能早於任意實際死亡，更不能在主角生還時搶走空白紙。 |
| 舊紙拓本 | 新增借閱、拓印、返還皆為提案，各有完成旗標；原件仍在拾六不代表各路玩家都看過。 |
| 信件與螺帽 | 15封、16封不是任意死亡時間都固定成立；寫信停止是紅的選擇。紀念須有已知死訊與實際立碑，生還路不觸發。 |
| B5 | 只有代收號仍待使用者確認；不阻礙收稿與角色圖進度。 |

請作者下一版先交「世界事件時間／玩家遭遇時間／物件狀態」三欄對照，再更新 X01、D01、S02、M01、F01 的依賴。不要把所有事件一律平移三年，也不要讓未知身體來源回滾覆蓋燈籍決定。
