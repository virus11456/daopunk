# Z01《半邊夢》檢查

本次檢查原稿、最新使用者決定、世界名錄與前兩篇接口。原稿不修改；下列均是修訂要求，不是聲稱已修復。

## 可保留的重點

零號把兩半身體的衝突歸回「是我想數葉子」，比單靠辯論更有人物力量。杭嬸與小滿使休耕不是抽象善惡題；錢穗延續醫師公社背景，並帶來紅篇關係後果。公社協商舊件服務在主角未參與時仍推進，符合世界自主活動。鯤鵬伏筆與木雕沒有直接當作超能力證據。

## 鯤鵬與能力邊界

原文用魚形木雕作粗糙夢像可以保留，不能以此把已確認的有翼巨鯨改成普通魚或把雕刻尺寸比例當生物設定。夢在改造、出家與某年雨季後開始是時間關聯，不證明任何一項造成夢。資料未登錄也不證明具有某種靈魂、人類稟賦或師門血緣。

零號尚未確認人類，能被算命不等於能學算命；兩者必須繼續分開。看到存活剪影不證明靈魂必然延續，沒有看到夢也不證明夢消失。
