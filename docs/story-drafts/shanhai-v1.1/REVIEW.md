# 山海經v1.1整合檢查

1. **宇宙數量**：山經對應「十大宇宙內部」是目前整理範圍，不是古代只有十個宇宙。殘頁可以記載未對應地點，不能先填成現有十域。
2. **師門知情範圍**：「只有師父知道」採師門內、開場時的語境。蓋亞後來揭露則更新主角知識，不追溯讓童年主角已知。其他道主知情仍是提案。
3. **導航資格**：人類看命線的特殊能力不表示機器人商隊不能正常星際航行；一般航路、未知間隙、夢底航行分開。獨占所有航行將衝突於既有文明。
4. **人類史**：古代曾眾多與今日稀少可共存；諸國全是人類、且全部消失尚屬提案。不得因此恢復當代隱性後裔來源。
5. **異獸身份**：帝江＝渾沌、禺彊＝鯤鵬是改編假說。稿內「自洽」不是新增定案。燭陰晝夜不能自動覆蓋每顆行星地方晝夜與四季。
6. **證據強度**：守帝之下都不能證明陸吾襲擊導師；仍需當代證據、反證與玩家確實讀過的記錄。
7. **古今對照**：「中山經寫歸墟」是遊戲改編，現實篇章引用與遊戲譯解分欄。歸墟等於／連著夢外的問題仍未解決。
8. **山海圖**：『失傳』可指完整圖失傳，允許殘片存世；不要求全收齊才能走關鍵主線。
9. **時間／接口**：主1～15為稿內章號，不覆蓋現有S01等ID；應另建對照，不能據此宣稱新增15章可玩內容。
