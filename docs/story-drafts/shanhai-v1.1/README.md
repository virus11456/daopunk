# 山海經融入設定 v1.1｜現行整合摘要

來源：使用者在本任務貼上v1、接著貼上v1.1並要求「更新」。此為整理摘要，非原文逐字檔；完整原文保留在對話中。本版取代v1的三項待決問題，不覆蓋《燈還掛著》背景原稿。

## 已確認，不再重問

- 遊戲內《山海經》是先人探索宇宙的紀錄；並非對現實古籍成書史的判定。
- 探索在造物主沉睡、夢形成之後；先人是夢裡的人類。
- 涂山氏只採九尾狐形貌；不引入大禹及相關關係。
- 師門內只有師父知道古籍確為探索紀錄；弟子起初當祖先故事。此處「只有」按本文師門語境解讀，並非否認別處道主可能知情。
- 保留較早已定：古代宇宙不只十個、圖鑑不保證收齊、鯤鵬為有翼巨鯨、人類衰亡原因仍為謎。

## v1.1其餘內容的提案登錄

| 部分 | 提案內容／使用限制 |
|---|---|
| 探索者 | 古代人類眾多，順命線跨宇宙與空隙航行；不等於現代存在已遭否決的隱性人類群體 |
| 記述方式 | 用熟悉形貌形容陌生生命；記錄可失真，不把每句都當精確描述 |
| 山海圖與抄本 | 地圖失傳、殘本分歧；燈籍閣藏古抄本；其他道主知其真實性仍依稿內提案處理 |
| 卷別 | 山經為宇宙內行旅，中山經對歸墟；海內為泡泡內緣，海外為間隙，大荒為梦底。這是遊戲對應提案 |
| 燭陰／燭龍 | 海外與大荒記載對應同一創世生命，晝夜對應寤寐；雙重目擊與具體機制尚非已定 |
| 帝江 | 對應遠觀渾沌仍為提案，不能因「無面目」直接證成同一生命 |
| 陸吾 | 與道主名相連；守帝之下都與奪位動機的解讀保持提案，不取代當代襲擊證據 |
| 九尾狐 | 本作對應涂山氏形貌已定；不延伸大禹故事 |
| 禺彊與鯤鵬 | 禺彊是否為另一視角／誤記保持爭議；《莊子》鯤鵬另列來源；本作形態仍以有翼巨鯨為準 |
| 海外諸國 | 古代人類聚落、今皆消失為提案；不能從未找到遺跡推斷全滅，也不能把所有非人族群一概判為人類 |
| 夸父 | 追向燭陰睜眼、未抵達而死是改編提案；喚醒路警告不等於喚醒必定錯誤 |
| 其餘道主 | 古籍無明確對應或篇章失傳為提案；不以缺載證明不存在 |
