# 第7批裁決

依使用者先前「把它都決定」授權，而非附檔自行授權。

## 本輪裁決（依使用者既有代裁決授權）

1. **C7-D1**：129保留獨立純經文神名，與英招等古籍記錄同類；N9仍禁止收遊戲現世人物檔案。道主同名比較、L01及幕後設定只留編輯說明，不入玩家未見欄。
2. **C7-D2**：130／137開局文字可見，文獻圖先隱藏；實際取得插圖才顯示。親見資料先存匿名個體，單個體可靠辨認便可連條，不以完整K7倒鎖個體辨認。這不額外增加主線收圖門檻。
3. **C7-D3**：138～140經外類型保留，無經文的未見短文採S09明示例外三欄；泛型示意不得冒充實際個體目擊，制度分類與生命本身分開。
4. **地方採用**：採本稿修訂後的器物、俗稱與消息地；無古國現代定位。124嘲罵、126身體玩笑改寫，135小圈不指定含義或作必需證據。既有死亡、遷居、取得及展示條件照常適用。
