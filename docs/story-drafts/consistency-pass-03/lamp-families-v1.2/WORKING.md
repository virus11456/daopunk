# DAOPUNK｜燈籍家庭 v1.2：每一輪的起點

> **歷史v1.1**：曾彙列五項建議；現行依N39、N40修正半選擇與等待規則，其餘採用狀態逐項見索引v1.3，不由此句整批定案。

## 一、落點規則（取代 v1 的 1.3）

### 1.1 待產清單與半選擇
主角死亡後，世界時間前進。當燈籍上出現**待產的孩子**時，玩家從當時的待產清單中選一戶。

| 情況 | 處理 |
|---|---|
| 清單有兩到三戶 | 玩家選一 |
| 清單只有一戶 | 沒有選擇，直接落在這一戶 |
| 清單超過三戶 | 【提案】依預估產期選列至多三戶；預估不等於保證出生，候選排序與出生失敗處理仍待設計 |
| 清單為空 | 世界時間繼續前進，直到有合格出生候選；約十年僅軟目標，不保證此時出現 |

**選擇時可見的資訊**（刻意有限）：
- 宇宙與星球
- 家業
- 這一戶與隱修院是否有聯絡
- 這一戶是第幾代下山

**不可見**：開場處境、當時的時代狀態、誰還活著。玩家要醒來之後才知道。

### 1.2 為什麼能選：師父那一刀留下的空隙

【已定 N39】選擇只存在於玩家介面；主角本人不記得選過（等待期間沒有經驗）。主線階段六，師父說「落在哪裡，是你自己選的」，主角才明白，並可以相信或懷疑。
【現行N39】最後選擇由玩家介面操作，不寫成主角死後有意識地挑選。師父如何描述那一刀是角色說法，不能替主角增加等待期經驗。

這在主題上是一個小小的反轉：師父替他決定了要記得，卻把「在哪裡重新開始」留給了他。依N39於主線階段六由師父說出，主角可相信或懷疑；不能改成他在此之前自行想起曾經選過。

### 1.3 直系規則
【提案】命運直送**不會**讓主角落在以下家庭：
- 父母任一方是主角任何一世的**直系子孫**（子女、孫輩及以下）。
- 父母任一方是主角任何一世的**配偶**。

這些家庭即使待產，也不會出現在清單中。
- 敘事說法（可由師父在階段六說出）：「那一刀，不讓你回到自己的血裡。」
- 旁系是否排除仍待裁決；原稿允許兄弟姊妹、表親後代為候選提案，不作已定篩選規則。

### 1.4 等待時間的軟目標

【已定 N40】十年為**軟目標**，以燈籍人口規模使其在多數情況成立；不放寬直系規則；不憑空新增家庭。原十年設計保證已退役，舊文保留於ORIGINAL。
- 人口規模仍待裁決與年表檢查，不把「多數情況」當作已驗證結果。沒有合格新生兒時繼續等待，不能強制生育或生成人口補洞。
- 下限不設；可能死後隔年就有人出生。
- W計至實際出生，包含選戶後的剩餘孕期。加14～15年成長後開始下一輪；14～25年只適用W不超過10年的情況，不是硬範圍。

### 1.5 抑制故意死亡換開局
- 清單降低可見資訊，但星球和家業仍可提供推測，不保證玩家無法選擇較有利的開局。
- 死亡後世界前進W＋14～15年；人物與地方依實際歷史改變。N19已由N20取代，沒有自動終局時限。
- 已發生的同一出生實例不重現；同樣戶名組合可能再出現，以孩子與出生實例辨識，不能為防重複強迫家庭改名。

## 三、新戶模板

燈籍人彼此成家，或下山弟子另立門戶，就會出現新戶。模板只展開既有燈籍人物的成家與立戶，不憑空生成父母。成家、遷居、出生各有世界日期與來源。

| 欄位 | 生成方式 |
|---|---|
| 地點 | 從 ATLAS 既有地點中選取，優先選「匿名、庇護、避難」性質的地方（例如深淵避難城區、神經網離線聚落） |
| 家業 | 取該星球的主要產出（ATLAS 的出口欄） |
| 對外身分 | 依家業 |
| 知情 | 新戶多半知情；但沒有祖傳的藏身方法 |
| 開場處境 | 取該地點既有的在地矛盾 |
| 時代掛鉤 | 一到兩個依時代而變的事件（多取自事件池） |
| 家人 | 引用已存在的燈籍人物ID及親子關係；兄弟姊妹須有實際出生紀錄 |

**範例**：錨家（v1 的第 7 戶）改為新戶模板的示範：深淵沉錨星墜索鎮，打撈工，在地矛盾是打撈商優先救貨不救人。

## 四、開場類型

不是每一輪都「覺醒、家裡有事、離家」。

| 類型 | 說明 | 例子 |
|---|---|---|
| 離家 | 家裡有事需要有人出門，主角順勢離開 | 卜家押糧箱出星 |
| 留家 | 家裡就是事件的中心，主角可以選擇不走 | 夏家被懷疑盜賣航圖；主角留下來洗清家人的嫌疑 |
| 危機 | 盤查、追殺、災難正在發生 | 蒐集時代的白家：封存室被要求交出受庇護者名單 |
| 秘密 | 家人不知道自己是誰，主角知道 | 林家：主角覺醒後讀得見命線，要決定告不告訴家人 |
| 接續 | 前世認識的人或地方就在附近 | 魏家在破爛一條街，須先確認拾六在世與所在地、紅的燈實存且保管鏈可查，才可接續 |

同一戶在不同時代可以有不同類型：例如夏家在燈下時代是留家型，在蒐集時代是危機型。

## 五、同一戶再次落點

- 主角可能在不同世落在同一戶（只要不違反直系規則）。
- 不保證一定跨代：若前世早逝，原父母後來仍可能生子；是否可成為該落點須依採用的親屬規則核對，不能逕自禁止或保證。
- 開場處境不同；主角記得這個家以前的樣子，家人是否知情依先前是否告知與相認，不重置既有知識。
- 可觸發一次性的記憶事件（例如認出祖母年輕時的照片）。
