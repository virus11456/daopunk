## 二、細節方案（F01～F05；皆為提案，暫不定案）

### F01　N29 單人承接：主角如何完成「接上」與「切斷」

**約束**：不能把陸吾或閻羅本人協助設為必需。已定必要法則：命運。

| 步驟 | 候選 | 代價 |
|---|---|---|
| **接上** | 甲：命運＋主角「未交接」的靈魂狀態（師父的剪刀讓他的靈魂不經交接，不會在渾沌中被洗散） | 不需額外法則；把剪命與終局接起來。風險：把剪命變成「為此而設」，需在台詞中保持師父動機的模糊 |
| | 乙：命運＋輪迴 | 需另取得輪迴（G01）；增加門檻 |
| | 丙：命運＋《守一不散》 | 需另取得靈魂法則（A01）；增加門檻 |
| **切斷** | 甲：命運（在接上之後，以命運找出造物主與夢相連的那一條，放開它） | 不需額外法則 |
| | 乙：因果《返因》（截斷一個必要環節） | 需另取得因果（K01） |
| **遮掩** | 無閻羅時沒有遮天掩護；燭陰會察覺。處理：察覺後燭陰開始睜眼，主角必須在「眼睛睜開之前」完成切斷。完成則弒神成立；來不及則行動中止、主角被推出夢心、可暫離（**不自動轉入喚醒**，因為睜眼到一半又闔上） | 形成終局的緊張段落；不需任何道主協助 |
| | 若主角自己持有遮天的傳奇版《藏命無痕》：只能藏自己，不能藏切斷的動作；可延長主角在夢心不被燭陰「看見」的時間，但不取消察覺 | 可選的助力，不是必需 |

**我的建議**：接上用甲、切斷用甲（只需命運），遮掩採「燭陰睜眼前完成」的限時段落；已持有遮天傳奇者可延長時間。這樣單人路線只以已定必要法則（命運）成立。

### F02　N32 主角擔任輔助者：誰做夢、誰修補、誰守夜

**約束**：一人不能同時占兩職；需說明誰能維持創世（修補）與遮天（守夜）。

**問題**：主角能取得的只是**傳奇版**法則（有限），不是道主的完整法則。若陸吾做夢，修補需要創世，只有陸吾有完整創世；主角的《一方小天地》不足以修補整個夢。

| 候選 | 規則 | 可行組合 | 代價 |
|---|---|---|---|
| **甲 主角只能做夢** | 三方共治中，主角必為做夢者；陸吾修補、閻羅守夜 | 一種 | 刪掉「主角也可以是輔助者」；共治的選擇性變少 |
| **乙 夢心放大傳奇法則** | 在夢心附近，傳奇版法則被放大到足以輔助；主角可擔任與自己所持法則相符的輔助位 | 做夢＝陸吾：閻羅守夜＋主角修補（需持創世傳奇）；做夢＝閻羅：陸吾修補＋主角守夜（需持遮天傳奇） | 需新增「夢心放大」規則；主角被綁在崗位上，也不能再回夢中生活 |
| **丙 做夢者不能是道主** | 道主做夢會把自己的法則帶進夢心，破壞主從結構；做夢者只能是主角 | 同甲 | 為甲提供世界內理由；但與陸吾「想成為做夢者」的動機衝突，陸吾會在此處反目 |

**我的建議**：**乙**。理由：保留「主角選擇不做夢、只當守夜人」這個強烈的結局選擇；放大規則只在夢心成立，不影響其他地方的法則邊界。前提是主角已取得對應的傳奇法則（Y01 遮天或 L01 創世）；沒有就只能當做夢者。

### F03　N33 閻羅拒絕：失去遮天後如何執行

**約束**：保留「主角做夢、陸吾修補」；不把閻羅寫回守夜。

| 候選 | 內容 | 代價 |
|---|---|---|
| 一 陸吾以創世造「夢殼」 | 陸吾在切斷點周圍造一層臨時的殼，吸收切斷時的震動，降低燭陰察覺的程度；這屬於他的修補角色 | 夢殼拆除後留下**永久裂痕**（世界損害，不可復原）；燭陰仍可能察覺，只是較慢 |
| 二 分段切斷 | 分數夜逐步切斷，每夜幅度小 | 每一夜都有被察覺的風險；耗時長，期間世界惡化加劇 |

### F04　N30 作者答案：不可再生之物（作者層，不在遊戲揭露）

**約束**：非歸墟破碎造成；符合 N12 人類不歸零。

| 候選 | 不可再生之物 | 作用鏈 | 與 N12 的相容 |
|---|---|---|---|
| a 人身之緣 | 靈魂落生為人類的「緣」 | 先人順命線開闢的航路，本身由人類與夢外相連的線織成；每走一次，就消耗一部分「緣」，之後落生為人類的靈魂變少，改落為其他生命 | 歸墟是夢外真實的倒影（N31）；倒影持續映照夢外，會緩慢生出少量新的「緣」，所以人類減少但不歸零 |

**我的建議**：**a 人身之緣**。與 N31 倒影互相支撐，自然給出「減少但不歸零」的底線；也與「轉生同門可能是任何生命」的已定設定一致（緣不足時，同門轉生為非人類）。
