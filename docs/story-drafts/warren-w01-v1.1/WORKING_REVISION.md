## 四、沃倫怎麼知道主角會輪迴【提案】

沃倫是道主，知道世界是夢【已定】，但**不自動知道**主角會帶記憶轉生。他得知的途徑（任一）：

| 來源 | 條件 | 沃倫知道多少 |
|---|---|---|
| 主角自己說出 | 任一場景中主角選擇透露 | 知道「此人自稱會帶記憶轉生」 |
| 記憶公證所 | 〈我記得〉結果為「受理前世記憶」，且主角曾在公證所證明自己 | 知道公證所證明過的內容；需付費調閱（公證所可拒絕） |
| 其他道主 | 閻羅 X、蓋亞之一曾向沃倫提起（依其關係，非必然） | 只知道「有這樣一個人」，不知道他這一世在哪 |

**沒有任何來源時**：沃倫只把主角當成一個讀契約很仔細的年輕人。W-2 的「延續」條款仍存在，但他不會特別說破。

## 五、契約的四層【提案】

沃倫的契約有四個層次，每一層各自成立或不成立。

| 層 | 意思 | 本篇的設定 |
|---|---|---|
| **聲稱** | 契約上寫了什麼 | 可以寫任何東西 |
| **司法效力** | 商盟的商事庭是否承認 | 商事庭承認「今生」的條款；「延續」到下一世的條款，只有在**公證所證明為同一人**時才可能被審理，而且商事庭從未判過這類案子 |
| **執行** | 誰去討、怎麼討 | 沃倫的查訪員；靠查訪、情報、人情，不是法術 |
| **法術效力** | 契約是否帶有法則的力量 | **本篇不設**。是否存在「契約追蹤術」列為待作者定案（第九節第一題） |

**不論哪一層，契約都不能**：
- 扣走主角已跨世保留的未花功德、已學仙術、已得法則、記憶【已定：這些跨世保留】。
- 指定主角下一世的落點【已定：燈籍新生兒；依燈籍家庭 v1.1 由主角從待產清單選擇】。
- 凍結或加速主角的承載時間。
- 讓任何人把主角「帶回」他前世的身分。

## 六、場景

### W-1｜帳簿塔下
- **地點**：萬衡京，秤臂形交易議宮外的廣場；帳簿塔（新增景觀）在頭頂緩緩翻頁。
- **處境**：賣香料的**阿衡**（提案）拿著兩份文件站在廣場上。債權人主張兩件事：
  1. **貨權**：依契約附加條款「遇不可抗力時，貨權轉歸債權人」，她倉裡的香料歸債權人。
  2. **店舖所有權**：依另一份擔保書，她的店舖作為借款擔保，債權人要求過戶。
- 「不可抗力」的定義寫在一份附件裡，阿衡說她從沒拿到那份附件。
- **對白**
  > 阿衡：「他們說香料是他們的，店也是他們的。」
  > 主角：「兩件事分開看。香料是一份契約，店是另一份。」
  > 阿衡：「有差嗎？」
  > 主角：「有。一份輸了，另一份不一定輸。」
- **調查**（非戰鬥，可複選）
  - 讀契約：找出附件是否曾交付（交付紀錄在帳簿塔的公開索引中可查）。
  - 讀擔保書：擔保範圍是否包含整間店，還是只有店內設備。
  - 找其他被同一條款波及的商戶。
  - 觀命（須阿衡同意、找對命錨）：對象是阿衡；條件是「申訴」或「不申訴」。示例：申訴後一季內保住店舖 約四成；只保住部分貨權 約三成；看不清 約三成。
- **結果**
  - 查到附件未交付：阿衡可以在商事庭**主張**貨權條款對她無效。這是申訴的開始，不是勝訴。商事庭約一個月後開庭（提案）。
  - 擔保書的範圍：若只含設備，店舖所有權的主張站不住；若含整間店，需另外爭。
- **沃倫在場**
  > 沃倫：「你讀契約的樣子，像在讀一個人的命。」
  > 主角：「它就是她的命。」
  > 沃倫：「說得好。可惜命不能轉讓，契約可以。」
  > 沃倫：「一個月後開庭。你會來嗎？商事庭很無聊，我保證。」
- **變體**
  - **拒絕**：阿衡自己申訴，但沒找到附件的交付紀錄；貨權照契約轉移。
  - **缺席**：同上；店舖所有權依擔保書範圍而定。
  - **晚到**（主角到衡金星時已過開庭）：阿衡已經輸了貨權；店舖的爭議仍在，主角可以幫她打第二件。
- **寫入**：`阿衡_貨權：主張中｜勝｜敗`、`阿衡_店舖：主張中｜勝｜敗`；沃倫對主角的狀態 `有趣`。

### W-1b｜商事庭（一個月後）
- **條件**：主角在 W-1 查到附件未交付，且一個月後仍在衡金星或趕回來。
- **結果**（依調查與陳述）
  - 貨權：附件未交付，條款對阿衡不生效；香料歸還。
  - 店舖：依擔保書的範圍判。
- **缺席**：阿衡獨自出庭；結果依她手上的證據（主角若已把交付紀錄抄給她，勝率較高）。
- **寫入**：更新 W-1 的兩項旗標。

### W-2｜沃倫的契約
- **開啟條件**：W-1 之後。
- **地點**：秤臂形交易議宮的私室。
- **沃倫的提議**
  > 沃倫：「我可以資助你。你要去哪裡、要找什麼，我不問。」
  > 主角：「條件呢？」
  > 沃倫：「全寫在這裡。你慢慢讀。我最喜歡看人慢慢讀。」
- **契約全文（可閱讀）**

  | 條 | 內容 |
  |---|---|
  | 一、標的 | 甲方（沃倫）提供乙方：衡金星至萬舶星的船位三次；商盟通行證一張；生活費，每月上限為「一名港口書記的月俸」 |
  | 二、期限 | 自簽約日起五年 |
  | 三、乙方義務 | 乙方於期限內發現的航路、遺物、交易機會，甲方有**優先購買權** |
  | 四、違約金 | 乙方違約，違約金按月複利計 |
  | 五、延續 | 本契約之權利義務，及於乙方**今生及其延續之一切時間** |
  | 六、爭議 | 由商盟商事庭管轄 |

- **可以讀出的問題**（主角讀得出，也可能漏讀）
  - 第五條：對一般人只是「一輩子」；對會輪迴的人，可能被主張為「每一世」。
  - 第三條：「發現」的範圍沒有上限，包括主角從前世記得的東西。
  - 第四條：按月複利的違約金，五年後會很大。
- **選項**
  - **指出第五條**：
    > 主角：「『延續』是什麼意思？」
    > 沃倫：（大笑）「你讀到了。」
    > 沃倫：「我只是好奇：一個人的下一世值多少錢？」（若沃倫已知主角會輪迴，他會補一句：「你就是那種人，對吧？」）
    - 可以要求刪第五條。沃倫同意刪。
    - **刪了第五條不代表其餘公平**：主角還可以要求修改第三條（限定為「本契約期限內、以甲方資助所得」的發現）與第四條（改為固定違約金）。沃倫逐條討價還價：
      > 沃倫：「第三條可以改。第四條不行，那是我唯一的保障。」
      > 主角可以接受、繼續談、或拒簽。
  - **沒讀出、直接簽**：契約成立。後果見 W-2b。
  - **拒簽**：
    > 沃倫：「好。你是第一個拒絕我還讓我覺得賺到的人。」
- **寫入**：`沃倫契約：未簽｜已簽_全條｜已簽_刪五｜已簽_刪五改三｜已簽_刪五改三改四`。

### W-2b｜查訪（僅在簽了第五條時）
這不是一個場景，而是一組依世界時間發生的事件。

- **這一世**：沃倫的查訪員定期來確認主角的履約狀態。
- **主角死亡後**：
  - 沃倫**不會自動找到**主角的下一世。
  - 查訪員只能靠線索找：有沒有人知道那份契約的內容？有沒有人讀契約的方式特別像？
  - **可能的結果**（依世界狀態與主角的行為）

    | 結果 | 說明 |
    |---|---|
    | 查不到 | 多數情況。主角不說、不去商盟，查訪員就找不到 |
    | 延遲 | 查訪員在主角覺醒後數年才找到線索 |
    | 錯認 | 查訪員找上一個無關的人。主角若得知，可以選擇介入（替無辜者澄清，會暴露自己）或不介入 |
    | 找到 | 主角自己去商盟、或自己說出、或被公證所證明 |

  - **找到之後**：查訪員拿出契約。主角可以：
    - 在商事庭主張「延續」條款對下一世不生效（商事庭從未判過；結果依公證所是否證明為同一人）。
    - 找沃倫本人談：沃倫可能直接撕掉第五條，因為他「只是好奇」。
    - 無視：查訪員會反覆出現，但沒有法術效力，無法扣走任何跨世保留的東西（第五節）。
- **燈籍安全**：查訪員找主角時，可能順帶查到他這一世的家庭。這是簽下第五條最實際的風險。
- **寫入**：`沃倫查訪：未找到｜延遲｜錯認｜找到`。

### W-3｜未出生者的時間（《借一刻》任務途徑）
- **開啟條件**：W-2 之後，沃倫提出；或主角在商港城區（U-005-P1-C1）自行發現。商港城區的 ATLAS 地方矛盾是「小商隊無法負擔旺季泊費」；本事件是其延伸（提案）：付不起泊費的移民家庭，以勞務合約換取入港。
- **處境**：勞務合約的附則寫著：若本人無法完成勞務，由其**尚未出生的子女**繼續履約。
- **沃倫的請求**
  > 沃倫：「有人在我的港口，拿還沒出生的孩子做抵押。它合法，因為沒有人說它不合法。」
  > 沃倫：「你去找出來。如果你能讓我承認它不該存在，我就撕掉它。」
- **調查**（非戰鬥）
  - 找到簽下這類合約的家庭（須取得同意才能看合約）。
  - 追到擬約的代書與承攬商；查出這批合約的債權是否已被轉售。
  - **觀命的對象是母親**，不是尚未出生的孩子。條件：須母親本人同意，且找對她的命錨【已定：觀命需找對命錨】。觀測對象：母親在「合約維持」與「合約撤銷」兩種條件下，一年內的走向。
  - 母親可以同意被觀命，但她**不能代替孩子**同意任何事。
- **核心論點**（取代 v1 的「價格無法計算」）
  > 主角：「這份合約的問題，不是它的價錢算不出來。」
  > 主角：「是她沒有權利賣。那是另一個人的未來。那個人還不存在，沒辦法說不。」
  > 沃倫：（很久）「……契約的兩方，有一方不存在。」
  > 沃倫：「那就不是契約。那是一張寫了字的紙。」
- **結果**
  - 成功：沃倫承認「無權代他人出售未來」。進入 W-3b 的正式程序。
  - 部分成功：沃倫承認這一份不該存在，但認為規則要由理事會改。進入 W-3b，只處理單案。
  - 失敗（主角只論證價格）：沃倫說「那我給它定一個價就好了」，不撕；任務失敗。**同一世**可以帶新證據再試（例如找到代書承認明知不合法的紀錄）。
- **寫入**：`沃倫任務_論點：無權代賣｜價格`。

### W-3b｜撕紙之後（新增）
- **撕紙是象徵**：沃倫在議宮當眾撕掉一份合約。這一幕會上報刊，但撕紙本身不改變任何法律狀態。
- **正式程序**

| 項目 | 處理（提案） |
|---|---|
| 撤銷 | 單案：沃倫以債權人身分放棄該份合約的附則。制度：沃倫在理事會提案，宣布「以未出生者履約」的附則一律無效；需衡金星主公告 |
| 債權轉售 | 若該批合約的債權已被轉售給第三方，沃倫需**回購**（單案）或理事會宣告轉售無效（制度）。第三方可能抗議，理事會內部有人反對 |
| 已履行者 | 已經工作的家長：已完成的勞務照付；未完成的部分，其子女的履約義務作廢 |
| 港口居留 | 居留與合約**分開**處理：撤銷附則不影響已取得的居留 |

- **理事會的阻力**：ATLAS 萬衡京的地方矛盾是「商盟理事將公共航路私有化」。反對制度改革的理事，也是推動航路私有化的同一批人；主角可以找出這層關係（紀錄層級證據），作為說服其他理事的依據。
- **寫入**：`未出生者合約_單案撤銷`、`未出生者合約_制度改革：通過｜否決｜未提`（兩者分開）。
- **缺席**：主角不在場時，制度改革在理事會被否決的機率較高；單案撤銷仍會發生（若 W-3 成功）。

### W-4｜資料的價格
- **開啟條件**：主角追查追殺事件或燈籍洩漏（接第四批、P01 人類登錄）；或在蒐集時代以後到商盟。
- **地點**：舊市城區（U-005-P1-C2）的地下拍賣廳。ATLAS 地方矛盾是「知名藏家販售精密贗品」；本事件發生在同一個地下市場（接 EV-016，示範事件 30 則 v1.1）。
- **證據鏈**（每一環都要主角實際取得，才能指認下一環）

| 環 | 內容 | 證據 | 取得方式 |
|---|---|---|---|
| 1 | 邊防系統上傳入境紀錄 | 邊防的上傳格式 | 寒序雪關（M01）或其他邊防的公開規格 |
| 2 | 紀錄被匯出到資料整理商 | 整理商的「未登錄旅客往返」整理包 | 在地下市場以買家身分查看目錄 |
| 3 | 整理包被轉賣 | 交易廳的成交紀錄 | 與拍賣廳的帳房談判、或協助記憶公證所比對 |
| 4 | 買家是誰 | 付款帳戶 | 追帳；可能只追到一個空殼商號 |
| 5 | 追捕行動使用了這份資料 | 追兵手上的地址單與整理包格式相同 | 追殺事件中取得的地址單（第四批） |

- **未登錄者不全是人類**：整理包裡大多數是改造人、拼裝機體、難民、失籍者（P01、F01）。人類只是其中極少數。這份資料外流，傷害的是所有未登錄者。
- **沃倫是否知情**（提案）：他知道資料市場存在，不知道被用來追捕。這是他的說法；主角可以相信或不相信。
- **對質**
  > 主角：「有人在你的市場上，賣沒有登錄的人的行蹤。」
  > 沃倫：「我的市場上賣很多東西。」
  > 主角：「那些人會被抓走。」
  > 沃倫：（安靜下來）「……我可以禁止。」
  > 沃倫：「禁止了，它會跑去黑市。價格會漲。我猜十倍。」
  - 「十倍」是沃倫的猜測，不是定律。
- **選項與可能的結果**（皆非必然）

| 選項 | 可能的結果 |
|---|---|
| 要求禁止 | 交易廳不再公開交易；黑市是否接手、價格如何變化，依世界事件而定 |
| 契約解法：未經本人同意的行蹤資料不得交易，違者契約無效、款項沒收 | 沃倫：「你讓違約比守約還貴。這我懂。」是否有效依執行：若沒有人去告，條款形同虛設 |
| 買下一份並銷毀 | 只銷毀這一份；**備份仍在**賣家與其他買家手上 |
| 公開揭弊 | 可要求報刊遮蔽當事人的身分與地址。若遮蔽不完全，或主角指認錯了賣家，錯誤公開的後果由主角承擔（無辜者被騷擾、真正的賣家轉移） |
| 不管 | 資料繼續流通 |

- **寫入**：`資料鏈_已取得：[環數]`、`資料市場_處置`；影響追殺事件與燈籍家庭的風險（世界事件）。

### W-5｜債與夢
- **開啟條件**：主角已知 K5，且與沃倫的狀態至少為「尊重」。
- **地點**：萬舶星保航鎮（U-005-P3-C2）的保單鐘樓；ATLAS 地標「刻著失事航線的保單鐘樓」、地方矛盾「保險商拒賠被封鎖航道」（接 EV-017）。
- **對白**
  > 沃倫：「你知道我為什麼要祂一直睡嗎？」
  > 主角：「因為醒來會毀滅一切。」
  > 沃倫：「那是他們的說法。我的說法是：祂醒來，所有的債都不用還了。」
  > 沃倫：「你以為那是自由？不是。那是所有的承諾都不算數。這座鐘樓上刻的每一條航線，每一個沒回來的人，都不算數了。」
  > 主角：「所以你守著夢。」
  > 沃倫：「我守著帳。帳在，那些人就還在。」
- 這是沃倫的自辯，不是作者判定。主角可以反駁：
  > 主角：「帳在，不代表人還在。」
  > 沃倫：（笑）「對。可是帳不在，連他們存在過都沒人記得。」
- **寫入**：關係變化；無新知識旗標。

### W-6｜借一刻
- **取得資格**（可以同時具備多種；**只能領取一次**【已定】）

| 資格 | 條件 |
|---|---|
| 任務 | W-3 成功（論點為「無權代賣」） |
| 親授 | 簽下公平的親授契約（見下） |
| 擊倒 | 主角在交易議宮挑戰他（戰鬥玩法未定） |

- 具備任一資格時，沃倫都會提出傳授；主角可以選擇領取、或**拒領**。拒領後，之後任何一世再訪，只要資格仍在（任務與擊倒的資格跨世保留，因為是主角親歷），沃倫仍會提出。
- **親授契約全文**（簽前由沃倫逐條說明）

  | 條 | 內容 |
  |---|---|
  | 一、標的 | 甲方傳授乙方時間法則之傳奇仙術《借一刻》 |
  | 二、乙方的承諾 | 乙方從下列選一：（甲）每一世至少來衡金星見甲方一次；（乙）若乙方將站在造物主面前，事先告知甲方（僅在乙方已知此事時可選）；（丙）替保單鐘樓刻一條尚未刻上的失事航線 |
  | 三、期限 | （甲）持續至乙方不再輪迴；（乙）一次；（丙）一次 |
  | 四、不可履行的例外 | 乙方死於抵達前、被囚禁、無法抵達衡金星、甲方已不在衡金星、或世界狀態使履行不可能 |
  | 五、違約的後果 | 甲方不再傳授乙方任何其他事物，並在帳上記一筆。**已傳授的《借一刻》不收回** |
  | 六、不加價 | 甲方不得於簽約後增加乙方義務 |

  > 沃倫：「第四條很重要。你死得早，不算違約。你失聯了，我會等。」
  > 沃倫：「第五條也很重要。我給出去的東西，我不收回。收回的話，以後沒有人會跟我簽約。」
  - 承諾（甲）可能因早死而多世無法履行：依第四條不算違約。
  - 承諾（乙）若無法履行，也**不影響**主角進入任何結局。
- **能力邊界**（依 DAO_RULER_POWERS 限制，提案）
  - 取得有限的時間窗口，用來反應或完成一個行動。
  - 不倒轉世界；【已定】世界時間只往前。
  - 不能無限生出資源、功德或物資。
  - 不能凍結或延長承載時間；不能繞過醫術延壽每世一次的限制。

## 九、仍待作者選擇的兩件事

1. **跨世追索的法術機制是否存在？** 本篇不設。若要有「契約追蹤術」，需定：誰能施、能追到什麼程度（只知道存在／知道宇宙／知道家庭）、是否受遮天或燈籍保護阻擋。它會直接提高燈籍人家的風險。
2. **「每世來訪」承諾是否允許有限改寫？** 例如改為「一生中若能，至少一次」，或改為「前三世」。目前靠第四條例外處理早死。
