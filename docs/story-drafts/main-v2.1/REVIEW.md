# 主線 v2.1｜覆核

十五歲下山、轉生公式、私人會面與無自動終局已更新。仍有跨段落的舊規則，需局部統一，不重開已定設定。

| ID | 問題 | 修訂要求 |
|---|---|---|
| M21-01 | 第四節紅過世後固定拾六接燈、相認、交物；第六節改由紅決定 | 全文改實際指定／接受／保管／身份核對，包含無承接者、燈熄與物件失落，不重置晚年篇結果。 |
| M21-02 | 階段十一直接寫取得命運且能自選記憶 | 完成會面、取得資格、接受傳法分開；自選交接仍須輪迴＋命運。拒領也能完成抉擇前的程序、暫離補条件及後來再領，不鎖死不需命運的候選結局。 |
| M21-03 | K6表格由有真實直接得到兇手；正式對質又可能才補K6 | 真實不自動知全案；依 L11-01／BG15-01 補來源與證據鏈。私人會面可補K6，K6＋K7才進正式階段十；進入不等於完成。閻羅立場可變，不永久鎖定「最終」。 |
| M21-04 | 當世關係列為不保留，與舊識記憶／組織承認相衝突 | 主角新身體不自動被承認，但對方仍記得前世互動。實物仍在世界保管人處，不等於玩家死亡就從世界刪除；住房／繼承依另案，勿由一般物品表擅自否定。 |
| M21-05 | 生死時鐘必留箱／寄信；道主任何時代皆可遇 | 日期標無介入預設，依存活、關係、授權、送達與實存物件。長壽不代表始終可接近；失聯／逐出需替代知識路徑。師父認得不等於隨時在院。 |
| M21-06 | 5～8輪、首輪20小時沿舊量規劃，與遊戲量v2的20輪、每輪3～6小時不一致 | 兩者皆為估算，不能都作同一目標；建議連結遊戲量v2並標待原型驗證，不以一次性劇本量保證100小時。 |
| M21-07 | 半選擇簡化成必有2～3戶；人類衰亡放慢似已證實；壽命延長等同傷害存活 | 候選0／1／多戶、親屬限制按家庭稿提案處理，不保證每次三戶。守護只確定夢延續，衰亡原因未解，不保證速度改變。延壽與抗傷／救治不同，閘門存活要相應能力與實際救援條件。 |

主線章節知識可保留，但仍需位置、人物、事件條件；不是所有開啟条件都只由永久知識構成。新版不用「同主X」含糊引用，請標具體版本與段落，避免再引回固定三世。未接Godot。
