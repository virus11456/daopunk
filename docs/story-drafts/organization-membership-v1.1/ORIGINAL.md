# DAOPUNK｜加入中立組織 設計提案 v1.1

> **起因**：你提到主角可能可以加入中立組織。本文件是故事與世界觀層面的設計提案：入會條件、身分、義務、內部線、退出、跨世承認，以及與燈籍祕密的衝突。
> **v1.1 已定**：殺手組織開放加入；跨世承認採三種方式（重新入會、暗號承認、不承認）；同時加入多個組織沒有上限，由義務衝突自然限制。
> 其餘為【提案】。不定數值、等級、獎勵；未接 Godot。
> **依據**：中立組織篇 v1；完整背景 v1.4；燈籍家庭 v1.1；已定規則（主角完整記得親歷、世界時間前進、每輪身體不同、只有人類能學算命、燈籍與人類身分需要隱藏）。

---

## 一、原則

1. **加入是選擇，不是必要**。主線與結局不要求加入任何組織；不加入的玩家仍可透過消息與支線接觸它們。
2. **加入有代價**。每個組織都有義務、規矩與敵人；加入一個，可能得罪另一個。
3. **組織不知道主角是誰**。主角每一世身體不同；組織只認得「這一世的這個人」。
4. **記憶可以幫忙，但不自動承認**。主角記得前世的暗號、航誌、規矩，可以更快被接納，但要看組織是否接受這種證明。
5. **燈籍的祕密優先**。有些組織要求登錄身分或交出來歷；加入它們，可能讓人類身分曝光。

## 二、跨世承認的三種方式

| 方式 | 說明 | 適用 |
|---|---|---|
| **重新入會** | 組織不知道他是誰，一切從頭 | 多數組織的預設 |
| **暗號承認** | 主角說出前世才知道的暗號、代收號、航誌內容，組織可選擇承認他延續前世的身分 | 黑匣信使局、星際商隊、斷鏈避難網 |
| **不承認** | 組織只認這一世；前世的身分不算數 | 雇傭兵團、殺手組織（若可接觸）、記憶公證所（依〈我記得〉的結果） |

**記憶公證所的特例**：若〈我記得〉的結果是公證所「受理前世記憶」，主角可以請公證所證明他的前世身分；但這需要把他的記憶交給公證所比對，等於讓一個組織知道他會轉生。

## 三、各組織的入會設計

### 3.1 星際商隊（以遠潮為例）
- **入會條件**：在一次航行中證明自己有用（讀航誌、找航標、看得見命線的人天生適合領航）。
- **身分**：航誌員或領航助手。
- **義務**：守商隊的航誌祕密；跟船出航時不能半途離開。
- **可得的（敘事）**：船位、航路知識、港口人脈。
- **內部線**：韋舷與簿九的分歧（賺快錢或找真相）；主角可以站在一邊。
- **退出**：離開不難；帶走航誌祕密則被列為不受歡迎者。
- **跨世**：暗號承認（主角說出前世的航誌內容）。
- **燈籍風險**：領航時看得見命線，太準會引人懷疑。

### 3.2 雇傭兵團（以灰隼、白纓為例）
- **入會條件**：受雇一次，完成契約，不違約。
- **身分**：隊員。
- **義務**：守約；聽隊長的指令；不私下接活。
- **內部線**：灰隼的討薪、白纓的「只護不攻」。
- **與其他組織的衝突**：受雇時可能站到某個星主府或另一個組織的對面。
- **退出**：契約期滿可退；中途退出是違約。
- **跨世**：不承認。兵團只認這一世的戰績。
- **戰鬥**：兵團的工作多半涉及武力；戰鬥玩法未定。白纓只接護送，較適合不想戰鬥的玩家。

### 3.3 拍賣場（以遺珍閣為例）
- **入會條件**：通過一次鑑定考驗（例如分辨一件遺物的真偽）。
- **身分**：鑑定學徒或修復師。
- **義務**：守買家隱私；不得私下交易拍品。
- **內部線**：祁掌櫃重鑑定、閣主重成交量；偽作醜聞。
- **燈籍風險**：主角背過古抄本，鑑定山海相關遺物時太準，可能讓人追問他的師承（接第三批甲-5）。
- **跨世**：重新入會，但記得鑑定知識，考驗容易通過。

### 3.4 星際海盜團（以裂帆為例）
- **入會條件**：替海盜團完成一次航行或一次交涉；新頭目要求參與打劫，老頭目只要求守航道。
- **身分**：領航員（人類看得見命線，天生適合穿迷陣）。
- **義務**：守據點祕密；分贓規矩。
- **內部線**：老頭目與新頭目的分裂；主角可以協助老頭目保住「只收護航費」的規矩。
- **與其他組織的衝突**：商隊、自由港聯席會視海盜為敵；加入後在這些組織中被列為不受歡迎者。
- **燈籍風險**：最高。海盜團內部最先知道「這個人看得見別人看不見的路」，蒐集時代這會成為被出賣的理由。
- **跨世**：不承認。

### 3.5 殺手組織（無聲會、秤）【已定：開放加入】

**與設定包的關係**：設定包寫「不預設讓玩家接刺殺任務」。開放加入後，刺殺委託**只在主角主動入會之後**才會出現，而且每一件都可以拒絕；不入會的玩家永遠不會收到。這保留了原規則「不預設」的精神。

**寫作原則**
- 每一件委託都有具體的對象：一個有名字、有家人、有生活的人。
- 每一件完成的委託，都有家屬與社區的後果場景；不描寫暴力的過程細節，只寫之前與之後。
- 主角完整記得親歷【已定】：他記得每一件他接過或拒絕過的委託，每一世都記得。
- 不把殺手寫成酷炫的裝飾；也不把入會寫成單純的懲罰。

#### 無聲會（暫名）
- **入會條件**：由一位中介引介；在一次「拒單審核」中說出自己會拒絕哪一類委託，並說明理由。無聲會看重的是規矩，不是身手。
- **規矩**（提案）：不接官員、不接孩童、不接為錢以外的恨。成員可以拒單；拒單不受懲罰。
- **身分**：成員。
- **委託的結構**
  1. 中介交付委託：對象、理由（委託人自述）、價格。
  2. 主角可以調查：委託人的理由是否屬實、對象的處境。
  3. 觀命：看對象的命需要**對象同意**；刺殺對象不可能同意。主角可以不經同意偷看，這是越界（與 R01 偷看紅同一原則），後果依對象或其身邊的人是否察覺。
  4. 主角決定接或拒。
- **拒單**：無聲會允許。拒單之後，委託可能轉給別的成員，也可能被整個組織拒絕（若違反規矩）。主角可以追蹤後續，也可以不追。
- **接單並完成**：後果場景（家屬、社區、報刊、巡捕），以及主角自己的記憶台詞。對象的死亡依正常流程交接【Y01 交接印制度】。
- **內部線**：守舊派與求客源派的分裂（中立組織篇）；主角的態度影響分裂的結果。
- **退出**：可以退出；須承諾不說出任何成員與中介的身分（封口）。違反封口的後果由無聲會決定。
- **跨世**：不承認。每一世都要重新引介。

#### 秤
- **入會條件**：接下一件公開標價的委託。
- **規矩**：什麼都接，但價格公開。成員可以拒單，但拒單要付違約金（敘事，不定數值）。
- **內部線**：創立者認為公開價格是一種誠實；後進者只看價格。
- **退出**：不容易；秤認為「價格公開過的人，不能當作沒存在過」。退出的代價由劇情決定。
- **跨世**：不承認。

#### 與主線、燈籍的交會（提案）
- 蒐集時代，可能有人委託殺手組織對付燈籍人家。身為成員的主角可能收到這件委託，或得知有同伴收到。
- 主角可以拒絕、阻止、或利用內部身分提前警告燈籍人家。這是加入殺手組織最尖銳的一種衝突。
- 陸吾與閻羅 X 的計畫不透過殺手組織執行（他們有自己的法則）；殺手組織不承載主線的必要證據。

#### 與其他組織的衝突
- 記憶公證所（若公證所證明某件冒名，而冒名者是會內成員）。
- 雇傭兵團（地下契約與公開契約的界線）。
- 斷鏈避難網（被追殺者的撤離）：同時是兩者成員時，義務直接衝突。

### 3.6 黑匣信使局
- **入會條件**：完成一段投遞，全程不拆信。
- **身分**：信使。
- **義務**：不看信的內容；送達或退回，不得私藏。
- **內部線**：「拒送可能造成傷害的信」與「信使不該看內容」之爭；〈遺失的第十七封〉。
- **可得的（敘事）**：各地渡站的通行、離線通訊的管道。
- **跨世**：暗號承認：信使局以代收號與暗號識人，不看身體。主角記得前世的代收號，就能延續身分。
- **燈籍風險**：中等。蒐集時代，資料掮客想收買信使局的投遞紀錄；主角身為信使，可以選擇保護或出賣這些紀錄。

### 3.7 義體醫師公社
- **入會條件**：協助一次巡診（不需要醫學學位；搬運、記錄、陪伴都算）。
- **身分**：巡診助手。之後若修醫術，可成為醫師（五術之一「醫」；修行路徑未定）。
- **義務**：保護病人隱私與醫療自主。
- **內部線**：與製造商合作或獨立；〈舊件〉。
- **跨世**：重新入會；記得醫術知識，但【已定】醫術修為每世須重修。
- **燈籍風險**：低到中等。公社的掃描可能顯示「未登錄」（Z01）；公社依規定保護病人資料。

### 3.8 廢軌打撈聯盟
- **入會條件**：參與一次打撈，且遵守「先救人」的規矩（聯盟內部對此有分歧，主角加入的是哪一派，決定了規矩）。
- **身分**：打撈工。
- **內部線**：先救人還是先救貨；〈祖先走過的路〉。
- **跨世**：重新入會。
- **燈籍風險**：低。

### 3.9 自由港聯席會
- **入會條件**：成為某個成員港的登記住民或商戶（需要一個港口身分）。
- **身分**：港務協理或商戶代表。
- **內部線**：大港與小港之爭；〈押金〉。
- **燈籍風險**：中等。港口身分需要登記；主角可以用化名，但化名被識破會有後果。
- **跨世**：重新登記。

### 3.10 斷鏈避難網
- **入會條件**：由網絡中的一個人引介，並完成一次撤離協助。
- **身分**：節點聯絡人。
- **義務**：絕不暴露安全屋；絕不記錄被安置者的來處。
- **可得的（敘事）**：撤離管道；在蒐集時代，這是保護燈籍人家最直接的方式。
- **內部線**：只救被追捕的人，還是也救自願離開的人；〈一個節點〉。
- **跨世**：暗號承認，但須引介人仍在世或網絡仍保有暗號紀錄。
- **燈籍的關係**：網絡本身就是燈籍人家可能借助的對象。主角加入後，等於同時守著兩份祕密：網絡的、燈籍的。若兩者衝突（例如為了救一戶燈籍人家，必須暴露一個不相干的安全屋），由玩家選擇。

### 3.11 記憶公證所
- **入會條件**：通過比對考驗（辨識一段剪接過的記憶）。
- **身分**：公證員。
- **義務**：只證明片段有沒有被改過，不判斷內容的道德。
- **內部線**：是否受理前世記憶；〈我記得〉。
- **燈籍風險**：高。公證員需要登記真實身分；且公證所的工作讓同事容易注意到主角「記得太多」。
- **跨世**：依〈我記得〉的結果：若受理前世記憶，可請公證所證明；若不受理，每一世重新入會。

## 四、組織之間的衝突

| 加入 | 會得罪 | 原因 |
|---|---|---|
| 星際海盜團 | 星際商隊、自由港聯席會 | 航道與劫掠 |
| 雇傭兵團（某一次受雇） | 受雇對象的敵人 | 依契約 |
| 拍賣場 | 廢軌打撈聯盟（若拍賣打撈遺物）、抗議的家屬 | 遺物所有權 |
| 記憶公證所 | 無聲會（若公證所證明冒名） | 地下信用 |
| 黑匣信使局 | 資料掮客（若拒絕出賣紀錄） | 蒐集時代 |
| 斷鏈避難網 | 任何在追捕的人 | 撤離 |

**同時加入多個組織**：可以，但義務可能互相衝突。例如同時是信使與公證員，若公證所要求調閱信使局的投遞紀錄，主角必須選一邊。

## 五、加入組織與主線、結局

- 主線不要求加入任何組織。
- 組織可以成為主線的**輔助路徑**：
  - 斷鏈避難網：追殺事件時，協助燈籍撤離。
  - 黑匣信使局：追查洩漏鏈；送信給散落的同門。
  - 星際商隊：前往邊緣世界的航路。
- 終章時，主角所屬的組織會依其立場表態（多半希望世界照常運作，傾向守護夢境；但各組織內部也有不同聲音）。
