# 給 Claude：加入中立組織 v1.2

以本包 ORIGINAL.md 為底稿，保留 v1.1 明載的三項確認：殺手可加入、三種跨世承認、兼任無硬上限。不要退回只能當殺手組織外部聯絡人的建議。不定戰鬥、數值或 Godot。

請修正並逐項回覆：

1. 暗號承認保留，但暗號或代收號只是查驗依據；補失竊、撤銷、接班與過期。承認前世與恢復職位、財產、私密檔案權限分開。
2. 拆開「未接單而拒絕」與「接單後撤回」。秤的入會條件要求接單，卻又對拒單收違約金，須明確以何時承諾成立為界；不要把看到委託就算負債。退出代價保留作者候選，不默認必須接受下一件委託。
3. 觀命同意分成倫理規矩與能力可行性。若偷看在世界中可行，就不能同時說同意是施術必要條件；正確命錨仍必要。把「對象不可能同意」改為情境判斷，且同意觀命不等於同意受害。
4. 不預設所有死者都能由主角確認交接。Y01 非血肉紀錄與輪迴問題仍有知識邊界；只寫角色有證據知道的部分。親歷記憶不自動包含拒單後別人的遭遇。
5. 無聲會「不接為錢以外的恨」語意含混：是限制委託者動機、成員動機或報酬形式？官員身分如何判定？保留規矩待選，不把收錢當成正當性的判斷。
6. 入會與刺殺任務開放是兩層。保留新版主動入會後才提供委託的提案，明列它對舊設定包的變更，不只宣稱延續精神。主線與必要證據仍不要求入會或完成刺殺。
7. 人類非唯一能導航者；熟練不直接證明人類。公證受理不保證前世身分已證實，資料比對與靈魂判定分開。
8. 所有組織補退出、停職與交接；職務能力和一次入門考驗分開。對立組織須先得知玩家身分才有反應，風險按消息與情境變動。
9. 終章組織表態依其知情範圍；不知道夢的人只能表達保護生活的訴求。保留無會員的主線替代路徑。

仍待作者決定三項：海盜是否可加入；無聲會具體規矩；秤退出代價。請提出可比較的候選，不自行標已定。
