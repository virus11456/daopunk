# 給 Claude：B01 聚變篇 v1.1 修訂

請以我最後提供、場景已改 B-1～B-6 的《試的人》為底稿，參照本包 REVIEW.md，交付完整 v1.1 與 BR01～BR15 逐項回覆。不要重寫其他篇，不定戰鬥或數值，不接 Godot；新細節仍標提案。

保留人物核心、失敗陳列室、「這個試壞了，就沒有下一次了」、改善居民生活的解法，以及薄牆替代入口。首都星補熾衡星。頁首改為世界持續前進與惡化、最終抉擇由玩家觸發；不要恢復時限自動結局。

重點修訂：

1. 明確分開工程成功、居民受害、任務成功、道主仍願授法。居民受害不算保護任務成功；若保留他仍想授法，作獨立的道德衝突提案，保留追責與補救，不用獎勵洗掉後果。
2. 不以做滿兩項自動成功。撤離不等於同意永久拆屋；補安置、异議、停止條件。說明遷基城為何原本移動；安全中止也可成功，配套修改授法台詞。
3. 觀命居民只給條件分支，不直接提供全城工程答案。區分命錨與空間錨；排熱减半只是待驗證預估。
4. 薄牆須能定位兩端才能配合折界步；補探測、另一端錨點、往返與中止流程，保留提案身分。不能免費到夢底，不能形成取得法則與進入入口的循環依賴。
5. 依玩家知識改 B-3 台詞；B-4 補聚變得知輪迴的來源。跨世認人需要確認，不是自動全知。聚變所謂試驗都有下一次是人物盲點，允許主角指出居民沒有重來。
6. 好奇不等於承諾喚醒；終章到場須邀請、路線及當時可用狀態。道主不老死不等於永遠在場。
7. 親授題需具體可行方案、證據與居民意願；累世知識需更新。三途徑資格可並存，法則只領一次；拒領保留資格，不用重新考試。
8. 通知一個月以世界日期起算；延期、中止、缺席結果皆持續。補關係升至信任、冷淡來源，以及工程、居民、授法、知識、立場的分離旗標。
