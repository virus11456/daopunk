# B01 最新對話稿｜結構摘要

來源：使用者最新貼文 B01 聚變篇 v1《試的人》，內文已改 B-1～B-6。此為編輯摘要，非逐字原稿。

聚變掌管空間，駐元素洪爐萬相京。他把失敗當試驗，卻不理解失敗可能是別人無法重來的生活；對喚醒造物主動搖，想知道卻不願自己試。

| 場景 | 核心內容與依賴 |
| --- | --- |
| B-1 搬家的街 | 冷卻城區重構通知，居民需搬遷；主角可整理生活需求、觀命、提議分段或離開。聚變開始理解搬家成本。 |
| B-2 高風險的重構 | 遷基城停城試驗；知情、撤離、觀命、分段；完成或中止且居民未受害為成功。原稿另寫受害後聚變仍願授法，需對齊 B-6。 |
| B-3 失敗陳列室 | 萬相京儀器發現薄牆；《折界步》加聚變同意作邊緣世界替代入口，保留航路偏離主要入口。 |
| B-4 如果祂醒了 | K5 與信任門檻；聚變承認這場試驗可能沒有下一次；主角回應影響立場。 |
| B-5 他沒想過的解法 | 以居住穩定為核心解答地方難題；過往經驗可協助，接受解法可親授。 |
| B-6 折界步 | 任務、親授或擊倒取得一次空間法則；有限距離或既有錨點，須定位兩端，不免費跨宇宙、不直達夢底。 |

後續：地方結果跨世延續；聚變保存記憶但須確認新身體的身分；陳列室隨時代增加內容。終章可傾向喚醒或不介入。
