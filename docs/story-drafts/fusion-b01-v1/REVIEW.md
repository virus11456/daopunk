# B01 審閱｜最新 B 編號版

## 可保留的核心

陳列室與居民生活的對照能使聚變的缺點具體化；「有沒有下一次」也呼應主角輪迴而世界不重置。中止危險試驗仍可成功、薄牆只是替代入口，均值得保留。場景編號已修正。

| BR01 | 頁首「時代延續到時限」沿用已撤回版本 | 改世界持續前進與惡化、結局由玩家觸發。不能把喚醒的不可逆性寫成自動倒數結局。 |

| BR03 | B-2 居民受害仍授法，B-6 卻只列任務成功 | 任務判定與道主授法意願分開。建議受害不算任務成功；若保留他仍提議傳授，明列獨立且有爭議的親授事件，不抹除傷亡、責任與修復。這是待作者選擇的提案。 |
| BR04 | 做「至少兩項」可能跳过關鍵前提；同意或撤離混同 | 改按實際條件判定：受影響範圍、知情與異議、必要安置、停止條件。撤離不代表同意永久拆屋；住處、工作、學校、返回安排分別處理。居民活著也不代表未受害。 |

| BR07 | 薄牆表示容易穿越，卻不等於已知另一端 | 加定位與穩定空間錨的前置流程，例如探測後建立可驗證的另一端錨點（提案）。空間錨與觀命的命錨分開；具備往返、失敗及中止條件。不讓取得折界步反過來要求先走此入口。 |
| BR08 | B-3 自動叫出邊緣世界；進入與主線揭露混同 | 未聽過名稱時改為詢問。分開得知薄牆、端點定位、聚變許可、可通行與 K5／主線揭露旗標。早期誤入不自動獲得夢底真相；主要入口保持可達。 |
| BR09 | 聚變知道輪迴、確認新身體缺來源 | B-4 增加聚變已知輪迴的來源；再訪用共同經歷或先前約定確認身分。記得舊人不等於看穿所有新身體。道主不老死也不代表被逐出夢外後仍能接待。 |
| BR10 | 「全是有下一次的東西」易變成世界替他卸責 | 保留為聚變的盲點，允許居民或主角指出作品可重做，死者與失去的生活不能回復。也不保證造物主醒後主角還能轉生。 |
| BR11 | 「我想知道」直接變成支持喚醒 | 好奇、願承擔風險、政治立場分開。回應可增加傾向，正式協助要再確認；終章到場需邀請、可達路線和道主當時狀態，不自動出現在夢底。 |
| BR12 | B-5 任意新解答就授法；拒領似乎需重考 | 提供可選方案及證據、居民意願和可行性判準；穩定不是強制所有人留下。舊經驗須核對現況。拒領保存既得資格；領過法則後再解題只改地方結果，不再刷法則。 |
| BR13 | 三途徑互斥與單次領取混同 | 取得資格可同時成立，只在領取時一次寫入法則；保存來源，不因拒絕消耗。擊倒後傳授與逐出夢外先後另留接口；玩家取得有限能力，不移走道主全部權能。 |
| BR14 | 一個月後拆街無起算；跨世重現恐重置 | 以世界中的通知日期起算，延期與中止改日期；晚到只能看到結果或後續。再訪不是重新拆同一條街；其他居民承接須是新事件實例。 |
| BR15 | 少量旗標無法支援結果與終章 | 分開工程狀態、安置與居民受害、補救、授法資格／提議／領取、關係與政治立場。列出信任建立途徑及冷淡寫入來源；不能只列讀取。 |

## 修訂稿需要通過的情境覆核

1. 第一世且未知邊緣世界：不自動使用未學名稱，不被當成已輪迴多次。
2. 未接 B-1、很晚抵達：按世界通知與施工紀錄呈現結果，不從抵達重新倒數。
3. 只完成任意兩項準備：若居民安置仍缺漏，不能自動判成功。
4. 居民安全但試驗中止：能保留成功；傳授台詞改為「你讓我停下來了」，不沿用「你讓我試了」。
5. 居民受害：工程成功不等於任務成功，拒收法則不會回復傷亡。
6. 只有薄牆資料、沒有另一端位置：不能直接折界；不能借此免費抵達夢底。
7. 同時取得任務與親授資格：法則只領一次；拒领後不強迫重做已完成任務。
8. 道主已離開夢內或主角未邀請：終章不憑空出現。
9. 世界前進許多世：沒有逾時自動結局，地方歷史與未解責任持續存在。
