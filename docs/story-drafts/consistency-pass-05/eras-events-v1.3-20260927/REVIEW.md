## 六則示範逐條檢查

- **EV-U001-001（L181）**：補狗本人與正確命錨條件、實際觀命節點、失蹤世界起算日、三天結算與每項選擇結果；主人提供的是候選資料。缺席抽樣不能覆蓋救援。
- **EV-U001-017（L189）**：兩人各有對象、命錨與完整節點；留越界選擇但依 N36 以身體跡象推知，不能一般人直接感知觀命。結婚／分開的世界結算與消息取得要分開。
- **EV-U001-033（L200）**：補報刊版次與刊期、原傳聞來源、實際死者與證明可達性、追查各結果和缺席；三人轉述同一來源不等於三份獨立證據。
- **EV-U001-B13-01（L207）**：地點修正接受；補離開、不可觀測及缺席。鳥群延遲為候選異象，不因日期／夢動切換保證親見或重置首次；抄本及知情人須實存可達。
- **EV-U001-051（L215）**：綁既有家庭、人物與當時地址；通知選項不等於成功送達／搬離，問話不等於真話。補各結果、離開、既有成果優先與缺席結算；盤查不直接改燈數。
- **EV-ANY-090（L222）**：補可觀測範圍與時點、記錄／查詢／離開及缺席；新聞需實際來源、刊登與送達，不保證隔天。到過夢底仍只起疑。
