## 一、原則

1. **時代由世界時間決定，不由玩家的輪數決定**。世界經過一個年代，不等於玩家親歷了它；玩家可能跳過整個年代。玩家可能在一個時代裡活完一生，也可能一死就跳過一整個時代。下一輪的開始時間＝死亡時間＋等待燈籍新生兒的時間＋十四到十五年【已定，你的更正】。
2. **人物的生死依世界時間與實際事件**。下表的死亡年份是「沒有人介入時」的預設；玩家的行動可以改變（例如救了誰、讓誰提早離開）。
3. **地點每個時代有不同狀態**，但保留前一個時代留下的痕跡。
4. **事件池是可重複內容的主體**；一次性劇本（主線、人物篇、道主篇）約佔一半是內容規劃提案，尚未實測。
5. **無自動終局**【已定 N20，取代 N19】：世界持續惡化；最終抉擇由玩家觸發。
6. **實際狀態優先**：本檔所有表格都是**無介入示例**；人物生死、物件保管、地方事件以實際紀錄為準。
7. **夢動是狀態，不是年代**：夢動可反覆出現與消退；消退只停止或減弱當前的異象，**不復原**已發生的死亡、拆除、遷移與政治結果。
8. **時代數量不固定**【已定 N27】：世界持續延續；世界年代依時間及實際世界事件劃分，不由輪數計數。玩家親歷的年代數依存活、轉生等待與行動而異。

## 二、時代

### 2.0 時代怎麼產生【提案】

- **世界年代**：前四個年代以世界事件為界（示例）；這是世界的年代，不是玩家必經的關卡。邊界事件若因玩家行動而未發生（例如閘門風險被消除），改以地方版本或時間界線替代。
- **延續時代**：第四時代之後，世界每隔一段世界時間（建議約二十到三十年）進入一個新的延續時代。延續時代的名稱與樣貌由當時的世界狀態生成（見 2.4）。
- **夢動狀態**：依本稿任何年代皆可能的提案，作為年代之上的狀態，不限延續年代。啟動／消退的因果條件及惡化門檻仍待設計；計畫狀態與異象狀態分別記錄，消退不復原永久後果。沒有自動終局。

### 2.4 延續時代的生成方式【提案】

延續時代不需要逐一手寫，由以下要素組合：

| 要素 | 來源 |
|---|---|
| 名稱 | 取自當時最顯著的世界狀態（例如「新街」「空座」）；「無燈之年」只可作地方名或比喻，不代表全人類熄燈 |
| 燈籍 | 燈數依世界事件增減【已定：不會歸零】 |
| 地點狀態 | 沿用前一時代，套上該時代的變化（重建、荒廢、易主） |
| 人物 | 第一代人物多已離世；新人物依既有家庭或組織、地方人物來源設計；人類必須符合已定人口與出生限制，不能用生成新組織人物規避家庭邊界 |
| 組織 | 已收十一類中立組織依前一時代的實際結果延續或改組 |
| 事件池 | 大部分事件模板的「一般變體」可用；少數模板有延續時代專屬變體 |

延續時代讓遊戲可以一直走下去，但不需要為每個時代準備完整的新內容。

### 3.3 事件模板結構

以下欄位分為模板定義與實例紀錄：template_id、條件及敘事分支屬模板；instance_id、觸發日期、人物綁定、抽樣與結果屬各實例。年代條件與夢動狀態條件分列，不共用第五年代值。

| 欄位 | 內容 |
|---|---|
| template_id | 模板 ID（正式全池 ID 查重後指定；草稿先用批次命名空間） |
| instance_id | 每次實際生成的實例 ID |
| 作用域 | 地點／人物／年代；同一人物的同一歷史不可復活重做 |
| 世界觸發日 | 世界型事件依世界条件記錄發生日；玩家到場型依其觸發條件生成。另記玩家遭遇日、缺席結算日及知識取得日，不互相冒充 |
| 已結算結果 | 實例結算後的結果；不因讀檔或夢動切換重抽 |
| 持久化抽樣 | 缺席結果只抽一次並存檔 |
| 類型 | 見 3.2 |
| 地點條件 | 宇宙、星球、地點類型（街區、港口、農地、寺院等） |
| 年代條件／夢動條件 | 分別記可出現的世界年代與獨立夢動狀態 |
| 前置條件 | 知識旗標、人物狀態、世界狀態（例如「紅在世」「閘門已發生」） |
| 排除條件 | 已發生過、人物已死、互斥事件 |
| 觸發方式 | 進入地點、與人交談、時間到達、世界事件連動 |
| 開場 | 一到三句 |
| 選擇 | 至少一個非戰鬥選項；至少一個「拒絕或離開」選項 |
| 觀命節點（若有） | 觀測時點、對象、條件、互斥結果與看不清的餘量（格式依 X01 v1.1） |
| 結果 | 寫入的世界狀態、人物狀態、圖鑑、知識旗標 |
| 時代變體 | 不同時代的開場與結果差異 |
| 缺席結果 | 主角不處理時世界怎麼演變 |
| 可重複性 | 一次性／每年代一次／可重複（可重複的是模板的**新實例**；冷卻由玩法決定） |

### 3.4 防止重複感

- **同一模板不同時代**：開場的人不同、問題的根源不同。
- **同一時代不同輪**：若主角在同一時代又一輪回來（例如早死後出生還在同一時代內），已發生過的一次性事件不再出現，改由其後續事件接上。
- **主角記得**：主角完整記得親歷【已定】。已處理過的事件，他下次遇到類似的會有記憶台詞（「上一輩子，我在這裡見過一樣的事」），但**不能**預知新的細節。
- **夢動切換不重置實例**；缺席結果只結算一次，不覆蓋玩家此前的成果。
- **世界記得**：玩家做過的決定會變成地方的習俗、傳聞或遺跡，進入後續事件的前置條件。

### 3.5 與圖鑑、主線的連結

- 約 15% 的事件是山海探索，能更新圖鑑條目；圖鑑不必收齊【已定 N9】。
- 主線**不依賴**不可保證抽到的唯一隨機事件；每項主線知識應有可達的保底來源（設計要求）；尚須逐項提交來源、前置、拒絕、缺席與替代路徑的對照，不能以第四批上第一節概括為已驗收。
- 允許事件提供**合格的替代證據**（圖鑑批註、第三方紀錄須逐件檢驗；未達歸責門檻的材料只起疑，不自動解鎖 K6），但區分三層：**起疑**（只讓玩家懷疑）、**證據**（可支持推論）、**知識解鎖**（寫入 K 系列）。
- 引用事件一律用完整事件 ID；短 ID 需附對照表。

### 3.6 知識層級與世界結果
- 盤查、遷移、死亡是不同事件；實際出生可增加、實際死亡可減少在世燈數；盤查或搬遷本身不改變總數；出生候選另依燈籍家庭 v1.3 的資格與直系規則。
- 主角的知識分：親歷、消息（需來源與傳播日期）、紀錄、作者真相（不直接成為玩家知識）。
- 報刊消息須有來源與刊登日期；主角是否得知依實際送達。

## 四、事件示範

### EV-U001-001　走失的巡檢犬（日常求助）
- **地點**：歸墟任一既有街區（依 ATLAS）。**年代**：任何。
- **開場**：一個孩子抓著主角的袖子：「我的狗不見了。牠是機器的，可是牠會怕打雷。」

### EV-U001-017　兩個人的命（觀命委託）
- **地點**：歸墟任一既有聚落。**年代**：燈下至蒐集。
- **開場**：一對年輕人請主角看看他們結婚之後的命。
- **選擇**：
  - 接：需兩人都同意被看。主角看到的分支依條件而定（例如「若其中一人接受外星的工作」）。
  - 只看其中一人：另一人未同意，主角可選擇遵守或越界（依 N36，一般人不直接察覺被觀命；是否發現越界須有主角身體跡象等可推知的線索，再決定後果）。
  - 拒絕：「你們自己決定吧。」
  - 說與不說：看完之後，主角可以只說條件、不說機率，或全說，或不說（延續 X01「知道本身就會改命」）。
- **缺席結果**：兩人照自己的判斷結婚或分開。
- **寫入**：兩人的人物狀態；若日後再遇，依結果有後續。
