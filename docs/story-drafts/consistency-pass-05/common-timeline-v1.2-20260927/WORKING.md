## 三、物件狀態規則

### 3.1 主角的遺物（依實際死亡）
| 條件 | 狀態 |
|---|---|
| 主角實際死亡 | 死亡不生成或搬運物件；只將仍存在的死者物件按實際所在地、保管人及權利紀錄轉入後續處理 |
| 遺物被尋獲 | 由尋獲者或原保管人持有 |
| 紅收存 | 需：紅在世、得知死訊、取得遺物、有保管權（例：陵墓登記為代管人）；四者皆成立才成立 |
| 主角生還（閘門存活） | 不觸發以死亡為前提的遺物交接；空白紙依回交、借閱、遺失等實際持有鏈，不保證仍在主角手上 |
| 遺物轉交時點 | 以死亡為前提的交接不得早於實際死亡；生前回交、借閱與保管另列，不受此限制 |

### 3.2 舊紙與拓本
| 物件 | 狀態旗標 | 條件 |
|---|---|---|
| 舊算命紙（原件） | `舊紙_原件：保管人ID／所在地／存在狀態／權利紀錄` | 預設拾六持有 |
| 紅借閱 | `舊紙_紅借閱` | 提案：C5 出示與其後借閱分開；拾六同意後，還需實際交付才完成借閱 |
| 拓本 | `舊紙_拓本：存在狀態／保管人ID／所在地` | 紅確實拓印後才生成；後續依實際持有鏈 |
| 返還 | `舊紙_已返還` | 預定次日不等於完成；實際返還才寫旗標 |
| 玩家是否看過 | 依主角在場與否 | 原件在拾六處不代表各路玩家都看過 |

### 3.3 信件與紀念
| 項目 | 規則 |
|---|---|
| 紅的信（寫給大師兄） | 封數依紅實際寫信與保管紀錄；寫信停止是紅的選擇；不固定十一、十五或十六封 |
| 大師兄的信 | 依大師兄實際寫信、寄出與送達 |
| 紅的登報 | 需：主角在此死亡、紅在世、得知死訊、決定登報；自實際刊登年起；是否逐年持續依實際紀錄 |
| 紀念螺帽 | 需已知死訊與實際立碑；生還路不觸發 |
