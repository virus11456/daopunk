## 二、收容調整案（統一政策狀態）

**背景**：避難城區（U-009-P2-C2）收容容量與來者需求失衡（ATLAS 地方矛盾）。空座京提出**收容調整案**（提案內容）：
> 一、新到者優先收容無法自立者。
> 二、已收容且經評估能自立者，限期遷出，騰出名額。

**時間**（D＝A-1 議席表決日；皆為提案）

| 時點 | 事件 |
|---|---|
| D | 表決 |
| D+30 | 若通過，生效；公布本期遷出名單 |
| D+90 | 本期遷出期限 |
| 之後 | 每季評估一次，公布下一期名單 |

**狀態旗標** `收容調整案`：`草案｜通過｜暫緩｜修正｜撤銷`
- 狀態一經主角介入而改變，後續各場**沿用**，不因主角離開而回到「通過」。
- 「通過」只是**從未有人介入**時的預設走向。

**使者的錯誤**：使者在議席上說「道主支持此案」。亞茲並沒有這樣說過。這**不等於**使者故意作假：可能是誤解，也可能是自行揣測。

## 三、場景

### A-1｜空座
- **地點**：空座京（U-009-P1-C3）。中心空缺的懸浮議席（ATLAS 地標）；地方矛盾：使者以自身解釋壟斷真相（ATLAS）。中央空座為何空著，本作**未定**，不暗指任何席位。
- **處境**：D 日，議席表決收容調整案。使者說：「道主的意思是，收容應優先給無法自立的人；能自立的，請他們讓出位置。」
- **來源**：使者的話是轉述；亞茲坐在議席邊緣。
- **調查**（非戰鬥）
  - 議席外等亞茲，直接問。
  - 查使者過去的公告，比對亞茲少數親口說過的話（紀錄）。
  - 觀命使者（須找對命錨；未經同意為越界，後果依是否被察覺）：只看得出使者的走向，看不出亞茲的本意。
- **亞茲的回答**
  > 亞茲：「我沒有那樣說。」
  > 主角：「那你為什麼不糾正他？」
  > 亞茲：「他說的時候，我在想另一件事。」（停頓）「……我總是在想另一件事。」
- **選項**

| 選項 | 需要 | 結果 |
|---|---|---|
| 當眾質疑 | 可引用的證據（亞茲親口的紀錄、公告比對） | 觸發議席**覆核**；表決延後（`暫緩`）。覆核中亞茲須親自說明。沒有證據時，議席記下質疑，照原議程表決 |
| 私下告訴亞茲 | — | 亞茲說「我會想」。她是否在下一次議席公開更正，取決於**查證**（她自己核對使者的轉述）與**責任**（此案影響多少人）；不取決於她是否喜歡主角 |
| 不管 | — | 照原議程表決；預設為`通過` |

- **亞茲公開更正時**（若發生）
  > 亞茲：「我沒有支持第二條。我只說過，不想拋下任何一個人。使者轉述時多加了一句。」
  - 使者是否要承擔責任，由議席另行處理；主角的質疑不等於證實使者惡意。
  - 更正後，案子改為`修正`：第二條改為「自願遷出，並提供安置」。
- **拒絕／缺席**：照原議程表決。
- **晚到**：依主角抵達的世界時間讀取狀態。可能還在 D 至 D+30 之間（尚未生效），也可能已過數期；不一律「已過多年」。
- **同世補救**：通過後、下一期名單公布前，仍可取得亞茲的親口說法，提出覆核。
- **寫入**：`收容調整案`；`亞茲_更正：已公開｜未公開`；亞茲對主角的狀態（見第五節寫入來源）。

### A-2｜回音（滯留案件）
- **地點**：回聲星（U-009-P2）回聲城區（U-009-P2-C1）。殘門石陣與回聲收束器（ATLAS 地標）；地方矛盾：探險隊偽造回音出售線索（ATLAS）。
- **相關事件**：EV-025「偽造的回音」（示範事件 30 則 v1.1）。
- **處境**：亞茲的機構把一筆紀錄列為**滯留案件**（Y01：滯留由亞茲的機構確認）。

**本案預設為「紀錄案」**
- 探險隊把某人的回音剪接進一段虛構紀錄，讓他在紀錄上被登成另一個人。
- 機構的比對因此對不上，**交接紀錄無法完成**。
- 這**只證明紀錄未完成**，不證明靈魂受困。那個靈魂可能早已經過交接、進入輪迴，只是回執對不上這筆錯誤的紀錄。
- 【已定：Y01】交接印是資料比對，紀錄錯配**不會**自動阻止靈魂輪迴。

**作者候選變體：真實拘束**【提案，機制待設計】
- 本案的靈魂確實被某種拘束困在石陣附近；偽造回音只是掩蓋拘束、延誤救援的手段。
- 拘束的機制、施加者與解除方式**未定**。
- 不論採用與否，登記權都**不是**控制生命輪迴的總開關。

**主角能知道的**：機構的轉述；收束器傳出的回音。以**本場目前的觀測方式**，主角無法直接看見靈魂；這不排除未來其他五術、仙術或法則的觀測可能。

**收束器的查驗**
| 方式 | 說明 | 限制 |
|---|---|---|
| 原始石陣紀錄 | 比對收束器輸出是否被插入片段 | 原始紀錄可能已損壞 |
| 時間戳 | 偽造片段的時間戳常與石陣的記錄週期不符 | 時間戳不合只是證據之一；無法驗證不等於判假 |
| 獨立證人 | 當時在場、聽過原始回音的人 | 證人記憶可能有誤 |

任何一種查驗都不保證絕對真實；三者互相印證時，可作為本案的證據。

**分欄處理**
| 欄位 | 內容 |
|---|---|
| 改紀錄 | 撤銷偽造的登記，恢復原紀錄 |
| 改名 | 若本人（可聯絡時）想用舊名、新名或無名【無名交接程序待設計】 |
| 解除拘束 | **僅真實拘束變體**；機制待設計 |
| 本人意願 | 僅在機構確認有回應的存在時詢問；同意用某個名字，不等於同意立刻離開 |
| 輪迴端回執 | 由神經網的輪迴端比對；是否找到回執，另行記錄 |

**可能的結果（紀錄案）**
- 改正紀錄後找到回執：紀錄結案；機構轉述「已對上」。主角**不知道**那個人轉生到哪裡。
- 改正紀錄後仍無回執：狀態未知；可能尚在延遲期，也可能另有原因。
- 查驗未通過：不能改紀錄；可在同一世補證。
- **拒絕／缺席**：紀錄維持錯配；機構可能在數年後自行查出偽造（世界事件）。
- **晚到**：探險隊已解散；原始紀錄可能已損壞。
- **寫入**：`滯留案_性質：紀錄案｜真實拘束`、`回音查驗：通過｜未通過｜無法驗證`、`紀錄：已改正｜未改正`、`回執：找到｜未找到`、`本人意願：未詢問｜已詢問（內容）`。

### A-3｜收容安排（《守一不散》任務途徑）
- **地點**：避難城區（U-009-P2-C2）：厚壁浮島上的環形安全院。
- **讀取**：`收容調整案`。

| 政策狀態 | 本場的照顧對象 |
|---|---|
| 草案、暫緩 | 目前的擁擠住民；尚無遷出名單 |
| 通過 | **本期遷出名單**上的住民 |
| 修正 | 本期**自願**遷出者，以及留下的擁擠住民 |
| 撤銷 | 目前的擁擠住民 |

- **範圍**：本任務只要求安置**本期**的照顧對象，並完成當期評估與後續交接；**不要求**安置未來所有新來者。
- **亞茲的請求**
  > 亞茲：「這一期的名單上有這些人。我不想拋下任何一個。」
- **判定**（依實際需求與資源，不按勾選數）

| 面向 | 本期需要的安排（提案） |
|---|---|
| 住處 | 每位對象有可居住的地方；借用島間空間需地主同意、可居住、航路可用 |
| 食物與燃料 | 本期有穩定來源（配額交換，ATLAS 政治提案） |
| 醫療 | 有人能看病（院內照護；公社巡診） |
| 安全 | **已評估**風險、**已告知**當事人、有**可行的防護**；不保證永不遇害 |
| 聯絡 | 當事人**願意**時，能與院內家人朋友聯絡；若聯絡會危及安全，依當事人意願 |

- **緊急暫時安置**：來不及完成時，至少提供安全的暫時照護，並安排後續追蹤。
- **結果**
  - 各面向在本期完成評估與安排，並交接給院方或機構：**完成**。
  - 擁擠仍在，但已有安全的暫時照護與追蹤：**部分完成**（亞茲認為可以，資格成立）。
  - 有人缺糧、失溫或被迫離開而無去處：**未完成**。同一世可補。
- **資格不倒扣**：資格成立後，多年後的新事件（例如某位對象日後遇害）不會取消已成立的資格；但會作為新的世界事件呈現。
- **責任記實際行為**：主角若參與後中途離開，記下他做了什麼、沒做什麼（`收容安排_主角作為`）。主角**拒絕介入**，不等於政策的加害者。
- **寫入**：`收容安排：完成｜部分｜未完成`、各面向旗標、`收容安排_主角作為`。

### A-4｜孤燈（《守一不散》親授途徑）
- **地點**：繫燈星守燈聚落（U-009-P1-C1）：漂浮石柱上的孤燈列陣。地方矛盾：守燈物資不足須取捨航路（ATLAS）。
- **處境**：一個失去形體的存在附在一盞孤燈上；這盞燈也照著一段航路。守燈人說燈油不夠。
- **亞茲的請求**
  > 亞茲：「陪它走完最後一段。」
  > 主角：「走去哪裡？」
  > 亞茲：「它自己決定。」

**兩件事分開核對**
| 項目 | 需要 |
|---|---|
| 航路的光 | 其他光源、航路合併；需守燈人同意 |
| 它的承載 | 這盞燈能維持多久；是否有替代承載；它是否知情並同意更換 |

替代光源能照亮航路，**不一定**能承載它。

**燃料與時間**（提案）
- 焰種城（U-009-P4-C1）的火種配額被收藏家囤積（ATLAS 地方矛盾）；主角可交涉取得燃料。
- 取得的燃料能維持多久，須告知它；它可以撤回先前的決定。

**判準**
- **不脅迫**：不威脅、不交換、不欺騙、不隱瞞關鍵資訊（例如燈油還剩多少）。
- **不替它定案**：不擅自熄燈，不否決它的選擇。
- **允許**：詢問、提供資訊、表達意見、在它要求時給建議。
- **親授須實際完成**：完成雙方約定的陪伴（例如陪到它做出決定，並協助落實），或建立可持續的安排（例如燃料來源與守燈人的照看約定）。只是沒有脅迫、或只回答了一句，**不算完成**。

**它可能的決定**：讓燈熄；繼續附在燈上（需有燃料或替代承載）；在某段時間後再決定。
- **傳話**：它可以另外請主角傳一句話。主角可以答應或拒絕。**拒絕傳話不影響親授資格**，也不決定它的去留。
- **燈熄之後**：它的狀態**未知**，除非有它本人的決定紀錄，以及機構或輪迴端的證據。油盡而回執未到時，記為未知，不判定轉生或消滅。

**亞茲的盲點**
- 主角給了建議，亞茲可能說：「你不該勸它。」
- 主角可以反駁：
  > 主角：「它問我怎麼想，我才說的。不說，才是把它一個人丟在那裡。」
  > 亞茲：（很久）「……我總是怕說錯話。所以我什麼都不說。」
- 這是她可被質疑的盲點；系統不認定她絕對正確。

- **失敗**：脅迫、隱瞞關鍵資訊、擅自熄燈或否決其選擇。
- **舊案責任**：失敗後，這盞燈的結果與主角的作為仍記錄在案；主角可在同一世補救這一案（例如向它坦承、恢復它的選擇權），不需要找新的對象來洗掉。
- **拒絕／缺席**：燈是否熄滅，由守燈人與它自己決定（世界事件）。
- **晚到**：燈可能已熄；主角從守燈人口中得知它最後的選擇（轉述）。
- **寫入**：`孤燈_結果：熄燈｜延續｜未決`、`孤燈_狀態：未知｜機構確認（內容）`、`孤燈_陪伴：完成｜未完成`、`孤燈_主角作為`、`傳話：答應｜拒絕｜未提`。

### A-5｜放下
- **開啟條件**：亞茲對主角的狀態至少為「信任」（寫入來源見第五節）。
- **地點**：空座京，中央空座旁。
- **對白**
  > 亞茲：「你背著很多。」
  > 主角：「我記得很多。」
  > 亞茲：「我可以陪你。我不能替你放下。」
  > 主角：「你能讓我忘記嗎？」
  > 亞茲：「不能。那是你親歷的，沒有人能拿走。」【已定：主角完整記得親歷】
  > 亞茲：「就算能，那也不該是我來決定。」（反事實假設）
  > 亞茲：「放下不是忘記。是你怎麼背著它。」
  - 這不表示她不能協助其他受創的靈魂；只是主角已親歷的記憶不可抹除。

- **已知 K5 時**（沿用 v1 原段）
  > 主角：「你也同意讓祂睡。」
  > 亞茲：「我守著的，是那些已經沒有形體、還不願意走的。祂醒來，他們會第一個不見。我是這樣相信的。」
  > 主角：「你確定？」
  > 亞茲：「不確定。所以我更不敢。」
  - 這是亞茲的信念，不是作者事實【已定 N18：喚醒的真正結果遊戲不回答】。
  - 未取得 K5 時，此段不出現（保留主線知識門檻）。

- **照魂辨我（有限觀測）【提案】**
  - **需主角明示同意，且亞茲實際施術**，才寫入觀測紀錄。主角只是進場、說話、自稱會轉生，都不寫入。
  - 觀測的是**本次可觀測的連續性**；不讀盡各世；不知道剪命的原因；不證明任何機器生命有無靈魂。
  - **首次觀測**：
    > 亞茲：「我只看得到你現在。你是完整的一個。你的前一世，我沒看過，所以我比不了。」
  - **若她曾在主角某一前世實際觀測過**：
    > 亞茲：「和我那一次看見的，是同一個。其他幾世，我沒看過。」
  - 不論哪種：
    > 主角：「那為什麼我會記得？」
    > 亞茲：「這個我看不出來。」
  - 她的判斷不具任何組織的法律效力（加入中立組織 v1.3 第九節，**引用待核**）。

- **三件事分開**
| 項目 | 意思 | 寫入 |
|---|---|---|
| 自稱 | 主角說自己會帶記憶轉生 | `亞茲_聽過自稱` |
| 觀測確認 | 亞茲實際施術後的判斷 | `亞茲觀測紀錄：[第幾次觀測][世界時間][主角當時的名字]`，**逐筆累積，不覆蓋** |
| 當世身分辨認 | 亞茲認得眼前這個身體就是她觀測過的那個人 | 只在有觀測紀錄可比對時成立 |

### A-6｜守一不散
- **取得資格**（可並存；取得一次【已定】）

| 資格 | 建立條件 |
|---|---|
| 任務 | A-3 完成或部分完成 |
| 親授 | A-4 陪伴完成 |
| 擊倒 | 在空座京挑戰她（戰鬥玩法未定）；擊倒**只建立資格** |

- **取得**：資格成立後，主角**接受**才取得。任何資格都可以拒領；拒領不消耗資格。
- **取得一次，不是只能用一次**：取得後跨世持有，依能力邊界使用；持有不需每世重新認證才生效。
- **傳授不抽走亞茲的權能**：她傳授的是有限的傳奇仙術；她自己的靈魂法則不減少，也不因此離開議席。

- **擊倒之後**【提案】
  - 【已定 N16】道主不會真正死。
  - **暫離議席**：若她選擇暫時讓出議席（她的決定，不是擊倒必然的結果），她離開前的交接是否完成，取決於機構是否有能接手的照護者（人物待設計）。
  - 她那句話改為：
    > 亞茲：「我走開一陣子。這段時間，它們少一個守的人。」
    - 指的是她離席造成的**照護缺口**，不是法則被拿走。
  - **使者擴權**：只有在她離席、且沒有人公開質疑使者時才發生（世界事件）。
  - **逐出夢外**與暫離議席是**不同的狀態**：逐出只會由其他因果造成（例如主線中陸吾式的出手），不由一次決鬥造成。

- **跨世領取（拒領後）**
  - 需要亞茲能辨認主角：依 A-5 的觀測紀錄比對。
  - **若她從未觀測過主角，其他道主也不知情**：仍可用**案件與見證**補證。例如：A-3 的收容交接紀錄、A-4 守燈人的證詞、機構的案件紀錄中記有主角當時的名字；主角說出只有當事人知道的細節。**不強迫**主角重做任務或透露全部記憶。
  - 需要可聯絡：亞茲若暫離議席，經機構轉達；若她已被逐出夢外（其他因果），**替代流程待設計**，取得路徑不因此永久封死。

- **能力邊界**（依 DAO_RULER_POWERS，提案）：維持自身連續性，抵抗指定類型的奪舍或靈魂干擾；不免於死亡或輪迴；不改變任何人的記憶。
- **寫入**：`亞茲資格_任務｜親授｜擊倒`（分欄）、`法則_靈魂：已取得｜未取得`、`亞茲_離席：否｜暫離｜被逐出`。

## 六、終章中的亞茲

最終抉擇由玩家觸發【已定】。亞茲是否出現，依以下條件分開判斷：

| 條件 | 說明 |
|---|---|
| 知識 | 亞茲是否知道主角要做什麼（主角是否告訴她） |
| 關係 | 信任或冷淡 |
| 邀請 | 主角是否邀請她同行 |
| 可聯絡 | 她是否在議席、暫離（經機構轉達）、或已被逐出 |

| 組合 | 終章 |
|---|---|
| 知道、信任、受邀、可聯絡 | 守護夢境時陪伴；喚醒時不阻止，但請主角先讓她去陪那些靈魂 |
| 知道、信任、未受邀 | 不同行；可能在事後出現 |
| 不知道 | 不介入 |
| 冷淡 | 不介入 |
| 不可聯絡 | 不出現 |

- 邀請她不等於帶她到達夢底；到達夢底另依主線條件。
- 無法告知或她不可聯絡時，**不鎖任何結局**。
