# 時代與隨機事件池 v1.2 工作修訂

基於本次 v1.1 收稿，修正與使用者已確認規則的衝突；新增內容仍為提案。這是可供後續撰寫的規格，並非300則事件已完成、100小時已驗證或Godot已實作。

## 1. 已定邊界與本次新資料

- 世界時間持續前進。下一次可玩時間＝死亡世界時間＋等待新生兒時間＋14～15年，不能一律寫至少15年。
- 世界與NPC可以惡化、死亡、遷徙；最終抉擇由玩家觸發。沒有超過世界日期就自動結束存檔的「未介入第五結局」。四結局不變。
- 人類與燈籍不歸零；不能以反覆抽到盤查事件清空所有出生來源。
- 跨世保留親歷記憶，不自動取得缺席時的新聞、死亡消息、保密資料。實體物件持有與記憶分開。
- 本次稿末明列「非人類可以被觀命，與人類一樣清楚，但須找對命錨」，按本次提供的新決定記錄，取代同稿巡檢犬範例的「非人類能否被觀命待定」。這不使非人類能學算命，也不自動批准「出家日可作命錨」；任何個體的有效命錨仍需有依據。
- 20～30年、300模板、比例與30地點都維持內容規劃提案。

## 2. 時代結構：時間推進、地方留痕、夢動疊加

前四段是用於製作的世界時間區間，並非玩家必須親自走完的關卡。轉生跨過區間時，世界照常演進。世界出生後早於T的紀錄可以存在，遊玩從T開始。

| 時段提案 | 編輯用標籤 | 地方呈現條件 |
|---|---|---|
| T+0～約15年 | 燈下 | 日常、舊居民、既有制度；角色仍須活著且在場 |
| 約15～40年 | 閘門之後 | 崩塌才有西段重建；避免事故則呈現整修、預防工程或原貌，不強制叫「崩塌之後」 |
| 約40～70年 | 世代交接 | 居民老化與繼任依人物資料；未必每位原角色都死去 |
| 約70～100年 | 蒐集壓力期 | 追查網依事件成敗擴張、受阻或轉入地下；不是人人必遭追殺 |
| 約100年以後 | 延續時代 | 建議20～30年一段作內容編排；段長待測。保留上一段結果並加入地方變化 |

「夢動」改為可疊加於晚期世界的異常狀態，不是時限前必定到來的最後倒數。燭陰異常、勢力行動與地方災害可繼續發生；進入夢動不直接選結局。最終行動由玩家依主線条件觸發，不能寫原諒某人等於替自動結局加幾年。

區分全域年代與地方狀態：同一年代可以有重建的深坑、仍繁盛的農鎮與被封鎖的港口；十大宇宙不因歸墟的一次事故同時換成同一政治面貌。「無燈之年」若保留只能是某個街區的俗稱，不能表示全宇宙人類滅絕，初稿建議用「遷燈之年」。

## 3. 人物與地點更新

原表T+50、55、60等死亡日期只留作無介入示範年表；不可在切換年代時直接覆寫人物。依出生日期、基礎承載、當世延壽、已得仙術、事故與救援等實際資料推進；無關角色是否受同一壽命規則限制須各自確認。

拾六不是無敵NPC；生存、機體故障、修復、所在位置各自有狀態。葉遲為人工生命仍是提案，不能借人物表升格。師父的衰弱或離院不可永久切斷必要真相；需延續已設的替代承接。閻羅X工坊空置須依本人離開事件，不能由「夢動」標籤自動刪除。

每地點記錄：既有地標、地方制度、居民／繼任者、物件保管鏈、前期事件後果、可見線索與消息來源。燈交接需原持有人、受領人及物件都符合條件；認識紅不等於自動得到燈。地點五種製作版本採「早期／事故後／交接期／壓力期／長期＋夢動覆層」，不用為每個延續年代重畫完整新城市。

## 4. 300模板的內容帳

地域配置：歸墟60＋其餘九宇宙各25＋跨宇宙通用15＝300。跨宇宙通用模板的多次實例不再按落地城市重複計入300。

| 主要分類 | 模板數 | 占比 |
|---|---:|---:|
| 日常求助 |75|25%|
| 觀命委託 |45|15%|
| 消息與傳聞 |45|15%|
| 山海探索 |45|15%|
| 中立組織 |30|10%|
| 燈籍與人類 |30|10%|
| 異象 |15|5%|
| 衝突 |15|5%|
| 合計 |300|100%|

地域與類型是同一批300模板的兩個分類軸，不能相加成600。每模板只選一個主要分類，其他用標籤。每模板1～5種變體不算新模板；300～1500個變體亦不等於同量獨立故事。

建議先寫並檢查30則試作，再擴至300。以有獨立困境、條件、選項和持久後果為入庫標準，不能只換名字／顏色／地點湊數。100小時與一半時數是目標，需日後遊玩測試，不能由模板數直接推得。

## 5. 模板、實例、消息與知識

保留原稿欄位，增加下列區分，與 ../../contracts/RANDOM_EVENT_DATA.md 對齊：

| 欄位 | 用途 |
|---|---|
| template_id / revision | 模板識別與版本 |
| instance_id / occurrence | 每次實際發生的事件與次序，不因輪迴重置 |
| repeat_scope | 全世界、地點、人物、組織或時代作用域；每時代一次必須指定era_id |
| participant_refs / eligibility | 實際參與者身份、存活、位置、意願、族屬保密範圍；替代角色不能承接原人的私人記憶 |
| created_at / occurs_at / deadline | 世界日期；主角抵達不是世界事件起算點 |
| outcome_snapshot / seed_key | 持久化結果與隨機種子，進出地圖與轉生不重抽 |
| world_effects / knowledge_effects | 世界改變與主角得知分開；缺席不自動寫親見 |
| evidence_source / received_at | 親見、轉述、紀錄、傳聞、觀命及消息抵達時間 |
| item_transfer / consent | 持有鏈、資料公開與觀命同意分別處理 |
| followup / fallback | 後果鏈及不可達時的替代證據來源 |

觀命機率描述指定時點與條件的未來；事件缺席抽選權重是作者模擬參數，兩者不必相等，不可把50%抽選當作主角已看見50%。觀命「看不清」是資訊不足，不必然是世界的一種結局。說與不說會改變條件，不能沿用舊機率保證未來。

一次性事件即使缺席已結算，也不可重演；冷卻到期不復活死者、不恢復已永久解決的問題。跨多年補算須按世界時間排序，只套用一次後果。未抽中事件不代表世界永遠靜止；世界事件的建立由世界排程負責，這仍未實作。

隨機事件不得成為唯一且不可替代的主線必要證據來源，但可提供同一證據的另一條可靠路徑。師父批註線索仍有效；證據足夠時應推進知識，不讓NPC為了等章節否認玩家已知事實。多份轉述同一來源不能冒充多份獨立證據。

## 6. 六個示範的修訂方向

| ID | 保留內容 | 本版修正 |
|---|---|---|
| EV-U001-001 | 走失巡檢犬 | 非人類可觀命但需正確命錨；找不到命錨仍可調查。孩子族屬不可默認人類。三日從走失世界日算；50/50只作示例权重，生成實例後持久保存 |
| EV-U001-017 | 兩個人的命 | 雙方同意與單人同意分開。只觀察同意者不代表另一人的私密資料可公開；越界是人物可做的行為及其後果，不是取得全知的捷徑。說出結果後重估條件 |
| EV-U001-033 | 第六版的更正 | 死亡證明只先屬紀錄；親屬亦只提供其知情範圍。結論可確證、仍有矛盾或無法證實，消息有傳播延遲，不直接寫作者真相 |
| EV-U001-008 | 每年同一天的鳥 | 青穗星為U-001-P3，原U003前綴錯誤；新ID待檢查全池唯一性。按當地曆法與遷徙季節觀測；允許離開。某次延遲是一次世界事件，不能每年重演「第一次」 |
| EV-U001-051 | 盤查 | 分開住址暴露、家庭遷徙、被捕、死亡與燈籍記錄。被找到不等於人死或燈熄；出生候選只改可用地點，不能預定主角下一個身體或把所有新NPC生成人類 |
| EV-ANY-090 | 天空暗一瞬 | 可選觀察、查詢或繼續行程；室內／地下／其他宇宙的角色不必看見天空。報刊須有觀測、出版與送達。到過夢底不等於知道此次確切原因；需已知燭陰關聯證據，否則只能懷疑 |

上表為示範修訂，尚非六則完整驗收事件；原稿缺失的各項觸發、結果與知識依賴仍需展開。

## 7. 製作順序建議

先採用 LOCATION_CANDIDATES.md 的30地點候選作編排，優先完成7個既有劇情地點的條件版本，再擴展。每地先寫居民與制度如何變、玩家缺席怎麼承接，再製作視覺覆層。後續交付需包括世界日期、分支結果、事件唯一性、物件保管链、不同季節與NPC作息條件。現有4個離線事件測試模板不算本次300則已交付。
