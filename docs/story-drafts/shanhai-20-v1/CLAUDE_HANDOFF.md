# 山海圖鑑20條 v1｜覆核

20個不同ID，類別8＋2＋5＋3＋1＋1＝20。不是20張已生圖；與前批合計32的說法仍須合併去重後確認。

1. 建木篇章已核：見《山海經》海內南經及海內經；正文可分述其形貌，不能把所有通天敘事都說成兩篇原文。眾帝上下的相關說法常引《淮南子・墬形訓》，本輪未成功取得該篇完整原文，先附核查線索而非宣稱完整校勘。見 SOURCES.md。
2. 鹿蜀「不證實效果」和「公社說沒有任何醫學效果」表述不同。可改公社未有足夠證據支持，不將虛構醫療聲稱當作者定律。
3. 貫匈族屬仍未知，遺跡只能是調查線索，不能已稱人類衰亡物證；丈夫國自稱後代不證實新現存人類群體。不能用這批新條目擴增燈籍之外的人類。
4. 英招是否道主／創世生命只為角色疑問，不增加第十一道主或第四創世生命。刑天條目收古籍異象／石刻紀錄，不轉成未經確認的可互動人物。
5. 古籍改寫、角色轉述、主角親見、作者候選各自留欄。看到石刻不是見到刑天；圖鑑名稱相同也不自動確證現生物與古籍同物。
6. 不新增地點不等於可把「某處」當既有地點ID。LOCATION_CANDIDATES 是既有星球的發現線索提案，不建立新城市；邊緣世界不硬塞進十大宇宙星球。
7. 扶桑十光源、十圓是兩種紀錄，可以不同地點發現；不能加成失聯宇宙數量證據。師父批註可起疑，主線必要線索仍有其他來源。

## 一、生命（8 條）

### SH-LIFE-201　鳳皇

- **出處**：南山經（南次三經，丹穴之山）
- **古籍摘要**（改寫）：一種五彩的鳥，身上的紋路像字；牠出現時，天下安寧。
- **本作**：生化樂園某處的一種大型鳥，羽紋確實排列成類似文字的圖樣。當地人說那是字，學者說那只是花紋。
- **發現方式**：觀察；比對羽紋與先人文字；向當地學者請教。
- **未解**：羽紋是不是字？如果是，是誰寫的？
- **連結**：岑絲（她想記錄這些紋路）。

### SH-LIFE-202　畢方

- **出處**：西山經（西次三經，章莪之山）
- **古籍摘要**（改寫）：像鶴，只有一隻腳，紅色的紋路、白色的嘴；牠出現的地方會有怪火。
- **本作**：元素洪爐某處的一種單足鳥，棲息在高溫區；牠出現時常伴隨管線起火。當地人把牠當成災鳥驅趕。
- **發現方式**：觀察；查起火紀錄與鳥的出現紀錄。
- **未解**：是鳥引起火，還是鳥被火吸引？（「見則」為相伴，不是因果）
- **連結**：聚變（他想拿牠做試驗；主角可以阻止）。

### SH-LIFE-203　狡

- **出處**：西山經（西次三經，玉山）
- **古籍摘要**（改寫）：像狗，有豹的花紋、牛的角，叫聲像狗吠；牠出現的國家會大豐收。
- **本作**：一種被農民視為吉兆的獸，農民會在田邊留食物給牠。
- **發現方式**：訪談農民；夜間觀察。
- **未解**：豐收是因為牠，還是豐年時田邊食物多，牠才來？
- **連結**：藥畦鎮或穗契城的農民。

### SH-LIFE-204　當康

- **出處**：東山經（東次四經，欽山）
- **古籍摘要**（改寫）：像豬而有獠牙，叫聲像在喊自己的名字；牠出現時天下大豐收。
- **本作**：一種會「喊自己名字」的獸，與狌狌（第三批乙）一樣，被部分居民誤以為會說話。
- **發現方式**：聆聽；比對狌狌的叫名行為。
- **未解**：牠喊的是名字，還是只是聲音？（與狌狌「叫回別人的名字」不同）
- **連結**：第三批乙〈知人名〉。

### SH-LIFE-205　化蛇

- **出處**：中山經（中次二經，陽山）
- **古籍摘要**（改寫）：人面、豺身、鳥翼，能像蛇一樣爬行，叫聲像在呵斥；牠出現的城邑會有大水。
- **本作**：歸墟或深淵某處水域的一種生物，雨季前常出現在河岸。
- **發現方式**：雨季前觀察；查水文紀錄。
- **未解**：先人把「牠出現」和「大水」記在一起，是因為牠預知大水，還是因為大水前水位變化讓牠上岸？
- **連結**：歸墟的排水與崩塌議題（D01 閘門的遠親）。

### SH-LIFE-206　鹿蜀

- **出處**：南山經（南次一經，杻陽之山）
- **古籍摘要**（改寫）：像馬，白頭、紅尾，身上有虎紋，叫聲像在唱歌；佩戴牠的皮毛能多子孫。
- **本作**：與旋龜（SH-LIFE-102）同一座山的記載。今日牠的皮毛在黑市被當成求子的護符，遭到獵捕。
- **發現方式**：追查黑市護符的來源；觀察野生族群。
- **未解**：「多子孫」是先人記下的民俗，還是某種真實的效果？本作不證實。
- **連結**：拍賣場、義體醫師公社（公社說沒有任何醫學效果）。

### SH-LIFE-207　狸力

- **出處**：南山經（南次二經，柜山）
- **古籍摘要**（改寫）：像豬，腳上有距，叫聲像狗吠；牠出現的縣會有許多土木工程。
- **本作**：一種會挖掘的獸，常出現在新建工地附近；工人把牠當成工地的吉祥物。
- **發現方式**：訪談工人；觀察工地。
- **未解**：是牠帶來工程，還是工程翻動的土讓牠出現？
- **連結**：陸吾（邊庭或初生城區的工地）。

### SH-LIFE-208　蠱雕

- **出處**：南山經（南次二經，鹿吳之山）
- **古籍摘要**（改寫）：像雕而頭上有角，叫聲像嬰兒；會吃人。
- **本作**：深淵某處的大型猛禽，被航行者視為危險；叫聲像嬰兒，讓遇難者以為有人需要救援。
- **發現方式**：從遇難者與救援者的證詞拼湊；遠距觀察。
- **未解**：牠是在模仿嬰兒，還是叫聲本來就像？
- **連結**：守燈聚落、墜索鎮的打撈（EV-036）。
- **衝突**：這是少數可能需要戰鬥或逃離的條目（戰鬥玩法未定）。
