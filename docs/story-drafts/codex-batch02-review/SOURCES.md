## 明確更正

- 不死民為此處正文用名，保留不死國作舊稿別名及同ID。[海外南經](https://zh.wikisource.org/wiki/山海經/海外南經)
- 丈夫國此段為佩劍；君子國虎字有文／大異文，不能一概判大虎錯。[海外西經](https://zh.wikisource.org/wiki/山海經/海外西經)、[海外東經](https://zh.wikisource.org/wiki/山海經/海外東經)
- 灌灌未在所核正文指明佩羽毛；鴸的痺所指未詳，不能補成痺鳥。猼訑頁面的施／阤在音注中，不宜直接充作異名。[南山經](https://zh.wikisource.org/wiki/山海經/南山經)
- 狌狌知人名及豕形人面能在海內南經定位；兩篇形貌差異不等於同篇抄本異文。[海內南經](https://zh.wikisource.org/wiki/山海經/海內南經)
- 建木三處分層成立；九欘九枸的白話形貌需另標釋義，不能用古文補成現場已觀測細節。[海內經](https://zh.wikisource.org/wiki/山海經/海內經)、[淮南子墬形訓](https://zh.wikisource.org/wiki/淮南子/墜形訓)
