# T01 v1 一致性審閱
以下為修訂要求／候選方案，不將新提案升為正史。

| ID | 問題 | 修訂 |
|---|---|---|
| T01-R01 | 時代延續到時限；道主不受時代影響 | 刪倒數，結局由玩家觸發。不真死仍可被逐出、離場、受傷、改變關係，須判在場。 |
| T01-R02 | 自稱看出「所有偽裝」造成全知與陸吾密謀漏洞 | 改成察覺權能範圍內不一致，不自动知道原因、內容、行為者。她未觀察過的地方不知；能辨假也不等於能讀心或看盡歷史。 |
| T01-R03 | 代表抱怨、紀錄與觀命全直接證明歷史設計 | 三來源分層：抱怨是轉述，設計檔是紀錄，觀命是條件機率。需核驗設計紀錄與實際機制才能較有把握；生理傾向不抹除自主與個體差異。 |
| T01-R04 | 揭露衝動替代棲地問題；所有代表第一次知情 | 各代表所知獨立；強勢物種也有真實生存需求。補界線如何執行、弱勢代表訴求、資源與申訴；揭露不自動解決棲地分配。 |
| T01-R05 | 病人已要求知情，卻以「無正確答案」抹平自主 | 可以有困難與代價，不把支持家屬即尊重病人。病患有理解能力並明確求知時，以其意願為任務判準；對話可呈現涂山的偏見，旁白不作普遍定論。觀命不能代替診斷，也不授權主角替病人決定知情。 |
| T01-R06 | T-3 傳聞變確證、創苑身分判斷變定案 | 記涂山自述首肯／知情／放任的範圍與日期，不等同全檔案證實。葉遲認為自己是創苑者仍為判斷；涂山認識當年女子不自动驗證今世葉遲身份。F01 v1.2 未定位，先列依賴待補。 |
| T01-R07 | 多數得選擇權即成功，與主題及少數住客相衝突 | 基本自選資格需對每位適用住客開放；不要求多數選同一項。蓼支持是推行條件之一，不是唯一道德裁判；異議、暫不回應、需要協助者都有保障。 |
| T01-R08 | 記憶選擇、資料保存、離苑綁成三套套餐 | 拆成是否參與記憶引導、紀錄存取／用途、是否離苑三軸；可願意修行但拒資料研究，可不修行但留苑。歸還原件不等於刪掉副本，列副本、用途、存取、更正與停止使用程序。 |
| T01-R09 | 避難網安置、葉遲見證、住客討論任一都當完整解法 | 分別提供安置、見證與共議，不能單獨保證制度改革。核對人員可用、自願、保密、容量與具體離苑方案；不能把不去避難網當拒絕保障的理由。 |
| T01-R10 | 離苑必有受害暗示自由錯誤；失敗等下一時代 | 後果依當地風險、資訊、保護與人選實際判定，不強制懲罰自主。新增進展本世可重試；下世接续既有改革，不重置住客或已完成結果。 |
| T01-R11 | 親授獎勵「傷人的真相」，聽聞即可 | 判證據、當事人意願與承擔責任，不因越傷人越有價值。公開洩露私密資訊不可自動加分；涂山需有消息來源並查證，不全球知道。T-1 私問本人未必已陪伴代表。 |
| T01-R12 | 真實必需，但苑關閉、葉遲死亡等可封死三路 | 留至少一條跨時代可達路徑：例如新當事人的自主案件／獨立授法試煉（提案）。不是新人物重演舊冤案。只驗證真實法則取得還不夠，階段八仍需原有知識、地點與證據。 |
| T01-R13 | 三路互斥；擊倒即傳；冷淡可能封死後續 | 三路資格可並存，實際接受只一次。拒收不扣次數。擊倒不自動逐出，必逐出時明確傳承先後；已離場不可直接再對話。信任私談不可成所有路的暗門檻。 |
| T01-R14 | 圖鑑把涂山的自述當古代客觀歷史 | 九尾影子是親見；吃人否認與先人見她是涂山轉述；古文對照為紀錄；主角解讀是判斷。親見外形不證明古籍全部記載對應此個體；圖鑑維持物類條目，不變人物傳記。 |
| T01-R15 | T-5 NPC讀取玩家腦內 K4／K5；固定蓋亞來源 | 涂山只有聽主角說過或可信傳達才知道主角知情。先詢問再選對話；知識來源若不同應有變體，K5與K4分支可累積而非錯誤互斥。 |
| T01-R16 | 關係冷淡＝政治不介入，揭露＝即可信 | 關係、守護立場、陸吾證據評估、能否到場分開。她可以冷淡卻追究陸吾；信任也可拒絕喚醒。主角說揭露不自動讓她接受結論。 |

## 能力與依賴
真我錨揭示「被改過」不直接顯示陸吾、閻羅 X、原始內容與動機；必須與第四批證據鏈交叉查證。不能靠局部存在穩定直接完成整個宇宙脫夢。新增辨痕用途雖與既有真實方向一致，具體範圍、條件仍提案。

## 文件覆核案例（尚非實機測試）
1. 未到 F01 先拜訪涂山；只聽傳聞，沒有創苑身分證據。
2. 葉遲不在／蓼退休／苑已關閉時仍有真實法則取得路徑。
3. 少數住客拒引導但願留苑；願引導却拒外部研究。
4. 拒絕授法後再訪、已得法則再做另一任務、逐出後重新尋求傳承。
5. 看見改寫痕跡但缺兇手證據時，不能直接解鎖指控成立。
6. 隔百年初訪、與涂山冷淡但提供可靠陸吾證據。
