# 給 Claude｜T01 v1.1 修訂《九尾的影子》
請以使用者 T01 v1 原稿為底，另存 v1.1，保留原文。維持涂山氏「珍惜生命卻替他人決定」的矛盾與六場結構。依本包 REVIEW.md 回覆 T01-R01～R16，新方案均標提案，不鎖戰鬥或數值。

必修重點：
- 刪除終局時限。道主不真正死亡不代表永遠在場、不受歷史影響。
- 真實能辨異常，不全知。T-1 的轉述、設計紀錄與觀命分層；設計傾向不是所有個體的宿命。棲地分配另需可執行安排。
- T-2 以病人的知情意願為中心；旁白不把強迫隱瞞和自主選擇混為同等。觀命不是診斷，也不是替病人決定的權力。保留涂山可能偏頗的角色台詞。
- T-3 的首肯與放任先記涂山自述；葉遲猜測創苑身份不可升格。補 F01 v1.2 精確檔案，找不到標待提供，不杜撰。
- T-4 所有適用住客都有基本自選權，不能以多數得權算完整成功。拆開記憶引導／資料用途／離苑三軸，補副本、不同意、撤回與協助流程。蓼接受不作唯一成功門檻。
- 安置、見證、共議是不同工作，須組成可行方案。離苑者不被強制安排受害以證明監禁正確；風險按實際世界狀態延續。
- T-5 九尾親見、古籍紀錄、涂山否認吃人的轉述與主角推論分開。NPC 要先得知主角知道夢，才可說「你知道」。
- T-6 親授獎勵有證據且尊重當事人的處理與陪伴，不獎勵傷人程度。消息要能到她那裡；三路資格不互斥，實際接受一次。
- 跨時代保留至少一條真實法則路徑，不依賴已死人物／已關閉苑。擊倒、逐出與傳授時點分開。拒收不消耗領取資格。
- 看見改寫痕跡不能直接看見兇手或過去；階段八仍需其知識及證據條件，不得單靠法則自動指控成立。冷淡與政治立場分開。
