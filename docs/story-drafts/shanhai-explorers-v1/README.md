使用者來稿原文存於 [ORIGINAL.md](ORIGINAL.md)，逐位元組保留，後續確認不改寫原件。本文與檢查是整合記錄，不代表古籍原文查證已完成。

## 收稿後最新已定

- 採用「岑行」：古代人類探索者；「潮簿」：後世航誌整理者的名字與定位。
- 潮簿是機械生命，看不見命線，靠航標與航誌導航。機械生命無須具有人類讀命能力也能利用已知航行基礎設施。
- 僅部分航路的「里」是命線里程；星球地表路程另辨，不能把所有山經距離都改為命線尺度。

名字與定位採用不等於本稿所有「最多」「最早」、親歷、失蹤、刪改動機都成正史。岑行行紀、潮簿增補的具體事件仍按提案編輯。

## 本批內容及狀態

五階段編纂抄傳史、兩位來源人物、矛盾原因分類與 12 條示範條目。條目分布為生命 4、地貌天候 2、國家聚落 2、風俗 2、航路 1、遺文 1；皆為草案，不是已驗收圖鑑、圖片或 Godot 內容。12 條不等於開局上百條經文已完成，自創與經外條目也不能冒充經文數。

探索者記為作者／編者／消息來源 metadata，不建立人物圖鑑條目。新地點仍為候選，沒有加入既有 40 星球／100 地點名錄。

主線 v2 採條件推進；時代與世次是觀察背景，不能把圖鑑親見鎖死在第二或第三世。五時代的時間段仍為提案。細節見 [整合檢查](REVIEW.md) 與 [下一輪修訂提示](FOLLOWUP_PROMPT.md)。
