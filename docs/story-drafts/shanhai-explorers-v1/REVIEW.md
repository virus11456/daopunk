# 山海古籍與探索者 v1｜整合檢查

本批檢查敘事一致性與證據邊界，未進行古籍版本學核對。保留原稿，以下供 v1.1 修訂，不默默更改已收稿文字。

| ID | 問題 | 修訂方向 |
|---|---|---|
| SE01 | 1.2 把山經全部「里」視為命線里程；最新確認只適用部分航路 | 每段附距離類型：地表／命線／待考；未知單位不可推算座標。岑行不必每一筆都用命線里程 |
| SE02 | 潮簿族屬仍列生化、機械等選項 | 更新機械生命；以航標、航誌及可記錄的經驗導航，人類同行者是可選提案，不作所有航行的必要前提 |
| SE03 | 兩名探索者容易擴為人物圖鑑 | 保留來源檔案 metadata；條目引用其行紀、整理本、抄本來源，不加人物收集格 |
| SE04 | 岑行「比任何人多」、潮簿「第一個」是全知式歷史定論 | 降為某版本聲稱／現存可考最早之一，或列待證；兩人定位獲准不等於誇張敘述也獲准 |
| SE05 | 「只有師父知道是真的」若全球適用，與道主知情相衝突 | 限為故事開始時師門內只有師父知情；弟子、學者、商隊可後續取得局部證據，不能永遠無法相信 |
| SE06 | 禺彊條目把「見鯤鵬」列為親見條件 | 見到鯤鵬只新增比較證據，不能使禺彊自動標為親見或證實同一存在 |
| SE07 | 羽民國先問是否人類，後斷言是人類衰亡物證 | 先記聚落遺跡、住居形制、文字，族屬待考；須另有可追溯證據才支持人類聚落假說，翼形屋舍不足定族屬 |
| SE08 | 帝江所見直接括註渾沌，有把對應提案當已定風險 | 玩家所見與身份假說分欄；勿鑿／無七竅不足自動確認帝江等同渾沌，作者對應仍標提案 |
| SE09 | 「無人親見」同時存在古代行紀的見聞 | 改「主角尚未親見」或「當代尚無可核對親見」，避免否定前文先人的目擊 |
| SE10 | 機械生命潮簿稱先人沒看過機器，可能被讀為全部先人已證實沒遇過 | 保留「现存早期書中未見明確記載」，缺載不證明未存在；不要靠一人的增補推定科技起源 |
| SE11 | 年年同一天鳥數不差與九天逆瀑是精確數值，但世界曆法、星球季節未定 | 指定當地曆／觀測範圍與抄本說法；真實性先作提案，不讓跨宇宙統一日期成为既成事實 |
| SE12 | 時代三旋龜回升、四後遺跡洗劫可能忽略玩家干預 | 用世界事件與保育／掠奪狀態決定，年代僅提供候選條件；任一輪可錯過但仍能讀歷史報告 |
| SE13 | 失聯、航標找不到、此路今絕容易被當成宇宙毀滅證明 | 分清航路可通性與宇宙存續；保留季節、航標失修、坐標過時等多解，不新增第十一宇宙正式座標 |
| SE14 | 12 條含改寫、自創、批註與經外，不全是開局經文 | 各條另標開局可知範圍；批註需讀到該頁、留燈需親歷／獲准訪談；不把 12 條計為百條已驗收 |
| SE15 | 留燈家戶位置與「每階段重讀便有新意思」可能造成知識自動外洩 | 保護家戶位置；重讀解讀需實際取得相關證據，不因主線階段號直接灌入作者真相 |
| SE16 | 奇肱善機巧、禺彊不同篇章等書目說明仍需核對 | 後續查原典版本，分經文／注文／本作改寫；本批沒有外部核引驗收，不以自檢表替代查證 |
