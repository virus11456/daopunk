# DAOPUNK｜山海圖鑑 設計提案 v1.1

> 【已定】圖鑑不收錄人物，專注山海與眾生；開局即有上百條「未見」的經文條目；師父的批註作為主線線索的另一條路。其餘為【提案】。本文件設計的是圖鑑在**故事與世界觀**上的角色、收錄範圍與條目格式；介面、數值、解鎖獎勵等玩法細節仍未定，不在此鎖死。
> 依據：《山海經融入設定 v1.1》、主線 v1、已定規則（主角完整記得親歷、世界時間前進、只有師父知道山海經是真的）。

---

## 一、核心概念

**這本圖鑑就是主角自己的《山海經》。**

主角小時候在隱修院把《山海經》背得滾瓜爛熟，當成祖先的故事。下山之後，他開始親眼看見書裡寫的東西，也看見書裡沒寫的東西。他把看見的逐條記下來，對照經文，補上、訂正、劃掉。

三世下來，這本圖鑑會變成一部新的山海經：先人寫了一半，他寫了另一半。

**它與已定設定的關係**
- 主角完整記得親歷【已定】→ 圖鑑跨世保留，不會因轉生消失。
- 世界時間持續前進【已定】→ 同一條目在不同世會出現變化：物種遷徙、滅絕、改名，地點重建或荒廢。
- 只有師父知道山海經是真的【已定】→ 圖鑑一開始全是「未見」的經文；第一次親眼看見書中之物時，主角才開始懷疑這本書不只是故事。

## 二、開局狀態

【已定】圖鑑一開始**不是空的**。主角背過整本書，所以一開局就有上百條「經文條目」，全部標為**未見**。

玩家的第一感受應該是：這些我都知道，但都沒看過。

第一次親見書中之物的時刻，可以放在第一世早期的一個小事件（例如在青穗星看見一種書中寫過的鳥），讓主角第一次對著經文發愣：「……原來是真的。」

## 三、收錄範圍

【已定】不收錄人物。拾六、紅、零號等個別人物不設條目；經外之物以「族群或類型」收錄（例如「退役邊防機甲」），個別人物只在條目的親見、轉述欄中被提及。

| 類別 | 內容 | 例子 |
|---|---|---|
| **經載之物** | 山海經中記載的生物、神、異象 | 九尾狐、帝江、燭陰 |
| **經外之物** | 書中沒有記載、先人時代之後才出現的生命 | 機器人、改造人、人工生命、義體生物 |
| **海外諸國** | 書中記載、如今已消失的人類聚落與遺跡 | 羽民國、長股國 |
| **神與道主** | 先人記下的神；其中部分是道主 | 陸吾、九尾狐（涂山氏） |
| **創世生命** | 三大創世生命 | 鯤鵬、燭陰、渾沌 |
| **山川** | 經中的山、水、國度與今日地名的對照 | 中山經的歸墟山川與現在的碎片 |

「經外之物」這一類很重要：整部作品的開場問題「機器人能被算命嗎」，也是先人從未遇過的問題。圖鑑讓玩家看見，這個世界已經比先人的書大了很多。

## 四、條目格式

每個條目分成幾層，依**證據層級**逐層填入（沿用五篇共用的證據用語）：

| 欄位 | 內容 | 層級 |
|---|---|---|
| 經中名 | 書中的名字；經外之物則空白 | 紀錄 |
| 今名 | 當地人現在的叫法（可能有多個） | 轉述 |
| 經文 | 原文 | 紀錄 |
| 出處 | 山經（哪一經）或海經（海內／海外／大荒） | 紀錄 |
| 先人圖 | 原圖已失傳，找到山海圖殘片後補上 | 紀錄 |
| 親見 | 主角親眼所見的描述與素描，註明第幾世、在哪裡 | 親見 |
| 傳聞 | 聽別人說的，註明說話的人 | 轉述／傳聞 |
| 經今之差 | 書中寫的與現在所見有哪些不同 | 主角的判斷 |
| 師父批註 | 隱修院古本的頁邊，有一些很淡的字，是師父寫的（見第六節） | 紀錄 |

**狀態**：未見 → 聽聞 → 親見 → 再見（下一世又見到）→ 訂正（證實經文有誤）

## 五、條目範例

### 九尾狐
- **經中名**：九尾狐
- **今名**：生化樂園各地叫法不一
- **經文**：「有獸焉，其狀如狐而九尾，其音如嬰兒，能食人，食者不蠱。」（南山經，青丘之山）
- **親見**（第三世，生化樂園）：主角見到道主涂山氏時，她的影子有九條尾。
- **經今之差**：經文把她當成獸記下。先人也許從未走到能和她說話的距離。

### 帝江
- **經中名**：帝江
- **經文**：「有神焉，其狀如黃囊，赤如丹火，六足四翼，渾敦無面目，是識歌舞，實惟帝江也。」（西山經）
- **親見**（第三世，夢的底層）：夢的正中央，一團沒有臉、沒有七竅的溫熱。
- **訂正**：帝江即渾沌。先人從很遠的地方看見祂，所以寫成了有腳有翼的東西。
- **備註**：主角在條目旁加了一行：「是識歌舞。祂聽得見。」

### 燭陰
- **經文**：「鍾山之神，名曰燭陰，視為晝，瞑為夜，吹為冬，呼為夏……身長千里。」（海外北經）
- **另見**：大荒北經「燭龍」。
- **親見**（第三世）：盤繞在夢的邊緣，閉著眼，眼皮在顫動。
- **經今之差**：經文寫祂住在鍾山下。主角看見的地方沒有山。

### 陸吾
- **經文**：「是實惟帝之下都，神陸吾司之。其神狀虎身而九尾，人面而虎爪。」（西山經）
- **親見**：第三世，永恆聖堂。
- **師父批註**：「帝之下都」四字旁，有一個很小的墨點。
- **隨主線更新**：主11 之後，主角在條目旁寫：「祂守的是什麼，祂想要的就是什麼。」

### 夸父
- **類別**：海外諸國／遺跡
- **經文**：「夸父與日逐走，入日；渴，欲得飲……未至，道渴而死。棄其杖，化為鄧林。」（海外北經）
- **親見**（第三世，邊緣世界）：一片長在虛空邊上的樹林。
- **經今之差**：主角懷疑夸父追的不是太陽，是燭陰睜開的眼。

### 羽民國
- **類別**：海外諸國
- **經文**：「羽民國在其東南，其為人長頭，身生羽。」（海外南經）
- **親見**（第二世或第三世，邊緣世界）：只剩遺跡。屋簷做得很高，門很窄，像是給有翅膀的人住的。
- **經今之差**：書中寫的是一國人。現在一個人都沒有。為什麼，主角不知道。

### 鯤鵬
- **經中名**：無（山海經未載；另一部先人之書有記）
- **他書經文**：「北冥有魚，其名為鯤……化而為鳥，其名為鵬。」（《莊子·逍遙遊》）
- **疑似經載**：禺彊（海外北經）「人面鳥身，珥兩青蛇」
- **傳聞**：零號的夢（第一世，轉述）
- **親見**（第三世，夢的底層）
- **備註**：主角在條目裡貼了零號刻的木雕的素描，翅膀一大一小。

### 退役邊防機甲
- **類別**：經外之物
- **經中名**：無
- **親見**（第二世，寒序星安居院）：九子曾經住過的機甲殼。
- **轉述**：大師兄說，九子問過他：我能被算命嗎？
- **備註**：這是圖鑑裡第一個「先人沒問過的問題」。

## 六、師父的批註

隱修院那部最古的抄本，頁邊有一些很淡的字。弟子們從小看到，以為是哪一代師兄的塗鴉。

【已定：批註作為主線線索的另一條路】【提案：以下批註內容】那是師父寫的。只有他知道這本書是真的，所以他在某些地方留了記號：
- 「帝之下都」旁的墨點（陸吾）。
- 帝江條目旁寫了「勿鑿」兩個字。
- 大荒經的最後一頁，寫了一個日期，是歸墟碎掉的那一天。

主角第一世就看過這些批註，但不懂。每一次主線揭露之後，重看批註都會有新的意思。這讓圖鑑成為主線線索的另一條路：玩家可能在師父說出口之前，就先從批註裡猜到。

## 七、跨世變化

同一條目在不同世可能不同，因為世界在往前走：
- 第一世在某地見過的物種，第二世回去已經遷走或絕跡。條目加上「第二世再訪：未見」。
- 第一世親見的遺跡，第二世已被拆除或重建。
- 某個經外之物（例如某型機器人）在第一世很常見，第三世已經停產，只剩少數。

這讓圖鑑本身記錄了世界時間，也記錄了主角記得、而世界已經忘了的東西。

## 八、與美術的關係

每個條目可以有兩張圖：
- **先人圖**：仿古版刻的線描風格，靠山海圖殘片補回。
- **主角素描**：與遊戲一致的像素風格，是他親眼所見。

兩張並排，就是「經」與「今」。
