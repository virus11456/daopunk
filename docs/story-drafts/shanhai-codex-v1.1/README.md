# 山海圖鑑設計提案v1.1｜整合摘要

來源：使用者本任務貼上《DAOPUNK｜山海圖鑑 設計提案 v1.1》。本檔為整理摘要，不是原文逐字存檔；完整原文在對話。未定玩法數值、介面或獎勵。

## 本版新增已定

1. 圖鑑不收錄個別人物，專注山海與眾生；拾六、紅、零號等不另設人物條目，經外之物以族群或類型收錄。
2. 開局已有上百條「未見」經文條目，因主角已背過書；不是空白圖鑑。上百條是製作要求，尚未逐條完成。
3. 師父批註作為主線線索的另一條路；具體批註內容仍是提案。

## 設計內容登錄（提案）

核心為主角自己的山海經：抄錄、親見、比對、訂正；跨世保存親歷記憶，世界變化以新記錄補入。古籍初始可讀不等於主角知道它是真的，也不提供作者真相。

六組收錄：經載之物、經外之物、海外諸國、神與道主、創世生命、山川。它們可重疊，建議作分類標籤而非複製多份條目。神／道主與不收人物之間的編輯邊界見整合檢查。

條目欄位：經中名、今名、經文、出處、先人圖、親見（世次／地點）、傳聞（來源）、經今之差、師父批註。經外類型經中名空白。狀態草案為未見、聽聞、親見、再見、訂正，資料結構不強制依序。

八個示例候選：九尾狐（涂山氏影子九尾）、帝江（渾沌身份訂正）、燭陰（所見無山）、陸吾（墨點與動機解讀）、夸父（虛空鄧林遺跡）、羽民國（高簷窄門空城）、鯤鵬（他書與零號木雕素描）、退役邊防機甲（九子舊殼與大師兄轉述）。這些是內容提案，不是已生成圖像或全部已定情節。

批註候選：帝之下都旁墨點、帝江旁「勿鑿」、大荒末頁歸墟破碎日期。主角先見不解、後由證據重讀；沒有看過某頁不能自動回憶其中內容。

跨世可發生遷徙、絕跡、遺址拆除、型號停產；每次記錄保留日期。美術提案為先人版刻線描與主角像素素描並列，先人圖依殘片補回；未取得的圖不先生成在玩家可見頁。

## 整合檢查

- 不收人物與「神與道主」並存：建議古籍對象仍可成條目，但只收形貌、古文與親見，不收人物傳記／好感／任務；此編輯解法是提案，不抹去原稿例子。
- 開局上百條未見不代表全宇宙總數已知；另可發現經外之物。初始條目數不等於完成數，也不要求全收集。
- 九尾狐對涂山氏形貌已定；帝江就是渾沌的具體訂正仍待證據與定案，不由示例直接升格正史。
- 親見一片空地不證明物種滅絕；再訪未見與全球滅絕分開。經文與現況相異也可能是遷徙、環境變化，不一定先人寫錯。
- 師父「勿鑿」不能替代所有結局的證據；拒絕批註解讀或缺頁仍有主線路徑，亦不能將猜测視為已證實真兇。
- 鯤鵬示例的零號夢／木雕只在玩家實際得知或見過後加入；固定第三世親見是示例時間，不能直接取消分支。
- 退役邊防機甲為『第一個先人未問的問題』會和開場機器人算命衝突；建議改為『另一個書外問題』。
- 實體書、古圖與木雕不跟輪迴自動傳送；記憶圖鑑可保留讀過畫過的內容，原件證據仍需保管來源。

後續優先做條目登錄與證據格式，再擴充上百條內容及兩種圖像；本批未生成正式素材或UI。
