# 來源查核範圍

本輪重新開啟海外西／南／東經與西山經相應轉錄；其餘承接codex-batch02-review/SOURCES.md，未聲稱重做影像校勘或注者歸屬。

- [西山經槐江段](https://zh.wikisource.org/wiki/山海經/西山經)：橊及籕音注未詳；不支持直接譯為抽水轆轤。若採其他現代釋義須具名。
- [海外西經](https://zh.wikisource.org/wiki/山海經/海外西經)：丈夫國確在維鳥北、衣冠帶劍；不誤改維鳥。刑天與常羊段承接前輪定位。
- [海外東經](https://zh.wikisource.org/wiki/山海經/海外東經)：大人坐而削船未記頻率；君子文虎／大虎版本須具名，不一概判大虎錯。
- [海外南經](https://zh.wikisource.org/wiki/山海經/海外南經)：貫匈與不死民沿前輪定位；名稱同ID保留。
- 建木釋義、郭璞注歸屬與丹朱他書說未完成新查證，維持逐項待核，不當作者選古籍原文。
