# 五處傷害級場景全文覆核

162行全文已讀。依既有作者授權採修訂後文本，不新增需作者選項。

|ID|問題|落稿處理|
|---|---|---|
|H01|玩家實際獲警示及可行選擇窗口|黑板、門牌、旗與設備訊號不自動寫已知；人在內部也須有可行窗口。|
|H02|貨梯結果不是互斥過程|卡梯可後續斷纜，乘員、設備、傷勢與知情分欄；同伴各自選擇。|
|H03|不新增機械牛必備門檻|工具、開口、載重、人手依實際；被困後補候援與救援條件。|
|H04|返航需可達与執行|可見泊位不足，船況、航路、操作及船家同意需實際成立。|
|H05|冷卻城區補回能量柱逆流|溫度是警示，非取代原定異象；操作閥門需能力與裝備。|
|H06|繭歸鎮補回同時裂縫|延期、繭損與生命結果分軸；不能自行撤離不等於一律不能轉移。|
|H07|事後台詞核可用性與知情|工頭不論結果必說、受損繭像死亡紀念的台詞已修。|
|H08|世界進程與角色持久化|缺席不凍結、修復不撤回損失，NPC不是用完即消失。|

依據：三十地點現行WORKING的五列及事前警示表、N69、N20、N14、SPEC S07、第8～9批救援與維護類型接口。未作醫療或工程現實指引，亦未跑引擎場景。
