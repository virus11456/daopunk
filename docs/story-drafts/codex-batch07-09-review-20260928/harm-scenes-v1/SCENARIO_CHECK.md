# 靜態分支對照（非引擎測試）

以下預期已與WORKING逐項對照；遊戲執行均待驗收。

|場景|情境|預期|
|---|---|---|
|共通|未讀看板直接進風險區|另有實際告知和可行拒入窗口；不足則場景驗收失敗。|
|共通|初次生成就在危險區|傷害前有實際警示與可行退出機會，不能倒補。|
|共通|主角不在|世界事故及他人救援照條件推進，主角知情另記。|
|共通|早離開後他人受傷|保留傷害，不因主角退出改成全員安全。|
|貨梯|同伴拒絕改走樓梯|各自狀態，不跟主角自動移動。|
|貨梯|先卡梯後斷纜|兩段過程保留，最終設備與每人生命另判。|
|貨梯|沒有機械牛但有其他可行救援|可救，不增必備工具。|
|引潮埠|未進領航室即登船|碼頭實際告知，不靠黑板存在。|
|引潮埠|船长拒絕返航|不寫已退回，核替代；事前拒搭窗口仍須成立。|
|冷卻|清潔生物不移動|讀數、燈號或實際喊話仍先警示。|
|冷卻|只知道閥門位置|不足以操作，核能力裝備與路徑。|
|冷卻|工頭死亡或離場|不播放工頭事後台詞。|
|繭室|受損並延期|兩軸均記，不塞入互斥選項。|
|繭室|繭無名字|使用交接編號，不影響自然輪迴。|
|繭室|沒有安全轉移設備|不假定搬繭成功，繼續實際加固與照護。|
|守燈|看得見泊位但航路已斷|不能直接返回；候援與其他可行路線另判。|
|守燈|油耗恢復但船已失聯|保留失聯及事故史，不直接判死亡或安全。|
|守燈|主角無修理能力|可查問，實際修復另找可用人手，不自動修好。|
