## 三、全文（修正版）

### 序　夢與燈

【已定】造物主睡著了。祂的夢形成十個泡泡，每個泡泡是一個宇宙。十位道主各掌一種法則，彼此認識，知道世界是夢。

【已定】世人不知道的是：道主們比夢更早存在，來自夢外。讓造物主睡著的，正是他們之中的九位。第十位反對，沒能阻止。

泡泡之間有空隙，空隙裡有邊緣世界，最底層連著夢境的底層，那裡游著有翅膀的巨鯨鯤鵬。

十個宇宙中的第一個叫歸墟，連著我們的宇宙與地球。它已經碎了很久。

世界上只剩一群人類，都是一個算命門派的後裔。只有人類能學算命。世人普遍相信，歸墟的道主、第一道主，死在了歸墟破碎的那一天。

【提案】門派的院子叫方舟隱修院。《燈籍》記著每一位下山的弟子和他們在外頭生下的孩子；每一位在世的人類，燈籍閣裡亮一盞燈。燈越來越少，為什麼，沒有人知道。

### 第二部　第二世

#### 一至四

「燈籍之家」「留燈的人」「九子的圍裙」「出繭」同 v1.1。

#### 五、未交接

【提案】幽冥數據流為每位亡者保存最後紀錄；靈魂經過交接進入輪迴時，紀錄蓋上交接印。主角第一世的紀錄沒有。

閻羅 X 在燈信城削燈骨。他說他只看過兩份沒有交接印的紀錄：一份是主角的，一份是「一個被認為死了的人」。

「你的師父叫什麼名字？」主角答不出來。

閻羅 X 替他封存了紀錄。臨走前說：「若你再見到你師父，替我問他，還記不記得那盤沒下完的棋。」

【作者層，已定】閻羅 X 是當年遮掩攻擊的人。他想確認導師是否還活著，也心懷愧疚，想知道舊友是否平安。這兩件事他自己也分不開。玩家此時不知道。

#### 六、殘局

師父在院子裡掃葉子。主角把話帶到。掃帚停了很久。

「……那盤棋，下到一半，他就走了。」
「然後呢？」
「然後那天晚上，歸墟碎了。」

【提案，第一個重大揭露】師父就是歸墟之主。

「世人說你死了。」
「他們看到歸墟碎了，看不到我。」
「為什麼？」
「因為是我打碎的。」

師父說，那天夜裡有人對他出手。他打碎了歸墟，讓自己的命途跟著碎成千萬片，散在每一塊碎片裡。任何人去找，都只會找到碎片，拼不出一個完整的他。

「是誰出手？」
「……」
「你知道。」
「知道。」
「為什麼不說？」
師父沒有回答。【已定】他知道，但不說。

「他們為什麼要殺你？」
「因為我知道一件事，也反對一件事。」
師父只說到這裡。

**命途碎片能做到與不能做到的**【提案】
- 能：讓所有以命運、因果、輪迴、紀錄追索他的手段都拼不出完整的他；讓出手者也無法確認他死了沒有。
- 不能：讓他公開動用法則（一用，碎片會重新聚攏，被人找到）；讓他離開隱修院太遠太久；讓閻羅 X 忘記那份紀錄沒有交接印。

#### 七、蓋亞

【提案】蓋亞想看主角的記憶，他拒絕。她改為告訴他一件事。

【已定的真相，在此向玩家揭露】十個宇宙是造物主的夢，道主都知道。

蓋亞沒有說出道主來自夢外、也沒有說出是誰讓造物主睡著。她只說：「你的靈魂每一次都從我的輪迴旁邊直接過去。你以為記得一切是天生的嗎？」

蓋亞的立場：待你決定（見第一節待決 3）。

#### 八、第二世的中段

同 v1.1，修改一處：

【提案】閻羅 X 在燈信城把遮天親手傳給主角。「你一直回來，你的結束從來不算數。總得有一樣東西，讓你能把自己藏起來。」
【作者層】這是閻羅 X 掙扎的一部分：他替一個他可能在追捕的人，準備了躲藏的方法。

#### 九、第二次死亡

【提案】有人開始蒐集人類。人類看得見命線；在夢的底層，只有看得見命線的人分得出往哪裡走。想走到造物主面前的人，需要人類。

追兵從外洩的登錄資料中，循「未登錄旅客」往返某處的紀錄找到了隱修院。
- 若主角在閻羅篇中曾把隱修院位置告訴閻羅 X：主角永遠無法確定，那份資料是從哪裡外洩的。閻羅 X 之後否認。
- 若沒有告訴：外洩來源與閻羅 X 無關。

主角六十八歲。他把燈籍交給孩子，讓他們從後山走。他本可以用遮天藏住自己，但那樣追兵會回頭找燈籍。他沒有藏。

追兵是誰的人，第二世不揭露。

#### 二、師父的罪

【已定＋提案】師父病了。散成碎片的命途，撐了三百年，快要撐不住了。

他終於說了兩件事。

第一件，關於主角。【已定】「你出生那天，我剪了你的命途。你死的時候不經過交接，你不會被洗掉，你會記得一切。」
【提案】「我需要一個永遠不會忘記的人。我自己不能動。我一動，碎片就會聚起來，他們就會找到我。有一件事，得有人替我走到夢的最底層去做。」
「什麼事？」
「叫醒祂。」【已定：導師的立場是喚醒真實】

「你沒有問我。」
「你那天才出生。」
「你後來也沒有問我。」
「對。」
「你知道記得一切有多累嗎？」
「知道。我記得的比你多。」

第二件，關於道主。【已定】「讓祂睡著的，是我們。九個人。我反對過，沒有攔住。」
「你們是什麼？」
「在夢之前就在的東西。」

他仍然沒有說出是誰出手。

人類為什麼衰亡，師父說他也不知道。【已定：保留為謎】

#### 三、四個結局

結局需求表更新：

| 結局 | 必要法則 | 必要關係或事件 |
|---|---|---|
| 守護夢境 | 命運、因果 | 阻止陸吾與閻羅 X 的暗殺 |
| 喚醒真實 | 輪迴、真實 | 與導師的目標一致；走到燭陰面前 |
| 弒神奪位 | 命運 | 與陸吾、閻羅 X 結盟，或擊敗兩人後自己取代 |
| 煉假成真 | 命運、真實、輪迴 | 三世中數位重要人物曾「自己選擇」被主角見證 |

**守護夢境**：主角阻止了暗殺，接回歸墟的碎片，讓造物主繼續睡。這違背了師父的心願。人類沒有回來，燈會一代代少下去，燈全熄時主角將無處轉生。代價：與師父的立場相反；人類衰亡只是放慢。

**喚醒真實**：主角完成師父託付的事。他沒有鑿竅，讓燭陰睜開眼。十個宇宙變成一段被記住的夢；夢外有什麼睜開了眼。那些在夢裡活過的生命還在不在，遊戲不回答。代價：一切夢中生命的存續未知；主角完成的是師父替他決定的事，他得自己回答這是不是他的選擇。

**弒神奪位**：主角先於陸吾與閻羅 X 走進渾沌，終止造物主的睡眠之源，接手做夢；或者與兩人結盟。他看得見所有人的分支，卻再也不會被任何人看見。代價：成為唯一的做夢者；若與陸吾、閻羅 X 結盟，還得與他們分享這個位置。

**煉假成真**：主角不喚醒、不取代，讓夢裡的生命自己成為真的。夢還在，造物主還在睡，但夢裡的一切第一次不再需要祂才能存在。沒有人再看得見命線，算命失傳。主角在第四世醒來，持有輪迴與命運，自己決定繼續記得。代價：師父的心願與陸吾、閻羅 X 的野心都落空；算命失傳；主角的記得從此是他自己的選擇。
