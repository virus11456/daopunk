# v1.1收稿檢查

本次提交替代上一版候選方案，不等於稿內所有「已同意」皆有逐項確認。舊v1四題仍未收到回覆；本版另有新增待決定事項，見DECISIONS.json。

| ID | 問題 | 修訂要求 |
|---|---|---|
| L11-01 | 1.5再次把N19寫成自動終局時限 | 刪除「更接近時限」；死亡代價為真實時間、人物與地方變化，最終四結局由玩家觸發 |
| L11-02 | 十年保證＋跨世後裔／配偶排除＋人類僅數十人，可能無合格出生 | 不能悄悄放寬血緣限制、添加新血緣或安排强制生育。十年是軟目標或另設保障須作者選擇；不歸零不代表還有合格生育來源 |
| L11-03 | 待產清單的出现時間與實際出生時間混用 | W計至實際出生，十年上限若採用也必須涵蓋剩餘孕期；不能等了十年找到待產者後再加未計孕期 |
| L11-04 | 死後主角看清單並選擇，與等待期無經驗相衝 | 分清玩家UI與角色經驗；若角色確有選擇經驗，須正式修訂能力／記憶邊界，不能同時說完全無經驗 |
| L11-05 | 「最早出生三戶」預知未來且忽略雙胞胎、流產、遷徙 | 區分預估日期與实际出生；家庭ID不等於孩子ID。同時候選需穩定排序與選定紀錄，不能進出清單重抽；出生未發生的處理另提案 |
| L11-06 | 家業與星球已足以推測資源、地點与風險，不能稱無法挑好開局 | 只能降低資訊，不保證杜絕刷開局。候選消耗、世界後果與再選规则需後續測試，不能加自動結局懲罚 |
| L11-07 | 「同清單不出現兩次」與同戶再次轉生混淆 | 同一出生實例不重現，同樣戶名組合可以再出現；以孩子／出生實例識別，不能為防重複強迫家庭換名 |
| L11-08 | 同戶必為不同世代不成立 | 早死後可能轉生為父母晚年新生的另一個孩子，即前世手足；原排除规则未禁止。若要禁止父母重複生出主角須另定，不能假裝已禁止 |
| L11-09 | 跨世親屬篩選不能用姓氏或當前戶籍 | 作者層需全世代人物ID、真實親子、配偶歷史；旁系是否排除待答。收養、前任／離異／喪偶範圍及資料缺漏需定義，秘密親屬不能因玩家不知就漏篩 |
| L11-10 | 新戶模板直接生成兩名燈籍父母可能憑空增加人類 | 父母引用現存人物，成家／立戶／遷居／出生為不同事件。星球出口不是每位居民天生的技能與資產；家業要有來源 |
| L11-11 | 七戶「固定」可能被實作成永不滅戶、保證存在 | 應指七個手寫家族來源提案，不保證每世可用。家人死活、失散、童年變化仍需獨立；第一世隱修院十五歲下山不變 |
| L11-12 | 林家不知情仍待批准；沈家明列候選 | 保持各自作者決策状态，不因表格「固定」升格；旁系未排除也不代表人類族群已擴充 |
| L11-13 | 白家仍缺城市，程家新戶未有遷居條件 | 白家保留星球級提案，需從現有城市選；新戶可移動但有連續歷史，不隨每輪瞬移 |
| L11-14 | 接續型無條件出現拾六、紅的燈及家族知情 | 依人物存活、位置、實物保管與資訊來源；家人可能已被主角告知前世，不該每次都無條件不知情 |
| L11-15 | D01 v1.2、S02 v2.2被當作已存在依據 | 本機收稿目前為D01修訂v1.1、S02修訂v2.1；本次只記預期下一版接口，未收到較新版不稱已修好 |
| L11-16 | 師父「不回自己的血裡」涵蓋旁系，但旁系被允許 | 改為明確「不落在你累世子孫或配偶所生的孩子身上」的候選台詞；詩性句可保留，但不能當精確规则證明 |

仍未解：葛家藥農配偶的族屬／來歷、溫家成立到子代成長的年表、無合格新生兒、童年提前死亡、母體與孩子身份綁定時間。這些問題不因模板化就自行消失。
