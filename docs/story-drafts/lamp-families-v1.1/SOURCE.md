## 一、落點規則

### 待產清單與半選擇
主角死後世界時間前進，燈籍出現待產孩子時，玩家從清單選一戶。兩至三戶選一；只有一戶直接落點；超過三戶只顯示最早出生三戶；空清單繼續前進，受十年上限保證。

可見宇宙與星球、家業、是否與隱修院聯絡、第幾代下山；不可見開場處境、當時時代狀態、誰還活著，醒來才知道。

### 師父留下的空隙
提案：那一刀只使主角不經交接、落在燈籍新生兒身上，沒有替他決定哪一戶；命運打開數條路，最後由主角意志決定。師父決定他要記得，却留下重新開始的地方。階段六可由師父說明或主角察覺。

### 直系規則
提案：父母任一方為主角任何一世的直系子孫（子女、孫輩及以下）或配偶，該家庭不入清單。師父可說「那一刀，不讓你回到自己的血裡」。前世兄弟姊妹、表親的後代不限制，遇到可寫家族往事，不作禁忌。

### 等待上限
提案：等待新生兒最長約十年；為設計保證，不作額外敘事解釋，世界看來剛好有人出生。下限不設，可能死後隔年出生；加14～15年成長，死亡至可玩約14～25年。

### 抑制故意死亡
清單不透露開場處境，故無法挑好開局。每次死亡付出14～25年世界時間，並更接近時限【稿件標已定N19】。同一清單不出現兩次，由當時世界決定。

## 三、新戶模板

燈籍人彼此成家或下山弟子另立門戶，可出新戶，不逐一手寫。

| 欄位 | 生成方式 |
|---|---|
| 地點 | ATLAS既有地點，優先匿名、庇護、避難，如深淵避難城區、神經網離線聚落 |
| 家業 | 星球主要出口 |
| 對外身分 | 依家業 |
| 知情 | 多半知情，但無祖傳藏身方法 |
| 開場 | 地方既有矛盾 |
| 時代掛鉤 | 一至兩個時代事件，多取事件池 |
| 家人 | 父母兩人為燈籍人，可有手足 |

錨家為示範：沉錨星墜索鎮打撈工，面對先救貨不救人的矛盾。

## 四、開場類型

| 類型 | 說明／例子 |
|---|---|
| 離家 | 家事需出門；卜家押糧箱出星 |
| 留家 | 家裡是事件中心；夏家遭懷疑盜賣航圖，留下澄清 |
| 危機 | 盤查、追殺、災難；白家封存室被要求交受庇護名單 |
| 秘密 | 林家不知身分，主角覺醒後決定是否說出 |
| 接續 | 前世熟人或地點在附近；魏家附近的拾六或紅的燈 |

同戶依時代可用不同類型，非每輪都先家事再離家。

## 五、同戶再落點

不違反直系規則即可再落同戶，為不同世代。前世父母可能已是祖輩或過世；主角記得家以前樣子，家人不知道他曾在此長大。可觸發認出祖母年輕照片的一次性記憶事件。
