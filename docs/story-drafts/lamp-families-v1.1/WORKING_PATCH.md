# 可直接合入的既定修正與待定界線

未改寫SOURCE。下列既定修正可採用；其餘仍等作者決策。未實作轉生選單或Godot。

## 1.5 替換稿

每次死亡會失去當世身體、修為及當世可用關係條件，世界依實際出生等待與成長時間向前。人物可能老去、地方可能改變，錯過的事件不能藉正式輪迴倒轉。最終結局由玩家觸發，不設死亡次數或世界時限自動終局。

待產資訊只能減少玩家對開局的預知，無法保證玩家不挑偏好的地點、家業或聯絡條件。避免重抽的規則另作設計：每個候選出生使用唯一實例，同一實例不重建；同戶名單日後可再次出現，但綁定不同孩子。讀檔與死亡重試政策仍未定。

只有當等待W≤10年被批准且保障机制自洽時，死亡到可玩才可概括為14～25年；在此之前，沿用D＋W＋A（A＝14～15），不聲稱25年硬上限。

## 七戶與新戶用語

「七戶固定家庭」暫改「七個手寫家族來源提案」。沈家仍候選；林家的失憶身分設定待確認。第一世固定隱修院十五歲覺醒後首次下山，不能抽家庭改掉開場。其後轉生家庭需根據出生與覺醒兩個時點分別記錄；父母、手足、家業與住址不因跳過童年而凍結。

新戶引用既有燈籍人物ID，记录成立和搬遷事件。新戶不自動生育；立戶不增加人數；可生育與是否已有孩子也不能由家業模板推導。無祖傳藏身方法可以是某戶的处境，不是每個新戶必然如此。

## 同戶重生與知情

同戶再次落點可能是不同世代，也可能是同代晚出生的手足，依最終排除規則判斷。人物姓名與戶名不是血緣判據。記憶事件依主角真正親歷与物件仍存在而觸發；家人是否知道主角前世，读取過往披露與可信消息，不一律當不知道。

## 半選擇等待確認

推薦把選單資訊與角色知識分離，但這是新提案：玩家可以看候選，主角的等待期不自動新增對家庭近況的記憶。若採主角短暫有經驗版本，必須在背景與階段六同步改明；不得先寫定「自己選的」台詞再讓決策表保持待定。
