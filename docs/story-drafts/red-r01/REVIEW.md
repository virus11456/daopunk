# R01紅篇銜接檢查

保留重點：紅有自己的界線；家屬不是死亡謎題的道具；新聞更正晚於流言；尊重拒算與偷看能產生關係差異；共同收信和旁觀分支給S02留下可核對的具體記憶。

| ID | 位置 | 問題 | 修訂要求 |
|---|---|---|---|
| RR01 高 | 開頭假設、阿灰、人口史接口 | 原稿假設三題未答並採散居隱性人類後裔，已被最新答覆否決 | 明示第一世已定、功德全保留；移除阿灰隱性人類伏筆，保留他的個人困境與未知族屬，不自行改成胚胎方案 |
| RR02 高 | R01-1、R01-3 | 修燈在清晨，兩天後卻用來證明「那天晚上」行蹤；證詞時段不一致 | 指明案發／最後在世時段、詢問時段與主角真正在場時間；不可用未見證的夜晚作不在場證據 |
| RR03 中 | 修燈及S02接口 | 把燈掛低避免撞頭的空間因果不清；結尾紅照樣撞燈，可能是刻意笑點但需要一致佈局 | 說明燈是否移到側邊、原先撞何處、新高度怎麼妨礙客人；固定可由像素場景呈現的方位與高度，再供S02核對 |
| RR04 高 | R01-4 | 偷看仍只呈現兩條模糊路，未顯示已確認的分支機率；知道下山時刻可替代生辰、被觀命能被察覺均為新增能力規則 | 機率／觀測條件需具體呈現；命錨替代與察覺範圍明示待定，不能拿此場直接定義全師門能力 |
| RR05 高 | R01-5、R01-6 | 偷看後是否被邀同行沒交代；R01-6拒說時紅不提大師兄活著，但結尾仍無條件寫該知識旗標 | 補同行動機或不同入場方式；逐分支設定主角知道什麼。紅知道的事與主角知道的事分開 |
| RR06 中 | R01-6及第一批人物表 | 本篇紅因承諾「相信」大師兄活著，第一批卻說她「知道」且承諾保密；不知道地址是否真話又交未來決定 | 作者版選擇一套一致知情狀態，角色可以說謊但編劇不能同時把互斥事實都當真。未定前以候選分開 |
| RR07 中 | R01-7、組織篇接口 | 「死亡被冒名」不準確：本篇沒有冒名者認領，只有報刊與街坊歸罪；地下匿名聲明也未驗證發布者 | 改稱「死亡被錯誤歸因／被嫁接到拒單傳聞」，除非另寫冒名事件；來源真偽不得由轉述自動證實 |
| RR08 中 | 到期、再訪與消息 | 後續依玩家走完R01-6才推一週，但死亡、登記令、更正應按世界時間推進；協助更正沒有實際送達步驟 | 分開世界事件與玩家場景；未參與也會有基礎更正流程，提早兩天須基於實際送達。缺席補再訪版本，不全世界等玩家 |
| RR09 中 | 全篇旗標與自評 | 宣稱沒有數值卻使用信任+1/+2/-3與回升1；多處選項是否互斥、可否補做未說明 | 先用敘事關係狀態，或者把數字明列非正式占位；至少註明問話／幫忙能否同做及後續讀取條件 |

死亡證明在作者層可對應病逝提案，玩家層只證明醫師結論；巡捕撤除對紅的懷疑需有其取得證據的過程。不可用主角預知未來取代過去案情證據。固定清白收束可以成立，但應讓玩家知道自己實際幫到了什麼。

本稿未修改；以上均是待修條目。原稿的家屬段落和中立組織間接呈現保留，不必為修問題增加戰鬥或強制加入組織。
