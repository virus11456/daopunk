## 一、落點規則（取代 v1 的 1.3）

### 1.1 待產清單與半選擇
主角死亡後，世界時間前進。當燈籍上出現**待產的孩子**時，玩家從當時的待產清單中選一戶。

| 情況 | 處理 |
|---|---|
| 清單有兩到三戶 | 玩家選一 |
| 清單只有一戶 | 沒有選擇，直接落在這一戶 |
| 清單超過三戶 | 只顯示最早出生的三戶 |
| 清單為空 | 世界時間繼續前進，直到有人待產（受 1.4 上限保證） |

**選擇時可見的資訊**（刻意有限）：
- 宇宙與星球
- 家業
- 這一戶與隱修院是否有聯絡
- 這一戶是第幾代下山

**不可見**：開場處境、當時的時代狀態、誰還活著。玩家要醒來之後才知道。

### 1.2 為什麼能選：師父那一刀留下的空隙
【提案】師父剪命時，只讓主角「不經交接、落在燈籍新生兒身上」，沒有替他決定落在哪一個。命運直送會打開幾條可能的路，**最後走哪一條，由主角自己的意志決定**。

這在主題上是一個小小的反轉：師父替他決定了要記得，卻把「在哪裡重新開始」留給了他。這一點可在主線階段六（師父的罪）中讓師父說出，或讓主角自己察覺。

### 1.3 直系規則
【提案】命運直送**不會**讓主角落在以下家庭：
- 父母任一方是主角任何一世的**直系子孫**（子女、孫輩及以下）。
- 父母任一方是主角任何一世的**配偶**。

這些家庭即使待產，也不會出現在清單中。
- 敘事說法（可由師父在階段六說出）：「那一刀，不讓你回到自己的血裡。」
- 前世的兄弟姊妹、表親的後代不在限制內；若主角落在這些家庭，可以寫成家族裡的一段往事，不作為禁忌。

### 1.4 等待時間的上限
【提案】等待燈籍新生兒的時間**最長約十年**。這是設計保證，讓一次死亡不會跳過數十年。
- 敘事上不另作解釋；世界呈現為「剛好有人出生」。
- 下限不設；可能死後隔年就有人出生。
- 加上十四到十五年的成長，每次死亡到下一輪開始，約在十四年到二十五年之間。

### 1.5 抑制故意死亡換開局
- 清單不透露開場處境，玩家無法挑到「好開局」。
- 每一次死亡都要付出十四到二十五年的世界時間，並更接近時限【已定 N19】。
- 同一份清單不會出現兩次：死亡後的清單取決於那時的世界。

## 三、新戶模板

燈籍人彼此成家，或下山弟子另立門戶，就會出現新戶。新戶由模板生成，不逐一手寫。

| 欄位 | 生成方式 |
|---|---|
| 地點 | 從 ATLAS 既有地點中選取，優先選「匿名、庇護、避難」性質的地方（例如深淵避難城區、神經網離線聚落） |
| 家業 | 取該星球的主要產出（ATLAS 的出口欄） |
| 對外身分 | 依家業 |
| 知情 | 新戶多半知情；但沒有祖傳的藏身方法 |
| 開場處境 | 取該地點既有的在地矛盾 |
| 時代掛鉤 | 一到兩個依時代而變的事件（多取自事件池） |
| 家人 | 父母兩人為燈籍人；可有兄弟姊妹 |

**範例**：錨家（v1 的第 7 戶）改為新戶模板的示範：深淵沉錨星墜索鎮，打撈工，在地矛盾是打撈商優先救貨不救人。

## 四、開場類型

不是每一輪都「覺醒、家裡有事、離家」。

| 類型 | 說明 | 例子 |
|---|---|---|
| 離家 | 家裡有事需要有人出門，主角順勢離開 | 卜家押糧箱出星 |
| 留家 | 家裡就是事件的中心，主角可以選擇不走 | 夏家被懷疑盜賣航圖；主角留下來洗清家人的嫌疑 |
| 危機 | 盤查、追殺、災難正在發生 | 蒐集時代的白家：封存室被要求交出受庇護者名單 |
| 秘密 | 家人不知道自己是誰，主角知道 | 林家：主角覺醒後讀得見命線，要決定告不告訴家人 |
| 接續 | 前世認識的人或地方就在附近 | 魏家在破爛一條街，拾六或紅的燈就在幾條街外 |

同一戶在不同時代可以有不同類型：例如夏家在燈下時代是留家型，在蒐集時代是危機型。

## 五、同一戶再次落點

- 主角可能在不同世落在同一戶（只要不違反直系規則）。
- 這時是不同的世代：前一世的父母可能已是祖輩，或已過世。
- 開場處境不同；主角記得這個家以前的樣子，家人不知道他曾經在這裡長大。
- 可觸發一次性的記憶事件（例如認出祖母年輕時的照片）。
