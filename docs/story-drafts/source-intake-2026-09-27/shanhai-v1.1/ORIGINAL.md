# DAOPUNK｜山海經融入設定 v1.1

> **已定**：《山海經》是古代先人探索這些宇宙後寫成的書；探索發生在造物主沉睡、夢形成**之後**，先人是夢裡的人類；涂山氏只取九尾狐的形貌，不提大禹；只有師父知道這本書是真的。
> 其餘對應、用途與劇情接點皆為【提案】。
> 《山海經》《莊子》為公有領域古籍，本文引用原文並作為本作虛構設定使用。

---

## 一、這本書在世界裡是什麼

【已定】《山海經》是先人對宇宙的探索紀錄，不是神話。

【提案】
- **先人是誰**：【已定】造物主沉睡、夢形成之後，很久以前的人類。那時人類很多，散居在各個宇宙；人類看得見命線，能在宇宙之間、甚至空隙裡找到方向。先人順著命線走過許多宇宙，把看見的山、水、生物、國度、神記了下來。
- **為什麼寫得像神話**：先人用自己熟悉的東西去描述從未見過的事物。「人面蛇身」「六足四翼」不是想像，是一個人類第一次看見創世生命、夢外生命時，能找到的最接近的說法。
- **原本有圖**：傳說書原本配有地圖（山海圖），標示航路與方位。圖早已失傳，只剩文字。
- **流傳現況**：
  - 世間：各地流傳多種殘本，被當成古老神話，版本之間互有出入。
  - 師門：方舟隱修院的燈籍閣藏有一部最古的抄本，是師門弟子啟蒙時讀的書。弟子們從小背它，把它當成祖先留下的故事。【已定】只有師父知道它是真的。
  - 道主：道主們知道這本書記的是真的。

## 二、書的結構與宇宙的對應【提案】

《山海經》分為「山經」與「海經」兩大部分。

| 書中部分 | 對應的世界 | 說明 |
|---|---|---|
| **山經**（五藏山經：南、西、北、東、中） | 十大宇宙內部的星球、山川、物產 | 先人在宇宙之內的行旅紀錄 |
| 中山經 | 歸墟 | 先人以歸墟為中心，因為歸墟連著夢外；其他宇宙依航路方向記為南、西、北、東 |
| **海內經** | 各宇宙泡泡的內側邊緣 | 宇宙之內、靠近邊界的地方 |
| **海外經** | 宇宙之間的空隙與邊緣世界 | 【已定】穿梭時可能誤入的邊緣世界 |
| **大荒經** | 夢境底層與夢的盡頭 | 【已定】邊緣世界的最底層連接夢境底層 |

「山」是有地可站的地方，「海」是地與地之間的東西。先人把宇宙裡的世界寫成山，把宇宙之間的空隙寫成海，把最深、最遠、再也沒有地的地方寫成大荒。

## 三、書中記載與本作的對應【提案】

| 書中記載 | 原文 | 在本作中是什麼 |
|---|---|---|
| **燭陰**（海外北經）／**燭龍**（大荒北經） | 「鍾山之神，名曰燭陰，視為晝，瞑為夜，吹為冬，呼為夏，不飲，不食，不息，息為風，身長千里。」<br>「人面蛇身而赤，直目正乘，其瞑乃晦，其視乃明。」 | 【已定】三大創世生命之一。【提案】先人在海外（空隙）看見祂盤在夢的邊緣，又在大荒（夢底）看見祂，所以兩處都有記載。「視為晝，瞑為夜」即造物主的寤寐 |
| **帝江**（西山經） | 「有神焉，其狀如黃囊，赤如丹火，六足四翼，渾敦無面目，是識歌舞，實惟帝江也。」 | 先人從遠處看見的**渾沌**。「渾敦無面目」就是沒有七竅 |
| **陸吾**（西山經） | 「是實惟帝之下都，神陸吾司之。其神狀虎身而九尾，人面而虎爪；是神也，司天之九部及帝之囿時。」 | 【已定】道主陸吾。【提案】先人記下他守著「帝之下都」，也就是造物主的下方居所。他守了太久，開始想坐上去 |
| **九尾狐**（南山經，青丘之山） | 「有獸焉，其狀如狐而九尾，其音如嬰兒。」 | 【已定】先人記下的道主**涂山氏**的形貌。本作不採用她與大禹相關的傳說 |
| **禺彊**（海外北經） | 「北方禺彊，人面鳥身，珥兩青蛇，踐兩青蛇。」 | 先人對**鯤鵬**的誤記或另一種看見。書中爭議：禺彊是否就是鯤鵬的一瞥 |
| **鯤鵬**（《莊子·逍遙遊》） | 「北冥有魚，其名為鯤……化而為鳥，其名為鵬。」 | 【已定】創世生命鯤鵬。【提案】《山海經》沒有直接記下牠，另一部先人之書記了 |
| **海外諸國**（羽民國、長股國、無腸國等） | — | 曾經住在各宇宙、各空隙邊緣的人類聚落。如今全都不在了。這是人類曾經很多、後來衰亡的物證；**為什麼衰亡，仍保留為謎**【已定】 |
| **夸父逐日**（海外北經） | 「夸父與日逐走，入日；渴，欲得飲……未至，道渴而死。棄其杖，化為鄧林。」 | 一位先人追向燭陰睜開的眼，想走到造物主醒來的地方，死在半路。是喚醒這條路最古老的警告 |

**書中沒有的道主**：奎托斯、蓋亞、玉皇 Prime、沃倫、聚變、閻羅 X、亞茲、導師，書中沒有明確記載。【提案】先人只走到部分宇宙的要地；其他道主可能以不同名字出現在殘本中，或所在篇章已經失傳。

## 四、在故事中的用途【提案】

### 4.1 主線接點

| 主線章 | 山海經的作用 |
|---|---|
| 主1 | 主角小時候在隱修院背誦山海經，把它當祖先的故事。開場可以有一句他對拾六說的：「師門的書裡有九尾狐、有人面蛇身的神，就是沒有機器人。」 |
| 主6 殘局 | 師父說歸墟是他打碎的。主角想起中山經寫的歸墟山川，與現在的地形對不上。 |
| 主7 夢 | 蓋亞告訴他世界是夢，也告訴他：「你們師門背的那本書，是真的。」這是主角第一次重讀山海經。 |
| 主9 師父的真相 | 師父指出西山經的一句：「帝之下都，神陸吾司之。」主角此時還不知道陸吾是出手者，只記下了。 |
| 主10 法則 | 主角用山經當地圖走各宇宙。書上的方位與現在的星圖有差異，因為宇宙會變，先人也會記錯。 |
| 主11 碎片上的空白 | 推出陸吾之後，主角想起那句「帝之下都」，明白陸吾守的是什麼、想要的是什麼。 |
| 主12 夢的底層 | 主角照著海外經、大荒經的記載往下走。他看見燭陰，對上「視為晝，瞑為夜」；看見渾沌，對上「渾敦無面目」。他也想起夸父。 |
| 主15 抉擇 | 選擇喚醒的玩家，會在燭陰面前讀到夸父那一段。 |

### 4.2 支線題材（之後可寫）

- **山海圖**：失傳的地圖殘片在各地出現，拼起來能標出通往大荒的航路。弒神一方也在找。
- **海外諸國的遺跡**：在邊緣世界找到先人聚落的遺跡，是人類衰亡之謎的物證，但不給答案。
- **版本之爭**：記憶公證所、拍賣場、學者為了哪一個殘本才是真的爭執。
- **書裡的生物還活著**：各宇宙中仍有書中記載的生物後裔，當地人叫法與書中不同。

## 五、自洽檢查

| 檢查點 | 結果 |
|---|---|
| 先人是人類，看得見命線才能航行 | 與「人類能讀命」「人類是夢底導航者」一致 |
| 先人很多、散居各宇宙 | 與「人類衰亡」一致；衰亡原因仍為謎 |
| 書中燭陰與已定的創世生命燭陰 | 一致 |
| 帝江＝渾沌 | 與已定的渾沌「無臉、無七竅」一致 |
| 陸吾在書中守帝之下都 | 與已定「陸吾想取代造物主」一致，並提供長期動機 |
| 道主來自夢外、比夢更早 | 先人只能記下他們在夢裡的樣子，不知道他們從哪裡來 |
| 鯤鵬不見於山海經 | 由《莊子》補上，並以禺彊作書中疑似記載 |
| 師門知道書是真的嗎 | 【已定】弟子當成祖先故事背；只有師父知道它是真的 |
| 先人的時代 | 【已定】沉睡之後；先人是夢裡的人類，因此看得見命線，也因此不知道道主從夢外來 |
