# DAOPUNK｜組織委託 設計提案 v1：不入會也能接的工作

> **起因**：你提到主角也可能只是協助組織護送、或執行它們的委託，不一定入會。
> **依據**：中立組織篇 v1；加入中立組織 v1.1（殺手組織開放加入、跨世承認三種方式、無上限）；時代與事件池 v1.1；燈籍家庭 v1.1。
> **全部為【提案】**，除非註明【已定】。不定數值、報酬、等級；未接 Godot。

---

## 一、三層關係

主角與每個中立組織的關係，可以停在任何一層：

| 層級 | 說明 | 義務 | 保護 |
|---|---|---|---|
| **委託者** | 接一件委託，完成後各走各的 | 只對這一件委託負責 | 無 |
| **常客** | 多次合作，組織開始信任他，會主動找他 | 守這個組織的基本祕密 | 少量：組織會提前告訴他危險 |
| **成員** | 入會（見加入中立組織 v1.1） | 組織的全部義務 | 組織的保護與內部資源 |

- 不入會也能接大部分委託。
- 有些委託只給常客或成員（例如斷鏈避難網的撤離、殺手組織的委託）。
- 【已定】同時與多個組織往來沒有上限；義務衝突會自然限制。

## 二、委託從哪裡來

| 來源 | 例子 | 公開程度 |
|---|---|---|
| 公告板 | 港口的護送招募、打撈聯盟的工程公告 | 公開 |
| 中介 | 黑市中介、兵團的招募人 | 半公開 |
| 口頭 | 常客才會收到的私下請託 | 不公開 |
| 事件延伸 | 事件池的某個事件結束後，組織找上門 | 依事件 |

## 三、委託的結構（模板）

委託是事件池的一個子類型，沿用事件模板欄位（時代與事件池 v1.1），另加：

| 欄位 | 內容 |
|---|---|
| 委託方 | 哪個組織、哪個單位、誰出面 |
| 委託內容 | 護送、送達、鑑定、調查、打撈、撤離、仲裁、執行契約等 |
| 報酬 | 敘事描述（錢、船位、通行、情報、人情）；不定數值 |
| 隱情 | 委託方沒說的事（可有可無） |
| 可拒絕 | 所有委託都可以拒絕；拒絕的後果依組織 |
| 失敗 | 委託失敗時，組織與世界的反應 |
| 缺席 | 主角不接時，委託由誰接、結果如何 |
| 關係變化 | 對該組織的狀態（陌生、合作過、常客、成員、不受歡迎） |

## 四、跨世

- 【已定】組織只認得這一世的這個人。
- 常客關係**不延續**；主角每一世都要重新建立信任。
- 例外（依加入中立組織 v1.1 的暗號承認）：黑匣信使局、星際商隊、斷鏈避難網可以因主角說出前世的暗號或航誌，更快接受他，甚至直接恢復常客關係。
- 主角記得每一件接過的委託。重接同一類委託時，他知道哪裡可能出錯，但不能預知新的細節。

每一類組織列出二到三種委託，作為事件池的委託子池。

## 六、殺手組織的委託

【已定】殺手組織開放加入。本節處理**不入會、以委託身分**接觸的情形。

- **可接層級**：常客或成員。陌生人不會收到執行委託；委託者層級只能接調查與見證。
- **寫作原則**（沿用加入中立組織 v1.1 第 3.5 節）
  - 每一件委託的對象都有名字、家人、生活。
  - 每一件完成的委託都有家屬與社區的後果場景；不描寫暴力過程。
  - 主角記得每一件接過與拒絕過的委託。
  - 觀命需要對方同意；刺殺對象不可能同意，偷看是越界。
- **拒絕**：所有執行委託都可以拒絕。無聲會的常客拒單不受追究；秤的常客拒單會失去常客身分。
- **不入會的差別**：常客不受組織保護；完成委託後若被追查，組織不會替他掩護。

## 七、委託與燈籍祕密

| 委託 | 燈籍風險 |
|---|---|
| 領航、帶路 | 高：太準的方向感會讓人懷疑 |
| 鑑定山海相關遺物 | 中：可能被追問師承 |
| 公證所作證 | 高：可能讓人知道他記得前世 |
| 護送、送信、打撈 | 低 |

主角可以刻意表現得不那麼準，以保護身分；但這可能讓委託失敗。

## 八、委託與肉鴿節奏

- 委託是每一世最容易找到的工作，適合在覺醒、離家之後、尚未推進主線時填補遊玩時間。
- 常客關係每一世重建，讓同一個組織在不同世代有不同的面孔。
- 主角的家庭開場（燈籍家庭 v1.1）可以直接接上委託：例如卜家押糧箱出星，就是一件商隊護送委託。
