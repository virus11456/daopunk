# DAOPUNK｜K01 奎托斯篇 v1《承擔》

> **位置**：道主篇第四篇。可在任何一輪、任何時代開啟【已定：肉鴿、時代延續到時限】。
> **主題**：主角每一世都能重來，那他的承擔算什麼？
> **依據**：完整背景 v1.4；道主篇總綱 v1；示範事件 EV-010；ATLAS 武神界（U-002）既有地點與地方矛盾。
> **標記**：【已定】註明來源；其餘為【提案】。關係以敘事狀態表示。「擊倒」是正史既有取得途徑，戰鬥玩法未定。不定數值；未接 Godot。

---

## 一、人物與前提

| 項目 | 內容 |
|---|---|
| 宇宙 | 武神界（U-002），首都星赤岳星（U-002-P1） |
| 駐地 | 赤旌京（U-002-P1-C3，道主駐地提案）：戰旗環繞的斷劍議殿；地方矛盾：主戰派要求全民徵召 |
| 法則 | 因果【已定】 |
| 人物核心 | 克制、守約，認為力量必須承擔後果；弱點是把拒絕戰鬥誤認成逃避（CHARACTERS 提案） |
| 身世 | 曾以決鬥代替全面戰爭的仲裁者；和平是否只是被強者壟斷，是他的人物矛盾（CHARACTERS 提案） |
| 對沉睡 | 守護（總綱提案）：讓造物主入睡時，是他用因果讓「沉睡」成為一件有人承擔後果的事；他覺得那個後果由他扛著 |
| 傳奇法則 | 《返因》（DAO_RULER_POWERS 提案）：辨識並改動一段可接觸的因果鏈，返還或截斷特定效果 |

**奎托斯的祕密**（提案，只在主角已知 K5 時揭露）：當年沉睡的「代價」，是他以因果綁在自己身上的。若造物主醒來，這個代價會一次回到他身上。他從未對其他道主說過這件事。

## 二、場景

### K-1｜被施壓的裁判
- **擴寫自** EV-010。
- **地點**：演武城區（U-002-P1-C1）：分層觀戰擂台與機械戰鼓。地方矛盾：裁判受軍閥施壓。
- **處境**：老裁判被軍閥的人堵在後台，要他明天判某一方輸。
- **選項**（非戰鬥為主）
  - 陪裁判去找擂台的主事。
  - 找出軍閥施壓的證據（擂台的押注紀錄、軍閥手下的往來）。
  - 教裁判怎麼拖延（例如依規則延賽）。
  - 戰鬥（玩法未定）。
  - 不管。
- **奎托斯在場**：他坐在觀戰台最高一層，不介入。
- **觀命**（須裁判同意、找對命錨）：對象：明天照實判，裁判一個月內的走向。
- **結果**：依選擇；奎托斯記住主角是用什麼方式處理的。
- **寫入**：`奎托斯_見證：非戰鬥｜戰鬥｜未處理`。

### K-2｜兵契（《返因》任務途徑）
- **地點**：戰後聚落（U-002-P2-C2）：用裝甲片搭建的義肢工棚。地方矛盾：退伍者被兵契束縛。
- **開啟條件**：K-1 之後，奎托斯派人找主角；或主角自行到訪。
- **奎托斯的請求**
  > 奎托斯：「有一個人，簽了一紙兵契。戰爭結束了，契還在。他走不了。」
  > 奎托斯：「替他解約。不能用刀。」
  > 主角：「為什麼不能用刀？」
  > 奎托斯：「因為用刀解的約，下一次會用更大的刀簽回去。」
- **出場**：退伍者**岳承**（新增提案；族屬未定），兵契的持有人（一位軍需官）。
- **兵契的內容**：戰時簽下，約定「戰爭結束後仍服役十年」；軍需官以此調用退伍者做私人工程。
- **解法**（非戰鬥，至少一條）
  - 找出兵契簽署時的條件：若當時未告知「戰後仍服役」，契約可主張無效。
  - 找到其他同樣被束縛的人，一起向軍令處申訴。
  - 替岳承觀命（須同意、找對命錨），看出軍需官的弱點條件（例如他自己也欠了上級的債）。
  - 與軍需官談判：以另一個對他有利的安排換取解約。
- **結果**
  - 成功（不用暴力解約）：任務完成。
  - 用了暴力：解約成立，但任務失敗；奎托斯：「你證明了刀比契約有用。這正是我怕的。」
  - 失敗：可在下一個時代再接（人物可能已換）。
- **寫入**：`奎托斯任務_成功｜暴力｜失敗`、岳承的狀態。

### K-3｜斷劍議殿
- **地點**：赤旌京。戰旗環繞，議殿中央是一把斷劍。地方矛盾：主戰派要求全民徵召。
- **處境**：鐵關星要求戰時自主調兵（ATLAS 星際矛盾），主戰派要求全民徵召。奎托斯提出：以一場決鬥代替全面戰爭。
- **主角的角色**（依與奎托斯的狀態）
  - 旁觀：主角可以私下問奎托斯。
  - 見證人：奎托斯請主角當見證人，因為「你會記得」。
- **對白**
  > 主角：「用一場決鬥決定一場戰爭，輸的那方就要接受？」
  > 奎托斯：「對。」
  > 主角：「那贏的，永遠是最能打的那個。」
  > 奎托斯：（很久）「……是。」
  > 奎托斯：「這是我的和平。它讓很多人不用死。它也讓很多人永遠贏不了。」
- **選項**
  - 支持決鬥。
  - 提出另一種解決方式（例如讓禾盾星、奔雷星的後方意見進入議殿；接 ATLAS「軍令權爭議」）。
  - 不表態。
- **結果**：依選擇，決鬥或協商舉行；戰爭是否發生是世界事件。
- **寫入**：`斷劍議殿_結果`。

### K-4｜承擔
- **開啟條件**：主角與奎托斯的狀態至少為「尊重」；且奎托斯知道主角會輪迴（來源：主角自己說出，或奎托斯從其他道主處得知）。
- **地點**：赤岳星採石城區（U-002-P1-C2）的試石碑前。
- **對白**
  > 奎托斯：「你每一世都能重來。」
  > 主角：「我每一世都記得。」
  > 奎托斯：「那你的承擔算什麼？死了就重來，錯了就換一個身體。」
- **主角的回答**（依實際經歷，旗標決定可選項）

| 可選的回答 | 需要的經歷 |
|---|---|
| 「我死了，世界會往前走十幾二十年。我認識的人會老、會死。我回來，他們已經不在了。」 | 主角至少死過一次 |
| 「我記得每一個我沒救到的人。」 | 任一世曾有人在主角面前死去或受害 |
| 「我在閘門裡轉輪子的時候，以為那是最後一次。」 | 主角曾在閘門事件中開閘而死 |
| 「我留在院子裡，讓孩子們帶著燈籍走。」 | 主角曾在追殺事件中不藏自己 |
| 「我還不知道。」 | 無 |

- **奎托斯的回應**
  - 前四者之一：
    > 奎托斯：（很久沒有說話）「……你的承擔，是你記得。」
    > 奎托斯：「我以為能重來的人，不必承擔。我錯了。」
  - 「我還不知道」：
    > 奎托斯：「那你去找。找到了，再回來告訴我。」
- **若主角已知 K5**（奎托斯的祕密）
  > 主角：「你也同意讓祂睡。」
  > 奎托斯：「我不只是同意。那一夜，是我讓沉睡有了代價，並把代價綁在我自己身上。」
  > 主角：「祂醒來的話——」
  > 奎托斯：「那個代價會回來。全部回到我身上。」
  > 奎托斯：「所以我守著祂睡。不是因為我怕毀滅。是因為我答應過要承擔。」
- **寫入**：`奎托斯_承擔的回答`；`得知_奎托斯的代價`（僅在 K5 已知時）。

### K-5｜決鬥（《返因》擊倒途徑）
- **地點**：赤旌京的斷劍議殿，或演武城區的擂台（主角選）。
- **奎托斯的邀請**
  > 奎托斯：「你打贏我，就得承擔拿走因果之後的結果。」
- **選項**
  - 應戰：戰鬥玩法未定。勝則取得；敗則可下一輪或下一個時代再來。
  - 拒絕：
    > 奎托斯：「你在逃。」
    > 主角（可選）：「我不打，不是因為我怕輸。是因為贏了，我也不會比較對。」
    > 奎托斯：（停住）「……」
    - 若主角說出這句，奎托斯的弱點被觸動：他第一次承認「拒絕戰鬥不一定是逃避」。記 `奎托斯_弱點被觸動`。這不直接給法則，但會讓親授的條件放寬（見 K-6）。
  - 拒絕且不說：奎托斯不追究，但關係不變。
- **寫入**：`決鬥_勝｜敗｜拒絕`。

### K-6｜返因
- **取得途徑**（三選一，互斥；每種法則只取得一次【已定】）

| 途徑 | 條件 | 場景 |
|---|---|---|
| 擊倒 | K-5 勝 | 奎托斯：「拿去。從今天起，它的後果也是你的。」 |
| 任務 | K-2 成功（非暴力） | 奎托斯：「你用契約解了契約。這才是因果。」 |
| 親授 | K-4 中主角給出前四者之一的回答；或 `奎托斯_弱點被觸動` 且主角曾在任一世為保護他人承擔重大後果 | 奎托斯：「你的承擔是記得。我把因果交給一個會記得後果的人。」 |

- **拒絕**：主角可以不接受；奎托斯：「那也是一種承擔。」
- **《返因》的使用邊界**（提案，依 DAO_RULER_POWERS 限制）
  - 辨識一段可接觸的因果鏈，把特定效果返還給施加者，或在結果完成前截斷一個必要環節。
  - 不能憑空創造一個承擔後果的人。
  - 已經發生的死傷不因此復原。
  - 截斷一條因果鏈，可能影響依賴它的其他人。
- **寫入**：`法則_因果`。

| 項目 | 說明 |
|---|---|
| 奎托斯 | 道主，不受時代影響 |

## 六、新增提案

1. 奎托斯把沉睡的代價以因果綁在自己身上；造物主醒來時代價回到他身上。
2. 退伍者岳承與兵契事件。
3. 斷劍議殿以決鬥代替戰爭，以及「贏的永遠是最能打的」的矛盾。
4. 主角對「承擔」的回答依實際經歷解鎖；「你的承擔是記得。」
5. 拒絕戰鬥觸動奎托斯的弱點，放寬親授條件。
