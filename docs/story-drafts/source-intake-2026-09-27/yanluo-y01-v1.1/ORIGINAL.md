## 二、交接印制度【提案】

### 2.1 定義

**交接印是一筆資料比對結果，不是對靈魂的直接觀測。**

| 資料 | 來源 | 說明 |
|---|---|---|
| 亡者紀錄 | 各地加入冥渡網絡的紀錄庫（例如深坑數據陵墓） | 死亡時間、地點、身分、見證 |
| 輪迴回執 | 神經網（蓋亞的輪迴端），經跨宇宙資料合作傳回 | 某個靈魂已經過交接、進入輪迴 |
| **交接印** | 冥渡網絡把兩者比對成功時蓋上 | 代表「此人已交接」 |
| 資料交接欄 | 僅人工生命紀錄有 | 記憶資料是否已歸檔；**與輪迴回執無關** |
| **逐出印**（v1.4） | 道主離開夢時，其法則存在從網絡中消失 | 代表「此道主已被逐出」【已定 N16：道主不會死，只會被逐出】 |

閻羅 X 掌管的是**紀錄**（遮天：事物如何被記錄、追索與揭露）。輪迴由蓋亞掌管，靈魂由亞茲掌管。交接印只是兩者在紀錄上的交會點，閻羅 X 不能憑它知道靈魂去了哪裡。

### 2.2 正常情況下為什麼會缺印

| 類別 | 說明 | 是否計入「異常」 |
|---|---|---|
| 延遲 | 回執可能晚到數月到數年 | 否；超過期限才計 |
| 身分錯配 | 無名屍、身分不明、名字寫錯 | 否；先轉入身分核對 |
| 非網絡地區 | 死於未加入冥渡網絡的地方 | 否 |
| 滯留 | 靈魂被困或被強制保存（由亞茲的機構確認） | 否；轉入滯留案件 |
| 人工生命 | 輪迴回執常常沒有，原因未明 | 否；另立「非血肉紀錄」，不作結論 |
| 資料毀損 | 紀錄庫損壞 | 否 |

### 2.3 「只見兩份」的限定

閻羅 X 說的「只看過兩份」，指的是**通過以上所有排除程序之後**仍然異常的紀錄：

| 紀錄 | 死亡已證實 | 身分已證實 | 在網絡內 | 超過延遲期 | 非滯留（亞茲機構確認） | 輪迴回執 | 逐出印 |
|---|---|---|---|---|---|---|---|
| 主角第一次死亡 | 是（多名見證） | 是 | 是 | 是 | 是 | **無** | 不適用 |
| 「被認為死了的人」 | 世人依事件登記 | 是 | 是 | 是 | 不適用（道主） | 不適用 | **無** |

**反例**（說明為什麼其他缺印紀錄不算）：
- 某礦工死於未入網的礦坑，缺印。原因：非網絡地區。
- 某商人的回執晚了三年才到，期間缺印。原因：延遲。
- 某被靈魂商人扣押的人，缺印。原因：滯留，由亞茲的機構處理。
- 九子，輪迴回執欄是「無資料」。原因：人工生命，另立非血肉紀錄，不作結論。

### 2.4 主角後來的死亡
若主角在本篇之前已死過不只一次，每一次死亡都會各自形成一筆異常紀錄。閻羅 X 說「兩份」，是指兩個**人**，不是兩筆紀錄；台詞依主角實際死亡次數調整（見 Y01-3）。

## 三、權限鏈【提案】

| 角色 | 單位 | 權限 |
|---|---|---|
| 保管方 | 深坑數據陵墓（伍櫃守） | 持有**原件**；地方隱私規則 |
| 裁決方 | 冥渡掌渡府（掌渡星主轄下） | 裁決異常紀錄的調閱、封存；【已定】冥渡為幽冥數據流首都星，由掌渡星主治理 |
| 申請方 | 神經網研究所 | 申請調閱異常紀錄作研究 |
| 會面地 | 燈津引燈府（燈信城所在） | 提供會面場所；不參與裁決 |
| 閻羅 X | 以「無名」身分出現 | 持有掌渡府的**審核副本**（已遮去身分），不是原件；道主在燈信城活動，不改首都駐地 |

### 3.1 資料層級

| 層級 | 內容 | 誰有 |
|---|---|---|
| 原件 | 完整紀錄 | 陵墓 |
| 摘要 | 死因、時間、異常類別；無姓名 | 掌渡府、申請方（經批准） |
| 審核副本 | 摘要＋比對程序紀錄；身分遮蔽 | 掌渡府、閻羅 X |
| 報刊 | 十幾年前的崩塌報導 | 公開 |
| 主角的記憶 | 他親歷的一切 | 主角 |

### 3.2 神經網怎麼知道

兩條來源，依主角的行動而定：
1. **主角本人去過陵墓**（查詢、申請、或與伍櫃守談過自己第一世的事）：伍櫃守依規定在紀錄上加註「申請人自稱為死者本人，身分有爭議」。這筆註記進入網絡，被神經網研究所看到。研究所得知的是「有人**自稱**是死者本人」，不是「主角帶著記憶回來」。
2. **主角從未去過陵墓**：網絡的定期稽核把這筆超期缺回執的紀錄列為異常，神經網作為回執的發出方，也收到異常清單。研究所只知道「有一筆死亡紀錄從未收到回執」。

### 3.3 紅向伍櫃守說了多少
（僅在 S02 之後主角與紅見過面時）
- 紅告訴伍櫃守：「那年死在閘門裡的那個人，有個年輕人說是他。我還在核對。」
- 紅**沒有**說主角現在的名字、住處或家人。
- 伍櫃守無法核對身分，只能在紀錄上加註「身分有爭議」。

### 3.4 缺席處置
- 掌渡府依規定發出通知，給本人或代管人一段**聽取期**（期限待定）。
- 本人到場：裁決會納入本人的意見。
- 本人不到場：期滿後，掌渡府以預設方式處理：**原件留在陵墓，摘要准予研究所調閱**，姓名與地點保持遮蔽。
- 主角日後仍可到陵墓或掌渡府申請更改。

| 不封 | 可看審核副本（身分仍遮蔽） | 無 | 可查閱原件 | 不受影響 | 本人可改為封存 |

**所有路線都不改變**：十幾年前的報刊報導（已公開）、陵墓的原件（仍在陵墓）、主角的記憶。

**選項二：研究**（與選項一獨立）
- 拒絕研究：研究所只能使用選項一允許的資料；不得聯絡主角。
- 同意受訪：研究所可經掌渡府聯絡主角一次；每次訪談前須再同意。
- 暫不決定：研究所不得聯絡；主角日後可改變。

## 七、待作者確認的新提案

1. 交接印是資料比對（亡者紀錄 × 輪迴回執），不是靈魂監測。

6. 研究同意與紀錄封存分開。
7. 本人重查的途徑：到掌渡府報現名，由「無名」核對。
8. 聽取期的長度；缺席時的預設處理。
