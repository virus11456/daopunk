## 一、古籍編纂與抄傳史【提案】

### 1.1 五個階段

| 階段 | 年代 | 發生了什麼 | 留下的特徵 |
|---|---|---|---|
| **一、行紀** | 先人時代盛期（年代未定） | 許多先人順著命線在宇宙間行走，各自留下行紀與圖 | 每份行紀只記一個人走過的路、看過的季節 |
| **二、彙編** | 先人時代晚期 | 有人把大量行紀整理成兩部：宇宙之內的路寫成山經，宇宙之間的航行寫成海經；原本配有圖（後世稱山海圖） | 山經格式整齊：從一座山走到下一座山，記距離、物產、生物、祭法。海經格式鬆散，多是方位加見聞 |
| **三、斷航** | 人類開始衰亡後 | 部分宇宙失聯，海經記載的航路一條條走不通；後世抄寫者把走不通的航路當成傳說，刪減或改寫 | 海經殘缺多於山經；同一航路在不同抄本中長短不一 |
| **四、流散** | 人類稀少之後 | 抄本流到不看得見命線的生命手上，被翻成各種文字，被商隊、學者、拍賣場轉手 | 異本大量出現；旁注、增補、誤譯混入正文 |
| **五、今日** | 本作時代 | 世間將它視為古代神話；師門藏有一部最古的抄本，弟子從小背誦；只有師父知道它是真的 | 各版本爭執不休；隱修院古抄本頁邊有師父的批註 |

### 1.2 「里」不是空間距離

山經裡的距離是「某山再往某方向幾百里，到另一座山」。後世學者一直無法把這些里數對上任何星圖。

【提案】先人的「里」量的是**命線上的路程**：沿著命線走一段所花的力氣，而不是兩地之間的直線距離。同一段路，命線平順時很短，命線糾結時很長。所以山經的里數不能直接當成星際座標，只能在「看得見命線的人」手上重新換算。

這解釋了為什麼只有師門的人讀得懂山經的方位，也讓「人類是導航者」的設定有了古籍上的根據。

### 1.3 師門的古抄本

- 【已定】弟子啟蒙時背的就是這部書，當成祖先的故事；只有師父知道它是真的。
- 【提案】古抄本的來歷：師父在歸墟碎後帶進隱修院。它可能是彙編階段之後不久的抄本，比世間所有殘本都早，但**不是原本**。
- 【已定】頁邊有師父的批註，是主線線索的另一條路。批註很淡，弟子以為是塗鴉。

## 二、山經與海經在遊戲中的功能【提案】

| 部分 | 記錄內容 | 玩家怎麼用 |
|---|---|---|
| **山經** | 宇宙之內、星球地表的路線、山川、礦物、生物棲地、聚落、祭法 | 到了一顆星球，對照現地的地貌、季節與居民說法，找出舊路改道、棲地遷移、祭俗的演變 |
| **海經** | 宇宙之間的航行、遠國、空隙、邊緣世界、失聯航路 | 比對商隊航誌與古老航標；尋找通往邊緣世界與夢底的路 |
| **旁注與異本** | 後世的增補、不同的見聞、翻譯與誤認 | 同一條目保留多種說法，一次親見不刪掉舊說 |

**與圖鑑的關係**【已定 N9】：開局即有上百條「未見」的經文條目，來自主角的背誦。條目依來源逐層增補，不必收齊；主線關鍵證據都有不依賴圖鑑的取得方式。

**與輪迴的關係**：主角記得自己讀過、看過的內容（完整記憶），但實體抄本、碑刻、航標留在世界上，有持有者，也可能損毀。記憶筆記可以重建，未讀過的頁面不會憑空出現。

## 三、兩位探索者【提案】

兩人的族屬與年代都是提案。第一位屬於先人，依已定設定是夢裡的人類；第二位的族屬是新提案。

### 3.1 岑行（先人，行紀階段）

- **年代**：先人時代盛期。
- **族屬**：人類（先人）。
- **做了什麼**：一生走過的山比任何人都多，山經的骨架大半出自他的行紀。他記東西很克制：只記親眼所見，不記聽說；看不懂的東西，就照樣子寫下來，不替它取名。
- **他看見而後人不信的**：他記錄過一種鳥，每年同一天飛越同一座山，一隻不差。後世抄寫者覺得太整齊，改成「時有鳥群過境」。本作中，那種鳥仍在，確實每年同一天飛過。
- **他看錯的**：他在某個季節看到一座終年積雪的山，就記作「無草木，多雪」。他沒在夏天去過。
- **與命線**：他看得見命線，所以他的里數是命線上的里數。
- **結局**：待定。一種可能是他最後走進了海經記載的某條航路，沒有再回來。

### 3.2 潮簿（彙編之後，斷航與流散階段）

- **年代**：人類開始衰亡之後。
- **族屬**：非人類（提案）；是一位替商隊記航誌的生命，可以是生化、機械或其他族屬，待定。
- **做了什麼**：人類減少之後，海經的航路一條條走不通。潮簿蒐集商隊的航誌，逐條比對海經，標記哪一條還能走、哪一條已經斷了。他寫下的增補，後來混進了許多海經抄本。
- **他看不見命線**：他只能靠人類留下的航標、商隊的經驗和一位人類同行者判斷方位。所以他把某些航路寫成「已亡」，其實只是換了季節才通。
- **他看見而先人沒看過的**：機械城市、義體商人、會自己選擇的機器。他是第一個在海經裡寫下「此地居民非血肉」的人。
- **他的刪改**：他把幾條他確認走不通的航路從抄本中劃掉，只留下一行「此路今絕」。這讓後世的抄本少了好幾個宇宙的方位。
- **與失聯宇宙**【已定 N10：最早不只十個宇宙；數量與失聯原因未知】：潮簿的「此路今絕」是本作中關於失聯宇宙最具體的紀錄，但他只記了「走不通」，沒有記為什麼。

### 3.3 兩人為什麼互相矛盾

岑行寫的是人類看得見命線時的世界，潮簿寫的是人類變少、看不見命線的人接手之後的世界。兩人記同一個地方，常常不一樣；兩個都可能是對的，只是年代不同、看法不同。

## 四、抄本互相矛盾的具體原因

【提案】每一條矛盾都能歸到以下至少一個原因。**先人不是全知者，但矛盾也不全是「古人把科技誤認成神」。**

| 原因 | 例子 |
|---|---|
| **季節** | 岑行冬天看到雪山，潮簿夏天看到綠谷 |
| **年代** | 先人時代還在的物種，後來遷徙或絕跡 |
| **看得見與看不見命線** | 先人以命線描述方位與里程；看不見命線的抄寫者只好改寫成空間距離，於是對不上 |
| **斷航** | 失聯宇宙的航路被抄寫者當成傳說，刪改或補寫 |
| **翻譯** | 抄本被翻成不同文字，名稱與形容詞失真 |
| **抄寫錯誤** | 漏字、重複、段落錯置 |
| **增補混入正文** | 旁注被後人抄進正文，分不出哪句是先人寫的 |
| **確實看錯** | 同一種生命的幼體與成體被記成兩種；遠看與近看記成兩種 |
| **把神異當成神異** | 有些記載本來就是真的異象，後人反而以為是誇張 |
| **故意改寫** | 某些抄本因為政治、商業或信仰的理由被刪改。例如拍賣場為了抬價，偽造「最古本」 |
| **把技術當成神異** | 確實存在，但只是原因之一，不能用來解釋全部 |

## 五、十二條示範圖鑑

**條目格式**：類別｜古籍摘要（本作改寫）｜可核對出處｜現代見聞｜可調查線索｜條件與年代｜非戰鬥發現方式｜未解問題｜與人物或組織的連結
**年代**沿用遊戲量規劃 v2 的五個時代（一：燈下；二：崩塌之後；三：老去；四：蒐集；五：夢動），皆為提案。

### 生命

#### SH-LIFE-101　精衛
- **類別**：生命
- **古籍摘要**（改寫）：北方有一種小鳥，頭有花紋、白嘴、紅腳，叫聲像在喊自己的名字。傳說牠原是一位溺死在海裡的少女，死後化為鳥，每天銜西山的木石去填東海。
- **可核對出處**：北山經（北次三經，發鳩之山）。
- **現代見聞**：邊緣世界的淺海邊，有一種小鳥反覆把碎石銜到空隙的邊上，堆成一道極細的堤。附近的航行者說，堤已經堆了好幾百年，從沒被海沖掉。
- **可調查線索**：堤的石頭來自哪裡；鳥群是否有固定的往返航路；牠們的叫聲是否真的像一個名字。
- **條件與年代**：需進入邊緣世界；時代二以後較易遇見。
- **非戰鬥發現方式**：觀察鳥群往返；跟著牠們的航路走；向商隊打聽「填海鳥」。
- **未解問題**：古籍說牠是少女轉生。這個世界確實有轉生，也確實有人轉生為非人類【已定 B3 的延伸】。那麼傳說是真的嗎？牠記得嗎？本作**不回答**。
- **連結**：零號（他夢見的是一片海）。

#### SH-LIFE-102　旋龜
- **類別**：生命
- **古籍摘要**（改寫）：南方一座山下的河裡，有一種龜，鳥頭蛇尾，叫聲像劈木頭；把牠的殼帶在身上，耳朵就不會聾。
- **可核對出處**：南山經（南次一經，杻陽之山）。
- **現代見聞**：某些溫暖星球的河流裡確實有鳥喙蛇尾的龜類。義體醫師公社的舊聽覺接頭，曾用這種龜的殼粉做絕緣材料，因此被大量捕撈，一度幾乎絕跡。
- **可調查線索**：公社的舊材料紀錄；河邊老漁人的說法；殼粉是否真的改善聽覺，還是只是材料特性。
- **條件與年代**：時代一數量稀少，時代三以後因公社改用新材料而回升（提案）。
- **非戰鬥發現方式**：訪談老漁人；翻閱公社舊檔；夜裡在河邊聽「劈木聲」。
- **未解問題**：古籍說的「不聾」，是藥效、材料學，還是先人看見了別的東西？
- **連結**：義體醫師公社（中立組織）。

#### SH-LIFE-103　帝江
- **類別**：生命（創世生命相關）
- **古籍摘要**（改寫）：西方一座山上有一位神，形狀像黃色的囊袋，紅得像火，有六隻腳、四隻翅膀，渾然一團，沒有面目，卻懂得歌舞。
- **可核對出處**：西山經（西次三經，天山）。
- **現代見聞**：無人親見。主角若到達夢底，會看見一團沒有臉、沒有七竅的溫熱（渾沌）。
- **可調查線索**：古抄本此條旁，師父批了兩個字「勿鑿」（提案）；各抄本對「六足四翼」的記載不一。
- **條件與年代**：主線階段九之後才可能親見。
- **非戰鬥發現方式**：讀批註；在夢底親見；對照《莊子》渾沌寓言。
- **未解問題**：先人是在哪裡看見祂的？夢的正中央，還是祂曾經出現在某座山上？
- **連結**：師父（批註）。

#### SH-LIFE-104　禺彊
- **類別**：生命（待考）
- **古籍摘要**（改寫）：北方有一位神，人面鳥身，兩耳各掛一條青蛇，腳下踏著兩條青蛇。
- **可核對出處**：海外北經；大荒北經亦有記載。
- **現代見聞**：無人親見。潮簿的增補中，有一條北方航路記著「航者見一翼影，大如海岸」。
- **可調查線索**：禺彊與鯤鵬是否是同一存在的不同看法；北方航路的舊航誌。
- **條件與年代**：任何時代皆可聽聞；親見需到夢底（見鯤鵬）。
- **非戰鬥發現方式**：比對兩部古籍；向北方航路的老船員打聽。
- **未解問題**：先人所見的「人面鳥身」，和鯤鵬的「有翼巨鯨」相差太遠。是看錯、是另一個存在，還是鯤鵬在不同地方有不同形態？**待考**。
- **連結**：零號（夢中的有翼巨鯨）。

### 地貌與天候

#### SH-LAND-101　鄧林
- **類別**：地貌
- **古籍摘要**（改寫）：有人追著太陽跑，一直跑進太陽裡，渴得要命，喝乾了兩條河還不夠，往北方大澤去，半路渴死了。他丟下的手杖，長成了一片樹林。
- **可核對出處**：海外北經（夸父、鄧林）。大荒北經另有夸父記載。
- **現代見聞**：邊緣世界裡有一片長在虛空邊緣的樹林，樹根懸空，樹葉朝向同一個方向。
- **可調查線索**：樹葉朝向的方向；林中是否有人留下的痕跡；那個方向通往哪裡。
- **條件與年代**：需進入邊緣世界。
- **非戰鬥發現方式**：量測葉向；在林中過夜，觀察光的變化。
- **未解問題**：夸父追的是太陽，還是燭陰睜開的眼？若是後者，他是想喚醒造物主的第一個人嗎？**不回答**。
- **連結**：星塵（一個不信命、一路往前跑的人）。

#### SH-LAND-102　逆流瀑（本作自創，非山海經原有）
- **類別**：天候與地貌
- **古籍摘要**（改寫，岑行行紀）：某座山的瀑布，一年中有九天往上流。
- **可核對出處**：無。本作自創，出自遊戲內的岑行行紀與潮簿增補，不屬於現實《山海經》。
- **現代見聞**：某顆星球的高原上有一道瀑布，每年同一季節的幾天裡，水霧會逆著瀑布往上捲。當地人說那是「山在吸氣」。
- **可調查線索**：逆流的天數（岑行記九天，潮簿記三天，現代觀測又不同）；當季的氣壓與風向。
- **條件與年代**：只在特定季節出現。
- **非戰鬥發現方式**：在當季到場觀測；向當地氣象站或老居民打聽。
- **未解問題**：這是行星氣候造成的現象，還是與夢的擾動有關？本條**刻意分開**兩種解釋：當地氣候能解釋大部分，但解釋不了岑行記的「九天」。
- **連結**：杭嬸式的在地農人（藥畦鎮類型的聚落；個別人物待定）。

### 國家與聚落

#### SH-NATION-101　羽民國
- **類別**：國家聚落（遺跡）
- **古籍摘要**（改寫）：南方海外有一國，其人頭長，身上生羽。
- **可核對出處**：海外南經。
- **現代見聞**：邊緣世界的一處遺跡。屋簷做得很高，門很窄，屋內沒有樓梯，只有高處的棲架。一個人都沒有。
- **可調查線索**：遺跡的年代；居民離開時帶走了什麼、留下了什麼；牆上的文字。
- **條件與年代**：任何時代皆可發現；時代四以後可能被拍賣場的人搶先洗劫。
- **非戰鬥發現方式**：考察遺跡；比對拍賣場流出的遺物；向遺物商打聽出處。
- **未解問題**：他們是人類嗎？如果是，他們為什麼不見了？這是人類衰亡的物證之一，但**不給答案**【已定 15】。
- **連結**：拍賣場（中立組織；遺物的來源與真偽）。

#### SH-NATION-102　奇肱國
- **類別**：國家聚落（待考）
- **古籍摘要**（改寫）：西方海外有一國，其人一臂三目，善作機巧。
- **可核對出處**：海外西經（奇肱之國）。「能造飛車」一說見於後世注文與其他典籍，非經文本身，**待考**。
- **現代見聞**：某顆機械星球上，有一個自稱「奇肱」的工匠族群，以單臂多目的義體為傳統，世代製造航行器具。
- **可調查線索**：他們的傳統是從古籍來的，還是古籍記的就是他們的祖先；族群內部對「祖先是誰」的說法。
- **條件與年代**：任何時代。
- **非戰鬥發現方式**：拜訪工坊；參加他們的造器節；交易舊器。
- **未解問題**：本條是「不能全用誤認科技解釋」的反例：先人記的「善作機巧」可能就是字面意思，這個國本來就擅長做機器。是不是同一個國延續下來，**待考**。
- **連結**：九子這類退役機甲的維修行當；記憶公證所（族譜真偽）。

### 風俗

#### SH-CUSTOM-101　祠禮（山經篇末的祭法）
- **類別**：風俗
- **古籍摘要**（改寫）：山經每一段的末尾，都記著祭這一帶山神的方法：用什麼牲、什麼玉、什麼米，埋在哪裡。
- **可核對出處**：五藏山經各篇篇末的祠禮段落（例如南山經首篇末）。
- **現代見聞**：許多農業聚落仍有類似的祭法，但牲換成了穀物，玉換成了舊零件。有些聚落說不出這習俗從哪裡來。
- **可調查線索**：各地祭法與古籍的差異；祭品為什麼改變；祭的是什麼。
- **條件與年代**：季節性，通常在收成前後。
- **非戰鬥發現方式**：受邀參加祭典；向主祭者請教（受訪者可拒絕公開細節）。
- **未解問題**：先人祭的「山神」是什麼？是某種生命、某位道主，還是對土地本身的敬意？
- **連結**：藥畦鎮的休耕田（Z01；杭嬸、零號）。

#### SH-CUSTOM-102　留燈（燈籍人家的習俗）
- **類別**：風俗
- **古籍摘要**：無。此習俗不見於古籍。
- **可核對出處**：無（本作設定，源自背景 v1.3 的燈籍提案與設定包 SH-CULTURE-001）。
- **現代見聞**：燈籍人家有在門口留一盞燈的習慣。有的人家每晚點，有的人家只在有人遠行時點，有的人家已經不知道為什麼要點。
- **可調查線索**：各戶做法的世代差異；習俗從何時開始；與隱修院燈籍閣的關係。
- **條件與年代**：任何時代；需先與燈籍人家建立信任。
- **非戰鬥發現方式**：家庭訪談；在燈籍人家出生時的親身經驗。
- **未解問題**：留燈是從燈籍閣學來的，還是燈籍閣學自某個更早的習俗？
- **限制**：不公開任何家戶的位置；個別家戶的做法不代表所有燈籍人家。
- **連結**：紅（破爛一條街的燈）。

### 航路

#### SH-ROUTE-101　無名失聯航路
- **類別**：航路
- **古籍摘要**（改寫，潮簿增補）：從某方向出發，沿著三座航標走，可以到一個有兩個太陽的地方。旁邊加了一行小字：此路今絕。
- **可核對出處**：無。本作自創，屬遊戲內海經異本中的潮簿增補，不屬於現實《山海經》。
- **現代見聞**：一支商隊帶回一份舊海經抄圖，上面畫著這條航路與三座航標。商隊說他們找到了第一座航標，第二座沒找到。
- **可調查線索**：三座航標的位置；「兩個太陽」指什麼；航路在不同季節是否可通；潮簿為什麼寫「今絕」。
- **條件與年代**：任何時代皆可聽聞；能否實際通航**待定**。
- **非戰鬥發現方式**：比對商隊航誌；親自尋找航標；請看得見命線的人（主角）重新換算里程。
- **未解問題**：這條航路通往的，是不是一個失聯的宇宙？【已定：失聯宇宙的數量與原因未知】本條**不生成**第十一個宇宙的座標，也不判定它已毀滅。
- **連結**：星際商隊（中立組織）；黑匣信使局（舊航誌的保管者）。

### 遺文

#### SH-TEXT-101　古抄本頁邊批註
- **類別**：遺文
- **古籍摘要**：不適用（本條是古抄本上的後人手跡）。
- **可核對出處**：無。本作設定，屬遊戲內方舟隱修院的古抄本。
- **現代見聞**：隱修院的古抄本頁邊，有許多很淡的字與記號。弟子們以為是哪一代師兄的塗鴉。
- **可調查線索**（提案內容）：
  - 西山經「帝之下都」一句旁的墨點（陸吾）；
  - 帝江條目旁的「勿鑿」；
  - 大荒經最後一頁的一個日期（歸墟碎掉的那一天）；
  - 字跡與師父寫給紅的信是否相同。
- **條件與年代**：第一輪就能看到，但不懂；每一個主線階段完成後重讀，會有新的意思。
- **非戰鬥發現方式**：閱讀；比對字跡；在不同輪次重讀。
- **未解問題**：師父為什麼留下這些？是寫給自己看的，還是寫給某一天會看懂的人？
- **連結**：師父（主線人物）；紅（信的字跡）。
- **限制**：批註只是**起疑**的線索，不是主線的必要證據。
