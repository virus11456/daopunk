# 人物晚年篇 v1｜覆核

保留「還在／最後／之後」、不重播缺席告別、由人物決定遺物的結構。以下是局部修訂要求，非新增正史。

| ID | 問題 | 修訂方向 |
|---|---|---|
| LL01 | S02 相認後即說「又換了一張臉」，忽略同世再訪與再次轉生未核對 | 依當前身體、上次相認的世次、此次核對與相信程度換台詞；不以歷史相認旗標直接識別所有新身體。首次才見紅、從未做過 R01 的路徑也須可達。 |
| LL02 | 零號問鯨，K7 即回答「它沒有看你，可是它知道你在」 | K7 只證明見過創世生命，不證明鯤鵬知道零號。可改「我見過有翅膀的巨鯨。它是不是你夢裡那隻，我不知道。」若要更確定，須具體對話或證據。紙條張數依起始日期、停寫、散失計算，標題不是固定五十幾張的數量保證。 |
| LL03 | 星塵可出獄／流亡，最後卻必在糧倉、交鑰匙 | 依存活、所在地、是否建立糧倉分最後場景；早死者不進晚年，無倉者無鑰匙。阿錨的背叛與情感、那夜台詞須依 X01 實際結果；不存在的往事不能用來相認。觀命同意與告知結果分開確認。 |
| LL04 | 大師兄默認見過主角童年；年表大師兄 T−25 下山，主角 T−15 出生 | 沒有回院／通信證據就不能知道童年歌或認得第一世樣子。優先用 M01 親歷或可查師門紀錄；若新增回院需標提案、補時地與來源。T+60 時約 103 歲（T−43 生），需列本世已完成延壽，未完成者依實際壽命提前離世；起算點仍待定。 |
| LL05 | 第133台、九子「紙牆」拓本、遺物和死訊來源尚未閉合 | M01 有132台基準，可將133設固定研究個體而非永遠最新總數。對象同意觀命，未找到錨不等於無生命。九子舊紙、紅所作拓本、後續複本分物件ID與合法交接；不要未交代就變紙牆。研究紀錄不是大師兄可任意處分的所有人資料，沿用受試者授權與封存範圍。 |
| LL06 | 晚到必見承接者、雪鈴必寄信，且指定等於交付 | 指定、接受、實際保管、交付分欄；收件人可能先死、拒收或失聯。雪鈴須在世／能聯絡／確知死訊；無消息時主角只能不知道。紅的街燈熄滅不等於燈籍全熄。 |

補共同資料：本世身體ID、死亡事件／日期、相認來源與程度、地點、物件實存與保管鏈、告別親歷／轉述來源。晚年、死亡、交接各自只結算一次；多次重訪不重播死亡。親友早逝或長期失聯應有缺席版本，不保證每輪趕得上。
