## 本次原稿全文

# DAOPUNK｜人物晚年篇 v1：紅、零號、星塵、大師兄

> **目的**：遊戲量規劃中「人物晚年與後續」的四篇。第一輪認識的人會在主角轉生的空窗中老去；晚年篇讓玩家在某一輪回來時，還趕得上、或趕不上他們最後的時光。 **依據**：完整背景 v1.5；R01 v1.1、Z01 v1.1、X01 v1.1、S02 v2.2、M01 v1.2；燈籍家庭 v1.1；時代與事件池 v1.2。 **沿用規則**：轉生時間依公式【已定 N23】；重逢、遺物、紀念物依實際死亡與人物狀態觸發【已定 N22、N25】；舊識不會自動認出主角的新身體（需核對或知情來源）；每篇有趕上、晚到、缺席版本；後人不是替身。 **死亡年份**皆為**無人介入時的預設**（提案）；主角的行動、醫療、事件都可能改變。 **標記**：【已定】附來源；其餘為【提案】。不定數值；未接 Godot。

---

## 一、共同結構

每篇分三段，依主角抵達時的世界時間觸發：

| 段 觸發 內容  |             |                    |
| -------- | ----------- | ------------------ |
| 一、還在     | 人物在世且能相見    | 相認（或不相認）、未竟之事      |
| 二、最後     | 人物臨終期間，主角在場 | 告別；物件的去向由人物自己決定    |
| 三、之後     | 人物已過世       | 從承接者、紀錄、遺物得知；不重播臨終 |

**相認的條件**：舊識依自己的方式核對主角（S02 的核對模式）；可以相信、部分相信、或不信。主角也可以選擇**不說**，以陌生人的身分陪伴。

**物件**：人物的遺物由人物自己決定給誰；若主角沒有被認出或沒有在場，遺物不會自動交到主角手上。

## 二、紅〈燈的高度〉

**預設**：約 T+55y 過世（九十五歲，提案）。

### 前提（依實際狀態）

| 狀態 影響            |                       |
| ---------------- | --------------------- |
| 主角是否在第一輪修過燈（R01） | 燈的位置、紅的說法             |
| 主角第一輪如何死亡        | 紅是否登報、是否保管遺物（N22、N25） |
| 主角是否曾在 S02 與紅重逢  | 紅是否已經相信主角會帶記憶回來       |
| 拾六與紅是否仍有往來       | 燈由誰承接                 |

### 一、還在

- 紅老了，攤位縮小成一張桌子，燈仍掛著（位置依 R01）。
- **若 S02 已相認**：紅說「你又換了一張臉」；她記得上一次核對過的內容。
- **若從未相認**：沿用 S02 的核對模式，但紅更累、更直接：&#x20;
  > 紅：「我沒力氣考你了。你說一件只有他知道的事。一件就好。」
- **未竟之事**（依狀態擇一出現）&#x20;
  - 櫃底的信：若大師兄仍未回音，紅問主角要不要替她寄出最後一封（代收號依 B5 暫存版本；B5 仍待確認）。
  - 登記令：若在後來的時代捲土重來，紅想在死前看到它被撤掉。
  - 阿灰：紅想知道他後來過得好不好；主角可以透過斷鏈避難網打聽（需引介；隱私優先，不一定查得到）。

### 二、最後

- 紅在後屋。燈亮著。
- **她決定燈給誰**（依關係與實際狀態）：&#x20;
  - 拾六（若兩人仍有往來）；
  - 主角（若已相認，且主角這一世能留在深坑）；
  - 魏家等鄰居（若燈籍家庭中魏家存在，提案）；
  - 或讓它熄。
  > 紅：「燈別掛太低。」（若主角修過燈） 紅：「……算了。掛你想掛的高度。」
- **遺物**：櫃中的信、拓本（若存在）、主角前世的遺物（若她曾保管），各自由紅指定去向。

### 三、之後

- 燈的承接者在門口。報刊可能有一則署名的廣告（僅在紅或承接者真的登過時）。
- 主角可從承接者口中得知紅最後說了什麼（轉述）。

### 缺席

- 紅過世；燈依她生前的指定；主角日後從承接者或報刊得知。若無承接者，燈可能被收走或熄滅。

## 三、零號〈五十幾張紙條〉

**預設**：約 T+50y 過世（提案）；死因依接頭方案與後續醫療（Z01）。

### 前提

| 狀態 影響                  |          |
| ---------------------- | -------- |
| Z01 零號選擇的方案與後續         | 晚年的身體狀況  |
| 主角是否在 Z01 陪他數過葉子、看過他的夢 | 零號是否記得主角 |
| 藥畦鎮的土況（Z01 七）          | 田的樣子     |

### 一、還在

- 零號仍在藥畦鎮，或在公社巡診站等零件，或在別處修東西（Z01 再訪規則）。
- 他每年寫一張紙條，只寫一個數字（若主角第一輪曾請他寫，或他自己開始的習慣；不預設一定寄給誰）。
- **相認**：零號不會認臉。主角若說出「肉那一半想睡覺，鐵那一半想數」或夢裡的鯨，零號會停下來：&#x20;
  > 零號：「……那天打斷我數葉子的人，也說過一樣的話。」
  - 零號可以相信，也可以只說「很多人都聽過我說這句話」。
- **未竟之事**：他想知道夢裡的鯨是不是真的。&#x20;
  - 若主角已到過夢底（K7），可以告訴他。零號聽完很久不說話：&#x20;
    > 零號：「那它看見我了嗎？」 主角：「它沒有看你。可是它知道你在。」
  - 若主角沒到過，零號說：「那就留著。有些東西，留著比較好。」

### 二、最後

- 零號在田埂上，機械那一半已經不太動了。&#x20;
  > 零號：「今天我數不完了。你幫我數後半。」
- **遺物**：一個木箱（紙條、木雕），由零號指定去向：主角、杭嬸或繼任田長、公社，或留在庵裡。

### 三、之後

- 閻羅 X 的紀錄上是否有交接印，只有在主角有調閱權限時才知道（Y01）；主角不知道零號的夢去了哪裡。
- 田依後來的治理演變（Z01 七）。

### 缺席

- 零號過世；木箱依他的指定；主角日後從鎮民或公社得知。

## 四、星塵〈糧倉〉

**預設**：約 T+60y 過世（七十九歲，提案）。

### 前提

| 狀態 影響               |                    |
| ------------------- | ------------------ |
| X01 的結果（O1～O5）      | 星塵是否入獄、是否脫身、無燈會的處境 |
| 主角在 X01 是否告訴過星塵觀命結果 | 星塵對「知道」的看法         |
| 阿錨與小瓶的後續            | 晚年的人際              |

### 一、還在

- **依 X01 結果**：星塵可能在經營只存居民糧箱的倉庫（提案）；可能剛出獄；可能已不在銅鹽星。
- **相認**：星塵不信算命，也不太信轉生。&#x20;
  > 星塵：「你說你是那個算命的。我不信。」 主角：「你不用信。」 星塵：「……那天晚上，是我選的。你記得這句嗎？」
  - 主角記得：星塵不一定因此相信，但會讓他留下來。
- **未竟之事**：&#x20;
  - 阿錨：若阿錨仍在世，星塵從未原諒她，也從未真的恨她。主角可以陪他去見她，或不。
  - 糧倉的交接：星塵想找一個不會把糧倉變成算命機的人接手。

### 二、最後

- 星塵在糧倉裡，數著居民的糧箱。&#x20;
  > 星塵：「你要是能看我的命，別告訴我。」 星塵：「……算了。告訴我也沒關係了。」
  - 主角可以看、可以不看；看了可以說、可以不說（須找對命錨）。
- **遺物**：糧倉的鑰匙，由星塵指定給誰。

### 三、之後

- 無燈會為他辦喪事；喪禮上沒有人算命（若無燈會仍存在）。
- 算命機的新標語依時代。

### 缺席

- 星塵過世；糧倉依他的指定；主角從報刊或聚落居民得知。

## 五、大師兄〈第一百三十三台〉

**預設**：約 T+60y 過世（提案；依醫術延壽）。

### 前提

| 狀態 影響              |                         |

| P01 聽證的結果          | 命錨測試是否撤回                |
| 大師兄離開安居院後的去向       | 晚年的地點【待設計】              |

### 一、還在

- 大師兄離開安居院後的去向未定；本篇提案：他在一顆邊境星球的小修理鋪，繼續替機器修膝蓋。
- **相認**：大師兄以主角**第一輪**的樣子記得他（M01 若見過則以當時的樣子）；他看見新身體，會用師門的方式核對：&#x20;
  > 大師兄：「你小時候，四師妹教過你一首歌。唱前兩句。」
- **未竟之事**：&#x20;
  - 他一直在看的第一百三十三台機器：一台他找不到命錨的機器。【已定 N26】非人類須找對命錨；大師兄想在死前找到它的錨。主角可以陪他找。

    > 大師兄：「原來它一直都在。只是我沒找對地方。」
  - 若找不到：&#x20;
    > 大師兄：「找不到，也沒關係。它還是每天在這裡。」

### 二、最後

- **遺物**：研究筆記、九子的紙牆拓本（若存在）、給紅的信。去向由大師兄指定：主角、雪鈴、紅（若在世）、公證所封存。&#x20;

### 三、之後

- 雪鈴寫信傳出死訊（背景 v1.5）；主角是否收到依他是否有可聯絡處。

### 缺席

- 大師兄過世；遺物依他的指定；雪鈴的信可能寄到紅處、魏家或信使局存檔。
