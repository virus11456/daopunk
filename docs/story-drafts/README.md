## 所有後續修訂共用的已確認決定

- 第一世、第一次下山開場；「約四個月後」「再兩個月後」仍是各稿年表提案。
- 未花功德全數跨世保留。
- 散居隱性人類後裔方案不採用；身體來源另設，不默認胚胎方案。零號、阿灰族屬不因外觀或掃描空白定案。
- 命運觀測須呈現分支機率與條件；不能只有模糊剪影，也不能把可能當必然。
- 世界在輪迴與玩家缺席時持續前進；新聞與組織事件不等待玩家按完每句對話。
- 所有原稿新真相與能力限制仍須標提案，主角不得使用自己未曾得知的資訊。

先在原Claude對話補上最新決定，再使用各篇REVISION_PROMPT。修訂回傳後另存版本並更新差異，不覆蓋ORIGINAL。S02已收到v2原稿；各篇修訂與完整主線尚未整合，未執行遊戲引擎驗收。
