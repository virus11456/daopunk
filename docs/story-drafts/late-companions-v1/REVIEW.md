# 後期同伴篇 v1｜覆核

三條弧線方向可保留，但它們是劇情角色提案，不是居民生圖登錄的新完成數。加入中立組織 v1.3 本輪未核得全文，引用標待核。

| ID | 問題 | 修訂方向 |
|---|---|---|
| LC01 | 叁和岑絲任何時代可遇卻又保證後期跨多輪；夏汐出生跟玩家某轮绑定 | 依世界出生／啟用日與實際生死、維修、離職狀態決定；不以輪數保證存活、不在後期復活已解體叁。夏汐設定固定世界出生事件提案，出生後不因玩家轉生改日期。後期同伴缺席時可有其他新人物，但不能換名重置同一弧線。 |
| LC02 | 申訴權／未分類即讓叁活下來 | 法律成立、暫停解體、叁實際获救／登錄分開；已執行解體不能被後來改革撤銷。三機體片段只是讀取資料或未知夢，不證明三個前世、三個靈魂。主角用來核對的話須曾被叁告知，而非「只有叁知道」。 |
| LC03 | 夏汐只在非夏家輪次結識，卻保留姊妹例外；第一位學生預設；血緣不完整 | 相遇不因出生戶關閉，親屬／非親屬換場景。記錄確切家譜，不能把同姓當直系；沿用直系限制的提案狀態。若之前教過他人，改「再次教學」。徒弟限既有燈籍人類，不新增不明散居人類或把非人類教成算命者。 |
| LC04 | 夏汐會認命錨卻看見「完全不同的人」，又說未來一定不記得 | 觀測今生命途不等於否定同一靈魂，生辰也不自動是正確命錨。核對不能單憑觀命；保留修行復憶的可能，夏汐可擔心不記得，不能作者保證永不記得。教算命前她已能領航，風險來自曝光與能力使用，不是只有教她才危險。 |
| LC05 | 岑絲「只有讀取記憶，沒有自己的」與她研究、抉擇、離職的親歷矛盾 | 改成她不確定哪些記錄是親歷、或覺得從未為自己做過選擇；若真要無親歷記憶需另設機制提案，不能不加說明沿用。刻鐘樓需已存在航線依據與管理者許可，不任意製造航海紀念紀錄。 |
| LC06 | 撤回授權等於刪岑絲全部記得的你；紀錄授權只有四格 | 區分外存紀錄、研究副本、她親歷的記憶與第三人資料；主角能撤回哪些用途由約定決定，不自動抹除岑絲人格記憶。寫清範圍、期限、可控副本、刪除回執，不能許諾刪除外流副本。拒絕旅程紀錄不取消同行；主角不能代夏汐／叁同意。 |
| LC07 | 岑絲任何結局都會問，等於自動在場且知道真相 | 限在世、同行、可達、知情且願意。問句置不可逆抉擇前；喚醒後不得靠她的紀錄確定夢外結果。見證叁取名可以記一項自主選擇，不自動滿足煉真全部門檻。 |

建議新增獨立旗標：個體世界出生日、存活／所在地、同意同行、辨認證據與相信程度、暫離原因、資料授權對象／用途、主角親見自主選擇。留下改規矩的岑絲仍可通信／重訪，不强迫離職才有故事。
