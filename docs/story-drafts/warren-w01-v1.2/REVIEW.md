# W01 v1.2｜收斂審閱

不重開已解問題，也不要求重寫人物核心。已解：N19、資助與債務區分、摘要不冒稱完整契約、秘密排除、調閱授權、債權來源、子女救濟、同格式不是同源、任務需要正式成果、跨世需查驗。前次 W01-R01～R16 仍保留供追溯；本輪只列剩餘問題。

## 需修的八組問題

| ID | 範圍 | 精修要求 |
| --- | --- | --- |
| W12-01 | W-5、場景依賴與缺席 | v1.1 的 W-5「已知 K5 且關係至少尊重」在本版消失，須補回，避免提前談造物主。恢復 W-2、W-3、W-4 的開啟條件或明確交叉引用。從未到商盟不等於沃倫一定不知道主角，他仍可能收到第四節其他來源；道主離場另有可聯絡條件。 |
| W12-02 | 第三節、W-2 契約 | 「承認這一世條款」改為當世條款亦逐項審理。待設計摘要不能真的在場景中以空白計價條款完成簽署：寫明實作簽前須展示填定版本，可詢問、暫緩、諮詢、拒簽。優先購買權須有價格與回覆期限的規則接口，無需現在填數字。 |
| W12-03 | W-1、W-1b 無後人與證據 | 無後人不等於店舖必然归債權人，仍依擔保範圍、清償與世界中的遺產處理結果；可用檔案呈現未知或不同結局。「沒有交付紀錄」也不等於證實未交付。開庭以世界日期起算；當事人已有相同有效證據時，不只因玩家缺席降低結果。保留阿衡是否訴訟與公開的意願。 |
| W12-04 | W-3b、W-6 實際成果 | 收到通知是程序成果，不保證執行者已停工、放人、停止追索。任務资格需核對選定案件已實際解除子女義務／停止追索；其餘工資與補償可另列追蹤，不強求整個宇宙改革才授法。債權人不明或轉售不應封死個案審理與暫緩執行，只能等制度改革；可設虛構法院程序候選。直屬機構不等於沃倫本人可任意放棄其債權，補授權；公告效力、地域與落地執行分開。 |
| W12-05 | W-3、W-4 公證與證據 | 「母親不能代孩子同意任何事」限縮為不能代賣未來／代替未來自主同意，避免把照護也否定。公證結果改為「在本次方法範圍未發現剪接」，非絕對真實；提供結果不自动透露當世住址。唯一錯字等是強線索，仍需來源、時間及交叉證據，不能只存環數就算全鏈證實。 |
| W12-06 | W-6 跨世資格 | 查验未完成不等於已完成資格被抹除；記為資格存在、當世辨認待核，提供補證或其他來源；重新做任務可選，非唯一解。擊倒後領取與道主逐出先後需留明確接口；已得法則在本人未被認出時仍可使用，領取一次不等於只能使用一次。 |
| W12-07 | W-3b 與情境六、狀態欄 | 正文說沃倫承認後玩家缺席仍可能單案撤銷；覆核六卻說未跟進一切皆未發生。改為當下尚未發生，日後依世界事件與代理進度。補通知送達／實際停止、資助期／既有債務、承諾完成／合理不能／違約、當世辨認與證據來源；避免枚舉組合漏掉「含五但議四」。旗標用 W01_ 前綴便於與其他篇區分。 |
| W12-08 | 九節來訪期限 | 仍待作者選，不代定。乙「一生中若能至少一次」需明確是簽約當世還是累世總一次；丙「前三世」需明確從簽約算起、無法履行的世是否計入。可以提出建議，不將未選期限写成簽約已完成。 |
