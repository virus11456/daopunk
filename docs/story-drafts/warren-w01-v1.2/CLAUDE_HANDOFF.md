## 五、場景

### W-1｜帳簿塔下
- **處境**：賣香料的阿衡（提案）面對兩項主張：
  1. **貨權**：附加條款「遇不可抗力時，貨權轉歸債權人」；「不可抗力」的定義在她沒拿到的附件裡。
  2. **店舖所有權**：依另一份擔保書。
- **對白**
  > 阿衡：「他們說香料是他們的，店也是他們的。」
  > 主角：「兩件事分開看。香料是一份契約，店是另一份。」
  > 阿衡：「有差嗎？」
  > 主角：「有。一份輸了，另一份不一定輸。」
- **調查**（非戰鬥）：帳簿塔公開索引查附件交付紀錄；讀擔保書範圍；找其他受波及商戶；觀命（找對命錨；經阿衡同意）。
- **結果**：查到附件未交付，只是**可以主張**貨權條款無效；商事庭約一個月後開庭（提案）。店舖依擔保書範圍另爭。
- **沃倫在場**
  > 沃倫：「你讀契約的樣子，像在讀一個人的命。」
  > 主角：「它就是她的命。」
  > 沃倫：「說得好。可惜命不能轉讓，契約可以。」
- **變體**
  - 拒絕／缺席：阿衡自己申訴，沒找到交付紀錄，貨權轉移；店舖依擔保書。
  - 晚到（已開庭）：貨權已輸；主角可幫她爭店舖。
  - 晚到（阿衡已過世）：
    - 有後人：後人有自己的主張（例如想把店賣掉），不是阿衡的替身。
    - **沒有後人**：店舖依擔保書歸債權人；帳簿塔上阿衡的索引標為「已結」。主角只能在索引上看到她的名字。
- **寫入**：`阿衡_貨權`、`阿衡_店舖`。

### W-2｜沃倫的契約
- **沃倫的提議**
  > 沃倫：「我可以資助你。條件全寫在這裡。你慢慢讀，我最喜歡看人慢慢讀。」
- **條文摘要**（可閱讀；**不是可簽的全文**，數額待設計）

| 條 | 內容 | 狀態 |
|---|---|---|
| 一、資助標的 | 船位三次（衡金星至萬舶星）；商盟通行證一張；每月生活費，上限為【待設計：數額】 | 提案 |
| 二、資助期 | 自簽約日起五年，**僅限乙方這一世**。五年屆滿或乙方死亡，資助即止 | 提案 |
| 三、優先購買權 | 乙方於資助期內、以甲方資助所得之發現，甲方有優先購買權。**排除**：涉及第三人隱私或秘密的資訊（例如他人的藏身處、記憶、身分、安全屋位置）；乙方資助期前已知之事 | 提案（v1.2 加排除項） |
| 四、違約金 | 乙方違約之違約金計算方式【待設計】 | 待設計 |
| 五、延續 | 本契約**已發生而未清償之債務**，及於乙方今生及其延續 | 提案 |
| 六、爭議 | 商盟商事庭 | 提案 |

- **資助與債務分開**：第五條不延續資助，也不延續新的義務；只主張**已經欠下、還沒還清**的部分可以跨世追討。
- **可讀出的問題**
  - 第五條：「延續」對會輪迴的人可能被主張為「每一世」。
  - 第四條：計算方式未定，簽前必須問清楚。
- **選項**
  - 指出第五條：
    > 主角：「『延續』是什麼意思？」
    > 沃倫：（大笑）「你讀到了。」
    > 沃倫：「我只是好奇：一個人的下一世值多少錢。」
    > 主角：「那你刪掉。」
    > 沃倫：「刪掉可以。刪掉以後，你也別指望第四條會對你太客氣。」
    - 刪第五條不代表其餘公平；主角仍可逐條談第四條。
  - 沒讀出、直接簽：契約成立；跨世部分見 W-2b。
  - 拒簽：
    > 沃倫：「好。你是第一個拒絕我還讓我覺得賺到的人。」
- **寫入**：`沃倫契約：未簽｜已簽_含五｜已簽_刪五｜已簽_刪五議四`。

### W-2b｜查訪（僅在簽了第五條且有未清償債務時）
- **前提**：主角死亡時，確有**已發生而未清償**的債務。若五年內履約完畢、或死時沒有欠款，第五條沒有可追討的對象，查訪不會發生。
- **沃倫不會自動找到主角的下一世**。查訪員只能依線索查：

| 結果 | 說明 |
|---|---|
| 查不到 | 多數情況 |
| 延遲 | 主角覺醒數年後才有線索 |
| 錯認 | 找上無關的人；主角若得知，可選擇替無辜者澄清（會暴露自己）或不介入 |
| 找到 | 主角自己去商盟、自己說出、或授權公證所提供比對結果 |

- **公證所**：查訪員要調閱公證所的比對結果，**必須有主角的授權**。即使主角授權，公證所的結果只證明記憶片段未被剪接，不證明主角與前世是同一靈魂；商事庭能否據此認定同一人【待設計】。
- **找到之後**：主角可在商事庭主張不同一人、找沃倫本人談（沃倫可能直接放棄這筆債：「我只是好奇」）、或無視（沒有法術效力）。
- **燈籍安全**：查訪員找主角時，可能順帶查到他這一世的家庭。
- **寫入**：`沃倫查訪`。

### W-3｜未出生者的時間（《借一刻》任務途徑）
- **地點**：商港城區（U-005-P1-C1）。ATLAS 地方矛盾「小商隊無法負擔旺季泊費」；本事件為其延伸（提案）：付不起泊費的移民家庭，以勞務合約換取入港。
- **處境**：合約附則寫著，本人無法完成勞務時，由其尚未出生的子女繼續履約。部分較早的合約，孩子已經出生，並已被要求開始履約。
- **沃倫的請求**
  > 沃倫：「有人在我的港口，拿還沒出生的孩子做抵押。它合法，因為沒有人說它不合法。」
  > 沃倫：「你去找出來。讓我承認它不該存在。」
- **調查**
  - 找簽約家庭（須同意才能看合約）。
  - 追擬約代書、承攬商，查每一批合約的**債權人是誰**（見 W-3b）。
  - 觀命的對象是**母親**（找對命錨；經本人同意）。母親不能代替孩子同意任何事。
- **論點**
  > 主角：「這份合約的問題，不是價錢算不出來。是她沒有權利賣。那是另一個人的未來。」
  > 沃倫：（很久）「……契約的兩方，有一方不存在。」
  > 沃倫：「那就不是契約。那是一張寫了字的紙。」
  > 主角（可選的反駁）：「你今天這樣說，是因為你手上剛好沒有這批債權吧？」
  > 沃倫：（笑）「你猜。」
- **論點只是開始**：任務資格**不取決於選到哪個論點**，而取決於實際成果（見 W-6）。
- **寫入**：`沃倫_承認無權代賣`（論點層級）。

### W-3b｜撤銷程序
**撕紙是象徵**。沃倫當眾撕掉一份合約，會上報刊，但不改變任何法律狀態。

**第一步：釐清債權人**（沃倫只能放棄自己持有或經授權的部分）

| 債權人 | 沃倫能做什麼 |
|---|---|
| 沃倫或其商盟直屬機構 | 直接放棄 |
| 承攬商（未轉售） | 需承攬商同意；沃倫可以用其他交易換取同意 |
| 已轉售給第三方 | 沃倫需回購；或等理事會宣告附則無效後，由第三方自行處理 |
| 無法查明 | 須等理事會的制度性宣告 |

**第二步：正式程序**

| 項目 | 單案 | 制度 |
|---|---|---|
| 撤銷 | 債權人放棄該份附則，經衡金星主府登錄 | 沃倫在理事會提案：以未出生者履約的附則一律無效；需衡金星主公告 |
| **停止追索** | 債權人發出停止追索的正式通知，送交當事家庭與港務處 | 公告後，所有同類附則的追索一律停止 |
| 已履行的家長 | 已完成的勞務照付；其子女的義務作廢 | 同左 |
| **已受害的子女**（已出生並被要求履約者） | 【提案】救濟：已做的工照付工資；立即解除；居留不受影響；紀錄中「履約人」身分刪除 | 同左，並由理事會設救濟窗口 |
| 港口居留 | 與合約分開；不受撤銷影響 | 同左 |

- **理事會的阻力**：反對制度改革的理事，與推動公共航路私有化的是同一批人（ATLAS 地方矛盾）。主角可以找出這層關係作為說服依據（紀錄層級）。
- **寫入**：`未出生者合約_單案撤銷`、`未出生者合約_制度改革：通過｜否決｜未提`、`已受害子女_救濟：已執行｜未執行`（三者分開）。
- **缺席**：主角不在時，單案撤銷仍可能發生（若沃倫已承認）；制度改革較可能被否決；已受害子女的救濟不一定執行。

### W-4｜資料的價格
- **地點**：舊市城區（U-005-P1-C2）的地下拍賣廳。ATLAS 地方矛盾「知名藏家販售精密贗品」；本事件發生在同一市場（接 EV-016：示範事件 30 則 v1.1）。
- **未登錄者不全是人類**：資料中多數是改造人、拼裝機體、難民、失籍者。
- **證據鏈**

| 環 | 需要的證據 | **格式相同不足以證明同源**時，另需 |
|---|---|---|
| 1 邊防上傳 | 上傳規格 | — |
| 2 匯出給整理商 | 整理包目錄 | 整理包內的序號或浮水印，與邊防上傳批次的對應 |
| 3 轉賣 | 交易廳成交紀錄 | 成交時間戳與整理包版本號的對應 |
| 4 買家 | 付款帳戶 | 帳戶與空殼商號、再與實際委託人的連結 |
| 5 追捕使用 | 追兵手上的地址單 | 地址單上的錯字、排序或欄位，與某一版整理包的**獨有特徵**一致；只有格式相同時，只能說「可能同源」 |

- **沃倫是否知情**（他的說法）：他知道資料市場存在，不知道被用來追捕。主角可以相信或不相信。
- **對質**
