> **目的**：問題狀態追蹤 v1.1 第 3.1 節第 1～5 項，出可比較的方案，供你裁決。每題列候選、與已定設定的相容性、對各結局的影響、代價，最後附**我的建議**。建議不是定案。 **必須相容的已定設定**：

> - 九位道主讓造物主沉睡，理由是「祂繼續睡宇宙才存在，否則一切將毀滅」（N1，這是道主們的理由）

## 一、Q2：暗殺並取代造物主的機制

### 候選

| 候選 內容 相容性 代價  |                                            |                            |                                               |
| ------------- | ------------------------------------------ | -------------------------- | --------------------------------------------- |
| **甲 切斷連結**    | 承接者先進入渾沌，把自己接上夢之本；再切斷造物主與渾沌的連結。造物主失去夢，死去   | 與「喚醒＝燭陰睜眼、造物主活著醒」清楚區分（C12） | 承接者必須長留夢心，無法再回到夢中生活；這讓弒神結局的「孤獨」有機制依據          |
| **乙 另造核心**    | 陸吾以創世造一個新的夢之核心，把夢移過去；原造物主隨之死去              | 最符合陸吾的法則與「守帝之下都」的動機        | 新核心是複製還是延續？會引出「夢中眾生是否仍是原來的自己」的大問題，可能搶走其他結局的主題 |
| **丙 遮天藏死**    | 閻羅 X 以遮天藏住造物主的死，讓夢在不知做夢者已死的情況下多撐一段，期間換上承接者 | 最符合閻羅 X 的法則                | 單獨成立時太像「騙過世界」；遮天有「空白太乾淨」的限制，燭陰或觀察者會察覺         |

### 各候選在陸吾與閻羅 X 的計畫中

- 甲：需要承接者（陸吾或閻羅 X 或主角）先到渾沌；陸吾的創世負責接上，閻羅 X 的遮天負責不讓燭陰察覺切斷的那一刻。
- 乙：陸吾為主，閻羅 X 為輔。
- 丙：閻羅 X 為主，需另一人承接。

### 對結局的影響

| 結局 甲 乙 丙  |                |                            |                   |
| --------- | -------------- | -------------------------- | ----------------- |
| 弒神・單人     | 主角接上渾沌、長留夢心    | 主角需要創世才能造核心（主角可從 L01 取得創世） | 主角需要遮天（可從 Y01 取得） |
| 弒神・共治     | 多人同時接上渾沌（見第四節） | 共用一個新核心                    | 遮天期間多人接替          |
| 守護夢境      | 阻止「接上」或「切斷」任一步 | 阻止造核心                      | 揭穿遮天的空白（真實法則）     |
| 煉假成真      | 不受影響（不切斷、不換核心） | 同左                         | 同左                |

### 我的建議

**甲為主、丙為輔**：機制以「接上渾沌、切斷連結」為核心（甲），閻羅 X 的遮天只負責掩蓋切斷的瞬間（丙的有限版本）。理由：

- 甲讓「喚醒」與「弒神」在機制上分得最清楚。
- 兩位共謀者各有不可替代的角色，符合已定的分工。
- 不引入乙的「新核心是不是原來的夢」這個大題，避免與煉假成真的主題重疊。

## 二、Q5：人類衰亡，作者層是否有答案

### 候選

| 候選 內容 代價         |                          |                              |
| ---------------- | ------------------------ | ---------------------------- |
| **甲 有答案，遊戲不揭**   | 作者層有明確答案，只用來維持一致；遊戲內只給線索 | 作者需自己守住；後續寫作不能無意暗示           |
| **乙 沒有答案**       | 永遠是謎                     | 劇情不能出現任何指向答案的線索；海外諸國遺跡等只能是氛圍 |
| **丙 有答案，只在深處揭露** | 某個非必要內容（圖鑑深處、某結局的尾聲）可揭露  | 需設計一條不影響主線的揭露路徑；揭露後不能改寫任何結局  |

### 若採甲或丙：作者答案的候選（不得與「非歸墟破碎造成」衝突）

| 答案候選 內容 與已定設定的關係  |                                       |                                                    |
| ----------------- | ------------------------------------- | -------------------------------------------------- |
| a 沉睡加深            | 造物主睡得越深，夢與夢外的連結越弱；人類與夢外連結最深，所以最先變少    | 與 N1「沉睡是宇宙存在的前提」形成張力：守護夢境也在慢慢讓人類變少。代價：會讓守護結局帶上原罪色彩 |
| b 先人的航行           | 先人順著命線在宇宙間穿行，消耗了某種不可再生的東西；失聯宇宙與人類減少同源 | 與「最早不只十個宇宙」「此路今絕」相呼應；不涉及道主                         |
| c 無單一原因           | 多種原因疊加（戰爭、失聯、登錄排除、遷徙），沒有神祕解答          | 最寫實；與蒐集時代、登錄議題一致；但「謎」的重量會變輕                        |

### 我的建議

**甲＋答案 b**：作者層有答案（先人的航行消耗了什麼），遊戲只給線索（海外諸國遺跡、潮簿的「此路今絕」、失聯航路）。理由：

- 不把守護夢境寫成原罪（避開 a）。
- 與山海經、失聯宇宙的設定自然接上。
- 保留謎的重量（避開 c）。

## 三、Q6：歸墟與夢外、地球的關係

**已定**：歸墟對應我們所在的宇宙，與地球有直接關聯。 **限制**：不得強迫喚醒結局揭示夢外（N18）。

### 候選

| 候選 內容 代價                   |                                         |                              |
| -------------------------- | --------------------------------------- | ---------------------------- |
| **甲 歸墟是夢對夢外的倒影**           | 歸墟是夢裡依夢外（地球所在的真實）而成的宇宙；地球在夢外，歸墟是它在夢中的投影 | 需決定蔓哈頓等星球與地球的對應；玩家會問「地球在哪裡」  |
| **乙 歸墟是夢中唯一有通道的宇宙**        | 歸墟與夢外之間有某種通道；地球在夢外                      | 喚醒結局即使不揭示，也會被玩家預期「會看到地球」     |
| **丙 歸墟就是造物主入睡前所在的宇宙**      | 造物主睡著時，把身邊的宇宙也收進了夢裡；地球原本在那裡             | 造物主與地球的關係成為新的核心謎團，份量過重       |
| **丁 作者層有關係，遊戲只保留「直接關聯」一句** | 不在遊戲內說明關聯的性質                            | 最安全；但「歸墟與地球相關」這條正史在遊戲內幾乎不被使用 |

### 對喚醒結局的影響

- 甲、乙、丙都會讓玩家在喚醒結局期待看到地球；N18 要求不回答，所以結局畫面必須保持不指明（目前的「陌生房間、窗外有雨、桌上一盞燈」可以相容）。
- 丁對喚醒結局沒有額外壓力。

### 我的建議

**甲，但在遊戲內只到「倒影」為止**：

- 作者層：歸墟是夢依夢外的真實所形成的倒影，地球在夢外。
- 遊戲內：只透過先人的中山經（歸墟為中心）、師父「歸墟連著外面」之類的**角色說法**呈現，不給定論。
- 喚醒結局畫面維持不指明。

## 四、弒神奪位・共治的穩定條件

### 問題

三個做夢者同時承接一個夢，如何不把夢撕裂？（第四批下 v1.2、L01 v1.1）

### 候選

| 候選 內容 穩定性 代價  |                                    |                       |                               |
| ------------- | ---------------------------------- | --------------------- | ----------------------------- |
| **A 分區共治**    | 三人各承接一部分宇宙                         | 低：宇宙之間的空隙會擴大，邊緣世界可能增長 | 夢會變成三個互不相通的夢；與「宇宙間有航行」的世界觀衝突  |
| **B 輪值做夢**    | 三人輪流做夢，其他人醒著守夜                     | 中：換班時夢會變薄，異象增加        | 需要三人長期互信；閻羅 X 的掙扎會成為隱患        |
| **C 主從共治**    | 一人做夢（接上渾沌），其他兩人不做夢：一人以創世修補，一人以遮天守夜 | 高：只有一個做夢者，夢不分裂        | 實際上不是「共同做夢」，而是一人承接、兩人輔助；權力不對等 |
| **D 共識錨**     | 三人共同接上渾沌，夢的穩定依賴三人意志一致；任一人動搖，夢就震動   | 不定：三人一致時很穩，分歧時劇烈      | 最有戲劇性；但需要規則說明「動搖」如何發生         |

### 與甲（Q2 建議）的相容

- A、D 需要三人同時接上渾沌。
- B 需要輪流接上。
- C 只需一人接上。

### 我的建議

**C 主從共治**，並明寫「這不是三人平等做夢」：

- 最穩定，而且誠實呈現權力不對等。
- 誰做夢，就是結局中的主要抉擇；主角可以是做夢者，也可以是輔助者。
- 陸吾的創世（修補）與閻羅 X 的遮天（守夜）在結局後仍有角色。
- 保留「輔助者可以背叛」作為共治結局的長期隱憂，但**不**自動觸發任何後續結局（N20）。

## 五、閻羅 X 拒絕時的兩方約定

**限制**：不得冒充三方共治成立（L01 v1.1）。

### 候選

| 候選 內容 代價        |                                        |                                |
| --------------- | -------------------------------------- | ------------------------------ |
| **一 兩人共治**      | 主角與陸吾依第四節的某一方案共治，缺少閻羅 X                | 若採 C 主從：缺少遮天守夜，燭陰更容易察覺；夢更不穩    |
| **二 主角承接、陸吾修補** | 主角是唯一做夢者，陸吾以創世輔助；本質上是**弒神・單人**的變體，陸吾在旁 | 陸吾的野心落空（他沒有成為做夢者）；他是否接受需在對質中說服 |
| **三 約定不成立**     | 閻羅 X 拒絕即無法進行共治；主角回到其他結局選項              | 最乾淨；共治路線變窄                     |

### 閻羅 X 拒絕的後果（三種候選共同）

- 閻羅 X 知道計畫與參與者；他可能揭發、阻止或袖手（依他的狀態）。
- 他的遮天不再為共治者所用。

### 我的建議

**二 主角承接、陸吾修補**，並把它歸類為「弒神・單人（有輔助者）」，而不是共治：

- 不冒充三方共治。
- 給陸吾一個艱難的選擇：放棄做夢者的位置，只當修補者。他接受或拒絕，都是有力的角色時刻。
- 陸吾拒絕時，回到**三 約定不成立**。
