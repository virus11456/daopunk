### EV-061　試石碑｜消息與傳聞
- **沿用已接受的工作稿開場**：採石工說，試石碑上刻的「合格石料」標準，是軍需官私下改過的。
- 地點：赤岳星採石城區（U-002-P1-C2）｜觸發：到場型
- 作用域：試石碑的**該版碑文**（版本 ID）、**該次爭議**（爭議 ID）；同一碑可有多次改動，各自獨立
- 發言來源：採石工（人物 ID）的轉述
- 選項→結果

  - 查實後協助申訴：受理與否另計；受理後審理結果另計。
  - 離開。
- 主角不在：採石工仍可自行申訴；劣質石料是否流入工程依另案世界事件。

### EV-063　老戰獸退役｜日常求助
- **沿用已接受的工作稿開場**：一頭老戰獸被判退役，牧人不知道該怎麼照顧牠。

- **世界狀態**（截止點時，互斥；以**主要照護者**分類）：
  - M 存活，主要照護者為原牧人
  - N 存活，主要照護者為其他人
  - O 存活，無人照護
  - P 死亡
  - （共同照護時，以投入時間最多者為主要照護者。）
- **條件**：「牧人**實際**自己照護」／「牧人**實際**轉交他人」；「決定」不等於已實行。
- 觀命示例可辨份額（非世界分布）：自照條件：M 五成、N 半成、O 半成、P 一成五、看不清兩成五；轉交條件：M 半成、N 四成五、O 一成、P 一成五、看不清兩成五。

- 主角不在：戰獸去向依牧人的實際決定、戰獸的反應與其他人的介入。
- **v1.5 取代上方分類與示例**（SPEC S07）：
  - 條件改為「牧人**已開始**自照」／「牧人**已開始**轉交」（開始實行，不是整年結果）。
  - 世界狀態（截止點，以照護者集合分類，互斥）：M 存活且照護者含原牧人／N 存活且照護者不含原牧人但非空／O 存活且無人照護／P 死亡（優先；照護史另存）。
  - 正錨須讀出分支的**條件與機率**，不只是看見一條線。
  - 原示例數字撤下，不作定值；待有世界分布 P 與可辨程度 r 時依 S07 計算。
