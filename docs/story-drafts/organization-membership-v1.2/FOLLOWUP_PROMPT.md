# 給 Claude：加入中立組織 v1.3 精修

以本包 ORIGINAL.md 為底稿；保留三項確認及九節的作者待選，不重新撤回殺手入會，不代選海盜、規矩或退出代價。請處理下列剩餘問題並逐項回覆：

1. 第二節「成員（或常客）」能收到執行委託，和同節「未入會者不會收到」矛盾。依現行入會後才開放的提案統一，刪除常客例外；若要保留例外另列待選。
2. 拍賣場保密協議、公社隱私守則、港口登記，不能同時等於接受每一件業務。拆會員成立、職務任命、單次委託接受；尤其港口居民不是自動港務代表，退出職務不必撤銷居留。
3. 「看到委託無任何責任」限縮為不產生接單與履約義務；已簽保密或隱私守則仍可能有效。信物交付须明示接受，不能被塞入手中就成立承諾。
4. 海盜「交還所知」、無聲會交還聯絡方式改為歸還載體、停用資格、撤銷授權、承諾不披露。主角完整記得親歷，不可當成能交還或刪除記憶。公社病歷只能交給合法承接者；公證退出後保密義務也要交代。
5. 無聲會的成員動機、官員、孩童規矩仍待選，不能先暗定。秤丙案即使禁止擔保人索取新委託，仍可能無限阻止退出；需呈現其壓迫性與替代退出接口，不宣稱已解決強迫問題。
6. 避難網退出即遷移所有已知節點不合理：依暴露證據、風險、住民意願和安置資源評估，非退出者必然不可信。疑似洩露可暫停權限，但補查明與恢復程序。
7. 固定「只有多條線索才有風險」改為證據可靠度：單一可信自述或直接證據也可能暴露，多條弱線索亦不一定證實。未登錄、無接口均不直接等於人類。職務能力不能只列服從與保密，也須相應航行、救援或審核能力。
8. 公證所可出具在方法限制內是否發現改寫的報告，不保證絕對真偽；未被剪接不等於事件一定真實。亞茲掌靈魂不自動代表其機構可普遍認證前世身分。紀錄有回執仍只代表該紀錄如此記載。
9. 「同意不是施術必要條件」與偷看可行相容，但本稿標已定需引用既有對應來源；不要因編輯建議自行擴張無條件遠距窺視。命錨、可觀測範圍與條件仍存在。
10. 未入會玩家接觸組織不只列舉的四種事件；新聞、傳聞、普通交涉仍可存在。「唯一接觸方式」改為既有示例。無會員付費調閱也須授權和可用紀錄，付費不取代隱私同意。
11. 固定停職一季、誤差一次就停職皆保留提案；區分疏失、不可抗力、惡意與申覆。死亡與轉生不自動恢復舊資格，機構可能改組或消失。

請補情境覆核：簽保密但拒接單；港務退職仍住港口；前世知道安全屋但已撤權；常客未入會；暗號已轉給接班人；有付款但無調閱同意；公證資料未發現剪接卻有來源造假；擔保人拒絕且沒有其他人可找；從未入會仍能推進主線。
