## 一、096「彪」：來源定位結果與替換提案

**查核結果**：本輪以維基文庫中山經全文、四庫本卷五、識典古籍檢索，**未找到**以「彪」為名、有形貌描述的條目。「彪」在經文中若出現，可能只是泛稱或列名，不足以撐起一條圖鑑。

**提案**：以中山經中已核的「蠪蛭」取代，保留 ID `SH-LIFE-364`、序號 096。理由：它已在第 5 批 094「蠪姪」中作為同名異物交叉索引，補上正好使兩條成對。

### 096　SH-LIFE-364　蠪蛭（替換「彪」，待你方確認）
- **經文層**：中山經（中次二經，昆吾之山）：其上多赤銅；有獸焉，其狀如彘而有角，其音如號，名曰蠪蛭，食之不眯。郭注：「上已有此獸，疑同名。」已對照（維基文庫、四庫本）。
- **未見短文**：中部昆吾之山上多赤銅；山中有一種獸，形狀像豬而頭上有角，叫聲像人在號哭，名叫蠪蛭；郭璞說前面已有同名的獸，懷疑只是同名。
- **本作**：有角的豬形獸，叫聲拉長像人在哭，夜裡常讓人以為附近有人出事。與東山經九尾九首的「蠪姪」（094）同名異物，本作分立兩條，不合併。經文所錄「食之不眯」只作先人所錄。昆吾之山產赤銅，郭注所記昆吾之劍屬注文，本作不採用。
- **落點**：首選 元素洪爐晶礦城區（U-006-P2-C1）周邊礦坑（新增微棲地提案）：產銅的礦區與經文相符。替代 赤岳星採石城區（U-002-P1-C2）。
- **取得**：經文；注文；親聞；親見（全身）。
- **image_brief**：親見圖透明；豬形、頭上有角；不可畫料理、文字。

**若你方不採替換**：096 維持暫緩，或從清單移除（180 條變 179 條）。
