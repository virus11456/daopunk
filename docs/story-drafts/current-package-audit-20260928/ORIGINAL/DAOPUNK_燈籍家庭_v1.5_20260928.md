## 一、落點規則

### 1.1 待產清單

- 主角死亡後，世界時間照常前進。
- 燈籍上**有人懷孕**時，這個預期中的出生成為一筆**待產紀錄**（家庭 ID、預估出生日）。
- 待產紀錄不是孩子。孩子只在**實際出生**時產生**出生實例**（孩子 ID、實際出生日）。
- 待產紀錄可能：如期出生、提前或延後出生、雙胞胎（一筆待產紀錄產生兩個出生實例）、流產或死產（無出生實例）、隨家庭遷居（家庭 ID 不變，所在地改變）。
- **穩定排序**：清單依預估出生日排序；同日依家庭 ID 排序。排序一經產生，不因玩家反覆查看而重抽。
- **選定紀錄**：玩家選定後，記錄「選定的待產紀錄」；該出生實例產生時，主角即為該孩子。
- **出生未發生**（流產、死產）：【提案】選定作廢；世界時間繼續；下一筆合格待產紀錄出現時再提供清單。已消耗的等待時間不退回。

### 1.2 為什麼能選

【已定 N39】選擇只存在於玩家介面。主角等待期間沒有經驗，不記得「選過」。主線階段六，師父說「落在哪裡，是你自己選的」；主角可以相信，也可以懷疑。

### 1.3 直系規則與親屬篩選

**規則**【提案，直系部分依 N40 不放寬】：出生實例的父母任一方，若是主角**任何一世**的：
- 直系子孫（子女、孫輩及以下），或
- 配偶，

則該出生實例不列入清單。

**篩選依據**：作者層的全世代人物 ID、真實親子關係、配偶歷史；**不**依姓氏或當前戶籍。

**需定義的邊界**（已由 N55 定案；以下為歷史提案，現行規則見第八節）：
| 情形 | 建議 |
|---|---|
| 收養的子女 | 不視為直系血緣；但若主角前世親自養大，建議仍排除（情感上等同子女） |
| 前任配偶（離異） | 視為配偶，排除 |
| 喪偶後對方再婚所生 | 對方仍是主角前世配偶，排除 |
| 資料缺漏（前世子女下落不明） | 以作者層真實關係為準；玩家不知道不影響篩選 |
| 秘密親屬（主角前世不知道自己有孩子） | 仍排除 |

**精確候選台詞**（師父，主線階段六）：
> 師父：「那一刀，不讓你落在你累世子孫或配偶所生的孩子身上。」

詩性版本「那一刀，不讓你回到自己的血裡」可保留為前導句，但**不作規則證明**；旁系是否排除見第八節。

### 1.4 等待時間

- **等待 W**＝死亡日至**實際出生日**。
- 【已定 N40】十年為**軟目標**：以燈籍人口規模使其在多數情況下成立；**不保證**。
- 十年的計算**包含**剩餘孕期；不能等了十年才找到待產紀錄，再另加未計的孕期。
- **不放寬**直系規則；**不**添加新血緣；**不**安排強制生育；**不**憑空新增家庭。
- 人類不歸零（N12）**不等於**必然有合格的生育來源；若長期無合格出生，世界照常前進。

### 1.5 死亡的代價與開局

- 每一次死亡，世界至少前進 W＋十四至十五年；人會老、會死，地方會改變。這就是死亡的代價。【已定 N20】沒有自動時限結局，也不以此設計任何自動懲罰。
- 清單只提供有限資訊（宇宙與星球、家業、與隱修院有無聯絡、第幾代下山）。家業與星球**足以讓玩家推測**資源、地點與風險；本設計只**降低**資訊量，不保證杜絕刻意死亡換開局。候選的消耗、世界後果與再選規則需後續原型測試。

## 三、新戶

新戶**不是模板生成的兩名新人類**。

| 事件 | 條件 |
|---|---|
| 成家 | 兩位**現存**燈籍人物（有人物 ID）成家 |
| 立戶 | 另立家戶，取得家庭 ID |
| 遷居 | 有連續的遷居歷史（從哪裡、何時、為何）；不隨每輪瞬移 |
| 出生 | 另依 1.1 產生待產紀錄與出生實例 |
| 家業 | 需有來源（學徒、繼承、受雇）；星球的出口品不是每位居民天生的技能或資產 |

**程家**（v1.1 的新戶示例）：保留為示例；須補父母的人物 ID 與遷居歷史，才能作為落點。

## 四、開場類型與接續

開場類型（離家、留家、危機、秘密、接續）沿用 v1.1，但：

- **接續型**（前世認識的人或地方就在附近）：只在人物**實際存活**、**實際在該地**、實物**實際仍有保管人**時成立；主角對他們的認識依其**資訊來源**（親歷、轉述、紀錄）。紅的燈、拾六都不無條件出現。
- **家人的知情**：若主角曾在某一世告訴家人自己會轉生，該家人記得；不是每次都無條件不知情。

## 五、同一戶再次落點

- 同一**出生實例**不會重現。
- 同一**家族**可以再次出現在清單上（不同的孩子）。
- **不保證不同世代**：主角早死後，可能轉生為前世父母晚年所生的另一個孩子，即**前世的手足**。現行直系規則**未禁止**此情形；是否禁止見第八節。
- 可觸發一次性的記憶事件（例如認出祖母年輕時的照片），依實際關係而定。

## 九、候選資料規則（SPEC S05）

| 項目 | 規則 |
|---|---|
| ID | 待產紀錄用 `pregnancy_id`；出生用 `child_id`；父母、家族、地址、孩子、人口各有 ID |
| 可列入 | 已懷孕且尚未出生者 |
| 排序 | 依當下已知預產日與穩定 ID；出生時再核真實親屬與資格 |
| 多胎 | 一筆待產紀錄依實際出生順序分 `child_id`；主角只綁一人，不複製 |
| 胎停、死產 | 不生成活人的主角實例；作廢後**先重掃**當時全部仍有效的待產紀錄，不只等新懷孕；已耗世界時間不倒流、不重抽流產 |
| 出生後、覺醒前死亡 | 記一個實際生命；主角沒有可操作的等待或童年記憶；轉回死亡後的候選流程；**99 年承載從出生起算不變**（N41）；世界紀錄保留這次死亡 |
| 配偶族屬 | 不由婚姻猜成新人類；沒有來源的人類親屬不得憑空新增 |
| 全體存續 | 任一家庭可受損或滅戶；但任何合法的世界進程都不得把**全體**燈籍燈熄滅；事件配置時避免所有存續家庭同時遭遇不可逃避的滅絕；這不是個人免死，也不保證主角有合格轉生對象（N12、N47、S05） |
