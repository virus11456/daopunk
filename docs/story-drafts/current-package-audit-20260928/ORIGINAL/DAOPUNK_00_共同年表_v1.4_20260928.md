## 三、物件狀態規則

### 3.1 主角的遺物（依實際死亡）
| 條件 | 狀態 |
|---|---|
| 主角實際死亡 | 遺物留在死亡地點或原居處 |
| 遺物被尋獲 | 由尋獲者或原保管人持有 |
| 紅收存 | 需：紅在世、得知死訊、取得遺物、有保管權（例：陵墓登記為代管人）；四者皆成立才成立 |
| 主角生還（閘門存活） | 不產生遺物；紅不收存；空白算命紙仍在主角手上 |
| 轉交時點 | 不得早於實際死亡日 |

### 3.2 舊紙與拓本
| 物件 | 狀態旗標 | 條件 |
|---|---|---|
| 舊算命紙（原件） | `舊紙_原件：拾六持有｜他處` | 預設拾六持有 |
| 紅借閱 | `舊紙_紅借閱` | 第一批 C5：拾六同意借一晚 |
| 拓本 | `舊紙_拓本：紅持有` | 紅確實拓印 |
| 返還 | `舊紙_已返還` | 次日歸還原件 |
| 玩家是否看過 | 依主角在場與否 | 原件在拾六處不代表各路玩家都看過 |

### 3.3 信件與紀念
| 項目 | 規則 |
|---|---|
| 紅的信（寫給大師兄） | 封數依紅實際寫信與保管紀錄；寫信停止是紅的選擇；不固定十一、十五或十六封 |
| 大師兄的信 | 依大師兄實際寫信、寄出與送達 |
| 紅的登報 | 需：主角在此死亡、紅在世、得知死訊、決定登報；自實際刊登年起；是否逐年持續依實際紀錄 |
| 紀念螺帽 | 需已知死訊與實際立碑；生還路不觸發 |
