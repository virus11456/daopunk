# DAOPUNK｜圖鑑遭遇場景：第 7～9 批（序 121～180）v1（2026-09-28，Claude 交付）

> **依據**：第 7 批 v1.1、第 8、9 批 v1.1（你方修訂稿，含 C7-D1～D3、C8-D1～D3、C9-D1～D3）的落點與規則。
> **格式與原則**：同第 5、6 批遭遇場景。另依本輪裁決：
> - 制度登記、生命／意識、個體意願分開；政策與訴訟不永久凍結。
> - 信使局只定外存資料的留存規程，**不**強制清除個體的親歷記憶（C8-D2）。
> - 多機體不自動合成單一命錨；停機不等於死亡；贈件不自動成為紀念遺物。
> - 薄牆的「知道、抵達、察覺、穿越」分開。
> - 遊戲內古籍的樣段未取得前不預顯；刮除的原文不預開（C9-D2）。
> - 地方習俗不保證發生，不自動觸發角色事件（C9-D1）。
> - 展示器物需物主在場、願意，且主角實際看見。
