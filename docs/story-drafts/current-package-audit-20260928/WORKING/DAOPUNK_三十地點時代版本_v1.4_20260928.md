> **讀法**：
> - 年代欄只決定**環境基底**（無介入示例）。人物與物件的**實際狀態優先**。
> - 標「任務」的內容，依該任務的**實際觸發日**開始與結束，不綁在某一年代：後期首次遇到的任務不因表格已到「老去」而自動揭露；早期完成的改革也不必等到下一年代才生效。
> - 「延續基底」是延續年代的普通生活版本；「夢動異象」是暫時現象，消退時**不復原**已發生的死傷、倒塌、遷移（永久後果另存）。
> - 異象分級：〔現〕純現象、無害｜〔修〕可維修的故障｜〔傷〕可能造成傷害（需事前可知的風險與後果）。異象皆**不證實**燭陰或陸吾為原因。
> - 年代是世界紀年；各星球的政策與事件依**消息到達、地方勢力與制度執行**而定，不與歸墟同步。

## v1.2 整合（已定）

- **分級採用**（N69）：〔現〕純現象、不直接致傷；〔修〕設備故障，具可知風險；〔傷〕必有事前可感知的警示與拒入或退出的機會。夢動消退不恢復永久損失。
- **〔傷〕五處的事前警示**（沿用第 5～7 輪補件 v1 第五節）：轉運聚落貨梯停頓增加；引潮埠浮標與航誌不符；冷卻城區冷卻塔溫度異常升高；繭歸鎮繭室溫濕度波動；守燈聚落燈油耗量異常。每處皆有拒入或退出的機會。
- **〔修〕的安全邊界**：未修時可能升級為〔傷〕的地點（破爛一條街坑壁、商港城區信號燈、避難城區厚壁）須同樣給出事前警示。
- **年代界線**：依 SPEC S06 半開區間；表中各年代欄只是環境基底，不保證事件在界線發生。
- **必要入口替代**：K4 由聚變或涂山氏替代（N50）；師父不可達時命運由燈籍閣夾頁取得（N49）；閻羅與陸吾皆不可達時改走終章調查結算（S03）。替代來源方向已列；實際取證須依核心缺口v1.2現行WORKING逐項核驗，不因表格填完即宣稱入口驗收。
