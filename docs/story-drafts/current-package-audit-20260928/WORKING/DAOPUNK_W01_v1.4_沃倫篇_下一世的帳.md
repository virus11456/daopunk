## 五、場景

### W-1｜帳簿塔下
- **處境**：賣香料的阿衡（提案）面對兩項主張：
  1. **貨權**：附加條款「遇不可抗力時，貨權轉歸債權人」；「不可抗力」的定義在她沒拿到的附件裡。
  2. **店舖所有權**：依另一份擔保書。
- **對白**
  > 阿衡：「他們說香料是他們的，店也是他們的。」
  > 主角：「兩件事分開看。香料是一份契約，店是另一份。」
  > 阿衡：「有差嗎？」
  > 主角：「有。一份輸了，另一份不一定輸。」
- **調查**（非戰鬥）：帳簿塔公開索引查附件交付紀錄；讀擔保書範圍；找其他受波及商戶；觀命（找對命錨；經阿衡同意）。
- **結果**：
  - 查到交付紀錄上**沒有**這份附件：只是一項證據，**不等於證實未交付**（紀錄可能漏登）；阿衡可以據此主張貨權條款無效。
  - 開庭日依世界日期：自阿衡提出申訴之日起約一個月（提案；W01_開庭日）。
  - 店舖依擔保書範圍另爭。
- **阿衡的意願**：要不要提告、要不要公開，由阿衡決定；主角可以建議，不能替她決定。
- **沃倫在場**
  > 沃倫：「你讀契約的樣子，像在讀一個人的命。」
  > 主角：「它就是她的命。」
  > 沃倫：「說得好。可惜命不能轉讓，契約可以。」
- **變體**
  - 拒絕／缺席：阿衡依自己的意願、可用證據與其他協助行動；判決、貨權與店舖各按實際程序，不因主角缺席降低結果。
  - 晚到（已開庭）：先讀實際判決與執行狀態，不預設已輸；經阿衡同意可協助尚可救濟的事項。
  - 晚到（阿衡已過世）：
    - 有後人：後人有自己的主張（例如想把店賣掉），不是阿衡的替身。
    - **沒有後人**：店舖的去向依擔保範圍、已清償的部分與世界中的遺產處理結果（可能歸債權人、可能依遺產程序另作處置、也可能尚未處理）；帳簿塔索引依實際狀態標示。主角只能從索引與檔案得知。
- **寫入**：`阿衡_貨權`、`阿衡_店舖`。

### W-1b｜商事庭（依世界日期開庭）
- 依證據判。主角若在開庭前找到新證據（同世補證），可交給阿衡。
- 缺席：阿衡獨自出庭。判決依**阿衡手上實際擁有的證據**；若她已自行取得同等有效的證據，主角缺席**不降低**結果。
- 阿衡若決定不提告，本場不發生；貨權仍須核契約有效性、其他程序及實際交付，不把不提告當自動敗訴。

### W-2｜沃倫的契約
- **開啟條件**：W-1 之後，沃倫主動提出；或主角自行到交易議宮求資助。
- **沃倫的提議**
  > 沃倫：「我可以資助你。條件全寫在這裡。你慢慢讀，我最喜歡看人慢慢讀。」
- **條文摘要**（可閱讀；**不是可簽的全文**，數額待設計）

| 條 | 內容 | 狀態 |
|---|---|---|
| 一、資助標的 | 船位三次（衡金星至萬舶星）；商盟通行證一張；每月生活費，上限為【待設計：數額】 | 提案 |
| 二、資助期 | 自簽約日起五年，**僅限乙方這一世**。五年屆滿或乙方死亡，資助即止 | 提案 |
| 三、優先購買權 | 乙方於資助期內、以甲方資助所得之發現，甲方有優先購買權。**排除**：涉及第三人隱私或秘密的資訊（例如他人的藏身處、記憶、身分、安全屋位置）；乙方資助期前已知之事 | 提案（v1.2 加排除項） |

| 五、延續 | 本契約**已發生而未清償之債務**，及於乙方今生及其延續 | 提案 |
| 六、爭議 | 商盟商事庭 | 提案 |

- **簽署前**：實作中，簽署前必須展示**填定版本**（數額、計算方式皆已填入）。本摘要中的【待設計】欄位不能在場景中以空白完成簽署。主角可以：詢問、暫緩（帶回去想）、諮詢他人（例如記憶公證所或商盟的代書）、或拒簽。
- **優先購買權的接口**【待設計】：甲方的出價規則（依市價或第三方估價）、乙方收到出價後的回覆期限、逾期的效果。
- **資助與債務分開**：第五條不延續資助，也不延續新的義務；只主張**已經欠下、還沒還清**的部分可以跨世追討。
- **可讀出的問題**
  - 第五條：「延續」對會輪迴的人可能被主張為「每一世」。
  - 第四條：計算方式未定，簽前必須問清楚。
- **選項**
  - 指出第五條：
    > 主角：「『延續』是什麼意思？」
    > 沃倫：（大笑）「你讀到了。」
    > 沃倫：「我只是好奇：一個人的下一世值多少錢。」
    > 主角：「那你刪掉。」
    > 沃倫：「刪掉可以。刪掉以後，你也別指望第四條會對你太客氣。」
    - 刪第五條不代表其餘公平；主角仍可逐條談第四條。
  - 沒讀出、直接簽：契約成立；跨世部分見 W-2b。
  - 拒簽：
    > 沃倫：「好。你是第一個拒絕我還讓我覺得賺到的人。」

### W-2b｜查訪（僅在簽了第五條且有未清償債務時）
- **前提**：主角死亡時，確有**已發生而未清償**的債務。若五年內履約完畢、或死時沒有欠款，第五條沒有可追討的對象，查訪不會發生。
- **沃倫不會自動找到主角的下一世**。查訪員只能依線索查：

| 結果 | 說明 |
|---|---|
| 查不到 | 多數情況 |
| 延遲 | 主角覺醒數年後才有線索 |
| 錯認 | 找上無關的人；主角若得知，可選擇替無辜者澄清（會暴露自己）或不介入 |
| 找到 | 主角自己去商盟、自己說出、或授權公證所提供比對結果 |

- **公證所**：查訪員要調閱公證所的比對結果，**必須有主角的授權**。公證所提供的只是「**在本次方法範圍內未發現剪接**」的報告，不是絕對真實，也不證明主角與前世是同一靈魂；報告**不包含**主角的當世住址。依 N67 啟動個案身分審理，核來源、時序、利益與反證；認定同一人不使跨世債務可強制。
- **找到之後**：主角可在商事庭主張不同一人、找沃倫本人談（沃倫可能直接放棄這筆債：「我只是好奇」）、或無視（沒有法術效力）。
- **燈籍安全**：查訪員找主角時，可能順帶查到他這一世的家庭。
- **寫入**：`沃倫查訪`。

### W-3｜未出生者的時間（《借一刻》任務途徑）
- **開啟條件**：W-2 之後，沃倫提出；或主角在商港城區自行發現。
- **地點**：商港城區（U-005-P1-C1）。ATLAS 地方矛盾「小商隊無法負擔旺季泊費」；本事件為其延伸（提案）：付不起泊費的移民家庭，以勞務合約換取入港。
- **處境**：合約附則寫著，本人無法完成勞務時，由其尚未出生的子女繼續履約。部分較早的合約，孩子已經出生，並已被要求開始履約。
- **沃倫的請求**
  > 沃倫：「有人在我的港口，拿還沒出生的孩子做抵押。它合法，因為沒有人說它不合法。」
  > 沃倫：「你去找出來。讓我承認它不該存在。」
- **調查**
  - 找簽約家庭（須同意才能看合約）。
  - 追擬約代書、承攬商，查每一批合約的**債權人是誰**（見 W-3b）。
  - 觀命的對象是**母親**（找對命錨；經本人同意）。母親不能代孩子出賣未來，也不能代替孩子未來的自主同意（這不否定她對孩子的日常照護與決定）。
- **論點**
  > 主角：「這份合約的問題，不是價錢算不出來。是她沒有權利賣。那是另一個人的未來。」
  > 沃倫：（很久）「……契約的兩方，有一方不存在。」
  > 沃倫：「那就不是契約。那是一張寫了字的紙。」
  > 主角（可選的反駁）：「你今天這樣說，是因為你手上剛好沒有這批債權吧？」
  > 沃倫：（笑）「你猜。」
- **論點只是開始**：任務資格**不取決於選到哪個論點**，而取決於實際成果（見 W-6）。
- **寫入**：`沃倫_承認無權代賣`（論點層級）。

### W-3b｜撤銷程序
**撕紙是象徵**。沃倫當眾撕掉一份合約，會上報刊，但不改變任何法律狀態。

**第一步：釐清債權人**（沃倫只能放棄自己持有或經授權的部分）

| 債權人 | 沃倫能做什麼 |
|---|---|
| 沃倫本人 | 直接放棄 |
| 商盟直屬機構 | 需機構依其內部授權放棄；沃倫可指示，但須有授權紀錄 |
| 承攬商（未轉售） | 需承攬商同意；沃倫可以用其他交易換取同意 |
| 已轉售給第三方 | 沃倫需回購；或等理事會宣告附則無效後，由第三方自行處理 |
| 無法查明，或已轉售而無法回購 | 【提案】可向商事庭聲請**個案審理**，並聲請**暫緩執行**（審理期間不得追索）；不必等制度改革 |

**第二步：正式程序**

| 項目 | 單案 | 制度 |
|---|---|---|

## 授法留痕與資格（N42、N49、SPEC S02；沃倫）

- **資格帳**：記法則 ID、取得途徑（任務／親授／擊倒）、客觀條件、證據、成立日期；**領取**另記接受、實際傳授日、已取得旗標。資格成立後跨世保留；辨認不足是「核驗待補」，不刪資格、不強迫重做任務；拒領只是延後。
- **留痕**：沃倫在衡金星萬衡京的交易議宮留下夢內的**傳承留痕**。它是三種既有途徑的領取接口，**不是**第四種免資格取得法：
  - 擊倒產生的資格，在沃倫被逐出夢外的瞬間結存，事後可依留痕領取。
  - 未完成任務者，可依留痕所載的客觀任務完成。
  - 親授途徑需沃倫離夢前**實際成立**的同意；留痕不發明新的同意。
  - 介面被破壞不刪抽象資格；依法則留痕重建同一接口，不召回道主、不與夢外通信。
- **N42**：已取得的法則不能歸還、主動放棄或被外力撤銷；主角可以選擇不使用。
- **N52 初始立場**：沃倫的初始立場為「守護」，之後依經歷改變。
