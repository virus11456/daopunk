## 二、事件底層（作者層）【提案】

1. 轉運聚落的貨梯優先給出口金屬。候運棚帆布破損，鹽霧滲入，糧箱受潮。
2. **D−10**：阿錨把「D3 子時接管三號井」的計畫告訴星主府，換得一年份的藥，首盒已交付。星塵不知道。
3. 府原打算讓灰隼守井口埋伏；灰隼因欠薪三個月拒絕續約，府改派巡衛，人手吃緊。府另外要阿錨在行動時切斷三號井電源。
4. 星塵十二歲（T−7y）時，「天衡運勢」的算命機印出：「本命格顯示二十歲前後有大凶，建議購買長期庇護方案。」母親賣屋購買方案，同年病逝。天衡在其母購買方案之後倒閉（原 T−10 早於 T−7，撤除；確切年月待敘事配置），站點與機台由「晴算」收購續營。
5. 糧箱總數 120：報廢 30（霉已穿透內袋），需分揀 25（外箱受潮、內袋待檢），可用 65。數字為敘事示例，不是正式數值。

**B｜灰隼**
- B-a 到舊營地找岳鋒。
  > 岳鋒：「府要我們回去當臨時巡衛，薪水砍一半。欠的三個月一個字都不提。」
  > 岳鋒：「今晚的事，我聽說了。你告訴我幹嘛？」

- 岳鋒的目的：讓府看見「沒有灰隼，巡衛連一口井都守不住」，作為討欠薪的籌碼；另有兩名隊員的家人靠這批糧箱吃飯。
