# DAOPUNK｜L01 陸吾篇 v1《帝之下都》

> **位置**：道主篇第八篇，也是最後一篇。可在任何一輪開啟【已定：肉鴿】。
> **兩段結構**：本篇依主角是否已推知兇手（主線 K6）分成兩段。推知之前，陸吾是一位嚴格、可敬的道主；推知之後，是對質。
> **依據**：完整背景 v1.4；主線 v2（階段八、十）；第四批下 v1.1；道主篇總綱 v1；山海經融入設定 v1.1；示範事件 EV-026；ATLAS 永恆聖堂（U-010）。
> **已定（你的裁決）**：世界持續惡化；最終抉擇由玩家觸發；**沒有自動時限結局**。本篇中陸吾與閻羅 X 的計畫會讓世界惡化，但不會自動結束遊戲。
> **沿用的寫作規則**：知情需有來源；觀命需找對命錨，同意是倫理規矩（提案）；證據分層、相似不等於證實；每場有拒絕、缺席、晚到、同世補救；資格可並存、取得一次；後人不是替身。
> **標記**：【已定】附來源；其餘為【提案】。不定戰鬥、數值；未接 Godot。

### 1.1 作者層（玩家在推知前不知道）
- 【已定 9、12】陸吾與閻羅 X 密謀暗殺並取代造物主；那一夜是陸吾出手、閻羅 X 遮掩。
- 【已定 N16】道主不會真正死，只會被逐出夢外；陸吾那一夜的目的是把師父逐出夢外。
- 【提案】陸吾不確定師父的生死：碎片打散了命途，他無法確認（背景 v1.4）。
- 【提案】陸吾的動機：他守著「帝之下都」太久，相信造物主遲早會醒；只有取代祂，夢才永遠不會醒來。他認為這是在守護夢中一切，而不是背叛。這是他的信念，不是作者事實。

### 1.2 陸吾知道主角什麼
- 預設：只知道他是一個讀得懂圖紙、會問問題的年輕人。
- 知道主角是師門的人：只有主角說出，或他從其他道主處得知（依關係）。
- 知道主角會轉生：只有主角說出，或其他道主提起。

## 二、推知之前

### L-1｜創議聖庭
- **地點**：曦冠京。冠狀光環下，聖庭的地板刻滿誓約。
- **處境**（ATLAS 地方矛盾的延伸，提案）：一個營造公會拿出百年前的誓約，主張自己有權統治光井城區的外環。外環居民說，那份誓約是他們的祖先在饑荒時被迫簽的。
- **陸吾的裁決**：誓約有效；但公會必須依誓約的原文，負起照顧外環的義務。
  > 陸吾：「誓約是約。約的兩邊都要做到。你們要權，就先把外環的燈點起來。」
- **主角可觀察的**：陸吾對誓約極為嚴格，對「偏差」極不容忍。
- **調查**（非戰鬥）
  - 查誓約簽署時的處境（饑荒紀錄、書院城區的舊檔）。
  - 找外環的老人作證。
  - 觀命（須找對命錨；經本人同意）：外環居民在「公會統治」條件下的走向。
- **選項**
  - 向陸吾提出「脅迫下的誓約」的證據：陸吾沉默很久，說「若屬實，此約不立」，並下令重審。
  - 接受裁決：公會必須點燈，外環暫時得到照顧，但統治權成立。
  - 不管。
- **拒絕／缺席**：裁決照原樣；外環的處境依公會是否履約（世界事件）。
- **晚到**：公會已統治外環多年；外環的燈點了，但居民沒有發言權。
- **同世補救**：重審前可補證據。
- **寫入**：`聖庭_誓約：重審｜維持`；陸吾對主角的狀態：`可堪一談`。

### L-2｜不照圖紙的街（《一方小天地》任務途徑）
- **地點**：啟曦星（U-010-P2）的邊庭聚落（U-010-P2-C2）。金屬日晷旁的邊界花園；地方矛盾：中心要求單一生活規範（ATLAS）。另接 ATLAS 政治提案：啟曦要求居民自行修改標準圖紙。
- **陸吾的請求**（在主角通過 L-1 之後）
  > 陸吾：「邊庭的人不照圖紙蓋房子。我給他們最好的圖紙，他們卻把牆蓋歪。」
  > 陸吾：「你去看看。如果你能說服我，歪的牆也有它的道理，我就把一件東西交給你。」
- **任務判準**：讓陸吾**接受**一個不符合標準、但居民想要的生活方式。
- **調查與做法**（非戰鬥）
  - 問居民為什麼把牆蓋歪：因為那個角度擋得住邊界吹來的風；因為那樣孩子可以從窗口看見日晷。
  - 畫下居民的做法，對照陸吾的圖紙，找出圖紙沒考慮到的條件。
  - 與居民一起，把他們的做法整理成一份「居民版圖紙」。
  - 以觀命看幾戶人家在「照標準圖紙」與「照居民版」兩種條件下的走向（須同意）。
- **陸吾的反應**
  > 陸吾：（看了很久）「……風。我沒算風。」
  > 陸吾：「完美的圖紙，是在沒有風的地方畫的。」
- **結果**
  - 成功：陸吾接受居民版圖紙，並准許邊庭自行修改。任務完成。
  - 部分：陸吾接受這一條街，不准其他地方比照。
  - 失敗：陸吾說「偏差就是偏差」；同一世可以帶新證據再試（例如一場風災中，歪牆那一排沒有倒）。
- **拒絕／缺席**：中心規範照常推行；邊庭的歪牆被拆除（世界事件）。
- **晚到**：歪牆已被拆除；主角可以協助居民重建，並以拆除後的損失作為證據。
- **寫入**：`陸吾任務：成功｜部分｜失敗`。
- **反諷**：若主角在推知前取得了陸吾的法則，推知後他會意識到，他從出手的人手上接過了東西。

### L-3｜查禁的異本
- **地點**：書院城區（U-010-P1-C2）。可旋轉的碑書與觀測台；地方矛盾：正統學派查禁異本（ATLAS）。
- **接**：EV-026「查禁的異本」（示範事件 30 則 v1.1）。
- **處境**：正統學派要燒掉一本《山海經》異本，理由是它把「帝之下都」一條寫錯了。
- **異本的寫法**（本作自創，非真實版本差異）：通行本寫「神陸吾司之」；異本寫的是「神陸吾**欲**之」。
- **主角可以做的**：借讀；替抄寫者說話；不管。
- **這一場的限制**：異本只是**起疑**的材料。一字之差可能是抄錯，也可能是有人刻意改的；它**不能**作為陸吾出手的證據，也不能代替主線階段八的推知。
- **與師父批註的關係**：隱修院古抄本「帝之下都」旁有一個墨點（N9 批註）。兩者都只讓玩家起疑。
- **寫入**：`異本_帝之下都：已讀｜已保存｜已燒`。

## 三、推知之後

**開啟條件**：主線 K6（主角以真實在歸墟碎片上看見遮天的空白與創世的接縫，推知陸吾出手、閻羅 X 遮掩）。

### L-4｜接縫
- **地點**：晝庭星光井城區（U-010-P1-C1）。同心階梯包圍的光井；地方矛盾：核心區長亮造成外環黑暗（ATLAS）。
- **處境**：光井的外環有幾處陸吾親手修補過的裂縫。
- **主角可以做的**：以真實比對這些接縫，與歸墟碎片上的接縫。
- **證據層級**
  - 相似的修補手法：**只能說「可能出自同一手法」**，不能單獨證明是同一次、同一人。
  - 配合歸墟碎片上遮天留下的空白（主線階段八）、師父的沉默、閻羅 X 的反應：才構成主角的推知。
  - 主角的推知是**他的判斷**；在其他道主面前，需要更多證據（見 L-5 揭發）。
- **寫入**：`接縫_比對：相似`。

### L-5｜對質（主線階段十）
- **地點**：曦冠京，創議聖庭。
- **開場**
  > 陸吾：「你來了。你看我的眼神，和上次不一樣。」
  > 主角：「歸墟碎掉的那一夜，是你。」
  > 陸吾：（沒有否認，也沒有承認）「你看見了什麼？」
  > 主角：「接縫。還有一塊太乾淨的空白。」
  > 陸吾：「……空白不是我的。」
  > 陸吾：「接縫是。」
- **陸吾的說法**（角色自辯）
  > 陸吾：「我守帝之下都，守了比你能想像的還久。祂在睡。可是睡著的東西，總有一天會醒。」
  > 陸吾：「九個人讓祂睡，以為這樣就夠了。不夠。只要祂還在，夢就可能醒。」
  > 陸吾：「只有換一個做夢的，夢才永遠不會醒。」
  > 主角：「所以你要殺祂。」
  > 陸吾：「我要守住這一切。你看見的每一個人，他們的街、他們的燈，都在這場夢裡。」
  > 主角（可選的反駁）：「那你問過他們要不要嗎？」
  > 陸吾：「你問過嗎？」
- **陸吾問師父**
  > 陸吾：「那一夜的人……他還在嗎？」
  - 陸吾**不確定**。主角的回答會影響世界：
    - 說他還在：陸吾與閻羅 X 從此確知；師父的處境更危險（世界事件）。
    - 說他不在，或不回答：陸吾仍不確定。
    - 主角若不知道師父是誰（K3 未取得）：此問題不出現。

- **主角的選擇**（與主線階段十一致）

| 選擇 | 需要 | 結果 |
|---|---|---|
| 揭發 | 向其他道主提出證據（接縫比對、碎片空白、閻羅 X 的供述若有） | 證據足夠時：其他道主要求陸吾說明；奎托斯可能擔任仲裁（K01）；涂山氏可能最早要求追究（T01）。陸吾的計畫**受阻**。證據不足時：其他道主只記下疑點 |
| 擊倒 | 戰鬥玩法未定 | 陸吾暫時離開聖庭（道主不會真正死）；計畫受阻；主角取得法則資格。聖庭的創議由司晝星主暫代（照護安排，提案） |
| 結盟 | 主角同意與陸吾、閻羅 X 共同承接夢 | 轉入弒神奪位・共治路線；親授資格成立 |
| 不處理 | — | 主角離開；陸吾的計畫繼續推進，世界惡化（第四節） |

- **拒絕／缺席**：主角從未對質：計畫繼續推進；世界惡化；最終抉擇仍由玩家觸發。
- **寫入**：`陸吾_對質：揭發成功｜揭發不足｜擊倒｜結盟｜未處理`、`陸吾_確知師父在世`（僅在主角說出時）。

## 四、世界的惡化（取代舊時限）

陸吾與閻羅 X 的計畫未被阻止時，世界依時間惡化【已定：世界持續惡化；結局由玩家觸發】。

| 惡化的樣子（提案） | 呈現 |
|---|---|
| 燭陰的眼皮顫動加劇 | 異象增加（EV-028） |
| 命線偶爾同時抖動 | 只有人類看得見 |
| 歸墟碎片不穩 | 破爛一條街等地出現新的裂縫 |
| 陸吾與閻羅 X 接近渾沌 | 主角若到過夢底，會在夢中察覺 |

**不會自動發生**：造物主被殺、遊戲結束。最終抉擇永遠由玩家觸發。陸吾與閻羅 X 的計畫進度，會影響抉擇時的處境（例如他們已在渾沌旁等著）。
