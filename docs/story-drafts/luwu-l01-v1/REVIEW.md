# L01 v1｜敘事依賴審閱

## 保留的內容

陸吾能接受居民圖紙，卻仍想替世界决定未來，形成有效的人物矛盾。先授法後推知能帶出感情代價。異本「司／欲」明標遊戲自創、不作出手證據，處理妥當。《一方小天地》沒有直接解決煉假成真，亦符合有限能力的定位。

## 修訂事項

| ID | 問題 | 修訂方向 |
| --- | --- | --- |
| L01-R01 | L-5 對質只要求 K6，和主線階段十接口不完整 | 主線 v2 目前列 K6＋K7；第四批又容許未持真實者由閻羅 X 供述補 K6。分開「可要求見面／足以起疑」與「完整推知／正式階段十完成」，對照既有接口消除循環。L-4 比對發生在 K6 後，只能補強或覆核，不能又宣稱它是取得 K6 的先決條件。若要提前私人對質，明標不自動完成階段十、不自動進終章。 |
| L01-R02 | 已推知便封掉全部地方篇，且自動假設有上次見面 | L-1～L-3 是地方事件，可依知情改台詞，不必全部只能 K6 前。若故意限時，寫清關閉條件及替代授法路徑。初次見陸吾的對質不能說「和上次不一樣」。K6 的標準路徑通常已依賴 K3／K5，未知師父分支要指明是哪條替代路徑才可達。 |
| L01-R03 | 否認空白、承認接縫與他人沉默被當成全案證據 | 陸吾承認的是哪處、何時、修補還是攻擊，須拆清。接縫承認不自動證明閻羅施遮天；沉默、反應也不是獨立證實。保留供述、親见痕跡、比對、推論四層，公開揭發另需來源與保存方式。真實法則不直接播放過去。 |
| L01-R04 | 主角說師父仍在即讓兩名道主確知；不回答卻恢復不知 | 分陸吾收到自述、相信／查證、消息是否送到閻羅及延遲。閻羅／蓋亞可能早有來源，不能被本場分支清零。陸吾本人若已從別處知道，改問句。曾到夢底不等於之後在夢中遠端監看敵人；刪自動感應或另列有限、可誤判的新提案。 |
| L01-R05 | 結盟替閻羅 X 決定，且看似直接鎖定結局 | 區分陸吾提出、主角同意、閻羅獨立同意、協議成立、終章最終執行。閻羅可能反悔、受傷、離場；共治穩定條件仍待設計，不能一選就自動成功。加入可撤回／改變立場及後果；結盟只開路線或親授資格，最終抉擇仍由玩家觸發。對質完成、階段十一命運取得與終章可用性要分開。 |
| L01-R06 | 無自動結局仍可能用惡化摧毀所有入口；計畫像永遠等玩家 | 設計可反覆變化的危機與延滯原因，不需新增宇宙倒數。政治、航路或地點可以受損，但主線必要證據與可達路徑有替代，不讓燈籍歸零或全部結局不可達。擊倒一方只能影響其參與的計畫部分，閻羅是否繼續另看狀態。正文「受阻」與第四節「未被阻止」需明確程度，不一律等於永久取消。 |
| L01-R07 | 永久持有被推成絕對無法歸還，領取資格又限推知前 | 不可重領與跨世保留不自动證明所有形式放棄都不可能。保留「不使用」選擇；物理／法則上不能歸還仍標新增提案。任務已完成卻得知真相，不应無說明抹除資格；可影響陸吾當時是否願意／能夠傳授。拒領後辨認需案件或見證，不只自報。擊倒建立資格、接受才取得；陸吾離聖庭或被逐出夢外需不同流程，不能把永久資格鎖在空殿裡。 |
| L01-R08 | L-1 重審被主角一句話自動觸發，L-2 驗收不夠明確 | 區分有效反證、重審與最終裁決，祖先誓約不自然授權統治後人。陸吾的裁決是角色制度，不是作者真理。L-2 的「沒算風」可改未納入當地風向／居民需求，避免創世專家忘了普遍有風。居民不必意見一致；觀命不能替代結構安全查核。許可與實際停止拆除／修建分開，部分成果及授法判準明示。 |
| L01-R09 | 事件時間與缺席總表重置、狀態不夠 | 為表決、重審、拆牆、焚書設定世界觸發與時間；晚到不必一律失敗。讀過、保存與焚毀能同時存在（原本燒了但留副本），不可只用互斥枚舉。缺席總表只作未介入預設，不覆蓋前世成果；从未造訪不等於陸吾無他人轉述。補知情來源、關係、協議、計畫、資格、領取與政務代理分欄。 |
| L01-R10 | 司晝星主代理容易被誤讀成接任道主 | 限定暫代行政與公共設施調度，不取得創世法則或道主身分；星主會隨世界歷史更替，記稱號與在任者。陸吾離場後的新造物與維護責任須交接，有資源缺口但不因授法抽掉全宇宙的維持能力。 |

## 情境覆核

1. 未持真實但已有可疑線索：能走第四批既有會面入口，不被「先 K6 才可取得 K6」鎖死。
2. 有 K6 無 K7：能否私人詢問與是否完成正式階段十分開，不直接跳到結局。
3. 首次見陸吾已推知：不使用「上次」台詞；地方事件依當時狀態存在。
4. 比對接縫後陸吾只承認修補：不自動證實攻擊、閻羅遮掩或全部動機。
5. 主角透露師父在世：只有在場者先得到自述，閻羅須收到消息；其先前已知不被覆蓋。
6. 閻羅拒絕／離場：主角不能僅與陸吾談完便建立三人共治。
7. 任務完成後才得知兇手、尚未領法則：資格保留，傳授可用性與主角拒領分開。
8. 擊倒後拒領且陸吾被逐出：資格仍在，不自動領取或永久丟失，接入後續聯絡流程。
9. 異本焚毀但已保存抄本：兩狀態並存，仍僅是起疑材料。
10. 多世缺席：世界歷史持續，保留必要線索與通路，不暗設自動終局或全路線鎖死。

以上是文本覆核，未作實機驗證；新補法維持提案。
