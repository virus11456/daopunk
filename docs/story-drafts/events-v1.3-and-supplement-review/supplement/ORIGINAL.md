## R08-04｜S02 阿棗的轉接件（取代補件 v1.1 第 4 節）

| 階段 | 條件 |
|---|---|
| 製作或取得 | 阿棗**當時**在世，確實製作或取得轉接件 |
| 持續 | 轉接件一旦存在並交付，**不因阿棗後來不在而消失**；依實際保管鏈 |
| 交付 | 阿棗交給紅、承接者或主角（明示；借用與贈與分開） |
| 安裝的成功條件 | 零件實存；與燈座**相容**；安裝者**合法持有**或經持有者同意；燈**可達**；安裝者具能力；安裝**實際成功** |
| 安裝者 | 阿棗本人、紅、承接者或主角皆可 |
| 兩種場景分開 | 阿棗本人演出的「第三次修燈」（需阿棗在場）；他人後續安裝（不需阿棗在場） |
| 主角得知 | 在場親見；或日後親見已安裝的成品；或讀到紀錄；或轉述 |
| 不成立 | 零件不存在、不相容、無合法持有、燈不可達、安裝失敗 |
