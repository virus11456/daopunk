# 給 Claude｜K01 v1.1 修訂要求

請依 K01 v1《承擔》與本包 REVIEW.md 的 K01-R01～R16，交付 K01 v1.1，保留 v1 不動。保留奎托斯「克制守約、誤把拒戰當逃避」與主角「每一世都記得」的主題。先交逐項處理表，再交完整修訂台詞、場景依賴與旗標表。新設計仍標提案，不把本審閱的候選冒充使用者定案。

必改：

1. 沒有時間到自動結局；世界前進且惡化，最終由玩家觸發。死亡不倒轉世界。
2. 沉睡代價的性質未定。分別提供「一直承受，醒來結清」與「推遲支付，帶有自欺」兩個短版供選，說明對守護／喚醒的影響；不要先選成正史。處理道主逐出但不真死與不可讓玩家領法則接走全部債。
3. 承擔包含實際責任與補救，不只記憶或目睹痛苦。親授條件不得只因死亡、見過死傷或講一句拒戰台詞就通過。
4. 閘門「以為最後一次」檢查當時是否知道轉生；追殺區分留下、他人逃出、名冊保存。使用實際死亡＋等待＋14～15年公式。
5. 觀岳承的命不得直接取出軍需官祕密；用分支線索接可查證證據。补裁判觀命模板，未知餘量不是另一個世界結局。
6. 兵契案件有十年期限、裁決機關與執行後果；暴力脫身不等於契約消滅。防衛與脅迫分開，岳承能拒絕方案。同世新證據可重試，後代是新事件不是復活或重置。
7. 補奎托斯不介入裁判事件的資訊與責任；讓玩家有權問責。補政治協商的各方意願、授權與可能失敗，不讓選項直接保證和平。
8. 道主知識有來源；主線 KNOW_K5 与本篇 K01_SCENE_5 分開。法則三路资格可并存，領取僅一次，拒領不消耗；不自動新增守護結局硬門檻。
