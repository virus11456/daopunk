# K01 v1｜一致性審閱

文件與敘事依賴審查，非實機测试。新提案保持提案；可保留角色的錯誤與偏見，但不能讓旁白或系統替其背書。

| ID | 問題 | 修訂要求 |
|---|---|---|
| K01-R01 | 開頭沿用時代延續到時限 | 刪除自動終局含義；世界可惡化、時代延續，最終抉擇由玩家觸發。道主不真正死亡不等於不受歷史影響，仍檢查受傷、逐出、離場等狀態。 |
| K01-R02 | 承擔代價的動機未自洽 | 目前是醒來才支付，卻因承擔承諾而阻止醒來；可故意寫成自我辯護，但需文本承認。提出互斥候選：沉睡期間一直承受負荷，醒來結清餘債；或代價全延後、守護其實兼具逃避。兩者未獲作者定案，不混合成正史。 |
| K01-R03 | 代價可能吞掉其他角色責任或強迫結局 | 說明來源、觸發、承受形式與逐出夢外後怎麼算；不得把所有受害者的損失都抵銷、令九位道主免責。道主不真正死，不能隨口新增永久死亡。玩家取得有限《返因》不自動接走此債，也不能把全宇宙代價反彈給造物主。 |
| K01-R04 | 輪迴被稱為重來，理解只落在記憶 | 「換個身體」是奎托斯的偏見；世界不重置，主角失去當世身體與關係、他人承擔後果仍存在。保留記得的主題，再加實際補救、守約與接受問責；能忘記的人也不因此免責，痛苦不是善行的證明。 |
| K01-R05 | K-4 台詞未檢查當時知情與真實事件 | 閘門句除開閘死亡外，還需當時不知會再生；已知轉生者改說明知會回來但他人未必等得到。追殺句分留下掩護、孩子真正逃出、燈籍有無送出，不把行為等同成功。再生時間按死亡＋等待＋14～15年，別將未定十年等待上限寫死。 |
| K01-R06 | 只要目睹受害或死過就符合親授 | 分開能說這句、道主相信這句、親授資格。目睹死傷不等於自願承擔；親授須具體保護行動、自己承擔的後果、後續處置與道主可核驗證據。第一次死亡不應自動送法則；拒戰一句話不能跳過。 |
| K01-R07 | 道主無來源得知主角身份和全部行為 | 補自述／哪位知情道主轉述／紀錄與可信度；不知道轉生者不能自動叫他跨世見證人。看見擂台不等於看見後台威脅與私下調查；見證旗標含來源、時間、觀察範圍。 |
| K01-R08 | 看岳承的命直接揭露軍需官欠債 | 觀岳承只見條件分支與對自身走向的影響；可起疑某種債務施壓，不直接斷言軍需官私密事實。欠債由帳冊、當事人或獨立查證支持。若另觀軍需官，另列對象、同意及命錨。觀命不能當契約已無效的證明。 |
| K01-R09 | 契約無效與暴力解約被視為自然成立 | 這是虛構制度：補誰裁定、何證據、執行與報復風險。暴力可能讓人脫身但債契未消；拆法律解約、事實自由、安全、被追索。未告知條款可爭議但非自動勝诉。岳承可拒絕主角方案，不以新兵契／第三人犧牲換表面成功。 |
| K01-R10 | 禁暴力把防衛、施暴與任務失敗混成一項 | 奎托斯可堅持狹隘標準，作者須標為他的判準而非唯一正義。區分主動威嚇、解救被攻擊者、迫使簽字等；任務未獲認可不抹掉救人結果，可提出反證／質問道主。 |
| K01-R11 | 岳承十年兵契卻等下一時代重接 | 記簽約、戰爭結束、屆滿、非法續役日期；等待後可能已解約或死亡。新時代事件是新當事人的新案件，絕不重置岳承。新證據本世即可重試，不強迫跳過數十年。自行到訪也可先救人，未接道主任務不應無效。 |
| K01-R12 | 奎托斯知道脅迫卻不干預容易變成拿人測試 | 需說清他當時看見什麼、為何不介入、制度限制或判斷失誤；若蓄意不救，允許主角追究。不能用「試煉」自動合理化受害者風險。裁判的意願、明日賽程與缺席後果要記錄。 |
| K01-R13 | 主角說協商就改全域戰局 | 補各方授權、拒絕、代表與執行鏈；勝利不等於大家服從。協商不保證和平，決鬥不保證一定失敗；記衝突狀態、方案、參與方、實際執行與世界後果。軍令权与付款争议不可無故被一局決鬥全部解決。 |
| K01-R14 | 法則三路互斥、傳授與逐出缺規則 | 三路資格可並存，接受時只領一次。拒領不消耗，補再訪與道主缺席的承接方式；擊倒、逐出、授法先後另列。既得者再做事件仍有地方後果，不重領。能力取得一次不等於全生涯只能使用一次。 |
| K01-R15 | 終章知悉代價就自动允許喚醒、因果變硬門檻 | 知道秘密、信任、守護立場、願意不阻止分開；一次談話不能無條件翻轉政治決定。仲裁須道主在場與證據可用，因果不充當全知測謊。守護是否必要持因果未定，不自行新增必要法則門檻。 |
| K01-R16 | 旗標太粗，命名撞主線 K1～K7 | 使用篇章前綴 K01_*，區分主線 KNOW_K5 與 K01_SCENE_5。關係、知識來源、案件狀態、取得資格、領取狀態分開。觀命補條件、期間、互斥結果與未知餘量；不在此鎖數值。 |
