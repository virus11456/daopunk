# 遊戲量規劃v2｜整合摘要與檢查

來源：使用者本任務貼上《遊戲量規劃v2（肉鴿）》。此為摘要非逐字稿，數量、時數、時代日期全部為提案，不是已完成或已驗證玩法。

## 來稿規模目標

- 每輪3～6小時，約20輪通關；12個主線階段，平均約1.5輪推進一階段。
- 100小時分配：主線25、人物／道主支線25、隨機探索30、時代重訪10、系統內容10。
- 人物支線10～12條、道主篇10篇、世界事件15～20、中立組織5類各3～4段、隨機事件約300、燈籍家庭8～12戶。
- 圖鑑總量約150～200，經載120～150、經外約50；加總实际是170～200，150下限需調整或改分項。
- 30重要地點各五種時代狀態共150個地點狀態；不是150座新增城市，也不代表全部城市圖已完成。
- 快速主線10～12輪、50～60小時；慢玩20輪以上。皆未經測試，不能當保證。

## 五時代候選

| 時代 | 時間提案 | 特徵 |
|---|---|---|
| 燈下 | T+0～15 | 熟悉人物尚在，紅的攤位 |
| 崩塌之後 | T+15～40 | 坑壁事故與重建，排水處改組 |
| 老去 | T+40～70 | 世代交接，拾六接燈 |
| 蒐集 | T+70～100 | 人類被追索，身份盤查 |
| 夢動 | T+100起 | 異常裂縫與反派接近渾沌 |

『第一時代等於第一輪』不成立：第一輪可能活過T+15，後續輪也按世界日期而非輪次判時代。閘門若被避免或減災，第二時代不能一律呈現全城崩塌；保留重建／補強／事故等分支。人物『年輕』也须與各自年齡相符。

## 必須修正的規劃邊界

1. 時限已答：世界持續惡化、終局玩家觸發；不因晚幾輪自動結束存檔。來稿末段未答說法已過時。
2. 每次死亡後至少十五年仍未定：等待出生＋十四至十五年成長。十九次至少十四年成長約266年，還沒加玩家在世與待生時間，故T+100後須支撐很長的遊戲歷史。
3. 20輪×3～6小時為60～120小時，100小時需平均5小時；不是劇本字數保證。12階段×1.5輪約18輪，只是均值，不能實作成每死幾次發下一章。
4. 系統時間與探索／戰鬥可能重疊；後續遊玩記錄用互斥活動分類，避免將同一小時計入兩欄。
5. 8～12燈籍家庭應區分家系與當代家戶，不能數百年後仍同一對父母。家庭選取、出生空窗及保證人類不歸零的世界機制仍待設計。
6. 錯過年輕角色可有歷史與承接內容，但不能用相同模板對話冒稱新支線；重要人物及法則的晚期入口要有來源。
7. 300事件是候選創作量，不是已存在內容；先驗證少量有差異的事件，不用換地名或換NPC就計為全新劇情。

## 隨機事件規格起稿（提案）

每個事件至少有event_id、題材家族、地點標籤、時代／歷史條件、參與者資格、可見線索、互斥條件、世界效果、消息、物件交接、缺席結果、再發條件、上次發生時間與永久解決狀態。

抽選順序：先判世界資格 → 排除已永久解決／互斥／冷卻中 → 按地區事件池選取 → 保存實際結果 → 生成能傳播的消息。不把作者秘密直接交給NPC。

三種重複性分開：一次性歷史事件不重置；周期生活事件可再發但需要時間和資源條件；後果型事件由先前結果觸發，不假裝彼此獨立。已發生結果不因開關地圖或讀檔重抽。

先寫12個原型：商隊通行、維修、風土調查、古籍異本各3例；每例含拒絕、缺席與再次遇見的差別。這12例目前是待寫清單，不是完成數。正式戰鬥未定，先不绑定卡牌／傷害／金錢獎勵。

第五時代建議使用多組可持續變化：地區修復／失修、組織交替、航路開閉、居民世代、異象節律。它們需具體因果，避免全宇宙永久線性惡化到實際無路可走；規則尚待作者與玩法設計。
