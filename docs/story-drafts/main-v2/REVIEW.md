# 主線v2銜接檢查

| ID | 問題 | 修訂要求 |
|---|---|---|
| V2-01 | 十四至十五歲遊玩與每死至少十五年衝突 | 用等待新生兒＋覺醒年齡；不要自行把所有後續輪鎖15歲 |
| V2-02 | 原T+0是18歲下山，現在第一輪15歲 | 定義T起點後重算閘門年齡、紅下山22年、所有生卒及旅行年表；不要只全表減3 |
| V2-03 | 人類保證不歸零，但可無限惡化 | 區分人口非零的作者約束與玩家可知機制；不自動解釋人類衰亡原因或承諾固定出生頻率 |
| V2-04 | 師父隨時鐘虛弱，所有真相與命運仍依賴他 | 設定可持續的會面／傳承條件，不让他在期限病死造成隱藏自動結局；不擅自定不死能力 |
| V2-05 | 道主不受人類壽命限制被當作任何一輪必可遇見 | 道主生死、醒後規則仍未定；壽命不同不等於永遠同地等待，需可追蹤會面線索 |
| V2-06 | K1、K2、K5各包含多個不同來源的事實 | 拆成具體知識原子，死亡不能自動得知師父知道，看到缺印不能自動證明存活 |
| V2-07 | 持真實就輸出K6／入邊緣就輸出K7 | 加實際調查、證據強度、現場或紀錄取得；完整記憶不是全知 |
| V2-08 | 法則任何顺序取得與K5統一門檻、命運綁第10階段衝突 | 分開一般能力可取得與主線推薦順序；命運是否唯一特例仍是提案。每種一次且跨世保留不變 |
| V2-09 | 閘門缺席按觀命分布發生 | 世界先有可重現的事件結果，觀命讀取條件機率；玩家沒觀測也有世界。不要每次讀檔重抽已發生結果 |
| V2-10 | 延壽仙術令玩家在崩塌中生還 | 壽命、生命值與抗傷是不同效果；只延長自然壽命不能默認防止砸傷／溺水 |
| V2-11 | 錢、物、關係列不保留 | 不直接帶在新身體上不等於世界中消失；別清空NPC記憶、遺產與關係歷史 |
| V2-12 | 線索只換給另一名NPC | 需繼任／檔案與可證實保管鏈；檔案毀損時也需可達替代證據，不能每人都永生 |
| V2-13 | 最終抉擇主動觸發與弒神者持續推進 | 可改變地區、代價和政治，但不在背景偷偷殺造物主、剝奪所有終局選項；具體停滯／受阻原因待寫 |
| V2-14 | 守護結局仍寫人類衰亡放慢 | 必須符合人類不歸零；不能再補燈終全熄或永久無處轉生代價 |
| V2-15 | S01／D01／S02等原文固定年齡、死亡、世次 | 保留原稿追溯，另交條件版腳本；圖鑑第三世親見及批註也改成實際觸發，不能自動補知識 |

本批僅更新設計與權威範圍，不宣稱上述十五項已在劇本或引擎修好。NPC生活參考模型仍只測抽象tick，不能當十五年離線補算驗收。
