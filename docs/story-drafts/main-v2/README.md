# 主線v2《燈還掛著》｜肉鴿階段結構

來源：使用者貼上《主線v2（肉鴿結構）》並於同輪答覆三項決策。本檔為整合摘要，不是來稿逐字檔；全文保留在對話。較早原稿保留，不宣稱已收到完整主線v1母稿。

## 最新已定

- 遊戲是肉鴿，輪迴次數由玩家決定；主線以條件階段推進，不綁定三世。
- 人類不會歸零，燈籍不會全熄。撤回『守護夢境最終無處轉生』的終極時限，不取消個人死亡、地方衰敗或歷史損失。
- 第一輪十五歲讀命覺醒後下山；開場仍是第一世第一次下山。後續每輪於十四至十五歲覺醒時開始遊玩，嬰兒期以記憶片段帶過。
- 後續轉生為燈籍人家新生兒，保留完整親歷記憶；等待出生多久仍為提案。
- 閘門、追殺改為可生還的重大世界事件，不能固定主角死亡或強制世次。
- 世界持續前進、惡化；最終抉擇由玩家觸發，不因晚幾輪自動結束整個存檔。
- 正式輪迴不倒轉世界時間，不能回到已發生事件之前。讀檔、當輪死亡重試另設。
- 跨輪保留親歷記憶、未花功德、已學仙術、已得法則、已讀／親見圖鑑；醫術延壽下一世清除。

恢復的是本次肉鴿定位與條件推進，並非退役的卡數、職業、舊獎勵池、戰鬥或購屋規格。

## 本輪生活與世界事件（提案）

- 等待下一個燈籍新生兒的時間＋成長十四至十五年，世界繼續運轉。不能直接斷言最少十五年；等待下限未定，起算點需與99年基礎壽命分開。
- 閘門：來稿約T+15年，西段坑壁滲水；在場者可開閘、委託、避讓或不介入。缺席按世界事件結果留下新聞。延壽不自動等於抗傷，具體生還條件另設。
- 追殺：時間未定，人類遭蒐集；可躲、逃、戰或保護燈籍，結果不預先固定死亡。
- 其他候選世界時點：大師兄訪紅T+20、零號逝世T+50、紅逝世T+55、星塵／大師兄逝世T+60。日期全為提案，T起點及各人年齡要重算。
- 紅的線索由拾六承接、大師兄由雪鈴承接、葉遲由傳承苑檔案承接、伍櫃守由繼任者承接。承接者也可能消失；需長期機構／備份來源，不可只把硬鎖延後一代。
- 來稿100小時、5～8輪僅為估算，未經玩法測試，不是開發完成度或保證時數。

## 輪迴不等於世界清空

新身體、所在位置、當世一般修為等依新輪建立（具體保留範圍仍提案）。未攜帶的錢與一般物品仍可留在世界，繼承、保管、損失另設，不憑空刪除。

主角記得關係，但對方現況按時間推進；留世者不因玩家轉生就被洗記憶，相認／信任／合作分開。不是所有人際關係歸零。
