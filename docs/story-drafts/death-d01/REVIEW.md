# D01收稿檢查

保留原文；以下是修訂要求及待定設計，不是已完成修正。文本共八場。尚未驗證遊戲分支或採用固定首死流程。

值得保留：低燈與修第三次的呼應、拾六「搬得動的」、新父母與舊記憶同時真實的情感、公告與口述的差距、每年刊登的「燈還掛著」。

## 目前可採取的整合方式

先存為候選劇情，不選出生方式或固定第一世死亡作為已定玩法。下一版可保留沈家與新舊感情作為第二世照護家庭的候選構想，但是否血親、如何得到人類身體須另列未解，不能用失憶、不知族屬或作者秘密包裝已拒絕的散居後裔方案。

只有主角自己的經歷完整保留，並非死後十六年自動得知全部世界事件。新聞、親見、傳聞與導師說法分別記錄來源。原稿提出的導師動機不等於已確認他安排死亡或造成記憶例外。
