# 給 Claude｜P01 v1.1《未分類》修訂
以使用者 P01 v1 原稿另存 v1.1，保留原稿。依本包 REVIEW.md 逐項回覆 P01-R01～R16。保留登錄保護與排除的核心，不把新增制度升格正史，不決定戰鬥數值。

先修三個核心矛盾：
1. 建立「人類」類別不等於登錄全體人類。主角可支持開放申請、登錄自己、受託代理；不能代表所有燈籍人。若寫越權揭露，限實際所知、明示未經同意及其後果。
2. 未找到命錨也能走完保護叁與親授路徑，否則本篇重新獎勵命錨門檻。首次站立只是叁的候選命錨。
3. 「未分類」基本保護不能以必須有別人作證作唯一門檻。申訴、代理、查核與停止不可逆處置要可讓孤立者使用。

其他必修：
- 刪倒數與自動未介入結局；道主依歷史可離場。
- P-1 觀命分支與缺席結果使用相同條件。未知餘量不是抽取的結局；送解體與執行分開。
- 核對 M01 封存期限、衛序府聲請程序、同意摘要用途；不是一封通知就自動開封。找不到 M01 v1.2／EV-014 標依賴未解析。
- 通知按實際見證、新聞、持有摘要分支；繼任者不自动識別主角。P-4 可拒絕自揭人類身分。
- 證據按可驗證論點與獨立來源，不硬湊三件。住客資料另經同意，九子交接只是制度紀錄，不判靈魂。
- 叁已死不因改革復活；成功、部分、失敗分別更新各政策及實施日期，有新證據可本世重試。
- 最小資料仍要列內容、權限、去向；洩漏須走實際資料鏈，不自動拿到全體燈籍。
- 三路资格可以並存，法則接受一次、拒領後可再來；擊倒／逐出／傳承分開。
- 「一次瀕危」先說明能力作用情境，不把使用次數當已定。救援不凍結靈魂承載時計；不延壽只限此仙術提案，不撤回已定的永久延壽仙術。
- 終章立場、關係、證據與到場條件分開；生命法則不是默認全結局門票。
