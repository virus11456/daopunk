# P01 v1 審閱
文件一致性審查，非實機或法律驗證。新增方案仍為提案。

| ID | 缺口 | 修訂要求 |
|---|---|---|
| P01-R01 | 時代延續到時限、未介入結局、道主不受時代影響 | 刪自動終局，維持玩家觸發。道主仍可能受傷、逐出、離場；關係冷淡不等於政治不介入。 |
| P01-R02 | 新增人類類別自動登錄所有燈籍人 | 分開制度開放、本人申請、受託代理與名冊交付。主角無全體授權與即時名冊；每人另決定。可保留越權揭露的負面劇情，但只能洩露他實際知道的資料，明示未經同意，不能寫成正常替全體登錄。 |
| P01-R03 | 生命保護反命錨，親授卻要求找到叁的錨 | 增加完全未找到錨但仍保護叁的有效路徑。首次站立僅此角色候選，非普遍機器生日；觀測清楚不必對所有未知未來全知。 |
| P01-R04 | 解體與收留不互斥、不窮盡；缺席必解體卻觀命45% | 定義期間、條件與事件順序，收留後仍可能解體。未知餘量是觀測不足，不是實際結局。缺席結果依同一條件與世界演變結算；若制度送解體是必然，可拆送達與真正執行，不能概率與保證混寫。 |
| P01-R05 | P-2 封存必遭強制開封，省掉權限流程與期限 | M01 v1.1 為可經衛序府聲請，不是必然成功；十年或聽證結束先到為期限。補是否聲請、何院審查、授權用途與到期保管，不把資料自動公開。分類聽證與開封程序分開，新聞旁聽不等於可看私密資料。 |
| P01-R06 | 未見證者收到見證通知、NPC自動知道論點 | 按實際見證／持有經同意摘要／只讀新聞分通知。繼任者需接手紀錄且有聯絡途徑，不自動認得主角轉生。P-4 先確認當世是否已登錄、是否願自揭族屬，不能強制說「是人類」。 |
| P01-R07 | 沒有正確錨被推為唯一失敗原因 | 改為未成功觀測不能推出沒有命；資訊不足、對象／條件錯誤亦可限制觀測。玉皇可說測試混入觀測者與資料條件，不說它完全不涉及對象。 |
| P01-R08 | 人類會觀命被等同自動掌握行政判生死權 | 是制度採用後形成的權力集中與可近性風險，不是自然必然；補誰測、誰解讀、誰裁決、能否反證。玉皇應回應制度盲點，不必直到這句才知道人類稀少。 |
| P01-R09 | 「有人見證生活」再次排除孤立無證人者 | 基本保護不依一名外部見證人才成立；見證是可用證據之一。先暫停不可逆處置，再提供當事人表達、代理與多源查核，避免用全新門檻取代舊門檻。 |
| P01-R10 | 至少三項證據綁已死人物與私密紀錄 | 改看證據所支持的論點與獨立性，不只數量。安居院需用途同意與遮蔽；九子資料交接須實際查得且允許引用，只證明紀錄制度差異，不證明有無靈魂。無前篇時提供替代調查。 |
| P01-R11 | 叁死亡後制度成立又出現在工坊 | 生存、拘留、解體、救出分别記；改革不追溯復活。若已死亡用檔案與後來住民承接，不能重置叁；避難工坊亦需真的接納。 |
| P01-R12 | 各方案組合都自動撤測試；拒原提案是否封死改革 | 分開未分類、申訴、資料政策、測試立法四個狀態與實施日期。本人登錄後仍可倡議改革，拒絕後可再提；有新證據本世即可重試，不強制等時代。跨轄區不自动全宇宙生效。 |
| P01-R13 | 資料最小化被等同完全不存資料、登錄必洩漏 | 明列必要資料、地方／中央可見範圍、保存與申訴需要。風險須有收集→存取→外流→追查鏈與時間；不能知道整份燈籍，不把保護政策保證不會外流。 |
| P01-R14 | 法則三路互斥、拒領與逐出後授法缺規則 | 三路資格可並存，實際接受一次；拒領不消耗，補再訪。分清擊倒、逐出、傳承先後；既得者再做任務只更新事件，不重領法則。 |
| P01-R15 | 「一次瀕危」可能被誤解為累世僅一用；救援可延長承載 | 區分能力領取次數與使用限制，後者尚未定。救急不凍結99年及已得延壽後的承載上限；不以反覆吊命無限延壽。此仙術不延壽是本篇提案，不撤回其他永久延壽仙術。 |
| P01-R16 | 道主出場、終章與法則結局旗標過度自動 | 大師兄、雪鈴不互為無條件替身，需在世、知情、自願、可達。合作關係與陸吾證據評估分開；法則生命不自動成四結局共同必需，列其確切用途或保持待定。 |
