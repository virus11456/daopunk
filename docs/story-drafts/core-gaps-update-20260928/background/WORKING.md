## 五、正文

### 序　夢與燈

【已定】很久以前，造物主睡著了。

讓祂睡著的，是九位從夢外來的生命。他們說：祂繼續睡，宇宙才會存在；祂醒來，一切都會毀滅。第十位反對，沒有攔住。

祂的夢裡曾經有很多宇宙。如今還被辨認得出、被十位道主各自據守的，是十個。其餘的去了哪裡，沒有人說得清。

十位道主各掌一種法則，彼此認識，知道世界是夢，因為夢是他們造成的。知道，不等於能做什麼。

宇宙之間有空隙，空隙裡有邊緣世界。邊緣世界的最底層連著夢境的底層，那裡游著一頭有翅膀的巨鯨，叫鯤鵬，是三大創世生命之一。

十個宇宙的第一個叫歸墟。它對應我們所在的宇宙，與地球有直接的關聯。它已經碎了很久。

世人普遍相信，歸墟的道主，第一道主，死在歸墟碎掉的那一夜。

### 先人與《山海經》

【已定】很久以前，夢裡的人類很多，散居在許多宇宙。只有人類看得見命線，看得見命運的分支。先人順著這些線，在宇宙之間、在空隙裡找路，把看見的山、水、生物、國度記下來，寫成一部書。

書分兩部：山經記宇宙之內可以落腳的地方，海經記宇宙之間的空隙與遠方。

後來人類少了。為什麼，沒有人知道。

書留了下來。世間流傳著許多互相矛盾的殘本，被當成古老的神話。

### 師門與燈籍

世上只剩一群人類，都是一個算命門派的後裔。【已定】只有人類能學算命。

【提案】門派的院子叫方舟隱修院。院中有一本《燈籍》，記著每一位下山的弟子與他們的子女；每一位在世的人類，燈籍閣裡就亮一盞燈。下山後不再修行的人家也在燈籍上。燈很少，有時熄了一盞，過幾年又亮一盞。【已定 N12】人類不會歸零，燈不會全熄。

弟子啟蒙時背的第一本書，就是《山海經》的古抄本。【已定 N8】弟子們把它當成祖先留下的故事，只有師父知道它是真的。抄本的頁邊有一些很淡的字，弟子們以為是哪一代師兄的塗鴉；那是師父寫的。

### 師父

師父在隱修院掃葉子、教書、下棋。他看起來是一個普通的老人。

【已定】他就是歸墟之主，第一道主。

【已定】約三百年前，陸吾與閻羅 X 密謀暗殺造物主並取而代之。師父知道道主們讓造物主沉睡的秘密，也反對他們的計畫。一個夜裡，他和閻羅 X 的一盤棋下到一半，閻羅 X 走了。那天夜裡，陸吾出手，閻羅 X 以遮天抹去痕跡。師父為了自保，把歸墟打碎，讓自己的命途散進千萬塊碎片裡。

【已定】沒有人能追到他。世人以為他死了。他知道是誰出手，但不說。

【已定 N16】道主在夢裡不會真正死，只會被逐出夢外。陸吾那一夜出手，是要把師父逐出夢外，讓他再也不能阻止他們。世人不知道道主不會死，所以相信第一道主死了。

**命途碎片能做到與不能做到的**【提案，C05】
- 能：讓以命運、因果、輪迴、紀錄追索他的手段，都拼不出一個完整的他；讓出手者也無法確認他生死。
- 不能：擋住認臉、聽聲、辨棋路。所以師父從不見任何道主，極少離開隱修院太遠。
- 不能：讓他自由動用法則。動用法則可能使碎片聚攏，依實際施作而定；不由每次使用自動寫暴露或逐出。
- 【提案】**看**與**動**不同：觀測過去、現在、未來（看）不聚攏碎片；改命、剪命、傳法（動）才會。他是否知悉某次危險須有來源與觀測條件；即使知情，也不保證可到場或無代價介入。

### 師父的一刀【已定＋提案，C03】

【已定】主角出生那天，師父剪了他的命途：主角死時不經交接，不會被洗去記憶。師父的目的，是要一個不遺忘的人，替他喚醒造物主（N2）。

【提案】這是三百年來師父唯一一次動用法則。範圍只有一個新生兒的一條命線，時間只有一瞬，碎片向他聚攏，又散開。那一瞬在夢裡留下一次命運的波動：
- 有能力感知命運變動的存在，可能察覺「某處有命運被改過」，但無法定位。
- 那一刀留下的具體痕跡，是主角此後每一次死亡都沒有交接印。

終章授予主角有限法則能力，不抽走師父全部權能。【提案】持續施術可能令碎片聚攏並暴露；是否被找到、追捕者能否到達及實際逐出分別結算。拒領不啟動這次傳授，也不保證其他事件永遠不能使他暴露。

### 轉生【已定＋提案，C07】

【已定】主角死後，生在燈籍人家的新生兒；十四到十五歲讀命覺醒時開始遊玩。

【提案】
- **等待**：主角死後，要等待可作落點的燈籍新生兒；半選擇依 N39 僅在玩家介面，亲屬排除依 N55／N56 已定。不能憑空生成新家庭。等待期間他沒有經驗，不會記得「等待」。等待多久，取決於燈籍人家何時生子，世界時間照常前進。
- **一身一魂**：他不是進入一個已有靈魂的嬰兒。師父的剪刀讓他的靈魂不經交接、由命運送到符合落點規則的燈籍新生兒，成為那個孩子本身的靈魂。沒有另一個靈魂被取代。

### 階段二　回來

**獲得知識**：覺醒後 K1a 自知帶記憶轉生；師父知情及主角得知師父知情另核來源與日期，不自動寫會面。
