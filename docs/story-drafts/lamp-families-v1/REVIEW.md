# 燈籍家庭v1檢查

家庭全部為提案；四個作者選擇尚待回覆。地點核對使用world-catalog.json與ATLAS，轉生接口對照背景v1.4的Q11修訂版及最新時代規格。

| ID | 問題 | 修訂要求 |
|---|---|---|
| LF01 | 每輪家庭開場可能改寫第一世隱修院下山 | 第一世固定十五歲隱修院覺醒／首次下山；十戶主要用於後續轉生。若第一世出生家庭要演出，另作童年背景，不覆寫開場 |
| LF02 | 第一個新生兒是新增選擇，不能因背景寫「下一個」就當已確認排序演算法 | 等作者決定。分開受孕、待產、實際出生；同時待產不等於同時出生，真正同時才需平手規則 |
| LF03 | 人類不歸零不等於一定會再有孩子 | 需保證轉生來源可持續的故事規則；不能靠强迫NPC生育或暗中新增人類解決。數十人提案須補親族與出生時間可行性，不把結婚自動當懷孕 |
| LF04 | 每人一燈與每戶熄燈混寫 | 人物生存燈、戶籍關係、燈籍紙本、聯絡與地址分開。結婚增加戶數不增加人數，搬遷不熄燈；紙本失落不能直接殺人 |
| LF05 | 第一新生兒規則與「保住名冊可生任何戶」相衝 | 聯絡網影響消息和協助，不自動等於命運可選目的地；名冊遺失後仍在世人類是否符合落點須與轉生規則一致 |
| LF06 | 14～15年童年被略過，家人卻像停在出生時 | 家庭成員可老死、遷徙、失散、被救援；覺醒時讀取當時狀態，不保證父母手足仍在。童年危機與提前死亡如何處理需另列提案，不能給主角隱形無敵 |
| LF07 | 葛家「嫁給鎮上藥農」未交代配偶族屬與孩子來源 | 藥農可以是已有燈籍人物但需有來源；若非人類則不能默認能生人類孩子，跨族生育規則尚未定。不得把普通鎮民批量升為人類 |
| LF08 | 溫家形成於四師姐創苑前後，卻在起始年代已有後代家庭 | 需列同門到達、家庭成立、生育與開局可用日期。四師姐前世年表及創苑細節仍依現有稿件提案；不能硬塞三代於十餘年 |
| LF09 | 林家失去身分認知可能重引散居隱性後裔 | 只有作者批准後才能用；必須可追溯至師門已有燈籍，不新增獨立人類來源，名冊上的知情與家庭自己的知情分開 |
| LF10 | 夏家天生能導航易變成看命線即全能 | 區分可學讀命、覺醒、受訓、命線導航知識與船舶操作；不能讓每個人類嬰兒或未修行家人自動能領航 |
| LF11 | 魏／葛／卜家把舊問題每世原樣重播 | 永久解決後不能重演同一登記令、休耕或糧箱危機。須有新因果的新實例，或呈現承接歷史的另一種問題；NPC與組織依存活和現況接線 |
| LF12 | 白家只到星球，程家無地址，不是完整十個開局地点 | 白家可提舊魂聚落U-008-P2-C2的封存室，但未定案；程家須從既有地點中按現實家庭遷移選，不因每輪換起點就瞬移家庭 |
| LF13 | 白家「最安全」與閻羅X連結含不必要的保證與洩密 | 安全只是相對條件提案；封鎖補給亦有風險。知道無名工匠不等於知道道主真身，名單上的作者關係不直送NPC對話 |
| LF14 | 錨家靠近時限，夢動燈數必最少，仍沿用已撤終局倒數 | 改依深層異象實際事件；夢動不自動終局、不保證人口單向減少。每戶不必親历全部時代 |
| LF15 | EV-008未完整ID，溫家与溫醫師、葛家与葛伯容易誤連 | 任務參照使用完整且存在的ID，未交付先標未解析；同姓不證血緣。沈家祖父「第三代弟子」與三代家族亦需分清 |
| LF16 | 覺醒即知道外界誰死或全球燈數 | 可知童年親歷；其他需家人口述、可驗紀錄或與師門通信。即使有聯絡，情報亦有日期與遲延；不自動獲得全域人口監控 |

8個明列城市ID與名稱均匹配現有名錄；白家靜白星匹配但缺城市；程家尚無固定地點。檢查不是宣布十戶正史、十套開局已可玩或已定人類繁衍機制。
