# 家庭開局銜接工作稿

本稿只修正已知接口；不代答四項作者選擇。所有家庭成員、人口數、起點機率、費用與技能尚未定案。

## 適用範圍

第一世：主角十五歲在方舟隱修院覺醒後首次下山。不能隨機抽家庭取代S01。後續轉生：由已定的一身一魂規則成為燈籍新生兒，童年片段之後在14～15歲開始遊玩。落點選取規則待確認；等待時間W不得擅自定成一年。

## 五層資料與敘事

1. **人物**：穩定身份、出生／死亡、族屬、親屬關係、當前所在、修行與知情範圍。非人類伴侶可存在不代表生育規則已定。
2. **家庭**：成員的組合、姓氏及別名、住址沿革、營生、與師門的聯絡。家庭不等於固定三口之家，也不等於每位都會讀命。
3. **燈**：個體是否仍在世的設定，與紙本記錄及現實可看見的燈具分開。家戶滅絕只是該戶沒有在世成員的結果；改姓、立新戶不能讓靈魂或人數複製。
4. **名冊與消息**：誰持有哪一版、最後更新日期、可聯絡哪戶、誰知道真名。燈亮不表示師門自動知道地址或近日遭遇。
5. **主角知識**：童年親歷與後續收到的消息。可完整記得過去，不可記得等待期無經驗的事件。
