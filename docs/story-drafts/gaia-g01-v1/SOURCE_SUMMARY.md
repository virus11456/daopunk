# G01 v1 來源摘要（非逐字原稿）
使用者提交《記得太多的人》，六場含一個既有主線接點，補研究所、樣本爭議、自主記憶、議場與傳法。
蓋亞：神經網 U-003，織憶星首都織心京 U-003-P1-C3；輪迴法則，《宿世印》名稱及細節提案。溫和好奇，將私人記憶當公共知識；懷疑導師生存，原稿理由為三百多年未接到其靈魂。不知道主角保留記憶的原因與誰攻擊師父。

|---|---|---|

宿世印：有限對象、須同意，讓跨世連結較容易想起，不直接恢復記憶；非人類須能輪迴，原稿不定。原稿說輪迴加命運可決定死後是否交接。
再訪：研究員換代、瀾後人或居民接替；道主原稿寫不受時代影響；夢動稱最終時代；缺席兩時代後家屬揭露。
終章：傾向喚醒且知師父在世可能出現並與葉遲同行；動搖或冷淡不介入。
新增提案：岑絲、瀾及哥哥、越權研究、宿世印具體邊界、議場自白。開頭仍引用「時代延續到時限」。
