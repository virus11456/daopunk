# G01 v1 審閱與修訂要求
核對：Y01 v1.1 ORIGINAL 的封存矩陣與研究選項、道主總綱審閱、使用者已確認的玩家觸發結局。不是實機測試。

| ID | 缺口 | 修訂方式 |
|---|---|---|
| G01-R01 | 開頭「時代延續到時限」、最終夢動仍是撤回設定 | 刪除終局倒數；梦動是可持續的世界狀態，最終抉擇由玩家觸發。 |
| G01-R02 | G-1 把暫不決定當聯絡許可 | Y01 明定暫不決定與拒絕均不得聯絡。僅同意受訪可一次聯絡；自行到訪不是同意錄音、分享或研究，每項再詢問。 |
| G01-R03 | 部分封＝沒有資料，與 Y01 摘要存取矛盾 | 分開全封僅知存在、部分封可看摘要、不封可看遮蔽副本；看紀錄、訓練模型、受訪與轉交蓋亞四種權限分開。部分封也可能出現摘要越權，不得憑封存程度推定合法訓練。 |
| G01-R04 | 借閱紀錄直接證明模型訓練，舉報必一月解決 | 借閱只是存取證據。補資料血緣／用途紀錄或可核验轉述；調查、暫停、查證、公告、補救各自有條件與日期。家屬未同意不等於死者生前未同意，須查實際授權；不預設家屬能推翻當事人意願。 |
| G01-R05 | 岑絲交給蓋亞答案不需另外授權；知道在研究＝知道越權 | 回答量不等於可分享内容。若未同意只轉達訪談已結束；蓋亞需收到調查結果才知道具體越權，制度責任可以先承認，事實不可憑空知道。 |
| G01-R06 | 未接道主靈魂推存活；玩家口述即知道 | 道主逐出夢外本來不走普通輪迴，缺紀錄只能保留疑問。新增存活跡象須標提案並附來源；玩家口述先記轉述，驗證後另旗標。三百多年改世界日期差，勿幾百年後仍固定說。 |
| G01-R07 | G-4 說尊重意願，卻只獎勵封存且強求哥哥滿意 | 成功看是否尊重瀾充分知情、無脅迫的當下選擇；她可維持封存，也可自主改變。單純提供資訊不自動失敗，逼迫或替她開啟才違反。哥哥不滿不使保護自主的行為失敗；冤案調查另列結果。 |
| G01-R08 | 命錨自報即真；觀命兩分支不窮盡 | 瀾同意不等於命錨已驗證。和解／破裂須有互斥判準與期限，補暫時疏遠等已見其他走向；看不清是觀测不足而非一种世界结果。數字只作示例，條件變動後重估，不拿來保證好結局。 |
| G01-R09 | G-3 會面與記憶交易、G-5 信任、G-6 傳授交纏 | K4 的必要來源不能靠同意交記憶才能開啟。G-6 在議場外可獨立赴約，不繼承 G-5 私談信任門檻；擊倒途徑亦不隱含先取得信任。 |
| G01-R10 | 三途徑互斥與拒收、冷淡後資格丟失 | 三途徑可各自完成資格，實際接受只一次。拒收不消耗領取次數；已取得重訪不重授。冷淡是否撤回尚未兌現的邀請須明示，不應把已完成擊倒／任務資格無預警抹掉。 |
| G01-R11 | 擊倒後必能傳授，未區分逐出；道主不受時代影響 | 不真正死亡不等於永遠在場。分挑戰勝利、受傷、逐出、再接觸；先確定授法時点，逐出後不可立即無解釋交談。世界事件仍能改變她的立場與所在。 |
| G01-R12 | G-4 失敗等下一時代換人重做；後人未必存在 | 本世可補救，尊重當事人拒絕；原案保存結果。新居民是新事件實例，不繼承瀾的晶片／冤案／同意；後人須有已建立人物關係。 |
| G01-R13 | 冷淡與政治立場混用，一句話決定終章 | 關係、政治傾向、證據、到場能力分開。不同意主角仍可能反對弒神；親近不等於支持喚醒。葉遲須有在世、可達、知情、自願條件。 |
| G01-R14 | 幾年後家屬發現與約兩時代後衝突，早到可在 Y01 前觸發 | 用事件發生世界日期加延遲；區分發現、揭露、公告，缺席照樣結算。Y01 未發生時不得預設授權或第一世死亡副本存在。 |
| G01-R15 | 宿世印只靠前世同意，與當世拒絕有缺口 | 印記不暴露位置、身分、私人記憶，不等於召回／自動追蹤。下一世接觸仍需當世意願；失去聯絡或拒絕就不強行喚醒。留印對象能否輪迴不靠能被觀命推出。 |
| G01-R16 | 所知無少多、已揭露二元值不足；外部引用未閉合 | 按具體事實記來源、取得時間、授權用途與已知主體。EV-012、EV-028 與第四批段落需作者補精確檔案錨點，不能稱依賴已驗收。 |

## 新增內容地位
岑絲、瀾、哥哥、研究所案及印記具體機制均仍提案。保留「把記憶當知識」與少數意願兩條人物核心；修訂不替使用者新增正史。
