### 2.2 死亡與世界時間
- 【已定】世界時間持續前進。
- 【已定 N23】下一輪開始＝死亡時間＋等待燈籍新生兒的時間＋十四至十五年。N39：半選擇只在玩家介面，主角無等待經驗；N40 約十年是軟目標，候選可為0、1或多戶，無合格者續等。親屬依 N55／N56，沈家依 N57；不新造家庭或保證合格出生。出生及覺醒前死亡依 S05，99 年從出生起算（N41）。
