## 三、地方事件（任何時候皆可發生；依知情換台詞）

**關閉條件**：
- L-1、L-3 依世界時間進行，不因主角推知而關閉。
- L-2 的**請求**在陸吾與主角關係為「敵對」時不會由陸吾提出；但邊庭的事件本身仍會發生，主角仍可協助居民（此時不建立任務資格，因為沒有陸吾的請求）。
- 已建立的任務資格不因之後的推知或敵對而消失（L-6）。

### L-1｜創議聖庭
- **世界時間**（D＝公會提出主張日；提案）
  | 時點 | 事件 |
  |---|---|
  | D | 公會在聖庭提出主張；陸吾初步裁決「誓約有效，公會須負照顧義務」 |
  | D+20 | 若有人提出有效反證，舉行重審聽證 |
  | D+60 | 若無重審，公會正式接管外環 |
- **陸吾的初步裁決**
  > 陸吾：「誓約是約。約的兩邊都要做到。你們要權，就先把外環的燈點起來。」
  - 這是陸吾的制度判斷，不是作者真理。
- **調查**（非戰鬥）：饑荒紀錄、書院舊檔；外環老人作證；觀命（找對命錨；經本人同意）。
- **三個步驟**
  | 步驟 | 條件 | 結果 |
  |---|---|---|
  | 有效反證 | 至少一項紀錄（例如饑荒時期的強制簽署紀錄）加上一項證詞 | 陸吾同意重審 |
  | 重審 | D+20 聽證；公會與外環居民各自陳述 | — |
  | 最終裁決 | 依聽證結果 | 可能廢約、部分維持（公會保留照顧義務但不得統治）、或維持 |
- **居民提出的原則**（可在聽證中出現）：
  > 外環老人：「祖先簽的約，是祖先的事。我們沒簽過。」
  - 陸吾是否接受此原則，依聽證；本作不預設。
- **推知後的台詞變體**：陸吾照常主持；主角可以問：「你這麼重視約，那你自己守過哪一個？」陸吾不答。
- **拒絕／缺席**：D+60 公會接管；後續依公會是否履約（世界事件）。
- **晚到**：依抵達時間。D+20 前抵達仍可提反證；D+60 後，公會已接管，主角可協助外環居民另提申訴。
- **寫入**：`聖庭_誓約：審理中｜重審｜廢約｜部分維持｜維持｜公會接管`。

### L-2｜不照圖紙的街（《一方小天地》任務途徑）
- **地點**：啟曦星邊庭聚落（U-010-P2-C2）。地方矛盾：中心要求單一生活規範（ATLAS）；政治提案：啟曦要求居民自行修改標準圖紙（ATLAS）。
- **世界時間**（E＝中心下令統一規範日；提案）
  | 時點 | 事件 |
  |---|---|
  | E | 中心下令邊庭依標準圖紙改建 |
  | E+45 | 預定拆除不合規的歪牆 |
- **陸吾的請求**（僅在關係非敵對時提出）
  > 陸吾：「邊庭的人不照圖紙蓋房子。我給他們最好的圖紙，他們卻把牆蓋歪。」
  > 陸吾：「你去看看。如果你能說服我，歪的牆也有它的道理，我就把一件東西交給你。」
- **調查與做法**（非戰鬥）
  - 問居民為什麼把牆蓋歪。居民的意見**不必一致**：有人說擋風，有人說孩子能從窗口看見日晷，也有人其實想照標準圖紙改建。
  - 畫下居民的做法，找出標準圖紙沒有納入的當地條件。
  - 與願意參與的居民整理「居民版圖紙」。
  - **結構安全查核**：請築垣的施工師傅（白垣星出口陶材與施工，ATLAS）實地檢查歪牆。觀命**不能**取代這項查核。
  - 觀命（找對命錨；經本人同意）：看幾戶在兩種條件下的走向，僅作參考。
- **陸吾的反應**（改寫）
  > 陸吾：（看了很久）「……我沒把這裡的風向算進去。也沒把住在這裡的人要什麼算進去。」
  > 陸吾：「完美的圖紙，是在沒有人住的地方畫的。」
- **判準**（任務資格）
  | 條件 | 說明 |
  |---|---|
  | 陸吾正式許可 | 陸吾以創議聖庭的名義批准居民版圖紙 |
  | 實際停止拆除 | 至少這一條街的拆除命令在 E+45 前撤回並停止 |
  | 安全查核通過 | 施工師傅確認結構安全 |
  | 居民意願 | 選擇照標準改建的住戶，不被強迫保留歪牆 |
- **結果**
  - 四項皆成：**成功**，資格成立。
  - 陸吾只許可這一條街、不准他處比照，但四項皆成：**部分成功**，資格成立。
  - 許可已下但拆除仍發生（許可與落地不一致）：資格不成立；主角可協助居民追究命令未撤回的原因（同世補救）。
  - 陸吾不許可：失敗；同世可帶新證據再試（例如一場風災中，歪牆那一排沒有倒）。
- **拒絕／缺席**：E+45 依令拆除（世界事件）。
- **晚到**：E+45 前仍可介入；之後，主角可協助居民重建，並以拆除後的損失作為新證據。
- **寫入**：`陸吾任務：成功｜部分｜失敗｜許可未落地`、`邊庭_拆除：已停止｜已拆除｜部分`。
- **反諷**：若主角在推知前取得法則，推知後他會意識到，他從出手的人手上接過了東西。

### L-4｜接縫（補強或覆核）
- **地點**：光井城區（U-010-P1-C1）。地方矛盾：核心區長亮造成外環黑暗（ATLAS）。
- **條件**：持有真實。
- **時機**
  - K6 **之後**：作為補強或覆核，不是取得 K6 的前提。
  - K6 **之前**：只產生起疑線索（`接縫_比對：相似`），滿足私人會面門檻之一。
- **證據層級**
  | 層 | 內容 |
  |---|---|
  | 親見痕跡 | 主角以真實看見光井外環的修補接縫，以及歸墟碎片上的接縫 |
  | 比對 | 兩者手法相似 |
  | 推論 | 可能出自同一手法；**不能**單獨證明是同一次、同一人、或出於攻擊 |
  | 供述 | 見 L-5b |
- 【提案】真實法則讓主角看見「這裡被改過」，**不播放過去**發生了什麼。
- **保存方式**：主角的親見無法直接交給別人；公開揭發時，需另有可保存的證據，例如取回一塊碎片樣本（需歸墟當地的許可）、請其他持有相應能力者到場見證【待設計】、或第三方的紀錄。

### L-5a｜私人會面
- **門檻**：見 4.1。
- **初次見面**（主角從未見過陸吾）
  > 陸吾：「我不認識你。你說你有事要問我。」
- **已見過**
  > 陸吾：「你來了。你看我的眼神，和上次不一樣。」
- 主角可以提出疑問（異本、批註、接縫）。陸吾依主角提出的內容回應，可能否認、沉默或轉移話題。
- 若閻羅 X 在場並承認（替代路徑）：主角取得 K6；此時可轉入 L-5b 的內容，但仍需 K7 才完成階段十。
- **寫入**：`陸吾_私人會面：已發生`、`陸吾知_主角已推知：懷疑`。

### L-5b｜正式對質（主線階段十）
- **門檻**：K6＋K7。
- **開場**（依是否見過）：沿用 L-5a 兩種開場。

**陸吾的供述**（R03）
> 主角：「歸墟碎掉的那一夜，是你。」
> 陸吾：「你看見了什麼？」
> 主角：「接縫。還有一塊太乾淨的空白。」
> 陸吾：「……空白不是我的。」
> 陸吾：「碎片邊上那幾道接縫，是我補的。」

| 陸吾承認的 | 陸吾沒有承認的 |
|---|---|
| 歸墟碎片邊緣的某幾道接縫是他修補的 | 他出手攻擊師父；何時修補；空白是誰留下的；閻羅是否參與 |

- 主角的推知（K6）來自：親見痕跡、比對、推論，加上陸吾的部分供述；**沉默與反應不是獨立證實**。

**陸吾的自辯**：沿用 v1（守帝之下都、睡著的東西總有一天會醒、換一個做夢的）；主角可反駁「那你問過他們要不要嗎？」陸吾：「你問過嗎？」

**陸吾問師父**（R04；僅在主角已知 K3 時出現）
- 若 `陸吾知_師父在世` 已是「相信」或「已查證」（他從別處得知），問句改為：
  > 陸吾：「我知道他還在。我只想知道，他知不知道是我。」
- 否則：
  > 陸吾：「那一夜的人……他還在嗎？」

| 主角的回答 | 結果 |
|---|---|
| 說他還在 | 只有陸吾收到**主角的自述**。他是否相信、是否去查證、是否告訴閻羅，各自分開（見下） |
| 說他不在 | 陸吾收到相反的自述；他可能不信 |
| 不回答 | 陸吾的知情狀態不變 |

- **陸吾之後**（世界事件，提案）
  - 相信與否：依他對主角的判斷。
  - 查證：他需要自己的途徑【待設計】；查證可能失敗。
  - 轉告閻羅：需要陸吾主動傳遞，有延遲；閻羅收到後也需自行判斷。
- **不清除他人既有來源**：閻羅與蓋亞本就懷疑師父在世（背景 v1.4）；本場的任何分支都不會讓他們的懷疑歸零。

**主角的選擇**（與主線階段十一致）

| 選擇 | 需要 | 結果 |
|---|---|---|
| 揭發 | 向其他道主提出**可保存的證據**（L-4 保存方式；閻羅的供述若有） | 證據足夠：其他道主要求陸吾說明；奎托斯可能擔任仲裁（K01）；涂山氏可能最早要求追究（T01）；陸吾計畫進入「延滯」或「部分中止」（見第五節）。證據不足：其他道主只記下疑點 |
| 擊倒 | 戰鬥玩法未定 | 陸吾**暫離聖庭**；主角建立《一方小天地》擊倒資格；陸吾參與的計畫部分受阻；閻羅是否繼續另看其狀態 |
| 結盟 | 見下 | 開啟弒神奪位・共治路線；建立親授資格 |
| 不處理 | — | 計畫繼續推進 |

**結盟的五個步驟**（R05）
| 步驟 | 說明 |
|---|---|
| 1 陸吾提出 | 陸吾邀請主角共同承接夢 |
| 2 主角同意 | 主角可以答應、拒絕或保留 |
| 3 閻羅獨立同意 | 閻羅不在場時需另行會面；他可能拒絕、猶豫、受傷或離場（依 Y01 與其他篇的狀態） |
| 4 協議成立 | 三方皆同意時成立 |
| 5 終章執行 | 最終抉擇由玩家觸發；共治的穩定條件【待設計】，不保證成功 |

- 任何一方都可在第 5 步之前撤回或改變立場；撤回的後果依當時關係（提案）。
- 閻羅拒絕時，主角不能只與陸吾談完就建立三人共治；可以只與陸吾達成兩方約定，但那不是既有的共治路線，後續【待設計】。
- 對質完成（階段十）、取得命運（階段十一）、終章可用的結局，三者分開判定。

**擊倒後的政務代理**（R10）
- 由**在任的司晝星主**暫代曦冠京的**行政事務與公共設施調度**。
- 司晝星主**不**取得創世法則，**不**成為道主。
- 陸吾既有造物的維護責任需要交接：交給誰、資源是否足夠【待設計】；可能出現維護缺口（例如外環的燈），但永恆聖堂整體的維持能力不因主角取得法則而被抽走。

**寫入**：`陸吾_對質：揭發成功｜揭發不足｜擊倒｜結盟中｜協議成立｜未處理`、`陸吾_供述：接縫修補`、陸吾知情欄（2.2）、`政務代理：司晝星主（在任者）`。

## 五、世界的惡化（R06）

**陸吾計畫狀態** `陸吾計畫`：`推進｜延滯｜部分中止｜中止`

| 狀態 | 意思 | 造成原因（例） |
|---|---|---|
| 推進 | 無人阻止 | — |
| 延滯 | 暫時停下，可能恢復 | 奎托斯仲裁拖延；涂山氏要求說明；閻羅猶豫；燭陰暫時平靜 |
| 部分中止 | 陸吾參與的部分受阻，閻羅的部分可能繼續 | 擊倒陸吾；揭發只針對陸吾 |
| 中止 | 兩人的計畫都停止 | 揭發兩人且證據足夠；或兩人各自被擊倒 |

- 狀態可以**反覆變化**：延滯可能恢復為推進；部分中止可能因閻羅繼續而惡化。
- **惡化的樣子**：異象增加（EV-028）；命線偶爾同時抖動（人類看得見）；歸墟碎片不穩、出現新裂縫；部分航路受損、部分政治秩序動盪。
- **必要入口保有替代**：主線必要證據與可達路徑，在惡化中仍有替代（例如某條航路斷了，另一條仍在；某個證人過世，紀錄仍在）。
- **燈籍不歸零**【已定 N12】。
- **不會自動發生**：造物主被殺、遊戲結束。最終抉擇由玩家觸發。
- **到過夢底**：主角**不會**因此獲得遠端監看陸吾與閻羅的能力。【可選提案】夢中偶爾出現與現實相關的異象，但可能誤判，不作為證據。

## 六、《一方小天地》（R07）

**資格、可用性、辨認、領取分開**

| 項目 | 說明 |
|---|---|
| 資格 | 任務（L-2 成功或部分成功）、擊倒（L-5b）、親授（結盟協議成立後） |
| 傳授可用性 | 陸吾此時**願不願意**、**能不能**傳授；受關係、是否在聖庭、是否被逐出影響 |
| 辨認 | 陸吾能否認出這一世的主角（知情欄；或案件與見證） |
| 領取 | 主角接受才取得；拒領不消耗資格；取得一次【已定】 |

- **任務資格不因後來的推知而消失**：主角在推知前完成 L-2、但尚未領取時，資格仍在。推知後，陸吾是否仍願意傳授，是可用性的問題：
  > 陸吾：「你知道了。你還要嗎？」
- **擊倒只建立資格**，主角接受才取得。
- **拒領後的辨認**：需要案件或見證（例如邊庭居民版圖紙上的署名、施工師傅的證詞、聖庭的許可文件），不只靠主角自報。
- **陸吾不在聖庭時**
  | 狀態 | 流程 |
  |---|---|
  | 暫離聖庭 | 主角需找到他本人；政務代理不能代為傳授 |
  | 被逐出夢外（其他因果） | 替代流程【待設計】；資格不因此永久丟失 |
- **推知前取得後**：主角可能想歸還。
  - 【已定】法則取得後跨世保留，不能重領。
  - 主角可以選擇**不使用**。
  - 【新增提案，待作者確認】法則在物理或法則層面上**無法歸還**。本稿不把「跨世保留」直接推成絕對無法放棄。
- **能力邊界**（依 DAO_RULER_POWERS，提案）：構成有限且需維持的局部棲居或庇護空間；需要資源與維護；不是無成本倉庫；不是煉假成真的直接解答；不能創造獨立靈魂。
- **寫入**：`陸吾資格_任務｜擊倒｜親授`（分欄）、`陸吾_傳授可用：是｜否（原因）`、`法則_創世：已取得｜未取得`、`法則_創世_使用：使用中｜不使用`。
