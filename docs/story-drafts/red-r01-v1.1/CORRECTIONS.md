# 已確認修正與可直接替換台詞

B5已定：紅知道代收號，不知道確切住處。將「暫存／仍待確認」改為本輪已定。

R01-6「不知道要寄到哪」替換為：

> 紅：「我寫了十一封，一封也沒寄。手上只有他的代收號，不知道他如今住在哪。每次寫完，又收回去了。」
> 主角：「你怎麼知道他還活著？」
> 紅：「我不知道。我只是信。他答應過我，死之前會告訴我。」

此處不新增代收号必然失效、信必然寄达或大師兄仍在世的確證。十一封只有世界狀態已写成時成立；未寄的具體心理可後續深化。
