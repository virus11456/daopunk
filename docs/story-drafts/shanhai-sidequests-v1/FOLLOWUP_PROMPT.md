請依原稿與本包 REVIEW 的 Q01～Q16，交付〈此路今絕〉、〈知人名〉兩篇完整 v1.1，不要只寫修改摘要，不覆蓋 v1。所有新增內容保持【提案】。主線按知識條件推進，世界持續前進，無晚輪自動結局；不能鎖固定第幾世。岑行為古代人類探索者；潮簿為機械生命、靠航標航誌導航；只有部分航路使用命線里程。

每篇保留互動劇本，另外附：事件實例及年代狀態表、分支條件表、NPC知識增量表、實物交割表、缺席／離開／拒絕後續與晚期查訪入口。不要用整體劇情旗標讓NPC自動知道全部秘密。

甲篇優先修正：不說來源但說差異也會形成第二主張；何人何時聽到；估價員的出場先後；季節偏移仍待實證；「今絕」的添寫者未知；觀測盲區不要作實際世界結果；後續不可不論抽選都固定成功或迷航。保管／抵押／買賣／副本權利分清，只有一份原件，死亡不能自動送至保管人。打聽紅或拾六必須有可追索的聯繫來源。

乙篇優先修正：聽聞兒子發燒與其他調查必須有實際取得条件；雨夜未聽清版本；接懸賞不自動攜武或攻擊；舉武後退避與重建接觸不矛盾。非人類觀命未定，候選畫面不能直接當已定能力。白耳只是族群條目的消息來源，不設人物圖鑑。「人又來」不要變成人類繁盛的新增正史。聚居地的親歷記憶、筆記與對外揭露分開，保密不能抹除主角記憶。協議要有狌狌與居民各自同意；供食、停伐、撤令分開才有合理後果。

所有概率仍只是示例；一組結果互斥且完整，觀測覆蓋度另外標示。拒絕和缺席不是同一選項：拒絕者可能已知些事，完全沒來者不繼承這些知識。幾百年後訪問的是後果或檔案，不是同一群人重演相同委託。不要加入戰鬥規則、金額或Godot程式。
