# 支線甲　〈此路今絕〉

一支商隊帶回一份舊海經抄圖，上面的航路和主角背過的古抄本對不上。

## 甲-0　設定

| 項目 | 內容 |
|---|---|
| 觸發地 | 蔓哈頓深坑星，東泊位與破爛一條街 |
| 觸發條件 | 主角在該星球，且商隊在港（每個時代都會來一次，時間提案） |
| 相關圖鑑 | SH-ROUTE-101 無名失聯航路 |
| 中立組織 | 星際商隊（遠潮商隊，名稱提案）、拍賣場（遺珍閣，名稱提案）、黑匣信使局 |
| 人物（新增提案） | 韋舷：遠潮商隊船長，務實，欠了一筆修船錢。<br>簿九：商隊的航誌員，非人類（族屬待定），把商隊所有航誌背下來。<br>祁掌櫃：遺珍閣的估價師，客氣，眼很利 |
| 燈的承接者 | 依時代：紅在世時為紅；紅過世後為拾六 |
| 已知的兩個版本 | **商隊抄圖**（潮簿增補系）：沿三座航標，到「兩個太陽」之地；旁註「此路今絕」。<br>**隱修院古抄本**（主角背過）：同一方向只記兩道光，沒有「今絕」，也沒寫目的地 |

## 甲-1　拍賣預告
- **地點／時間**：東泊位港務板前，上午。天氣依季節；雨天時商隊延後一天卸貨。
- **出場**：主角、港口居民、韋舷（遠處）。
- **消息**
  - 紀錄｜遺珍閣拍賣預告：「海經古抄圖一幅，附航路三標，疑為潮簿增補本。」
  - 傳聞｜港口閒談：「聽說照著那張圖走，可以走到另一個宇宙。」「另一個？十個還不夠？」
- **互動**
  - 看預告：記 `聽聞_抄圖拍賣`。
  - 去找商隊：進入甲-2。
  - 不理會：本支線在世界時鐘上繼續（見甲-6 缺席版本）。

## 甲-2　兩份不同的航路
- **地點**：遠潮商隊的船艙。
- **出場**：主角、韋舷、簿九；祁掌櫃稍後到。
- **各自目的**：韋舷想賣個好價錢還修船錢；簿九想知道這條航路是不是真的；祁掌櫃想確認真偽，才好定價。
- **畫面**：簿九把抄圖攤在桌上。三座航標、一道虛線、一行小字：此路今絕。

**對白**
> 韋舷：「你是來買的，還是來看熱鬧的？」
> 主角：「……來看的。」
> 簿九：「你看得很久。你認得這種圖？」
> 主角：（他記得古抄本同一方向只寫了兩道光）「我在別處見過這條路。寫法不一樣。」
> 簿九：「哪裡不一樣？」

**互動｜主角說多少**（主角知道古抄本的內容，但古抄本是師門之物）

| 選擇 | 結果 |
|---|---|
| 說出兩處差異（兩道光 vs 三座航標；沒有「今絕」），**不說來源** | 簿九：「兩道光……我們找到第一座航標時，確實看到兩道光。第二座沒找到。」記 `甲_差異已告知商隊` |
| 說出差異，**並說出古抄本的存在** | 簿九很想看。祁掌櫃聽見，眼睛一亮。記 `甲_古抄本存在已外露`。後果見甲-5 |
| 只說「我見過」，不說內容 | 簿九追問，主角可堅持不說。記 `甲_保密` |
| 什麼都不說 | 韋舷：「那就別擋著。」可離開 |

- **祁掌櫃到場**
> 祁掌櫃：「潮簿增補本，市面上十幅有九幅是假的。這一幅的墨是舊的，紙是舊的。可是『今絕』兩個字，筆畫比其他字新。」
> 簿九：「你是說有人後來加上去的？」
> 祁掌櫃：「我是說，我還不確定。」

- **線索層級**
  - 親見：抄圖的樣子。
  - 紀錄：抄圖上的字。
  - 轉述：祁掌櫃對墨色的判斷。
  - 主角的記憶：古抄本的寫法（主角親歷，但無法拿出實物作證）。
- **圖鑑更新**：SH-ROUTE-101 新增「商隊抄圖：三標、今絕（墨色存疑）」「古抄本：兩道光（主角記憶）」兩項主張，並列，不互相取代。

## 甲-3　第一座航標（可選）
- **觸發**：韋舷要再出航試一次，問主角要不要同行（他需要一個「認得這種圖的人」）。
- **地點**：港外的航路起點，第一座航標。
- **季節條件**：抄圖沒寫季節。主角若以觀命換算命線上的里程，會發現：第二座航標的位置不是固定的，隨季節偏移。

**觀命**（須說明觀測條件）
- 觀測時點：抵達第一座航標時。觀測對象：「本季沿此航路繼續航行」的結果。
- 分支（示例）：到達第二座航標 30%；迷航後返回 45%；看不清 25%。
- 附在「到達」分支上的條件：航行在季節交替的某幾天內進行。

**互動**
- 建議韋舷等到季節交替再走：韋舷不一定聽（他急著賺錢）。聽了則甲-6 有「第二座航標已找到」的後續。
- 不說觀命結果：航行照常，結果依分布。
- 不同行：商隊自己去，結果依基準分布；主角日後從航誌得知。

**線索**：第二座航標隨季節偏移。這解釋了潮簿為何寫「今絕」：他可能只在錯的季節試過。**不證明**第三座航標與「兩個太陽」之地存在。

**圖鑑更新**：新增「第二座航標隨季節偏移（主角觀命與商隊航誌）」。

## 甲-4　誰來保管
- **地點**：遺珍閣或商隊船艙。
- **時間**：拍賣前一日。
- **情勢**：韋舷得決定賣不賣。祁掌櫃開了價。黑匣信使局的人也來了，說他們願意以保管費收存，不賣。

**互動｜主角可以做的事**（可複選，但抄圖只有一份）

| 選擇 | 結果 | 抄圖最後在誰手上 |
|---|---|---|
| 勸韋舷賣給遺珍閣 | 韋舷還清修船錢；抄圖進入拍賣 | 匿名買家（見甲-6） |
| 勸韋舷交給信使局保管 | 韋舷拿到較少的錢，但保留日後取回的權利；信使局開放副本讓航行者比對 | 黑匣信使局 |
| 主角出錢買下或借出副本 | 需主角當世有足夠財物（未定數值）；主角持有實物，但轉生後實物留在世上，由主角指定的保管者持有（例如燈的承接者） | 主角或其指定保管者 |
| 要求公開比對兩份航路 | 主角必須交出古抄本的內容；若交出，古抄本的存在與部分內容會被商隊、信使局、遺珍閣知道 | 不變；但知識外流 |
| 不介入 | 韋舷自己決定（提案：他選擇賣） | 匿名買家 |

**保密的代價**
- 主角若一直不說出古抄本，這份抄圖在所有外人眼中就只有「三標、今絕」一個版本。
- 主角若說出古抄本，等於告訴外人：世上有一部比潮簿增補本更古老的抄本，而且有人背得出來。這會讓人好奇「那個人是誰、從哪裡來」。**這是對師門的風險**，本支線不替玩家判斷值不值得。

## 甲-5　（僅在古抄本外露時）有人來問
- **時間**：甲-4 之後數月（玩家不在場也會發生）。
- **發生了什麼**：遺珍閣向幾位收藏家透露「有人背得出更古的航路寫法」。有收藏家託人打聽主角的來歷。
- **主角在場時**：祁掌櫃來找他，客氣地問他師承。主角可以拒絕回答，也可以編一個來歷。
- **主角不在場時**：打聽的人找上燈的承接者（紅或拾六）。紅會說：「不認識。」拾六會說：「我只接搬得動的單。」兩人都不透露。
- **後果**：此事本身不會讓人找到隱修院，但會成為一筆被記下的「未登錄者與古抄本」的消息。它與背景 v1.3 的洩漏鏈（資料掮客）是否會在日後合流，**待作者決定**。

## 甲-6　後續（世界照常前進）

| 狀況 | 數月後 | 數年後 |
|---|---|---|
| 抄圖賣給遺珍閣 | 報刊：「潮簿增補抄圖以高價成交，買家匿名。」 | 抄圖可能再度出現在另一場拍賣（時代不同，價格不同） |

**本支線不會**：生成第十一個宇宙的座標；判定失聯宇宙已毀滅；證明「兩個太陽」之地存在。

# 支線乙　〈知人名〉

一種被當地人叫做怪物的生命，夜裡會叫人的名字。

## 乙-0　設定

| 項目 | 內容 |
|---|---|
| 生命 | 狌狌 |
| 可核對出處 | **南山經**（南次一經，招搖之山）：形如禺（猿類），白耳，能伏行、能人走；經文另記「食之善走」。<br>**海內南經**：記「狌狌知人名」，並描述為形如豕而人面。<br>兩處形貌記載不同，本作視為**抄本矛盾**的實例 |
| 古籍摘要（改寫） | 南方一座山上有一種獸，像猿，白耳，會用四肢爬，也會站起來走；吃了牠的肉，人會走得很快。另一處又說，這種獸知道人的名字 |
| 觸發地 | 某農業星球的山林邊緣（候選地點名：招搖嶺，**不加入名錄**） |
| 觸發條件 | 主角到訪該星；各時代皆可 |
| 中立組織 | 義體醫師公社；黑市掮客（非公社）；雇傭兵團（受雇獵捕） |
| 人物（新增提案） | 柏嬸：林邊的果農，田被糟蹋三年了。<br>鉤三：收購狌狌腿筋的掮客，說是做「善走」義體的材料。<br>狌狌的長者：對外自稱「白耳」（這是牠們為了讓外人好叫而取的名字；牠們內部的稱呼另有，本作不公開） |

## 乙-1　懸賞
- **地點**：林邊聚落的告示牆，白天。
- **消息**
  - 紀錄｜地方懸賞：「山林獸害，每獵一頭，發給獎金。」（金額不定）
  - 轉述｜柏嬸：「牠們晚上來，把果子一顆顆摘下來，吃一半扔一半。還會叫人的名字，我家小兒子被叫了三次，嚇得發燒。」
  - 傳聞｜酒館：「被叫到名字的人，三天內會死。」（本支線**不兌現**此傳說）
- **互動**
  - 接下懸賞：可以接，但本支線不提供「獵殺即完成」的路徑；接下之後，進入乙-2 時主角會帶著武器，這會影響狌狌的反應。
  - 聽柏嬸說完：記 `乙_聽聞_叫名`。
  - 不理會：見乙-6 缺席版本。

## 乙-2　夜裡有人叫他的名字
- **地點**：柏嬸的果園邊，夜。
- **天氣**：晴夜月光可見樹影；雨夜聲音被雨蓋住，改為聞到的氣味與樹枝晃動。

**畫面**：樹影裡有東西在動。然後有一個聲音，很清楚地叫了主角**這一世的名字**。

**主角的反應（互動）**

| 選擇 | 結果 |
|---|---|
| 回應（說「我在」） | 樹影停住。過了很久，一個白耳的影子從樹後探出半張臉，又縮回去。記 `乙_回應了名字` |
| 舉起武器 | 影子立刻散開；此後數夜都不再出現。狌狌的長者之後會記得他是「舉手的那個」 |
| 不動，不說話 | 聲音又叫了一次，然後換成柏嬸小兒子的名字，最後安靜下來 |
| 觀命（須說明條件） | 對象：樹影中的那個生命，今夜之後的走向。**是否能觀非人類的命，本作已定為另一問題**；本場只呈現主角看到的：幾條細線，其中一條通往林外，一條斷在果園邊。沒有機率，太模糊。記 `乙_觀命_模糊` |

**牠怎麼知道名字**：本場不解釋。乙-3 由狌狌自己說。

## 乙-3　牠們的說法
- **條件**：`乙_回應了名字`，或隔夜再來且沒有帶武器。
- **地點**：林中，狌狌的聚居處（主角被帶進去，不知道確切路線）。
- **溝通**：狌狌會說人話的只有幾個字；主角靠手勢、字詞與耐心。長者「白耳」能說得多一點。

**對白**
> 白耳：「名字。你的。聽到的。」
> 主角：「你們……聽來的？」
> 白耳：「人叫人。我們聽。記住。叫回去。」（停頓）「叫回去，是說：我們在這裡。」
> 主角：「柏嬸的兒子被你們叫得發燒。」
> 白耳：（很久）「……我們不知道，會怕。」
> 主角：「你們為什麼摘果子？」
> 白耳：（指著林子的另一邊）「那邊，樹沒了。」

**可調查線索**
- 林子的另一邊有伐木的痕跡（親見）。伐木是誰做的，需到聚落查（乙-4）。
- 狌狌聚居處的牆上刻著很多名字。有些是聚落居民的名字，有些很舊，舊到沒有人記得是誰。
- 若主角提起「吃了會走得快」這句經文：白耳沉默，然後說：「以前，人吃我們。後來，人少了。現在，人又來了。」

**不兌現的傳說**
- 「被叫名字的人三天內死」：假的。
- 「吃了會走得快」：本作不證實也不否認有這種效果；只呈現有人相信，並因此獵捕。

**圖鑑更新**
- 新增主張：「親見：白耳，能站立行走；會說少量人語；會重複聽到的名字，意在表示自己在場。」
- 保留經文兩處不同形貌的記載，並列。
- **位置**：狌狌的長者請求主角不要記下聚居處的位置。主角若答應，圖鑑此條**不顯示位置**，只寫「招搖嶺林中，所在應居民要求不記」。

## 乙-4　市場
- **地點**：聚落市集與掮客鉤三的攤位。
- **發現**：
  - 鉤三收購狌狌的腿筋，說是給「善走」義體用；他給獵人的錢比地方懸賞高。
  - 懸賞告示是地方府出的，但伐木合約的受益者之一，也是向地方府申請懸賞的人。（紀錄：伐木合約與懸賞申請的署名，需主角去地方府查閱）
- **義體醫師公社的說法**（轉述，公社巡診醫師）：「公社不用這種材料。腿筋對義體沒有任何特別的效果。那是鉤三在賣故事。」
- **互動**

| 選擇 | 結果 |
|---|---|
| 查閱伐木合約與懸賞申請 | 取得紀錄層級的證據：兩份文件有同一個受益者 |

## 乙-5　協議
- **地點**：聚落的議事處。
- **出場**：主角、柏嬸、聚落長、鉤三（可能缺席）、受雇的傭兵隊長；白耳不會來（牠們不進聚落）。

**主角可以提出或支持的方案**（可組合）

| 方案 | 需要的條件 | 結果 |
|---|---|---|
| 劃一片不伐的林子給狌狌，換牠們不下田 | 需說服伐木受益者，或向地方府呈交乙-4 的合約證據 | 若成功：果園損害大幅下降；伐木者損失部分收益 |
| 教聚落居民分辨「叫名字」的意思 | 需主角在乙-3 取得白耳的說法 | 居民不再那麼怕；柏嬸的兒子可能會學著叫回去 |
| 撤銷懸賞 | 需地方府同意；有合約證據時較可能 | 傭兵隊長：「沒錢賺，我們就走。」 |
| 公開鉤三的材料不實 | 需公社醫師的證言 | 鉤三的收購價下跌；他換到別的星球繼續賣 |
| 什麼都不提 | — | 懸賞照舊；獵捕繼續 |

**保密分支**：若主角答應白耳不記位置，他在議事處也不能說出聚居處。聚落長若要求「帶我們去談」，主角只能拒絕，或去問白耳願不願意。白耳的回答是：「不。」這會讓部分居民懷疑主角偏袒怪物。

**觀命**（可選；須說明條件）
- 觀測時點：議事結束時。對象：柏嬸的果園在未來一年的狀況。條件：依議事結果。
- 示例分支（劃林且撤懸賞）：損害大幅下降 55%；狌狌仍偶爾下田 30%；看不清 15%。
- 示例分支（無協議）：損害持續 50%；狌狌遷走 25%（其他地方的林子）；看不清 25%。
