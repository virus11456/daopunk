## 二、交接印制度【提案】

### 2.1 定義

**交接印是一筆資料比對結果，不是對靈魂的直接觀測。**

| 資料 | 來源 | 說明 |
|---|---|---|
| 亡者紀錄 | 各地加入冥渡網絡的紀錄庫（例如深坑數據陵墓） | 死亡時間、地點、身分、見證 |
| 輪迴回執 | 神經網（蓋亞的輪迴端），經跨宇宙資料合作傳回 | 某個靈魂已經過交接、進入輪迴 |
| **交接印** | 冥渡網絡把兩者比對成功時蓋上 | 代表「此人已交接」 |
| 資料交接欄 | 僅人工生命紀錄有 | 記憶資料是否已歸檔；**與輪迴回執無關** |
| **逐出印**（v1.4） | 以實際見證、可核驗的夢內施作與離場紀錄確認逐出後登記；失聯、斷網或本人不在不能單獨建立 | 代表機構對已核事件的記載，不是全域監測，也不代表他人已得法則消失【已定 N16：道主不會死，只會被逐出】 |

閻羅 X 掌管的是**紀錄**（遮天：事物如何被記錄、追索與揭露）。輪迴由蓋亞掌管，靈魂由亞茲掌管。交接印只是兩者在紀錄上的交會點，閻羅 X 不能憑它知道靈魂去了哪裡。

### 2.2 正常情況下為什麼會缺印

| 類別 | 說明 | 是否計入「異常」 |
|---|---|---|
| 延遲 | 回執可能晚到數月到數年 | 否；超過期限才計 |
| 身分錯配 | 無名屍、身分不明、名字寫錯 | 否；先轉入身分核對 |
| 非網絡地區 | 死於未加入冥渡網絡的地方 | 否 |
| 滯留 | 靈魂被困或被強制保存（由亞茲的機構確認） | 否；轉入滯留案件 |
| 人工生命 | 輪迴回執常常沒有，原因未明 | 否；另立「非血肉紀錄」，不作結論 |
| 資料毀損 | 紀錄庫損壞 | 否 |

### 2.3 「只見兩份」的限定

閻羅 X 說的「只看過兩份」，指的是**通過以上所有排除程序之後**仍然異常的紀錄：

| 紀錄 | 死亡已證實 | 身分已證實 | 在網絡內 | 超過延遲期 | 非滯留（亞茲機構確認） | 輪迴回執 | 逐出印 |
|---|---|---|---|---|---|---|---|
| 主角一筆已核死亡（不固定第一世） | 有可核證據，記來源 | 已核 | 已入網 | 已過適用延遲期 | 已排除 | **無** | 不適用 |
| 「被認為死了的人」 | 僅世人依事件登記；不等於死亡證實 | 是 | 是 | 是 | 不適用（道主） | 不適用 | **無** |

**反例**（說明為什麼其他缺印紀錄不算）：
- 某礦工死於未入網的礦坑，缺印。原因：非網絡地區。
- 某商人的回執晚了三年才到，期間缺印。原因：延遲。
- 某被靈魂商人扣押的人，缺印。原因：滯留，由亞茲的機構處理。
- 九子，輪迴回執欄是「無資料」。原因：人工生命，另立非血肉紀錄，不作結論。

### 2.4 主角後來的死亡
若主角在本篇之前已死過不只一次，每一次死亡只有具備實際入網紀錄並完成排除核驗後，才可能形成一筆可知異常紀錄。閻羅 X 說「兩份」，是指兩個**人**，不是兩筆紀錄；台詞依本人獲授權可讀、已核驗的紀錄數與內容調整（見 Y01-3）；實際死亡次數另記。

## 三、權限鏈【提案】

| 角色 | 單位 | 權限 |
|---|---|---|
| 保管方 | 深坑數據陵墓（伍櫃守） | 持有**原件**；地方隱私規則 |
| 裁決方 | 冥渡掌渡府（掌渡星主轄下） | 裁決異常紀錄的調閱、封存；【已定】冥渡為幽冥數據流首都星，由掌渡星主治理 |
| 申請方 | 神經網研究所 | 申請調閱異常紀錄作研究 |
| 會面地 | 燈津引燈府（燈信城所在） | 提供會面場所；不參與裁決 |
| 閻羅 X | 以「無名」身分出現 | 持有掌渡府的**審核副本**（已遮去身分），不是原件；道主在燈信城活動，不改首都駐地 |

### 3.1 資料層級

| 層級 | 內容 | 誰有 |
|---|---|---|
| 原件 | 完整紀錄 | 陵墓 |
| 摘要 | 死因、時間、異常類別；無姓名 | 掌渡府、申請方（經批准） |
| 審核副本 | 摘要＋比對程序紀錄；身分遮蔽 | 掌渡府、閻羅 X |
| 報刊 | 實際存在、內容對應該次事件的公開報導；日期按刊登紀錄 | 公開 |
| 主角的記憶 | 他親歷的一切 | 主角 |

### 3.2 神經網怎麼知道

兩條來源，依主角的行動而定：
1. **主角本人去過陵墓**（查詢、申請、或與伍櫃守談過自己第一世的事）：伍櫃守依規定在紀錄上加註「申請人自稱為死者本人，身分有爭議」。註記只供有權稽核單位核驗；研究所取得須另有有效授權，不因網絡互通自動看到。研究所得知的是「有人**自稱**是死者本人」，不是「主角帶著記憶回來」。
2. **主角從未去過陵墓**：網絡的定期稽核把這筆超期缺回執的紀錄列為異常，神經網有權的回執稽核單位只取得必要異常欄位；研究所不能因同屬神經網自動取得。經合法授權時只知道「有一筆死亡紀錄從未收到回執」。

### 3.3 紅向伍櫃守說了多少
（須紅實際存活、知道該次死亡與主角自述，並決定轉告；只見過面不成立。非閘門死因依紀錄換句）
- 紅告訴伍櫃守：「那年死在閘門裡的那個人，有個年輕人說是他。我還在核對。」
- 紅**沒有**說主角現在的名字、住處或家人。
- 伍櫃守無法核對身分，只能在紀錄上加註「身分有爭議」。

### 3.4 缺席處置
- 掌渡府依規定發出通知，給本人或代管人一段**聽取期**（採程序設計：合法送達後三十日；未送達不開始）。
- 本人到場：裁決會納入本人的意見。
- 本人不到場：期滿後，掌渡府以預設方式處理：**原件留在陵墓，暫停新增非必要研究分享**；缺席不是同意。既有效授權按目的與期限處理，必要稽核限有權機關與最小欄位。
- 主角日後仍可到陵墓或掌渡府申請更改。

- **場景**（原稿組裝）：蔓哈頓深坑星，數據陵墓。坑內雨季，入口止水坎外積了一層淺水。伍櫃守（年邁；依實際在職，否則由繼任承辦者）領主角走到一格墓碑伺服器前，螢幕上是主角**有紀錄的那一世**的名字。
- **死亡紀錄的三種情況**（PKG-01）
  | 情況 | 伍櫃守的開場 |
  |---|---|
  | 有死亡紀錄（死亡經見證或遺體證實） | 下方對白 |
  | 只有失蹤紀錄（目前尚未取得足以核定死亡的證據；無見證與未入網另欄） | 「你那一世在紀錄上是失蹤，不是死亡。這份失蹤紀錄還不能拿來比對交接印；它不證明你沒有死，也不證明自然輪迴的狀態。」本篇的「未交接」比對**無從進行**；掌渡府的通知不會因這一世發出。若主角另有一世有死亡紀錄，改用那一筆。 |
  | 任何一世都沒有紀錄 | Y01-1 不以陵墓來信觸發；主角可自行到陵墓查詢，伍櫃守只能說「這裡沒有你」。查無紀錄不寫 K2a，也不要求再死一次。依 N50／SPEC S03，查本來那次死亡的可核證據、補建更正鏈，或由有實際依據的閻羅陳述取得；不得以本人的自稱或閻羅全知代替證據。具體補查替代場景仍列 OPEN-01，未完成前不宣稱此路完整。 |

### Y01-2　河燈
- **場景**（原稿組裝）：燈津星燈信城，實體河岸工坊。霧季，河上起霧，河燈在霧中只看得見一團團光（替代：雨，燈暫留岸架）。河面上漂著上千盞燈，每一盞都綁著一個防水信套。
> 主角：「這些燈是……」
> 杭燈娘：「每一封送不到的信，就點一盞。」
> 主角：「送不到？」
> 杭燈娘：「收信的人死了、轉生了、不肯收了。信寄到這裡，點成燈，讓它漂。」
> 杭燈娘：（看著手上的信）「這封是給我的。因為我不收。」
- **互動**（原稿）：問她有沒有看過信 →「第一年看了。寫得很好。所以後來就不看了。」／說這不公平 →「對誰不公平？」／什麼都不說、陪她放燈 →「謝謝。你是第一個沒有勸我的人。」記 `杭燈娘_好感`。
- **修改：前世關係是來信者的主張**
> 杭燈娘：「寫信的人說，我前世是他的妻子。他這樣說。我不記得。」
> 杭燈娘：「是不是真的，我不用知道。我這一世有丈夫，有三個孩子。」
- **修改：漂燈的私密處理**
  - 信在點燈前由引燈府的燈匠以封套密封，封套上只有編號，不寫收件人。
  - 漂到下游的燈由燈匠收回，信套依寄信人選擇退回或焚化。
- **好感**：只影響杭燈娘在 Y01-7 願不願意說出信的內容；信的內容由寄信時決定，不因好感改變。

**選項一：紀錄處理**

| 選擇 | 神經網研究所 | 一般公開 | 主角本人 | 代管人（紅或拾六） | 撤回途徑 |
|---|---|---|---|---|---|
| 全封 | 看不到摘要，只知道「有一筆封存的異常紀錄」 | 無 | 可經掌渡府申請查閱原件 | 不受影響（代管權不因封存消失） | 本人可申請解封 |
| 部分封 | 可看摘要（死因、時間、異常類別），看不到姓名、地點、見證者 | 無 | 可查閱原件 | 不受影響 | 本人可改為全封或不封 |
| 不封 | 可看審核副本（身分仍遮蔽） | 無 | 可查閱原件 | 不受影響 | 本人可改為封存 |

**紀錄處理不改變**：實際存在的公開報導、既存原件與主角親歷記憶；缺件不生成原件，沒有研究申請時不冒稱有人申請。

**選項二：研究**（與選項一獨立）
- 拒絕研究：研究所只能使用選項一允許的資料；不得聯絡主角。
- 同意受訪：研究所可經掌渡府聯絡主角一次；每次訪談前須再同意。
- 暫不決定：研究所不得聯絡；主角日後可改變。

### 5.2 小芽的消息（依 F01 實際結果；PKG-02）

- **送達**：消息經斷鏈避難網中繼，或葉遲的來信；**只在實際送達時**主角才知道。未送達只表示未從本封信得知；不抹除親見或其他合法來源的已知資訊。逐封記發信時間、所述事件時間、送達時間與來源；舊消息不覆蓋較新的已核事實。
- **時間**：承諾期從實際作出該約定之日與約定內容計算；F01 結束日只作場景參照，不改約定期限。
- **分軸**（依 F01 v1.5 的 R／L／N 與另軸）：

| 軸 | 狀態 | 消息（示例） |
|---|---|---|
| 生命 | 存活／死亡／尚未知（事件真值與來信者已知分欄） | 死亡時：「小芽……不在了。」（只在已證實時） |
| 母親 | 已重逢（R）／只知下落（L）／均未成（N） | R：「她見到媽媽了。」L：「找到媽媽在哪裡了，還沒見到。」N：僅實際仍在搜尋才說「還在找」；否則照報搜尋停止或未知。小芽已死亡時，R 改「她生前見到了媽媽」，不抹除歷史重逢。 |
| 居所 | 仍在苑／已離苑（自行離開或經審查出星） | 自行離開：「小芽離開了傳承苑。苑裡在找她。」（須來信者確知離開且苑方實際仍在尋找；離開不證明已知她現在的位置） |
| 申請 | 審理中／獲准／被拒／未申請／撤回／死亡結案 | 審理中：「出星審查還在排。」 |

- 小芽的日常細節（畫地圖、畫船）只在來信者實際提到時出現，不固定為「每天一張」。
- 主角若在 F01 承諾「之後再來問小芽」，介面可依既有約定顯示提醒；世界內訊息仍需來源與實際送達。是否履約另按實際行動，不由 UI 提醒生成消息。

## 七、本篇提案（未經作者裁決；不影響主線門檻）

1. 交接印是資料比對（亡者紀錄 × 輪迴回執），不是靈魂監測。
2. 逐出印：道主離開夢時的紀錄。
3. 人工生命另有「資料交接」欄，輪迴回執常為「無資料」，不作結論。
4. 權限鏈：陵墓保管、掌渡府裁決、研究所申請、引燈府提供會面地。
5. 院名與其他線索的可連結風險逐項核驗，不保證無法追索。
6. 研究同意與紀錄封存分開。
7. 本人重查的途徑：到掌渡府報現名，由「無名」核對。
8. 聽取期的長度；缺席時的預設處理。

## v1.2 整合

- **N70 無名紀錄**：掌渡府以**交接實例編號**追蹤無名者，記來源、交付與更正鏈；名字或編號都**不是**自然輪迴的必要條件。
- **N48 陵墓改寫**：歸墟破碎那夜，陵墓對外欄位中「受襲」的記載被刪去。**權限記號只核授權來源，不能單獨認人**；K6b 需原值回執、更正單、值守附記與閻羅當次確認簽記共同指向本人（第五批上 v1.3 碎-7，你方覆核整合稿）。調閱依本篇的權限、目的與範圍，本人重查途徑不適用於他人紀錄。
- **閻羅的供述**：具體且可核對時可作證據；需記錄內容、來源、取得時點，並核對他實際所知。
- **N68**：記憶公證所〈我記得〉是支線，可提供非唯一的佐證；入會不是主線必要條件。

## 授法留痕與資格（N42、N49、SPEC S02；閻羅 X）

- **資格帳**：記法則 ID、取得途徑（任務／親授／擊倒）、客觀條件、證據、成立日期；**領取**另記接受、實際傳授日、已取得旗標。資格成立後跨世保留；辨認不足是「核驗待補」，不刪資格、不強迫重做任務；拒領只是延後。
- **留痕**：閻羅 X在燈信城的燈匠工坊留下夢內的**傳承留痕**。它是三種既有途徑的領取接口，**不是**第四種免資格取得法：
  - 擊倒產生的資格，在閻羅 X被逐出夢外的瞬間結存，事後可依留痕領取。
  - 未完成任務者，可依留痕所載的客觀任務完成。
  - 親授途徑需閻羅 X離夢前**實際成立**的同意；留痕不發明新的同意。
  - 介面被破壞不刪抽象資格；依法則留痕重建同一接口，不召回道主、不與夢外通信。
- **N42**：已取得的法則不能歸還、主動放棄或被外力撤銷；主角可以選擇不使用。
- **N52 初始立場**：閻羅 X的初始立場為「密謀」，之後依經歷改變。
