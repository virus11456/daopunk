# 給 Claude｜W01 v1.1 修訂要求

請將 W01 v1《下一世的帳》依本包 REVIEW.md 的 W01-R01～R16 修訂成 v1.1；保留 v1。先列處理表，再交完整場景與台詞、旗標、拒絕／缺席／晚到／已得法則變體。保留沃倫的風趣、算計與「帳在，那些人就還在」；其自辯不等於作者事實。新增內容仍標提案。

必須做到：

1. 首都星用 ATLAS 的衡金星 U-005-P1。帳簿塔只是新增景觀提案，不替换秤臂形交易議宮或原地方矛盾。世界可惡化，結局由玩家觸發，沒有自動時限終局。
2. 沃倫知道主角輪迴與認出新身份須有獨立來源。追債不是每世覺醒自动定位；設查訪、錯認、延遲、查不到。若希望有契約追蹤術，另列待作者定案的能力、限制與對燈籍安全的影響，不能先寫成正史。
3. 區分契約的聲稱、虛構司法效力、執行與法术效力。不能藉跨世債務扣走已定永久功德、仙術、法則、記憶，不能指定輪迴落點或冻结承載時間。W-2 明示交易標的、期限、資源上限與可閱讀條文；刪一條不代表其餘公平。
4. W-1 貨權與整店所有權拆開；查到未交附件不是瞬間勝訴。W-3 觀的是母親在條件下的命途，不是替未出生孩子找錨；母親不能代孩子同意被賣。主張應是無權代他人出售未來，不是算不出價錢而已。
5. 撕紙是象徵，另寫正式撤銷、債權轉售、已履行者與港口居留的處理；單案與制度改革分旗標。
6. W-4 補資料來源到追捕的證據鏈；未登錄者不全是人類。不把禁令十倍漲價或契約政策必有效寫成客觀定律。買一份不會抹掉所有備份；公開揭弊可遮蔽身份地址，保留錯誤公開的後果。
7. 公平親授須在簽前說明承諾、期限、不可履行例外與後果，不許沃倫事後任意加價。每世來訪可能早死；先告知可能失聯，不能因此封死終章。違約不收回已永久取得的法則。
8. 三種取得資格可並存，領取一次；拒領可再訪。能力不倒轉世界、不無限生資源、不凍結承載時計。任務新證據可同世重試，後人不是原人物無條件替身。

最後提供最多三個真正需作者定案的選擇（例如跨世追索的法術機制是否存在、每世來訪承諾的有限改寫），不要重問已定規則。EV-016、EV-017 若無精確來源則明標引用待補，不聲稱完成實機驗證或 Godot。
