# W01 v1｜一致性審閱

此為虛構世界與劇情依賴審查，不推定任何真實法律規則。保留沃倫的算計、偏見與狡辯；系統後果須另有成立條件。

| ID | 問題 | 修訂要求 |
|---|---|---|
| W01-R01 | 首都星與地標不一致 | U-005-P1 依 ATLAS 用衡金星，不能無說明改金潮星。萬衡京既有秤臂形高架交易議宮；帳簿塔可作新景觀提案，註明與議宮的位置關係，保留公共航路私有化的地方矛盾。地下交易廳可位於既有地下拍賣廳，不替換贗品矛盾。 |
| W01-R02 | 時代沿用自動時限、道主不受時代影響 | 維持世界前進、最終抉擇玩家觸發。道主仍可能離場、受傷、逐出，不能保證任何時代本人都在。交易、起訴、訪問需可達地點與在場者。 |
| W01-R03 | 沃倫自動知道輪迴並在覺醒時定位 | 補何時、由誰、用何證據知道主角跨世；不把一般生命轉生與完整記憶例外混為一談。追債需辨認當世身份、線索、傳遞與旅行時間；可認錯、查不到。若設契約追蹤術屬重大新能力提案，不能默認有全域燈籍名冊或自動讀取導師剪命祕密。 |
| W01-R04 | 含糊條款一簽就取得一切時間 | 區分契約對方主張、法庭承認、實際執行、法術能否作用。不得因此擅自扣走跨世功德、仙術、法則或記憶，也不控制出生／死亡／99年承載。其他生命失憶轉生是否承債須另設，不能只因主角記得就普遍成立。惡意條款可存在，但讓主角挑戰有效性與範圍。 |
| W01-R05 | 錢船證無上限、刪一條即公平 | 補交付、義務、期限、轄區、終止及申訴；資助受資源和通行管轄限制。刪掉延續不等於整份已公平。玩家能閱讀關鍵條款並詢問，不把角色沒讀到與玩家被隱瞞混成選擇；可暫緩、諮詢、拒絕後繼續其他劇情。 |
| W01-R06 | 貨權條款直接吞整店 | 說明貨物、店舖、租約各為何物及被查封範圍；若只擔保貨物，不自然取得房屋。未交附件是阿衡申訴依據，不自動勝訴；補虛構裁定與暫緩執行，並尊重阿衡願不願公開或訴訟。 |
| W01-R07 | 觀孩子未來與觀母親混寫 | 明確對象是當下母親，在特定家庭合約延續條件下的命途；不能替尚不存在的特定孩子建命錨或保證出生。母親同意不等於孩子日後同意被看命／賣工。可觀測家庭負擔的分支，不能斷言未出生者身份或同意。 |
| W01-R08 | 無法估價才不得抵押 | 將無權代另一主體同意與价格不確定分開；即使能算出價格或找到風險模型，也不因此能賣孩子。母親的話是價值理由，不是合同無效的自動證明。沃倫既說知道又叫玩家找出，需區分知道制度、掌握哪些具體案件、願否面對責任。 |
| W01-R09 | 撕紙就解除所有債務 | 紙本、電子正本、債權轉售與執行機構需有撤銷／通知／停止追索鏈。區分免未出生者連帶、父母原債、已被迫勞務者救濟、入港居留，避免孩子自由但家人被逐而任務全成功。單案解約與制度修法分开，沃倫權限與各港承認非全宇宙自動生效。 |
| W01-R10 | 一個紀錄包直接證實追捕全鏈 | 分拆收集→整理→存取→出售→買方→追捕使用的證據及日期。未登錄旅客不必是人類，不能直接指出所有燈籍地址。依 P01 實際個人登錄、資料知情與洩漏狀態分支；未登錄仍可能有邊防痕跡，不保證一定可追到。 |
| W01-R11 | 禁令十倍漲價、同意契約必顯著降低追捕 | 十倍可作沃倫推測，不寫固定經濟真理。政策效力依管轄、查核、執行、替代來源、腐敗與時間。本人同意可被脅迫或用途偷換，需列用途、轉售與同意真實性。制度不能保證有效，也不因有黑市就宣告禁止無用。 |
| W01-R12 | 買下銷毀消除資料、公開無二次傷害 | 買副本不能刪掉全部備份、已售資料及人腦記憶；可買存取權、查流向、切斷一個來源，但不保證抹除。報導應選擇是否遮蔽地址與身份；若越權曝光可演出實際後果，不把公開名冊当唯一揭弊手段。 |
| W01-R13 | 公平親授允許無限每世義務、後果任意追加 | 簽前明示承諾範圍、期限、例外、履行證明與違約後果。「每世來訪」遇早死、失聯、道主逐出須有履行可能；不任意事後加價。先告知不能在沃倫不可達時鎖死終章，可用合理替代傳遞或容許違約並承擔敘事後果。 |
| W01-R14 | 親授履約與能力永久性、三路互斥 | 資格可並存，實際接受只一次，拒領不消耗。記承諾未履行／完成／合理不能／違約，與法則持有分開；不能違約就收回已得時間法則。刻航線有核實來源及家屬／相關者意願，非編一條即可。擊倒、逐出、傳授順序須交代。 |
| W01-R15 | 時間能力可繞承載、欠款與履約 | 明列有限窗口仍在世界因果內，不複製資源、不回滾契約與已死傷者，不藉局部停時凍結靈魂承載。醫術每世一次及永久延壽規則不變。領取一次不等於能力累世只用一次；使用成本與上限仍待設計。 |
| W01-R16 | 亡者因帳存在、親屬自動繼承與粗旗標 | 「帳在，人就在」是沃倫的記念方式，不證實靈魂困在帳簿，債被免除也不抹掉歷史。後人可拒承債且未必存在，續案不是重置死者。使用 W01_ 前綴，分資助契約／親授承諾、案件／政策／實施／追捕結果、關係／政治立場；新證據本世可重試，非必等時代。 |
