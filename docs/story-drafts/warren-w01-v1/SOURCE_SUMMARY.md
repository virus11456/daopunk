# W01 v1｜對話稿結構摘要（非逐字原稿）

來源：使用者本次貼文《W01 沃倫篇 v1〈下一世的帳〉》。此處摘要原稿，不表示已採用新提案或已套用審閱修正。

## 核心

沃倫掌時間，居星際商盟萬衡京 U-005-P1-C3，重契約、把犧牲換算價格；守護夢境的個人理由是「帳在，那些人就還在」。首都星原稿稱金潮星，與現有名錄待對齊。《借一刻》提供有限行動窗口，不能倒轉世界或無限產生壽命、功德、物資。

| 場景 | 梗概與選擇 | 主要寫入 |
|---|---|---|
| W-1 帳簿塔下 | 香料商阿衡因未見附件的不可抗力條款失去店舖；主角查契約交付、找其他商戶、經同意觀命或離開。沃倫旁觀並對主角感興趣 | 阿衡狀態、關係有趣 |
| W-2 沃倫的契約 | 提供金錢、船與通行證；條款「乙方今生及其延續之一切時間」可能涵蓋主角所有世。可刪條款再簽、含盲點簽、拒絕。原稿含盲點時每世覺醒後有人追債，可到契約法庭挑戰 | 沃倫契約三種狀態 |
| W-3 未出生者的時間 | 移民家庭以勞務換入港，未完成部分由未出生子女履行。查契約、代書與承包商；原稿經母親同意觀命。讓沃倫認同價格無法計算或未出生者不能同意，可廢一份或整類附則，或失敗 | 任務成功／部分／失敗，家庭狀態 |
| W-4 資料的價格 | 舊市城區 U-005-P1-C2，資料掮客交易邊防／登錄整理包，涉及未登錄旅客。沃倫知市場不知追捕用途。禁止、同意交易規則、買下銷毀、公開、不管，影響追殺 | 資料市場處置 |
| W-5 債與夢 | K5 已知且尊重，保航鎮 U-005-P3-C2 鐘樓對話：醒來讓帳與承諾失效，沃倫以守帳記住失事的人 | 關係變化 |
| W-6 借一刻 | W-3 成功、公平承諾親授或擊倒；可拒領。承諾候選為每世來訪、K5 後終章先告知、替鐘樓刻一條航線。原稿違約後果由沃倫決定，通常不再授物 | 時間法則、承諾 |

## 原稿後續與新提案

阿衡與家庭按世界時間老去，後人承接；含盲點契約跨輪追索到法庭挑戰成功。資料市場處置影響追殺规模。終章承認非賣品者支持守護並質問陸吾，承諾先告知者要求終章前告知，冷淡者不介入。

新提案包括跨世債務條款、未出生子女的勞務抵押、沃倫對資料用途的知情界線、守帳與亡者的隱喻、承諾式親授。契約的跨世法律效力、追查方式、法術作用與繼承方式尚未分清。
