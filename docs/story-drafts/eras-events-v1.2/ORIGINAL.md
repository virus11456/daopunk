# DAOPUNK｜時代與隨機事件池規格 v1.2

> **目的**：一百小時的肉鴿遊戲，約一半內容要靠可重複、會隨世界時間變化的事件撐起（遊戲量規劃 v2）。本文件定義五個時代的世界狀態，以及隨機事件池的結構、觸發條件與分量。
> **依據**：完整背景 v1.4；各篇修訂稿；你的五項更正（轉生時間依公式、物件與人物狀態需各自條件）。
> **標記**：全部為【提案】，除非註明【已定】。事件分量是**內容規劃數字**，不是玩法數值；未定戰鬥、獎勵；未接 Godot。

---

## 一、原則

1. **時代由世界時間決定，不由玩家的輪數決定**。玩家可能在一個時代裡活完一生，也可能一死就跳過一整個時代。下一輪的開始時間＝死亡時間＋等待燈籍新生兒的時間＋十四到十五年【已定，你的更正】。
2. **人物的生死依世界時間與實際事件**。下表的死亡年份是「沒有人介入時」的預設；玩家的行動可以改變（例如救了誰、讓誰提早離開）。
3. **地點每個時代有不同狀態**，但保留前一個時代留下的痕跡。
4. **事件池是可重複內容的主體**；一次性劇本（主線、人物篇、道主篇）只佔一半。
5. **無自動終局**【已定 N20，取代 N19】：世界持續惡化；最終抉擇由玩家觸發。
6. **時代數量不固定**【已定 N27】：世界持續延續；時代數量因玩家的輪數與行動而異。

## 二、時代

### 2.0 時代怎麼產生【提案】

- **固定開頭**：前四個時代以明確的世界事件為界，每個玩家都會經過。
- **延續時代**：第四時代之後，世界每隔一段世界時間（建議約二十到三十年）進入一個新的延續時代。延續時代的名稱與樣貌由當時的世界狀態生成（見 2.4）。
- **「夢動」時代**（v1.2 改寫）：不再是固定的最後時代。當陸吾與閻羅 X 的計畫處於「推進」且世界惡化達到一定程度時，當前的延續時代呈現為「夢動」樣貌；計畫延滯或中止時，可以回到一般延續時代。沒有自動終局。

| 順序 | 名稱 | 世界時間（T＝第一輪下山） | 邊界事件 |
|---|---|---|---|
| 一 | 燈下 | T−3y～約 T+15y | 閘門事件 |
| 二 | 崩塌之後 | 約 T+15y～T+40y | 第一代人物開始老去 |
| 三 | 老去 | 約 T+40y～T+70y | 追殺事件（蒐集人類開始） |
| 四 | 蒐集 | 約 T+70y～T+100y | 蒐集常態化 |
| 延續時代（0～數個） | 依世界狀態命名 | 每段約二十到三十年 | 依世界事件 |
| 依狀態 | 夢動 | 計畫推進且惡化加劇時 | 計畫狀態改變 |

### 2.4 延續時代的生成方式【提案】

延續時代不需要逐一手寫，由以下要素組合：

| 要素 | 來源 |
|---|---|
| 名稱 | 取自當時最顯著的世界狀態（例如「無燈之年」「新街」「空座」） |
| 燈籍 | 燈數依世界事件增減【已定：不會歸零】 |
| 地點狀態 | 沿用前一時代，套上該時代的變化（重建、荒廢、易主） |
| 人物 | 第一代人物多已離世；新人物由燈籍人家、組織、地方勢力產生 |
| 組織 | 五類中立組織依前一時代的結果延續或改組 |
| 事件池 | 大部分事件模板的「一般變體」可用；少數模板有延續時代專屬變體 |

延續時代讓遊戲可以一直走下去，但不需要為每個時代準備完整的新內容。

## 三、隨機事件池

### 3.1 分量（內容規劃）

| 項目 | 建議 |
|---|---|
| 總數 | 約 300 個事件模板 |
| 每個模板的時代變體 | 1～5 個（不是每個事件都要五個版本） |
| 分布 | 依宇宙：歸墟較多（約 60），其餘九個宇宙各約 25 |
| 類型比例 | 見 3.2 |

### 3.2 事件類型

| 類型 | 比例 | 說明 | 例子 |
|---|---|---|---|
| 日常求助 | 約 25% | 當地居民的小困難，通常可用觀命、五術或行動解決 | 找走失的機器寵物；替攤販判斷一批貨的真偽 |
| 觀命委託 | 約 15% | 有人要主角看命；可拒絕、可接、可要求對方同意 | 一對要結婚的人想知道未來；一個人想知道母親會不會醒 |
| 消息與傳聞 | 約 15% | 世界事件的在地版本；判斷真偽 | 茶攤流傳某商隊失蹤；地下聲明的真假 |
| 山海探索 | 約 15% | 對應圖鑑條目；非戰鬥發現 | 逆流瀑的觀測；某種鳥每年同一天飛越 |
| 中立組織 | 約 10% | 商隊、傭兵、拍賣、海盜、殺手的在地事件 | 拍賣場請主角鑑定；傭兵隊臨時缺人 |
| 燈籍與人類 | 約 10% | 與燈籍人家、人類處境有關 | 一戶燈籍人家的孩子被盤查 |
| 異象 | 約 5% | 與夢、觀察者有關的少量異常；多在時代四、五 | 所有人同時看見天空暗一瞬 |
| 衝突 | 約 5% | 可能需要戰鬥或逃離的事件；戰鬥玩法未定 | 被誤當成未登錄的逃犯追捕 |

### 3.3 事件模板結構

每個事件模板包含以下欄位：

| 欄位 | 內容 |
|---|---|
| ID | 例如 EV-U001-042 |
| 類型 | 見 3.2 |
| 地點條件 | 宇宙、星球、地點類型（街區、港口、農地、寺院等） |
| 時代條件 | 可出現的時代 |
| 前置條件 | 知識旗標、人物狀態、世界狀態（例如「紅在世」「閘門已發生」） |
| 排除條件 | 已發生過、人物已死、互斥事件 |
| 觸發方式 | 進入地點、與人交談、時間到達、世界事件連動 |
| 開場 | 一到三句 |
| 選擇 | 至少一個非戰鬥選項；至少一個「拒絕或離開」選項 |
| 觀命節點（若有） | 觀測時點、對象、條件、互斥結果與看不清的餘量（格式依 X01 v1.1） |
| 結果 | 寫入的世界狀態、人物狀態、圖鑑、知識旗標 |
| 時代變體 | 不同時代的開場與結果差異 |
| 缺席結果 | 主角不處理時世界怎麼演變 |
| 可重複性 | 一次性／每時代一次／可重複（冷卻由玩法決定） |

### 3.4 防止重複感

- **同一模板不同時代**：開場的人不同、問題的根源不同。
- **同一時代不同輪**：若主角在同一時代又一輪回來（例如早死後出生還在同一時代內），已發生過的一次性事件不再出現，改由其後續事件接上。
- **主角記得**：主角完整記得親歷【已定】。已處理過的事件，他下次遇到類似的會有記憶台詞（「上一輩子，我在這裡見過一樣的事」），但**不能**預知新的細節。
- **世界記得**：玩家做過的決定會變成地方的習俗、傳聞或遺跡，進入後續事件的前置條件。

### 3.5 與圖鑑、主線的連結

- 約 15% 的事件是山海探索，能更新圖鑑條目；圖鑑不必收齊【已定 N9】。
- 事件**不承載主線的必要證據**；主線知識都有主要來源（第四批上第一節）。
- 部分事件可以提前讓玩家起疑（例如異象），但不能代替主線揭露。

## 四、事件示範

### EV-U001-001　走失的巡檢犬（日常求助）
- **地點**：歸墟任一街區。**時代**：一～五。
- **開場**：一個孩子抓著主角的袖子：「我的狗不見了。牠是機器的，可是牠會怕打雷。」
- **選擇**：幫忙找（沿街打聽、看看雷聲往哪個方向）／觀命找狗（**非人類能否被觀命待定**；若可行，只見模糊的方向）／不幫。
- **時代變體**：時代四，孩子說「巡捕說狗的登錄晶片過期了，找到了也要沒收」。
- **缺席結果**：狗三天後自己回家，或被回收商撿走（各半，由作者或系統決定）。
- **寫入**：人物狀態（孩子）、街區傳聞。

### EV-U001-017　兩個人的命（觀命委託）
- **地點**：歸墟任一聚落。**時代**：一～四。
- **開場**：一對年輕人請主角看看他們結婚之後的命。
- **選擇**：
  - 接：需兩人都同意被看。主角看到的分支依條件而定（例如「若其中一人接受外星的工作」）。
  - 只看其中一人：另一人未同意，主角可選擇遵守或越界（越界的後果依對方發現與否）。
  - 拒絕：「你們自己決定吧。」
  - 說與不說：看完之後，主角可以只說條件、不說機率，或全說，或不說（延續 X01「知道本身就會改命」）。
- **缺席結果**：兩人照自己的判斷結婚或分開。
- **寫入**：兩人的人物狀態；若日後再遇，依結果有後續。

### EV-U001-033　第六版的更正（消息與傳聞）
- **地點**：深坑茶攤。**時代**：一～三。
- **開場**：茶攤在傳某人死於暗殺，報刊第六版卻有一格更正。
- **選擇**：追查來源（死亡證明、家屬、報社）／不理。
- **結果**：主角可以證實或無法證實；流言仍會流傳一段時間。
- **寫入**：街區傳聞的走向。

### EV-U003-008　每年同一天的鳥（山海探索）
- **地點**：青穗星的山區。**時代**：一～五。
- **開場**：當地人說，有一種鳥每年同一天飛過這座山，一隻都不差。
- **選擇**：等到那一天觀測／向老人打聽／翻閱遊戲內岑行行紀的抄本。
- **結果**：更新圖鑑；若主角等到那一天，親見。時代五時，鳥群的日子第一次延遲了一天（異象的前兆）。
- **寫入**：圖鑑。

### EV-U001-051　盤查（燈籍與人類）
- **地點**：燈籍人家所在的聚落。**時代**：四、五。
- **開場**：一群人拿著地址單在問「沒有登錄的人住在哪裡」。
- **選擇**：通知燈籍人家先離開／假裝不知道／向盤查者問他們替誰工作（可能引起注意）。
- **缺席結果**：盤查照常；該戶燈籍人家依當時狀況離開或被找到。
- **寫入**：燈籍的燈數、主角下一輪可能的出生地點。

### EV-ANY-090　天空暗一瞬（異象）
- **地點**：任一。**時代**：四、五。
- **開場**：所有人同時抬頭；天空暗了一瞬，又亮起來。
- **結果**：人類看得見命線同時抖動；其他人只看見天暗。報刊隔天寫「無法解釋的天象」。
- **寫入**：若主角到過夢底，他知道這是燭陰的眼皮；否則只是一條異常紀錄。
