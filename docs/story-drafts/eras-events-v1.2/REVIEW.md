# 時代與事件池 v1.2 覆核

無自動終局與夢動可反覆出現的方向已修正。原稿仍有前次 ER03～ER15 的殘留；v1.2 是新收稿，尚不能取代既有 WORKING_REVISION 的全部規格。以下補法維持提案；沒有新增 300 則事件或引擎實作。

| ID | 殘留問題 | 修訂要求 |
| --- | --- | --- |
| E12-01 | 原則按世界時間，但 2.0 說每個玩家必經前四時代；表格仍稱「最終」、事件仍用一～五 | 世界經過不等於玩家親歷。分世界年代、地方事件與夢動狀態；夢動不是第五輪或必然最後時代。退出夢動只停止／減弱當前異象，已發生的死亡、拆除與政治結果不復原。二十到三十年仍為提案。 |
| E12-02 | 崩塌後必重建、拾六仍在、葉遲長大、工坊必空、燈數必最少等覆蓋實際事件 | 全部標無介入示例，實際狀態優先。閘門避免崩塌時改地方版本；轉生和年齡按實際時間；道主不真正死不代表不離場。燈數不歸零不代表必單調下降。「無燈之年」若保留需限定地方／比喻，不能全人類熄燈。 |
| E12-03 | 巡檢犬仍寫非人類觀命待定／只模糊方向，與稿末已回答矛盾；鳥在青穗卻標 U003 | 非人類找對命錨可同樣清楚；失蹤對象的接觸或媒介條件另列待設計，不把算命當定位雷達。青穗用 U-001-P3；新事件 ID 需查重後分配，不直接覆蓋其他 EV-U001-008。 |
| E12-04 | 60＋9×25＝285；類型比例合計 100%，但模板量與示例完整度未閉合 | 可沿前次工作稿提案增 15 跨宇宙通用模板，合計 300。變體不另算模板；100 小時仍待測。先試作 30 則；每則含拒絕、前置、結果、缺席、知識来源。組織範圍需納入已收的其他中立組織，不能只假定五類。 |
| E12-05 | 模板未區分實例、每時代一次作用域；缺席各半可能反覆抽，夢動切換可刷事件 | 補 template_id、instance_id、地點／人物／年代作用域、世界觸發日、已結算結果、持久化抽樣。夢動切換不重置實例；缺席結算一次，不覆蓋玩家此前成果。可重複的是模板的新實例，不復活同一人重做同一歷史。 |
| E12-06 | 盤查直接改燈數、到過夢底即知道燭陰、世界結果直接成玩家知識 | 盤查／遷移／死亡分開，只有實際生死改在世燈數；出生候選另按家庭資格與直系規則。親歷、消息、紀錄與作者真相分開；曾到夢底不足以確認異象原因。報刊消息須有來源和傳播日期。 |
| E12-07 | 隨機事件不得承載主線證據可能排掉圖鑑批註另一條路；跨篇 EV 短 ID 不明 | 主線不能依賴不可保證抽到的唯一隨機事件，但允許合格替代證據。區分起疑／證據／知識解鎖，另設保底來源。保留完整事件 ID 與引用對照；不要宣稱 EV-026／028 已核對原事件全文。 |

前次 REVIEW 一併附入交接包，已修正 ER01／ER02 的核心方向不用重開。N20／N27 僅沿本稿來源標號，不宣稱已完成全案编号遷移。

驗收情境：一生跨越三個年代；轉生跳過一個年代；救下閘門；夢動進出两次不復活／重抽；無介入數十年；盤查後家庭只是搬遷；未到現場只聽新聞；不抽到探索事件仍可推主線。
