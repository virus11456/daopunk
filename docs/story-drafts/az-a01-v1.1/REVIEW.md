# A01 v1.1｜收斂審閱

不重寫已成立的核心。前次 R01、R02、R08、R10、R11 的主要問題已改善；R04～R07、R09、R12～R14 仍有以下具體缺口。所有新解法是提案，不代替作者選擇。

| ID | 缺口 | 修訂方向 |
| --- | --- | --- |
| A11-01 | A-2 把紀錄錯配直接當作靈魂不能輪迴 | Y01 把資料錯配與真正滯留分開。可選：本案只是紀錄交接未完成，未證明靈魂受困；或本案真的被某種拘束困住，偽造回音只是掩蓋／延誤救援的手段。後者拘束機制仍為提案。不能把登記權擴大成控制所有生命輪迴的權力。改名、改紀錄、解除束縛、本人願否離開、輪迴端回執分欄。 |
| A11-02 | A-1～A-3 政策可被缺席總表重置 | 總表「缺席：收容案通過」限於從未介入的預設；已暫緩或修正必須沿用。補世界中的表決／生效／遷出日期，晚到不一律已過多年。亞茲公開更正須有查證與責任理由，不全由對主角信任決定；公開質疑可觸發覆核，不等於主角說了就證實使者惡意。 |
| A11-03 | 五項照護缺任務範圍，安全像永久保證 | 指定本案照顧對象、當期評估與後續交接；不要求把未来所有新来者都安置完。安全是已評估、風險告知及可行防護，不保證永不遇害；同理家人聯絡需尊重意願與安全。保留緊急暫時安置及後續追蹤，不因多年後新事件倒扣已得資格。舊案責任應記主角實際行為，拒絕介入不自動等於政策加害者。 |
| A11-04 | A-4 沒有脅迫就能領法則；熄燈仍等於轉生 | 親授須實際完成雙方約定的陪伴／可持續安排，並尊重選擇；僅沒脅迫、沒參與或回答一句不等於完成。拒絕傳話不自動失敗。航路替代光源不必能供靈魂承載，分別核對；油盡與回執未到時狀態未知。傳話與去留已分開，保留。 |
| A11-05 | A-5／A-6 觀測與跨世辨認可能形成死結 | A-5 比較須主角實際同意且施術才寫入觀測紀錄，不由進場／說話自動寫入。記錄觀測世代與來源，不能單一「本世」覆蓋歷史。曾完成任務但未做照魂、其他道主不知情時，仍應能用案件／見證補證；不強迫重做任務或透露全部記憶。自稱、觀測確認、當世身分辨認分開。 |
| A11-06 | 擊倒／領取／離席混寫 | 第八節情境十說擊倒便取得，正文仍允許拒領：改為擊倒建立資格，接受才取得。暫離議席與被逐出夢外是不同狀態，不能只寫機構轉達就解決所有離場。「你拿走了」改清楚指離席的照護缺口，非抽走權能。交接是否完成與使者擴權各有條件，不因一次決鬥自動發生。戰鬥細節保留待定。 |
| A11-07 | 引用、能力界線與可讀性 | 中立組織 v1.3 未收到，標引用待核，不用它替新能力背書。「主角看不見靈魂」限本場目前觀測方式，不鎖所有未來能力。A-5 的 K5 台詞沿用 v1 可以追溯，但完整修訂稿應帶入原段。終章保留知識／關係／邀請與可聯絡條件，不縮成一句而遺失分支；無法告知不鎖結局。補信任、冷淡及親授資格的明確寫入來源。 |
