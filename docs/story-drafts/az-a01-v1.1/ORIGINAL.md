## 二、收容調整案（統一的政策狀態）

**背景**：避難城區（U-009-P2-C2）的收容容量與來者需求失衡（ATLAS 地方矛盾）。空座京提出一份**收容調整案**（提案內容）：

> 一、新到者優先收容無法自立者。
> 二、已收容且經評估能自立者，限期遷出，騰出名額。

A-1 與 A-3 讀取同一個旗標：

| `收容調整案` 狀態 | 意思 |
|---|---|
| 草案 | 尚未表決 |
| 通過 | 依原案實施：能自立者限期遷出 |
| 暫緩 | 表決延後 |
| 修正 | 第二條改為「自願遷出，並提供安置」 |

**使者的錯誤**：使者在議席上說「道主支持此案」。亞茲並沒有說過。

## 三、場景

### A-1｜空座
- **地點**：空座京（U-009-P1-C3）。中心空缺的懸浮議席（ATLAS 地標）；地方矛盾：使者以自身解釋壟斷真相（ATLAS）。
- **處境**：議席表決收容調整案。使者說：「道主的意思是，收容應優先給無法自立的人；能自立的，請他們讓出位置。」
- **來源**：使者的話是**轉述**；亞茲本人不在議席中心，坐在邊緣。
- **調查**（非戰鬥）
  - 議席外等亞茲，直接問（她允許陌生人等她）。
  - 查使者過去的公告，比對亞茲少數親口說過的話（紀錄）。
  - 觀命使者（須找對命錨；未經同意為越界，後果依是否被察覺）：只看得出使者的走向，看不出亞茲的本意。
- **亞茲的回答**
  > 亞茲：「我沒有那樣說。」
  > 主角：「那你為什麼不糾正他？」
  > 亞茲：「他說的時候，我在想另一件事。」（停頓）「……我總是在想另一件事。」
- **選項**
  - 當眾指出使者的話與亞茲本意不符：表決暫緩（`收容調整案：暫緩`）。
  - 私下告訴亞茲：她說「我會想」。若她對主角的狀態為「信任」，她在下一次議席親自發言，案子改為修正版（`修正`）；否則維持原議程。
  - 不管：案子通過（`通過`）。
- **拒絕／缺席**：案子通過。
- **晚到**：案子已通過多年；已有一批住民被遷出，他們的去處是世界事件（A-3 讀取）。
- **同世補救**：案子通過後，主角仍可在下一次議席前取得亞茲的親口說法，提出修正。

### A-2｜名字（滯留案件）
- **地點**：回聲星（U-009-P2）回聲城區（U-009-P2-C1）。殘門石陣與回聲收束器（ATLAS 地標）；地方矛盾：探險隊偽造回音出售線索（ATLAS）。
- **相關事件**：EV-025「偽造的回音」（示範事件 30 則 v1.1）。
- **處境**：亞茲的機構確認一件**滯留**案件（Y01：滯留由亞茲的機構確認）。
- **滯留的原因**（提案，本案個案）：一次偽造回音事件中，探險隊把這個靈魂的回音剪接進一段虛構的紀錄，讓它在紀錄上被登成**另一個人**。機構的比對因此對不上，交接無法完成。
- **主角能知道的**：機構的轉述；回聲收束器傳出的斷續回音。主角看不見靈魂。

**收束器的查驗**（因為此地有偽造回音）
| 方式 | 說明 |
|---|---|
| 原始石陣紀錄 | 比對殘門石陣留存的原始回音，看收束器的輸出是否被插入片段 |
| 時間戳 | 偽造回音的時間戳常與石陣的記錄週期不符 |
| 獨立證人 | 當時在場的居民、或曾聽過原始回音的人 |

只有通過查驗的回音，才能作為這一案的證據。

**解法**（提案；不是所有滯留都要恢復舊名）
| 解法 | 說明 |
|---|---|
| 改正紀錄 | 找出偽造的部分，請機構撤銷錯誤登記；靈魂以原本的紀錄完成交接 |
| 恢復舊名 | 若它自己想要回原本的名字 |
| 自選新名 | 若它不想再當那個人，可在機構登記一個新名字交接 |
| 無名交接 | 【提案】機構以「無名」完成交接的程序；細節【待設計】 |

- **同意**：每一種解法都由機構向那個靈魂確認。它可以拒絕舊名；**拒絕舊名不等於只能被困**，它可以選其他解法。
- **結果**：交接完成（主角只知道「機構說完成了」；轉生到哪裡，主角不知道）；或它選擇暫時留下，由機構照看。
- **拒絕**：主角不接；滯留持續，由機構照看。
- **缺席**：同上；機構可能在數年後自行查出偽造（世界事件）。
- **晚到**：探險隊已解散；原始石陣紀錄可能已損壞，查驗更難。
- **同世補救**：查驗失敗時，可再找獨立證人或其他時段的原始紀錄。
- **寫入**：`滯留案_解法：改正紀錄｜舊名｜新名｜無名｜暫留`；`回音查驗：通過｜未通過`。

### A-3｜收容安排（《守一不散》任務途徑）
- **地點**：避難城區（U-009-P2-C2）：厚壁浮島上的環形安全院。
- **讀取**：`收容調整案`（第二節）。

| 政策狀態 | 本場的處境 |
|---|---|
| 草案、暫緩 | 還沒有人被遷出；主角可以提出替代安排 |
| 通過 | 一批能自立者正在限期遷出；主角要處理他們的去處 |
| 修正 | 只有自願者遷出；主角要處理擁擠與照護 |
| 晚到且已通過多年 | 已被遷出的人散在各處；主角可追查並補救 |

- **亞茲的請求**
  > 亞茲：「這裡的人太多了。我不想拋下任何一個。可是我不知道怎麼做。」
- **任務判準**：不是「有沒有趕人」，而是**真正的照護安排**。依以下五個面向判定：

| 面向 | 需要的安排（提案） |
|---|---|
| 住處 | 每個人有地方住（院內、擴建處、或經同意安置的外地） |
| 食物與燃料 | 有穩定來源（與沉錨星、微焰星的配額交換，ATLAS 政治提案） |
| 醫療 | 有人能看病（義體醫師公社、院內照護） |
| 安全 | 遷出者不落入更危險的處境（例如被掮客找到） |
| 連續性 | 遷出者仍能與院內的家人朋友聯絡 |

- **非戰鬥解法**（皆為提案，可組合）
  - 與繫橋聚落（U-009-P1-C2）協商借用島間空間；需處理島民通行優先權的矛盾。
  - 爭取配額交換，換燃料與建材擴建。
  - 經斷鏈避難網安置自願離開的人。
  - 以觀命看住民在不同安排下的走向（須找對命錨；取得本人同意）。
- **結果**
  - 五個面向皆有安排：任務完成。
  - 部分面向缺漏：任務未完成；亞茲說「還不夠」。同一世可以補。
- **舊案責任**：若主角在未完成的情況下離開，被遷出者的遭遇仍記在 `收容安排_未完成` 旗標中，之後的事件會讀取。
- **拒絕／缺席**：政策依狀態實施；照護缺口由世界事件呈現。
- **寫入**：`收容安排：完成｜未完成`、各面向旗標。

### A-4｜孤燈（《守一不散》親授途徑）
- **地點**：繫燈星守燈聚落（U-009-P1-C1）：漂浮石柱上的孤燈列陣。地方矛盾：守燈物資不足須取捨航路（ATLAS）。
- **處境**：一個失去形體的靈魂附在一盞孤燈上。守燈人說燈油不夠，這盞燈可能要熄（燈也照著一段航路）。
- **亞茲的請求**
  > 亞茲：「陪它走完最後一段。」
  > 主角：「走去哪裡？」
  > 亞茲：「它自己決定。」

**燈油與替代方案**（提案）
| 來源 | 說明 |
|---|---|
| 微焰星的燃料 | 焰種城（U-009-P4-C1）的火種配額被收藏家囤積（ATLAS 地方矛盾）；主角可以交涉 |
| 航路合併 | 讓這盞燈與鄰近一盞共用航路，省下燈油 |
| 替代光源 | 以其他光源照航路，這盞燈只為那個靈魂留著（需守燈人同意） |

**判準**（v1.1）
- **不脅迫**：不以威脅、交換或欺騙逼它做決定。
- **不替它定案**：最後的決定是它的。
- **允許**：尊重它的要求而給建議、陪它討論、說出自己的看法。
  > 主角：「如果是我，我會想留到燈油真的沒了那天。可是你不是我。」

**它可能的決定**（依陪伴與資源）：讓燈熄、進入輪迴；繼續附在燈上；請主角替它傳一句話。
- **傳話與去留並存**：它可以留下，也請主角傳話；也可以走，並請主角傳話。傳話對象依世界狀態；主角可以答應或拒絕。
- **亞茲的盲點**
  - 若主角給了建議，亞茲可能說：「你不該勸它。」
  - 主角可以質疑：
    > 主角：「它問我怎麼想，我才說的。不說，才是把它一個人丟在那裡。」
    > 亞茲：（很久）「……我總是怕說錯話。所以我什麼都不說。」
  - 這是亞茲把「放下」「不介入」誤當成救贖的盲點（CHARACTERS 提案）；是否被說服，依她對主角的狀態。
- **失敗**：主角脅迫它，或替它定案。親授資格不成立。
- **舊案責任**：失敗後主角可在同一世找另一件事陪伴，但這一盞燈的結果與主角的作為仍記在 `孤燈_主角脅迫｜替它定案` 旗標中，不因找了新對象而消失。
- **拒絕／缺席**：燈是否熄滅，由守燈人與它自己決定（世界事件）。
- **晚到**：燈可能已熄；主角可從守燈人口中得知它最後的選擇（轉述）。
- **寫入**：`孤燈_結果`、`亞茲親授_資格`。

### A-5｜放下
- **開啟條件**：亞茲對主角的狀態至少為「信任」。
- **地點**：空座京，中央空座旁。
- **對白**
  > 亞茲：「你背著很多。」
  > 主角：「我記得很多。」
  > 亞茲：「我可以陪你。我不能替你放下。」
  > 主角：「你能讓我忘記嗎？」
  > 亞茲：「不能。那是你親歷的，沒有人能拿走。」【已定：主角完整記得親歷】
  > 亞茲：「就算能，那也不該是我來決定。」

- **已知 K5 時**：沿用 v1（亞茲守護靈魂的信念；「不確定。所以我更不敢。」）。這是她的信念，不是作者事實【已定 N18：喚醒結果遊戲不回答】。

- **照魂辨我（有限觀測）【提案】**
  - 亞茲只能把主角**現在的靈魂**，與她**曾經親自觀測過**的紀錄比較。
  - **首次見面**：她沒有任何比較依據。
    > 主角：「你能看出，我是不是每一世都是同一個？」
    > 亞茲：「我只看得到你現在。你是完整的一個。你的前一世，我沒看過，所以我比不了。」
  - **若她在主角的某一前世曾親自觀測過**（主角前世曾請她看）：
    > 亞茲：「和我上次看見的，是同一個。」
    > 亞茲：「其他幾世，我沒看過。」
  - 不論哪種情況：
    > 主角：「那為什麼我會記得？」
    > 亞茲：「這個我看不出來。」
  - 她的判斷**不具任何組織的法律效力**；她的機構也不是普遍認證前世身分的機構（加入中立組織 v1.3 第九節）。
  - 此請求會讓亞茲知道主角自稱會帶記憶轉生（知情來源）。
- **寫入**：`亞茲_觀測過主角：本世`（供下一世比較）、`亞茲_知道主角輪迴`。

### A-6｜守一不散
- **取得資格**（可並存；**取得一次**【已定】）

| 資格 | 條件 |
|---|---|
| 任務 | A-3 收容安排完成 |
| 親授 | A-4 不脅迫、不替它定案 |
| 擊倒 | 在空座京挑戰她（戰鬥玩法未定） |

- **取得一次，不是只能用一次**：取得後，主角跨世持有，依能力邊界使用。
- **傳授不抽走亞茲的權能**：亞茲傳授的是有限的傳奇仙術；她自己的靈魂法則不因此減少。
- **擊倒的後果**【提案】
  - 若主角擊倒亞茲，她不會死【已定 N16：道主不會真正死】，但可能**暫時離開議席**，原因是她選擇不再抵抗、讓出位置一段時間（她的決定）。
  - **照護安排**：她離開前，把滯留案件與孤燈的照看交給機構的資深照護者（提案人物，待設計）；使者可能趁機擴大解釋權（ATLAS 地方矛盾加劇，世界事件）。
  - 她說：「你拿走了，它們就少一個守的人。」
- **拒領**：資格保存。之後回訪可領取，但：
  - **跨世回訪需要辨認**：亞茲不會自動認得主角的新身體；需有知情來源（主角自報並經她觀測比較，見 A-5；或其他道主提起）。
  - **需要可聯絡**：亞茲若暫時離席，需經機構轉達。
- **能力邊界**（依 DAO_RULER_POWERS，提案）：維持自身連續性，抵抗指定類型的奪舍或靈魂干擾；不免於死亡或輪迴；不改變任何人的記憶。
- **寫入**：`法則_靈魂`。
