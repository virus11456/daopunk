# 開場 v1.1 檢查

改善：知識旗標、拒絕觀命、午餐選擇、研究未校準、世界消息與觀眾尾聲有區分。仍未全數驗收：

1. 高：C3把老鉗當人的命錨，默認他為人類，與新增居民不得默認人類矛盾；不要擅自把他加入最後人類師門。建議用主角自觀未來作對照，是否可自觀須另論證，或以紅自願接受的一段有限觀命取代，需重寫，不在此擅定。
2. 高：D3夜截止、D4動工，C3卻說三天內動工與第四天以後品質下降；改成絕對日期並統一維修條件。
3. 高：觀命三列混合「路徑機率」與「資料保全比例」；條件可能重疊，不能以加總100%代替互斥性。先分共同條件下的結果事件，未校準不得用假精度。
4. 高：C7缺少「試過前三錨但沒有細線」及「只在C5看到細線」的分支；C5須實際同步写入見過細線，不依賴表格兜底。
5. 高：C5可選但C8尾聲固定拿拓本；無借閱、拓印、返還不得憑空產生。C5提前借閱與共同年表原S01後一週不同，需選同一時點。
6. 高：C6只有陵墓停留也會寫入申請／封存／選擇不知的混合旗標；查詢線索不等於有權查看。依實際選項写入。
7. 高：保管信失約不必等死亡，死亡也不保證紅拿到遺物；返還時間、失落、接收者拒收與保管授權需補。新生代無法憑記憶攜帶原件。
8. 中：C8固定完成及空白紙持有與缺席/拒絕路不符；必要場景不能阻塞時間，明列完成、退出、世界已進展三種狀態。
9. 中：C2離開後三日維修與D4時鐘不一致；C3缺席誰通知與備料仍需交代。
10. 中：F01 v1.2引用未在本次收稿附上，不能宣稱已驗證其修改。命錨、功德防濫用、觀察者權限等仍待設計，非本次自動定案。
