# EV-031～060 v1｜覆核

已收 30 個不同短 ID 的事件草稿；尚未達完整模板驗收。不是新增30個已可玩事件，也不能僅憑稿末自評判定全數有拒絕／缺席。

| ID | 問題 | 修訂方向 |
|---|---|---|
| EB01 | 分布本批數字合計32，兩批合計64，與標稱30／60不符 | 重新以每則一個主類型統計；委託屬子類／標籤，時代專屬亦非重算事件。第一批全文未在本輪核對，合計暫不驗收。自動盤點見 validation.json。 |
| EB02 | 明示選擇／缺席欄缺漏，觀命節點缺完整條件與結果 | 補每個實際選項結果、拒絕／離開，以及世界型／玩家到場型觸發。到場型可標不生成實例，世界型要結算缺席；沒有欄位不等於無需。EV-031 舉報結果補對應選項；EV-036 先貨／拒絕不能留空；EV-035 存活才有事後台詞。 |
| EB03 | 受雇條件、人物在世、機構存續、地點映射未齊 | 韋舷與老頭目可能已死或卸任，繼任者有新個體ID；「任一渡站／巡診站」須映射既有地點設施，不任意擴建ATLAS。30短號先在批次命名空間保存，正式全池ID查重後指定。 |
| EB04 | 舊燈、紙與鑰匙場景可能憑空重生物件 | EV-042 需有燈、實際承接者與所在地；043 需拾六／跑腿站及舊紙實存、保管權；045 需糧倉存在且真實交接，新主不得固定背棄星塵。死亡只改事件可用性，不生成遺物。 |
| EB05 | 故事歷史條件不足 | 041 只有舊登記令實際撤回才叫「回來」；延期或從未撤回另寫。058 須主角真的擺攤，不能僅曾到過；059 須主角確實主動說前世。055 祖先從山下來不能證明燈籍，需玩家既有來源。 |
| EB06 | 導航／觀測與主線知識 | 049 空白不給宇宙座標處理正確。051 親見的是鳥與行為，對應精衛為待比對，不確證傳說。052「第一次延遲」須歷史基準，不能每次計畫推進重置第一次；EV-030 引用待核。054 作者可有真因，但玩家需調查，不因世界狀態直接知道。046 報刊消息與主角親見命線分開。 |
| EB07 | 機構印章、隱私與主角記憶 | 048 缺回執不等於缺宇宙交接；封存／匿名權限依Y01。038 不記錄節點應解為不外存可洩漏位置，不能要求主角忘掉亲歷。044 錯字只是比對線索，需傳遞鏈證據；040 本件非刺殺不擴成殺手組織不得加入。 |
| EB08 | 固定結果看似只要玩家到場就無敵；可重複性缺失 | 032 按在場、威懾與對方知情條件定當晚結果，不是任意主角必能嚇退。每則補實例ID、冷卻／一次性作用域、觸發日期、已結算結果；缺席只抽樣一次，不因讀檔／夢動切換重抽。 |
