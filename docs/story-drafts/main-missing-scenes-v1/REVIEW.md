# 第四批（上）整合檢查

保留原稿，以下是對知識門檻、可達性及世界時鐘的檢查，不代替作者選定尚未定案的結局真相。

| ID | 問題 | 修訂要求 |
|---|---|---|
| MS01 | Q11 又列是否有終局時限，與已選答案矛盾 | 移除待選：世界惡化，但不以時間／晚幾輪自動結束存檔；最終抉擇玩家触發 |
| MS02 | K4 的替代來源為階段六師父承認，但六本身需 K4 | 不可列獨立解鎖替代；保留蓋亞的可靠路徑，或在進入六之前設可取得 K4 的事件 |
| MS03 | K6 替代在階段十由閻羅承認，但十需 K6＋K7 | 對質入口另設「足以要求對話的線索」門檻，承認後才得 K6；否則未持真實路線循環鎖死 |
| MS04 | 十二需十一完成，而十一原稿是取得命運；本稿允許拒絕 | 明確定義十一完成可含拒絕，將已完成會面、持有命運分開；拒絕後可否再接受需記錄 |
| MS05 | K5 前半後選離開，仍可能被當完整 K5 | 拆剪命、沉睡、動機三個事實；中途離開能續談，不自動發整包知識 |
| MS06 | K2 替代只有自己的半份，殘局又轉述閻羅原話 | 分別記兩份紀錄知識、聽過棋局原話；沒有聽過者不能使用那句轉述作開場 |
| MS07 | 分享一段指定記憶可能包含師父身份，後表卻說只有主動說才知情 | 依實際記憶內容更新蓋亞知識，先告知分享範圍；拒絕不得讀心，限定片段不得授權讀全部 |
| MS08 | 「你不經過我」同時依賴蓋亞能知道每次繞過的能力 | 列她可觀測的記錄缺口與推論，不因未收到靈魂就全知所有經過與主角經歷 |
| MS09 | 師父被動觀測過去現在未來近乎全知，卻無法提前警告或撤離眾人 | 提案須界定條件、盲點、成本；區分一般通知／行走與法則改命，避免任意為悲劇禁用普通救援 |
| MS10 | 三百多年「動過兩次」把未發生終章算成既往，可能遺漏碎歸墟 | 分已發生／候選未來，交代破碎當夜是否計算，勿先固定玩家一定接受命運 |
| MS11 | 師父日漸虛弱又是 K3、K5 唯一來源；玩家可無限晚期 | 需保障可回訪或可靠的存留證言；若可死亡必有承接，不因晚來造成主線永久鎖死 |
| MS12 | 追兵先找哪裡依玩家所在地，可能變成世界繞玩家運轉 | 用洩漏來源、目標名單與可達航路決定攻擊地點；玩家當時位置只影響介入方式 |
| MS13 | 遮天藏自己必生還、孩子必被轉向；生命延長仍不等於抗傷 | 改為條件結果，別把能力自動當無敵或強制犧牲；危險與可選代價在行動前合理提示 |
| MS14 | 追殺死亡又寫至少十五年、燈籍是否保住決定下輪家庭 | 採等待出生＋十四至十五年；地方名冊毀損不等於全人類／出生可能性歸零，需區分實體名冊與人口 |
| MS15 | 沒命運或輪迴時，四結局仍可能全部無選项，且只是隱藏不可達選項 | 進終章前驗證至少一條可行、允許退出補足條件；可提示尚缺準備而不劇透，不能進空選單 |
| MS16 | 煉假成真仍要求「三世中」多人選擇，恢復固定世數 | 改跨任意輪取得的具體見證條件，記錄本人選擇而非玩家代選；數量保持待定 |
| MS17 | Q7 甲稱夢結束不是毀滅、丙記住整夢，容易預定 Q10 和全知主角 | 將各候選的成本與依賴並列，不把記憶完整偷換成知道全宇宙；未定前不寫成真相 |
| MS18 | 未傳法師父可到燭陰當替代，但師父是否在世、移動代價未定 | 替代條件須連到師父現況和抵達事件；Q8 未定時只列候選，不保證可行 |
| MS19 | 原諒／揭發／擊敗直接支配閻羅終局，缺 NPC 自主與證據傳播 | 原諒不等於他合作；揭發要有接收者與證據；擊敗不等於死亡或永遠失能，依 Q8 拆狀態 |
| MS20 | 守護完全／部分接回與師父暴露、煉真後算命失傳、法則作用變化未定 | 逐結局列已知代價、未知後果與法則依賴；夢外力量與夢脫鉤後的關係要對齊 Q8–Q10，不先固化 |

## 可先寫與應等待

可先寫殘局返院、兩種到訪順序、蓋亞拒絕分享亦告知 K4、追殺的警訊與各地報導、師父坦承剪命及玩家中止談話；但須採上表分開的知識旗標。

罪-4 的最終理由、造物主醒後眾生命運、道主死亡規則、夢中生命承接者資格仍需決定。可保留候選綱要，不能把並列台詞當已完成可實作結局。
