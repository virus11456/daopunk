## 〇、本批新增的一條規則提案：師父「看」與「動」的分別

背景 v1.3 說師父「每動用一次法則，碎片就會向他聚攏」。追殺事件需要回答：師父能不能預見危險而先走？

【提案】
- **看**（觀測過去、現在、未來）不聚攏碎片。這是他作為命運之主的被動感知。
- **動**（改命、剪命、傳授法則）會聚攏碎片。
- 三百多年來他「動」過兩次：剪主角的命（一瞬），以及終章傳授命運（完全聚攏）。

這讓師父看得見危險，卻不能出手改變它。所以他需要主角。

## 四、追殺（世界事件，原「第二次死亡」）

【已定 N14】改為可能發生的重大事件，不強制死亡。
**時點**：待定（建議時代四）。
**原因**：有人開始蒐集人類；在夢的底層，只有看得見命線的人分得出方向。追兵是誰的人，本事件**不揭露**。
**洩漏來源**（作者層，背景 v1.3）：資料掮客購得邊防與登錄紀錄。與主角是否告訴閻羅 X **無關**。

### 狀態矩陣

| 狀態 | 選項 |
|---|---|
| 主角在隱修院 | 見下表 |
| 主角在燈籍人家（非隱修院） | 追兵先找到的是燈籍人家；主角可保護這一戶，或趕回隱修院 |
| 主角不在兩處 | 事件照常發生；主角日後得知損失（燈數、燈籍去向） |

**主角在隱修院時**

| 條件 | 可選的行動 | 可能結果 |
|---|---|---|
| 持有遮天 | 藏住自己／不藏，當誘餌 | 藏住自己：主角活下來，但追兵轉向燈籍與孩子。不藏：孩子帶燈籍從後山走；主角可能死 |
| 未持有遮天 | 逃／躲／戰／留下當誘餌 | 依行動；主角可能死 |
| 燈籍在主角手上 | 交給孩子帶走／自己帶走／藏起來 | 決定燈籍去向 |
| 燈籍不在主角手上 | 支援隱修院的人轉移／不支援 | — |

**師父在哪裡**（C05）：師父以「看」預見追兵，事前離開隱修院（提案）。他不能「動」，所以不能阻止。主角若事後問他：「你看到了，為什麼不擋？」師父：「我一擋，他們就會找到我。然後他們會找到你。」

**死亡時**：主角轉生，世界往前至少十五年；燈籍是否保住，決定下一輪的燈數與起始家庭。
**存活時**：主角繼續這一輪；追兵之後仍可能再來。

## 六、四結局（階段十二）

### 6.1 路徑對應：未獲遮天、拒絕傳法、未交地址

| 路徑 | 影響 |
|---|---|
| **未獲遮天** | 追殺事件只能逃、躲、戰、當誘餌；四結局都**不要求**遮天 |
| **拒絕傳法**（階段十一拒絕接受命運） | 師父不會被找到；主角沒有命運。需要命運的結局改走替代條件（見 6.2） |
| **未交地址** | 殘局不觸發坦白分支；追殺事件照常（洩漏與地址無關） |
| **未取得真實** | 無法以碎片推知兇手；由閻羅 X 在對質時說出（若他願意） |
| **拒絕給蓋亞記憶** | 輪迴需另尋取得途徑（待道主篇設計）；若始終沒有輪迴，喚醒與煉假成真需替代條件 |

### 6.2 結局條件（主要條件與替代條件）

| 結局 | 主要條件 | 替代條件（缺命運或輪迴時） |
|---|---|---|
| 守護夢境 | 命運、因果；阻止陸吾與閻羅 X | 因果＋真實：以真實找出碎片原位、以因果讓代價有人承擔，比命運慢，歸墟只能部分接回 |
| 喚醒真實 | 輪迴、真實；到燭陰面前 | 真實＋師父在場（若未傳法，師父仍可親自走到燭陰面前，但會因此暴露） |
| 弒神奪位 | 命運；確立承接者 | 無命運時：主角無法親自承接；只能協助或阻止陸吾、閻羅 X 承接（依待選 Q9） |
| 煉假成真 | 命運、真實、輪迴；三世中數位重要人物曾「自己選擇」被主角見證 | 無命運時不可行 |

**不可達時的處理**：若玩家的法則組合使某結局不可達，該結局在抉擇時**不出現**，而不是出現後失敗。

### 6.3 四結局場景綱要
