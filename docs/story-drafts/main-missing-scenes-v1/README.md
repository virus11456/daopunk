# 第四批（上）｜主線缺頁場景綱要收稿

[原稿](ORIGINAL.md) 逐位元組保留。範圍是殘局、蓋亞會面、追殺世界事件、師父的罪、四結局；本稿為場景綱要、選項與證據依賴，**不是完整台詞稿，也不是已實作任務**。

## 已確認規則優先於稿內待選

世界持續惡化，最終抉擇由玩家主動觸發；不因輪數或世界時鐘自動終結存檔。因此稿內 Q11 不是仍待選的問題，不新增強制「未介入」結局。正式輪迴不倒時，第一輪十五歲覺醒後下山；後續十四至十五歲覺醒，等待出生間隔未定，不能一概寫死亡後至少十五年。

師父「看不聚攏、動會聚攏」是新提案，不自動成為正史。Q7、Q8、Q9、Q10 的動機與本體規則在本稿仍未定，不由收稿替使用者選定。
