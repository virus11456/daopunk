# NPC 知識與秘密分層｜離線設計提案

依《燈還掛著》v1.2新增；是生活系統與新聞的資料邊界，不是已完成AI、排程或Godot功能。本文不決定尚未定案的NPC數值。

## 四種資料不能混用

1. 作者真相：事件實際發生什麼，例如陸吾出手、閻羅遮掩。只供編劇／世界事件判定。
2. 公共報導：誰在何時公開聲稱什麼，例如第一道主被認為已死。報導可以錯。
3. 私人知識：NPC親見、聽聞或取得哪份證據；傳聞的多次轉述仍可能源自同一人。
4. 當場可說內容：NPC知道、願意說、能向此對象透露的交集。知道不等於同意公開。

建議消息欄位：claim_id、source_event_id、source_id、audience、published_at、arrived_at、supersedes、epistemic_status。私人知識另存subject_id、learned_at、evidence_ids；未知時間為null。不得將作者秘密直接放進一般NPC對話的提示上下文。

## v1.2具體案例

| 議題 | 作者層 | 常見居民可說 | 特殊知情者／條件 |
|---|---|---|---|
| 歸墟之主死亡 | 新稿命途碎裂、導師仍活著 | 「大家說他死在破碎那夜」 | 目擊／紀錄只提升特定推論；缺印不是存活證明 |
| 歸墟破碎 | 新稿導師遇襲後自保 | 災難、地方損失與傳聞 | 不因玩家到第三世就讓全宇宙自動知道真兇 |
| 主角記憶 | 新稿師父剪命途 | 僅能描述自己見過的異常 | 同門相認需個別記憶解鎖；主角重生不刷新其他人記憶 |
| 隱修院位置 | 作者須有實際位置與洩漏鏈 | 一般居民未知 | 玩家告知某人僅增加其知識，不立即證明對方洩漏 |
| 閻羅的野心 | 新稿兩人密謀 | 普通新聞不能直接播出作者秘密 | 可信揭露事件後才開放相應報導與反應 |
| 葉遲的希望 | 「喚醒或使人類回來」仍為信念 | 按來源說「她相信」 | 不是系統保證或所有同門共識 |

## 與作息、天氣和新聞的接口

- NPC在旅店、港口、新聞亭等時間／地點收到消息；城市未接通消息渠道就不立即同步全宇宙新聞。
- 暴雨、停航可延遲商隊及口述到達，不能回溯修改原事件發生時間。電子渠道是否受影響按當地設定另判。
- 玩家缺席時世界繼續前進；返回只呈現NPC實際收到的消息及當下生活，不觸發全員讀取劇情進度。
- 更正新增消息並引用舊claim，不抹除曾傳錯的歷史；尚未收到更正的人可以仍持舊認知。
- AI若日後接入，只表達給定知識與性格；不能創造任命、死亡、法則獎勵、洩漏來源或天氣結果。權威事件由受控資料更新。

## 待實作驗收

- 普通商人被問誰襲擊導師：無證據時不洩露兩位真兇。
- 閻羅有缺印紀錄：可以懷疑，不能因一個布林值變成確知導師現在位置。
- 商隊延誤：新聞到達延後；同一來源十次轉述不算十份獨立證據。
- 舊謠言已傳、後發更正未到：兩地居民可有不同認知。
- 玩家轉生：世界消息不清空，陌生新NPC也不自動認得玩家。
- 角色拒絕交代住所：後續不得生成已提供地址的洩漏路徑。

以上是檢查案例，尚未執行；下一步再做排程、容納避雨人數及消息時序的離線模型。

## 山海經v1.1新增邊界

開場師門弟子背過書但不代表知道它記錄真實探索；只有師父知道。後來蓋亞告知的場景仍為提案，必須實際觸發才更新主角知識。帝江＝渾沌、禺彊＝鯤鵬不得作一般NPC的已知真相。作息與消息的[離線參考模型](NPC_LIFE_DATA.md)已完成14項檢查；完整AI仍未實作。
