# NPC生活離線參考模型

三名無名測試居民位於既有地點U-001-P1-C1「破爛一條街」；不新增正史人物，不取代1000位NPC圖像登錄。使用Python標準庫，可重現作息、雨天避讓、消息延迟、個別更正及輪迴保存。

## 可執行內容

- 週期作息，休息時回家；露天工作遇雨才找遮蔽，室內工作不受同一規則影響。
- 避雨容量一名，超額測試居民改回家；雨停恢復工作意圖。
- 同一場雨從tick8到11（不含11），商隊原tick9到達延到12；電子消息仍於9到達。
- 更正只影響收到更正者；保留舊報導，不用新消息覆蓋整個世界真相。重複轉述同來源不算獨立證據。
- 輪迴只更換本模型中的player_life；世界時間、NPC所知、相認與待到消息保留。出生來源、成長等待與壽命不在本模型內。
- 存檔再續跑、大步補算與逐步執行結果一致；拒絕倒流時間、重複ID和逆序消息日期。

## 執行

```sh
python3 tools/check_npc_life_contract.py --report docs/contracts/npc-life-validation.json
```

14項行為檢查通過；報告只代表此參考模型。資料見npc-life-sample.json，程式見tools/npc_life_reference.py。

## 明確限制

時間為抽象測試tick，24週期不是正式一天24小時。雨是預設事件，未做季節生成、預報或季長；不是坑底直接下遍整片天空。避雨結果只表示目的地意圖，沒有瞬間移動角色的引擎實作；移動時間、導航、阻擋、服務替代仍待做。

容量競爭暫用固定ID排序以利重現，不是正式公平排隊。所有商隊在此樣本同受雨影響，尚未分段路線或所在地判斷；電子消息免延遲只是樣本條件。固定收件者是路由測試，不代表所有居民隨時可收到。

新聞更正須明列被取代的report ID；別的獨立聲明不自動被判假。未知作者秘密不列進消息資料。AI對話、Godot、跨宇宙大規模補算和完整作息尚未完成。
