# 輪迴資料保存契約 v1｜引擎整合前提案

依最新確認規則整理；資料欄位、交易和計算方式為工程提案，不代表Godot已接入。能力來源見[仙術設定](../worldbuilding/IMMORTAL_ARTS_FRAMEWORK.md)及[傳奇法則](../worldbuilding/LEGENDARY_LAWS.md)。

## 四類狀態各自保存

| 範圍 | 保存內容 | 輪迴時的行為 |
|---|---|---|
| 世界 | 共同時間、城市歷史、組織事件、星主繼承、NPC所處人生與記憶狀態 | 持續前進，不清空。NPC記憶解鎖由自身事件決定，不由玩家新生觸發 |
| 主角跨世 | 親歷記憶、未花功德餘額、已學仙術ID、已取得法則ID、永久能力來源 | 原樣保留；不乘輪迴次數，不重新發放同一法則 |
| 主角當世 | 當世ID、已消耗壽命、當世醫術達標、醫術延壽已使用、暫時增益 | 新世建立新資料；醫術須重新達標，本世延壽清除 |
| 身體 | 肉身／義體標識、當前生命與氣、適配狀態 | 換身可更新，但不得因此刷新當世醫術延壽次數或假裝已輪迴 |

未花功德全數跨世保留已確認。醫術與換身是否共用額度、轉生等待期與標準年定義仍未定；後續輪於十四至十五歲覺醒開局已定。資料保存契約必須保留「未定」，不可用0或清空作默認答案。驗證工具不替這些項目作決定。

## 效果保存來源，不只保存加總

每項永久加成由唯一的仙術ID提供；每項本世增益包含當世ID與來源ID。派生的壽命、生命上限、氣上限於需要時重算，不把舊總值當新基礎再加一次。

驗證用的加法例：基礎99年＋永久術甲10年＋永久術乙20年＋本世醫術20年＝149年；下一世未重修時為129年，重新修成並使用醫術後為149年。這些增量都是測試例值；加法示例不鎖定正式技能數值、上限、百分比或平衡。

生命／氣上限提高不代表當前值自動補滿；開局當前值、升級時補量另待設計。效果可疊加已確認，不自動允許同一仙術無限重買。

## 取得、授予及重試

一般仙術學習未定升級規則前，只能驗證首次取得的唯一記錄；不把拒絕重複首次取得等同永久禁止未來設計升級。

傳奇法則的每次授予，建議引用對應道主、法則ID及世界中的資格事件。資格種類為擊倒、指定任務或親授三者之一。授予同一法則時檢查跨世持有記錄，讀檔或事件重播不可再次疊加；不同法則可以分別取得。完成任務與最終授予應分開，不以每個普通委託自動給法則。

功德購買實作時，扣款、持有權及交易紀錄應一起成功或一起失敗；同一交易重試不可重複扣款。因各術價格、傳奇是否付費未定，本批未實作購買流程。

## 世界與NPC不可被玩家輪迴清空

NPC的前世片段、辨認主角、信任、幫助意願分開。玩家進入新世不更動NPC的當世ID；只有NPC自己的轉生事件才進入其記憶處理流程。主角同門可修行解鎖記憶，但解鎖門檻、範圍與再次輪迴後保留未定。

中立組織事件記錄真實發生時間；消息另記發布、抵達與更正時間。玩家未遇見組織不影響事件存在。消息不能在到達當地之前成為普通居民的已知資訊，也不能把傳聞自動提升為事實。

## 本批離線驗證

`python3 tools/check_reincarnation_contract.py`驗證輪迴保存契約的有限參考模型，輸出JSON檢查報告。涵蓋：跨世永久保存、當世醫術清除與重修、一次使用、換身不刷新、不同仙術疊加但新生不再翻倍、同法則重領無效、多法則持有、時間不倒退、存讀資料後限制仍成立、當前生命與氣不被上限加成偷偷補滿、重播同一次輪迴不重複建立新世。

通過不代表正式遊戲能讀檔、NPC會排程或世界已模擬。工具沒有連接現有autoload/Reincarnation.gd；舊程式的world_flags清除與失憶規則仍待整合階段重寫。沒有執行Godot、效能或完整存檔遷移測試。

## 主線v2追加邊界

第一輪十五歲下山；後續新生至十四至十五歲覺醒以片段帶過，世界持續前進。待生期加成長期不能默認至少十五年；不得用玩家輪迴清空世界財物、人際關係或重抽過去事件。人類不歸零，終局由玩家觸發；壽命起算點與等待期仍未定。現有離線檢查沒有涵蓋長年補算、劇情可達性或Godot新開局。
