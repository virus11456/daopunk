# Grey Valley — Milestone 1

Godot 4.x playable exploration prototype. Open `project.godot` and run the project.

## Controls

- **WASD / Arrow keys:** move
- **Shift:** run
- **E:** interact with the nearest NPC
- **Mouse wheel:** camera zoom
- **F1:** debug overlay
- **Escape / E:** close dialogue

The prototype intentionally contains only Milestone 1: one navigable test region, a player,
one route-walking NPC, unified interaction, dialogue presentation, and debugging telemetry.
