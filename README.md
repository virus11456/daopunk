# Kiro: Dream of the Observer — Milestone 1

Godot 4.x playable exploration prototype for **《Kiro:觀測者之夢》**. Open
`project.godot` and run the project.

The current `Grey Valley` map and NPC are technical placeholders used to validate the
Milestone 1 exploration systems. They are not canonical locations or characters from the
game's setting. Canonical terminology must come from the design sources in
[`docs/design/`](docs/design/README.md) before placeholder content is replaced.

## Controls

- **WASD / Arrow keys:** move
- **Shift:** run
- **E:** interact with the nearest NPC
- **Mouse wheel:** camera zoom
- **F1:** debug overlay
- **Escape / E:** close dialogue

The prototype intentionally contains only Milestone 1: one navigable test region, a player,
one route-walking NPC, unified interaction, dialogue presentation, and debugging telemetry.
